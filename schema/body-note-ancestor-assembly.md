# 正文祖父與直接所附裴注明父的祖先接合

`parent_between_body_and_attached_note_ancestors` 僅新增明確 `interpretation_basis: body_grandfather_attached_note_father`。既有無basis支維持。兩個原始斷言必為同一人物父／祖父，父系且source_attested；中間父子為contextual_provisional編輯接合，source_assertion_id null。不得新增明父斷言。

`witness_binding` 保存正文、注、下一正文paragraph IDs、固定revision、sources相對raw_file及SHA256。helper實讀root內UTF8原檔，核response SHA與git blob SHA，逐fragment真位置與原字，正文→括注→正文邊界必接合；只容原換行/頁標，不接受僅retained text投影。

四個body/note subject/ancestor mention IDs均須已解析；正文祖父名之前為祖父，注中局部須為subject+父+father。role_clause完整綁古注引書authority、work mention與work ID、原attribution span，不能跨來源或對話/否定。正文層不可攜annotator/attached note偽裝；注層與各source_position不得相互矛盾。無循環或另一明父，兩原始完整引用必保。

UI沿原有型別呈現assembly_inferred；本basis不是新raw father，不推母或出生。孫之缺代星號不作人物。
