# Bounded source surname components

`bounded_source_name_binding` is opt-in `{kind: bounded_source_name_components, key, slot}`. Trusted `scripts/bounded_source_surname.json` binds complete received source text/positions/mentions, original raw SHA and source dimensions; person IDs expand only from source MIDs. Required names and source assertions must exactly match reviewed templates. New literal surname:null and full-name seed records are checked at native and bundle boundaries too.

`contextual_surname_from_bound_legacy_biography` follows only the listed existing validated `biography_family_clause` father records from an actual full-name token anywhere in the complete unit; the seed need not be paragraph-initial. It does not weaken existing same-source father-chain or complete-witness branches. No mother, adoptive or editorial assembly route.

`contextual_surname_from_bound_note_ancestor` is a separate finite Wei-book-note grandfather frame: original received Cao Ren full-name seed and same subject's source-attested paternal grandfather at distance2; original note layer/work marker retained, father role distinct. No inferred Chi→Bao father assertion, surname source-explicit flag or literal full-name claim.

All inferred readings are contextual_provisional and human_reviewed:false. Literal records and source text remain independent; names do not generate people, relations, aliases or ancestry. Unknown proof kind, body/note/work swap, raw/SHA/boundary change, role/PID/source mismatch or malformed input fails closed. Both package and direct-script imports are supported. Existing source/name helper branches remain unchanged apart from the opt-in dispatcher.
