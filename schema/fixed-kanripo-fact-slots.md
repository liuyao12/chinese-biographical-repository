# 固定 Kanripo 完整單元人物事實槽位

受信 JSON 配方定義完整收到單元、全部人物角色位置及有限事實，不執行來源資料中的程式。固定 raw SHA／commit、八段完整逐字投影及人物提及順序均驗；不是人物 ID、姓名或家族白名單。角色端點依現行正文人物錨解析，來源技術 ID 不變。所有有旗標槽位須恰一筆，缺項、重複、移人、改名、改年月或原文均拒。

同源明兄、子、女可為姓名的有資格姓氏解讀，並不補未名父母。琇本源只記名；093來源另證父姓。外孫為憲英外孫，祖母方向為孫→祖母；未名女兒不造。從子羊祜及季母為夫家旁親稱用，僅上下世代與未知橋，不當作生母、父親或唯一共祖。

官爵、授辭、追稱分開，未知任終不借死亡填滿。毗未應辟召不造職名；尚書僕射薦而不用不是實任；敞嗣不把嗣當爵名。軍師、使持節原名及實際受任者分綁。原『令』不默改為更長原稱。

魏略張郃死亡後對話受裴松之質疑，保具體資格，不把引語事件當獨立考定；其祖宗死亡婉稱無年，不作首選日期。臨崩只存臨終託孤報告。毗薨年未知；不能借青龍二或亮卒年。憲英泰始五年卒269／79原詞保留，不反推生年。咸熙中僅264–265最寬界。數值年份依實讀教育部年號表，仍為中國曆年，不換公曆日期。

未圖校，數位見證與傳世刊本資格沿既有來源；不修改原字或 source-only 舊封包。範圍止辛毗完整八段，不稱全卷完成。

`source_title_resolution` 只對同句具名官員共前綴的編輯解析：保 `original_title`、`resolved_title`、原前綴／後綴雙錨、`contextual_provisional` 與未人工審閱；收到 `title`／attestation仍是令，不把編輯拼名冒原引。`source_report_qualification` 保存被評論明駁的原報／評論者錨、反對原句及 `preferred_as_independent_historical_event:false`，不據引語自動裁定事件或官稱真偽。
