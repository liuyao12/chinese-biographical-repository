# 跨篇父系姓氏依據

`contextual_surname_from_cross_chapter_paternal_path` 用於原篇只記名或稱號、但另一篇傳世正文明載家族全名，且兩篇之間有逐代父子原文可追的情形。姓氏是編者暫定判讀，不得回寫收到正文或當成人工審定。

每筆記錄必須連到一筆明載姓氏與全名的姓名構件記錄。`source_frames` 保存該全名所在段及路徑各段的固定來源修訂和段落雜湊。`steps` 按世代列出每個已存在的 `father` 斷言、父子人物 ID、原文人物提及錨及精確 `source_term`。每個斷言都必須有來源段落、固定見證、父子兩端人物提及和可在引句中找到的原詞；不能只靠家族 ID、label、郡望或編者組裝路徑。

不納入母系、收養、姻親、單純排行、爵位承襲或未明父子關係。任何一代缺少可綁定的父子來源，就停止姓氏傳遞；不跨越缺代補姓。`scripts/surname_cross_chapter_paternal_path.py` 執行逐筆驗證，姓名組件仍由一般使用端讀取，不自動新增或改寫資料。
