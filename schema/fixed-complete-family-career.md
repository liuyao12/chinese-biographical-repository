# 完整固定本傳的受任角色槽位

`fixed_complete_family_career` 僅接受已審核有限語法：一個完整收到單元的所有段、每一人物提及順序及固定見證 SHA/revision。資料不能提供可執行規則，也不以人物 ID、姓名或家族編碼白名單判受任者。

角色以固定原段人物提及位置綁定；改號從現行原生提及解析，技術陳述 ID 與字位不變。每個槽位的名號、事件模式、實際受任者、來源詞與授辭結果均由受信語法固定；一致移換同段人物也拒絕。省略主語只容許已審核的相鄰本傳段承接，保前段人物錨及完整引文。世代/婚配不由官爵新增。

原生與匯出 `load_catalog` 同驗。批次來源旗標生效時，每個槽位須恰有一筆，缺筆、重複、錯型或錯受任者拒絕。原 raw 完整投影另驗，且本語法獨立固定 raw SHA，拒絕 raw/metadata/offset 一致改寫後冒原 revision。

`appointment_service_unreported` 與 `unassumed_appointment` 分開；前者是明召任而實任未載，不當作明辭未任。秦涼使持節/都督任命須綁後段「遂不西行」，不產生外任 holding。伐吳先辭後受則保實任並存辭受報告。左右夫人只有共同安排且充不敢當，不分左右也不當已授。

持職起點只綁本次明示年月；所有未知任終保 unknown，去職/兵權解除不結束所有官職。歷史官稱、皇室稱用與追贈分 mode。假充節作非連續原句權限報告，不拼假爵名或冒原字錨。襲父爵與嗣保承襲報告，不把「爵」當展示爵名；明父前任從來源角色另連。賈充父陽里亭侯可記有資格的編者解析名，源明載爵名仍為空。
