# 《史記》「太史公」的跨篇身份

篇首、篇末作者署稱「太史公」應連到同一位司馬遷，不能每收一篇便新增人物。本次撤除72個章別來源人物，把85處既存提及接回司馬遷；字元位置、提及ID、原句與文字層次都保留。人物JSON收集各篇證據，來源記錄不因人物接合而消失。
