# 趙世家第二輪核讀

第1–27段已再次核讀，第1段惡來被周殺有明文，秦趙共祖為來源世系；造父以下六世、叔帶以下五世不可補未知中間人物。第4段徐偃王敗非明示死，賜趙城與氏名分開。第8段霍公奔齊復位不作死亡，賜耿有明示而不補爵名。第9–11段共孟出生與趙衰諸子出生、翟妻及晉妻世系各按原句；晉妻迎翟妻及盾為適嗣不是所有兒子同母。趙衰居原與原大夫分存，成季是卒後諡。

第12–20段：晉襄公卒、靈公立、趙穿弒靈與趙盾景公時卒各有來源。太史書趙盾弒君及君子譏正卿亡不出境是責任表述，不能蓋過同段實際敘事主詞趙穿。宰人被殺是匿名受害者，待核既有錨點，不補姓名。第15段趙朔、同、括、嬰齊殺各自保存，皆滅其族不展開匿名全族。第16段遺腹生男、他人嬰兒與公孫杵臼被殺、趙氏真孤仍生分開；不把替代嬰兒映到趙武。第17段屠岸賈滅族不自動推每個族人死亡。程嬰冠後自殺、趙武服三年有明文，但未載絕對年不自行換算。三郤殺為群體，晉厲公弒另存。趙武正卿平公12年授職與死後文子諡分開；後一段13年外交不能直接借作卒年。

第21–27段：景叔卒與生趙鞅的句序不推死後出生。祁羊舌氏族誅不造個人死；六卿各令族大夫保留群體。陽虎來奔與受賂有來源，但目的地要依趙簡子上下文。趙簡子昏迷及寤不是死亡，扁鵲引秦繆公夢與簡子夢熊羆死是引語夢境，不列現實人命事件。賜扁鵲四萬畝明示，但不是具名官爵授予。

第28–46段已再次核讀。當道者授官邀請未受，不作具名官職。姑布子卿相毋卹為將軍是預言，不作當時授職；伯魯廢太子及毋卹太子明示分時段。第30段午晉陽殺、董安于自殺有實行敘事，法律始亂者死不是所有人物已死。周舍死及周捨異寫留原文。衛太子蒯聵不得入衛、居戚，不能當已復位；中行文子奔邯鄲、柏人、齊分來源遷徙。趙名晉卿為用稱，不假設初授日期。第34–39段定公、簡子、代王、襄子姊、伯魯與出公死亡分記，代王從官是群體；伯魯蚤死回述不借襄子當年。摩笄之山來源死地命名不補現代地圖。第36–39段簡子卒、襄子元年越圍吳及出公紀年可能不合，原文不改，換算須另附依據。

第40段神書滅知氏為預言；第41段實行滅知氏另存，三神與百邑祠祀不改成歷史人物授爵。空同氏五子為群體，不能替每位加姓名；代成君先死及浣太子、襄子卒、浣立、桓子逐獻侯、桓子一年卒與其子被殺分事件。治中牟是明示治所，可記人物居處但不作籍貫。第46段三家相立諸侯與獻子追尊獻侯不同；追尊不回填生前受爵。

第47–59段已再次核讀。烈侯擬賜槍、石二歌者萬畝，相國未給且最後止賜，不作實際田產；牛畜師、荀欣中尉、徐越內史明示授職。烈侯、武公、魏文侯卒分來源相對日期，武公子朝亂敗奔魏不作死。敬侯、成侯卒及公子紲敗奔韓分記，成侯公子勝爭立未見死。太戊午相與後段大戊午異寫保留；庶長國、太子及痤被虜不作死亡。端氏封晉君與後徙屯留分處理，晉君未名不套熟知名字。公子范、秦孝公、商君、魏惠王、趙疵及韓舉死亡有文字，趙疵河西、韓舉桑丘明示死地。肅侯起壽陵是營建，不直接當實際墓地；會葬諸國軍隊不補未名個人。肅侯24年卒與武靈立君分事件。

第60–75段已再次核讀。武靈王少而未聽政、後聽政與肥義加秩，不補確切開始年份或級數。八年五國相王趙獨否且自令稱君，王號追稱與當時稱君分存；敘事中武靈王用稱不得直接當八年授王。公子職燕王、公子稷秦王明示立君，子之君臣互換留來源主張；趙莊被虜非死。秦惠王卒、秦武王舉鼎死、惠后卒有明文。孟姚／娃嬴／惠后吳娃同指須本篇證據，不憑熟知姓名合併。夢見處女與實際納女分層。胡服議論中先王及神農、堯舜誅等泛述不補個別死亡。公字成與公子成原文異寫留存。第73段諸軍任命與周袑傅何有明示，但不能都變成未載正式官名。第74段五月戊申傳國、何立王、肥義相國兼傅王及主父自號分事件，武靈王讓位與主父用稱可形成有據時段；主父假使秦不是實際受封秦使者。

第76–107段已再次核讀。中山王遷膚施不推死亡。公子章封代安陽君與田不禮相章有明文；分趙王章計未決而輟，不作已授代王。第81段肥義、公子章、田不禮死亡與主父三月餘餓死沙丘宮分記，滅黨不補全部具名個人。公子成相及安平君、李兌司寇授職各分記。第82段章太子廢、何出生及立王是回述，不借段首是時；吳娃死已有前文惠后卒互證。第83段公主死需核既有匿名身份，主父死文字括注保持原文。蘇厲書分段引語不得直接作所有已發生事件，秦廢帝來源表述另存。公子丹太子22年、趙豹平陽君27年、趙奢馬服君29年、丹惠文王卒後立君有時段。長安君質齊非籍貫，舒祺黑衣補缺需保留太后允諾證據。惠文后二年卒有明文。馮亭封侯提議未受，吏民益爵群體不套每位個人。長平趙括以軍降與全卒阬的表述不改成他篇射死趙括；年月校讀原樣保存。第107段太子死、鄭安平死、趙勝死分項，匿名太子不套丹而造成重複死亡。

第108–122段已再次核讀，全122段包括另層述贊完成第二輪閱讀。廉頗信平君、樂乘武襄君、李牧武安君授爵與樂乘代將、廉頗奔魏、司馬尚免職各分時段。栗腹被殺與卿秦樂閒被虜不同；劇辛禽非本段明示殺。春平君留秦後遣，不借文信侯談判作死；本段郎中之疑句不直接補官職。傅抵居平邑、長安君封饒保留來源，不按同名強合前段長安君。扈輒敗死與李牧誅有明文；趙怱軍破、顏聚亡、王遷降與嘉敗亡國皆不推死亡。太史公引馮王孫評遷母倡、嘉廢及李牧誅，保留引述來源層次，與正文另作同指證據。述贊仍分層，岸賈與屠岸賈省稱、周穆與繆王異寫不全庫按同字串合併。身份、紀年與版本仍需逐項覆核。

本批次保存75項生死（61項死亡、14項出生，45項附來源時間表述）、27項地點及七項太子終點，沿既有人物ID與錨點。122段文字及109筆稱號ID、原始證據保持不變；替代嬰兒與真孤分開，不由族滅、亡國或被虜推個人死亡。
