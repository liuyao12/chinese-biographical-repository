本篇文帝、景帝、竇太后仍使用既有局部家族身份；此前篇章另有不同 ID。須讀登錄表與既有相互對應，先以明確史料辨認，再選穩定身份與別名轉向；不可直接全庫字串替換，亦不可把新 ID 順序當作出生次序。此問題尚未解決。
