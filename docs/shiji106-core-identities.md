# 〈吳王濞列傳〉同篇與跨篇身份接合

書信中五國王號依同篇景帝詔書具名接合：膠東雄渠、菑川賢、濟南辟光、趙遂、楚戊。限同一七國事件，不把「楚王遂西」副詞遂誤作姓名。

英布與黥布、荊王劉賈、惠帝母高后、文帝母薄太后、酈寄、周勃、劇孟及弓高侯穨當依明示身份或平行事件接合。各篇原文與時點分存，不為合併改字或補生年。

周亞夫已有明示周勃父子來源，補家族路徑，與已記之子沿原父系歸同根；接合106父絳侯候選，不把父之故客鄧都尉當父親。支字不是出生排行，缺生母不補。

孝文時被殺吳太子、七國時吳太子、少子、子華、子駒不僅憑家屬稱謂合併；德侯與膠西太子德分開；城陽景王引稱、其他未定王號、全篇紀年與版本仍待續核。本批不代表全篇完成。
