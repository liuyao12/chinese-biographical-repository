# 〈楚世家〉首輪與待核範圍

固定來源為維基文庫修訂8736796，保存96段正文及1段獨立附載索隱述贊。全97段已核讀明示人名首輪；JSON為編輯來源，XML同步行內錨點，尚未核讀古籍影像。首輪不表示全部人物、身份、匿名與代詞已完成。

只去除段落外緣空白，並明記第70段笔轉筆。熊渠生子三年、衞康叔子牟、西取筆秦、伯與索隱子圉等保留，不按通行姓名或世系改字。傳說祖系、氏族、寓言及未定指代分開；後裔不作直接父子。

身份判讀與親屬主張分開，既有ID保留。跨篇同指限定實際引文與提及；子玉、子反及項燕死亡異說、景缺／景快分年並存，不由同指決定來源優先。兩位未名齊王先各存候選，不表示確證不同人，也不按齊王泛接齊湣王。

武關冒稱秦王與子綦隱匿昭王的冒稱、讓位提議、棄疾恐嚇王至的話語與實際君主分開。索隱短稱依正文明示王號及具體事件暫接，子圉仍未定；正文與附載不算同一事件的兩份獨立佐證。

稱號局部試點區分授予、自立及既有用稱，未知起訖不由首次提及、死亡、逃亡或被俘補造；全部稱號、兼任、辭讓、制度與時段尚待核。可靠底本與現代研究未完成，全篇及全庫收錄目標均未完成。

首輪統計：1039處錨點、214個新增候選、189項身份判讀、90項親屬來源主張、52項稱號記錄、3項人物區分及18項跨ID暫同指。全庫2052筆候選；數量不表示已完成學術審閱。下一書為卷四十一，尚未開始轉錄。
