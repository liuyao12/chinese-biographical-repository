# 〈衛將軍驃騎列傳〉第26至33段

本批保存53處姓名或群體錨點，新增7名來源候選；全篇首33段共95名候選，並非身份全部覆核完成。六人傳首義渠、郁郅、義渠、雲中、成紀、河東分別保存為傳首出身地，不推現代轄區。

賀父渾邪、賀子敬聲、敖妻與次公父隆有原文明示關係。渾邪不按同名接渾邪王或隴西太守；敬聲與陽石公主的姦不記為婚姻。父系組裝保持來源ID及相容JSON入口，不由編碼推排行。景帝與孝文帝另據卷109李蔡仕歷暫同指。

新增42筆官爵用稱；小傳重述合騎侯、南窌侯、樂安侯、岸頭侯的原授爵，追加見證而不重複授予。渾邪失侯、賀酎金失侯、敖贖為庶人、次公失侯保存明示終點，確切年份未定。隆的輕車武射暫列未分類，不判正式官職；括號（驃）騎將軍照原文保存。

已核讀的平行事件：

- [《資治通鑑》卷18](https://zh.wikisource.org/wiki/資治通鑑/卷018)：馬邑役賀輕車將軍、息材官將軍，暫換算前133年。

數字日期附本篇原句、平行事件及數位編輯年標，僅年精度；不直接串算後幾歲，不將年標冒作古文。敖早先詐死不記死亡，只記後發覺復繫後的族，卒年仍未定。未把族滅自動轉成所有家屬的個別死亡，也不以卒年截斷全部稱號。

本批僅核數位正文，未核影像；相對紀年、太后身份及版本仍待整理。新卷篇未接入線上閱讀器。
