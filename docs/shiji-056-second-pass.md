# 《陳丞相世家》第二輪核讀

全29段已逐段核讀，第29段索隱另層保存；本稿為下一批編輯紀錄，本批來源事件、地點與身份稱號修訂已納入工作分支。第一輪姓名標記不等於全篇身份、版本及任期完成。

第1–3段：陳平陽武戸牖鄕人為本人來源籍貫，原戸、鄕字保持；兄伯、嫂與張氏女、張負女孫、張仲分別核來源關係，不以兄事或事如父母造血親。伯逐其婦而棄之為婚姻離異，不是婦死亡。張負女孫五嫁而夫輒死保存來源多人死亡，不在未可分辨時造五個具名丈夫；邑中有喪未記死者。喪所、負郭窮巷與陳平家保留原語，不補城市或今日地址。平爲宰、陳孺子與宰天下願望分開：社祭實任、指人稱呼與未實行願望不可混為同職。

第4–7段：魏王授太僕、項羽賜爵卿及信武君、楚都尉、漢都尉與亞將、護軍中尉逐項任事分存，楚與漢都尉不是一次同任。陳平封金印間行亡離楚為棄任來源，不以項王將誅或船人欲殺當已死。臨濟、河上、修武、彭城、滎陽、廣武行程與軍事居處依人物主體保存；秦軍攻臨濟不是每人個別在場。萬石君奮與中涓為回述爵號／當時任事分開。絳侯、灌嬰讒語盜嫂受金是來源指控，不提升為已證事實；諸項與妻之昆弟為群體，不補全部姓名。請骸骨為離職請求，不當已死或已准離任；尾生孝己為引古比況。

第8–10段：反間話術中終不得裂地而王、欲與漢為一與滅項氏是散布語，不當實受王號或實際全部族滅。亞父怒請骸骨、歸未至彭城疽發背而死是明示死亡；不能記已回彭城或以彭城為死亡城市。楚使是否單人依角色錨點核，不按常見姓名補名。女子二千人與楚軍仍群體。陳平與漢王從滎陽西門出去、入關再東為實行，原地名不補精確路線。其明年淮陰侯破齊自立及漢王遣張子房立信齊王分存來源敘述，不把回述淮陰侯當當時新授爵；戸牖鄕受封不是居處。

第11–14段：楚王韓信被告、被捕、赦為淮陰侯分存；告反不等已證謀反，信我固當烹是自語預期，不當死亡。雲夢為佯遊方案，實行會陳及還雒陽另存；行未至陳遇韓信為途中不明地，不錄已至陳捕人。戸牖侯與曲逆侯改封，除前所食戸牖只限食邑及相應改號，不廢所有軍職。從韓王信於代、至平城、曲逆所在依實行保存，韓王信與楚王韓信分人。使單于閼氏不按常識補姓名；奇計祕、六益封不造六個未知封地或六次精確日期。御史有實際答話，未名角色與王廷通稱分開。

第15–17段：高帝破布軍、病創與噲冀我死不是黥布或高帝在本段已死。斬噲頭詔未實行，實際囚送長安、周勃代將及後赦復爵邑分存，不造樊噲死亡或永久失爵。呂嬃為呂后弟原用字保持，樊噲為呂嬃夫有來源；不默改弟為妹，但關係判讀須保留女性及原詞。陳平聞高帝崩、屯滎陽詔、返宮與宿衞中、郎中令授予分存，詔屯不冒稱實際已屯。第17段孝惠帝六年相國曹參卒，與卷54惠帝二年卒有來源紀年衝突；兩句保持，不把第17段默改二年，也不把曹參生死主檔改成無衝突定論。王陵右丞相、陳平左丞相任事另核日期範圍。

第18–21段：王陵故沛人為本人來源籍貫、居南陽為居處；高祖兄事陵不是親兄弟。陵母置項羽軍中、自殺及被烹為同一未名母親死亡，不重複計死亡，不補母姓名或具體營地。使者送別不造本人死；雍齒為高帝之仇是敵對敘述，不推殺害。右丞相二歳、孝惠帝崩、王陵遷帝太傅後謝疾免及七年而卒分存，二歳是官職年數，七年錨點待核，不倒推生年。陳平左轉右、審食其左丞相為明示改任，任次分段不合併一條不間斷左丞相。食其沛人及居中為來源籍貫／宮中活動，彭城西敗不能推每人住址；太上皇、呂后為質不是死亡或婚姻事件。

第22–25段：戲婦女與兒婦人口是指控／泛稱，不拆造具名女性。呂太后崩有明示，誅諸呂為群體不逐人補死；孝文皇帝立、審食其免相分存。陳平讓右丞相周勃而徙左，後周勃請免、平專為一丞相保存任次與改號；謝病不作死亡，不以高祖時比較功績重授職。廷尉、治粟內史與宰相職責講論為職位泛稱，不造現任官員或本次授官。天下一歳決獄等統計期不是官職任期；長安盜賊是假設提問，不作在長安的具名犯罪事件。

第26–29段：孝文帝二年陳平卒、諡獻侯為明示死後命名，子買、恢、何父子承爵分存。買共侯與恢簡侯是來源用稱，未見命名原句不補諡授事件。二年卒、二十三年卒與何二十三年棄市分別核主體、持爵年數及日期，不將持爵年數倒推精確起訖或生年。何略人妻不造無名妻為其配偶，棄市為處死、國除為封國終止分存。陳掌為陳平曾孫明示隔代，不指定為何子或補缺代；願續封終不得不當復爵。黃帝老子為學說師承署稱而非當時會面，太史公評論與索隱用稱另層保存。
