# 〈李斯列傳〉第二輪核讀（進行中）

諫逐客書的四位秦君與五位取士人物、商鞅、張儀、范睢、穰侯及華陽，以及後書商君按共主、共臣、政事與王位接續對讀。秦穆公／繆公、百里傒／百里奚／五羖大夫保留各自原字；自粥／被虜贖取、荊鄙人／虞大夫與并國二十／益國十二等不同故事不改寫。商君名鞅姓公孫與穰侯姓魏名冉的原文另作姓名依據；前者祖本姬姓、後者其先姓羋分存。華陽限定華陽君羋戎，不接華陽太后或地名。此次共更新22個重複登記的全部引用後撤號；引古不是當世在場或獨立見證，紀年、姓氏、法條與其他敘事仍各存其限制。

已重讀固定數位修訂2364605全部38個正文區塊，包括兩篇上書與論贊；原文字串與提及位置不改。先以荀卿篇師生配置，及莊襄王卒、政代立、李斯為文信侯舍人、止逐客令的共同事件接合五組身份。辭師前秦王與楚王仍各存候選，不由後文繼位直接倒推前文指涉。

補16項死亡原語（含上林未名行人及四項引古／傳說記載）與8項地望。李斯開篇楚上蔡為籍貫，咸陽市為受刑地；三川守與上郡監兵、為將分作任事地。公子高請從死、願葬酈山之足與允其書未當已核實葬地。蒙恬不肯死被系陽周與後段「蒙恬已死」分存；中子只按俱執後夷族記死亡，未補其姓名、絕對排行或腰斬刑法。引韓子的禹死葬、李斯引古三忠臣各記敘述範圍，不作獨立見證。

始皇「其年七月」沙丘崩與李斯「二世二年七月」受刑，對讀固定《六國年表》原紀年及編者西元欄，暫記前210、前208年，只到年；原七月不換算公曆月日，年表始皇三十七十月出巡不當其死亡月。其餘年序、子嬰親屬與三月／四十六日異說、引古人物、未名指代及官爵時段仍待核。
