# 〈魏其武安侯列傳〉死亡與紀年取捨

新增竇太后、張孟、竇嬰與田蚡四項明示死亡。張孟死於吳軍不是灌夫死亡；韓安國說辭中的魏其必齰舌自殺是假設；鬼見魏其灌夫不是新的實際行刑。田蚡竟死在子恬嗣以前，不把嗣爵後同號武安侯當死者。

原文五年十月、十二月晦與其春均不改。按本文字面敘次的數值候選另存，與《漢書·武帝紀》元光四年冬、春三月的候選分開；兩項取捨暫選本紀四年。集解徐廣存疑、正義明言五年誤及其春即四年春分存為參考，不把單一著作全域列為較可靠。原月日及兩個西元年端點保留，沒有以首選偷填確切單年，也不以死亡終止爵職。

《正義》明記元光四年十月灌夫弃市及三人同年，另列三人的所報紀年參考；這是古注所記，沒有塞進傳世正文或將本文悉論改寫成逐字行刑語。灌夫的注家事件層仍待獨立整理。古注固定修訂2514777，HTML指紋61ba36dd1909155d637a22db47e12b868061a39cd62f5c82d26f05854b64456a，僅核數位文字，未核書影。
