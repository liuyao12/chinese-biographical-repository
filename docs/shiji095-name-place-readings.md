# 〈樊酈滕灌列傳〉人地辨讀與餘下軍將

田橫、項冠、周蘭、項聲、侯敞及〈季布欒布列傳〉汝陰侯滕公，依戰役、爵地與同僚脈絡接合六組身份；引用遷移後撤除九個候選 ID。兩處被俘或不同人記功不合為一次事件，異地、異時及斬獲歸屬各留原文。

「破雍將軍焉氏」對讀《索隱》縣名注與《漢書》「破章邯別將於烏氏」，人物錨點由焉氏移至雍將軍，仍用同一未名對手候選 ID；不補其姓名，也不改正文焉氏為烏氏。補一筆將軍用稱，授職及任期不明。

滕公依徐廣令也及《漢書》「初嬰為滕令奉車，故號滕公」分官稱與沿用尊稱：本篇轉任記錄不作公爵，後來滕公用稱不推一直任滕令。同稱不同性質在人物頁以小標籤區分，名物辨讀可展開原文與參考。

薛公各篇有東阿／下邳、彭越／灌嬰斬獲差異，英布反時又有故楚令尹薛公；程縱兩篇受虜次序亦不同。分存未決候選，不只憑同稱合人、統一卒年或軍事事件。錢大昕《廿二史考異》對夏侯頗配偶的異人說另作署名參考，不宣稱已驗證全部論證或為最新研究。
