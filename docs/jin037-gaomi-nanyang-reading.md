# 《晉書》宗室近系節選

本批獨立讀既存固定修訂2630018的泰、略、模、保、綏、虓完整單元及兩疏，權段沿用已存來源。實際印本未知，沒有新增掃描、OCR或人工／書影覆核。

模的平昌公、馮嵩與成都穎／東海越同事件，保的南陽王／右丞相／湣帝同官同時，略與090所稱高密王簡的曹攄／崔曠／王逌同戰，分別支持跨篇接合；簡／略兩字仍分源。西方建興朝愍帝與江東諸人傳所稱湣帝接為同一君主，原三份身份限定與review按MID保全，不把字形差異作不同人。

石鑒兩個已存候選中，349年後趙主顯然不合；山濤共宿者年代相容但未讀到司空正橋，故本篇來源內先登泰所代司空之石鑒，保跨篇待核，不宣稱必異。保將張春不接漢初同名。劉氏是模妃，被粲強制轉賜張本；不作保妻，也不推保或黎所生母。

兩疏的太宰按顒與張方、關右敘事辨；先帝遺體按惠帝朝指武帝，帝／天子依惠帝西遷／還都局部語境，不按最近君主統一替換。臣、陛下及代詞不作姓名alias，任真／攻略／安定等普通詞、地名不拆成單字人名。
