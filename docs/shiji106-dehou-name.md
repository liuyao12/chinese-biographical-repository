# 德侯名辨與年表姓名來源

正文〈吳王濞列傳〉僅稱德侯及宗正。徐廣注名通、父廣，裴駰所引《漢書》則作德侯廣。〈高祖功臣侯者年表〉德列高后欄先二年再通六年，孝文欄二十三年，孝景欄先五年再六年齕承侯；景三年宗正德侯暫取通，廣說另存。正文不改為通，姓氏不補，不因表列承爵新增父子。
