# 〈季布欒布列傳〉稱呼、承爵與授封詳年

補十二處將軍、君、足下及述贊越：周氏所稱將軍為季布；朱家對滕公所稱君與文帝對季布所稱君分開；竇長君對曹丘生說足下，曹丘生見季布後足下改指季布。述贊欒布哭越回述彭越，保留段落層次與原文。每處以完整引語及原提及錨點記錄，不全域配對。

子賁嗣依原有跨段父子主張連前段欒布兪侯持有記錄。驗證要求明列同篇、實際相鄰兩段，父子錨點各在其來源引句內；錯父、漏引、插入中段或跨篇均不接受。不補成賁本人原文中有兪侯字樣，也不從父卒年補承爵年。

欒布授封詳年暫採史記侯表六年亖月丁卯及漢書侯表六年四月丁卯，較傳文吳楚反時具體；傳文仍保留，兩表不當獨立證據投票。以將相表原年欄及數位西元151對照、前太初歲首規則，保留公元前152至151年尺度範圍，天文年-151至-150，未換算四月丁卯公曆日。兪、俞、鄃各見證原字分存，未核書影。欒布卒年及所有官爵未知終點不改。
