# 〈項羽本紀〉第二輪核讀（進行中）

項籍「下相人」、召平「廣陵人」、范增「居鄛人」按傳首原文保存籍貫；避仇、出亡、軍事駐地、遷都與死亡地分開，不補今日位置。年二十四、年七十未倒推精確生日。

項燕「為秦將王翦所戮」與〈秦始皇本紀〉自殺表述分存。李由在相鄰兩段的斬殺敘述各保留來源，不建立第二人或宣稱兩次死亡。田榮要求殺田假等不當已執行死亡。

項梁持會稽守印綬與任守、項籍為裨將保存起兵後任職，未推秦廷合法授命。召平矯陳王命拜楚王上柱國保留為用稱見證，不作陳王真實授予或確定有效起點。故獄掾、故令史、故齊將不當本段事件時仍在任。未知端點不因死亡補齊。

原紀年尚未換算西曆，影像與紙本校勘未完成。全篇身份、匿名者、稱號與其餘行跡仍待續核；本批已重建7282份人物JSON；兩套資料驗證、112篇XML同步、155項JavaScript測試與語法檢查通過。完整Python 289項測試通過（292.552秒），尚未提交及接入線上閱讀器。

第十一至十五段新增項羽次將、假上將軍與諸侯上將軍階段；候始成保留候字職稱，不改成侯爵。宋義之死保存實際斬殺，楚王陰令誅之只保留項羽宣稱。宋襄命相齊不當已實任，追及齊殺之有死亡與地點記錄。王離被虜不當死亡；匿名秦卒群體不補姓名。陳餘書中白起賜死、蒙恬斬陽周是追述見證，與他篇分存。

鴻門敘事中的大王分別指沛公或項王，按對話逐處連結；壯士指樊噲，非正式官爵。大將軍獻玉斗的指向仍待覆核。使子嬰為相為曹無傷告密內容，不記真實授職；可都以霸為建議，不記項羽定都關中。逃離鴻門的五人同行路徑分存，未推為籍貫。

分封段落保存原文都城，標明政治居處用稱不等於分封當日本人已抵達。韓廣遼東的未從命不作遷移，義帝被命遷徙及陰令擊殺仍待後文核對。韓成、韓廣、田市、田安、田榮死亡各存原文。梅鋗十萬戶侯授爵字面保留。彭城戰役路徑分存，欲過沛收家室不作到達證據。

滎陽戰事保存范增未至彭城而死，不指定彭城為死亡地。紀信乘黃屋車詐降不當稱王；周苛拒絕上將軍與三萬戶之提議不記授予。漢王、滕公渡河走修武與廣武駐軍分存；滕公同人判讀仍待核。武涉盱台人保存出身。太公被威脅及漢王受傷不記死亡，韓信自立齊王依本篇原事件保存。
