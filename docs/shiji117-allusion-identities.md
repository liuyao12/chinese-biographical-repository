# 〈司馬相如列傳〉典故人物與治水稱謂

依已核讀的正文與古注，接合本篇專諸、禹、契、唐堯、虞舜、軒轅、后稷、公劉、文王、湯、武、烏獲及二世的十三個重複身份。另將治水敘事的「夏後氏」接夏禹，共更新二十個既有提及。

每項同指決定保留兩篇的確切引文、提及錨點、範圍及信心。專諸與禹、契另附《漢書》卷57上古注的固定提交、原始行文、行號及回應指紋；卨、剸等來源異字不回寫本篇正文。湯、武的省稱與烏獲力士比喻的接合標為中等信心，其他同名者不批量合併。

「夏後氏」依堙鴻水、決江疏河及親勞的敘事，與〈夏本紀〉夏禹治水相接，並非把夏王朝所有君主視為一人。哀二世賦的秦亡語境，與〈秦始皇本紀〉明稱胡亥為二世皇帝相接；沒有據吊古文字補死亡年或墓址。

保留既有傳說人物的歷史性標示，不把賦中的架空君臣或神祇套入本批。能辨典故人物不等於能確認文學場景為史事，也不由此補父系、任官或生卒日期。全部判讀為 AI 暫定，未經人工覆核、未核書影。
