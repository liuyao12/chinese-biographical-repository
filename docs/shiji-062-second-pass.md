## 本批資料

四項死亡為公子糾、召忽、管仲、莊公；莊公據尸哭句保存既亡，無卒日不補。兩項傳首籍貫為管仲潁上及晏嬰萊之夷維，保留完整原地名，不轉現代行政區或當出生地。

三筆既有稱號增補來源起點：小白立為桓公 accession，御者薦為大夫 grant，越石父延入為上客 grant。日期均未知，桓公回顧用號不當即位時授諡，上客不當正式官爵，薦大夫不補國君核准；不自動截斷此前御職。十四筆稱號ID保持。

十一項既有跨篇同指保持。《齊太公世家》第二十九段管仲召忽傅糾、鮑叔傅小白與本篇人物組合相配；第三十段另載召忽自殺、管仲請囚，本篇仍保留召忽死之，不以他篇死因覆寫原句。小白詳死不可另列實際死亡。既有父母與御者夫婦主張已核，妻請去不推已離婚。

全篇人物指代、任期與版本仍待；百餘年、三世與身高不當精確年表或享年，新篇未接入公開閱讀器。
