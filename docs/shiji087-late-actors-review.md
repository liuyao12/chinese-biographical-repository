# 〈李斯列傳〉末段人物身份接合

四組身份判斷收於 `087-equivalences.json` 的 `eq-shiji087-late-*`，每項含逐段全文、人物提及、來源與篇章 ID；未冒充人工審閱。

- 沛公：〈李斯列傳〉末段、〈秦始皇本紀〉與〈高祖本紀〉皆述武關入秦、子嬰系頸降軹道、沛公以屬吏。接合至高祖的既有家族 ID；高祖本紀開篇「姓劉氏，字季」不另改成有本篇名的斷言。
- 項王：〈李斯列傳〉項王至而斬子嬰，對讀〈項羽本紀〉項羽殺秦降王子嬰；後者同段項羽、項王連稱。不由稱謂前推特定王號受封時間。
- 章邯：二世時破逐陳勝、吳廣等軍隊，對讀〈陳涉世家〉與〈秦始皇本紀〉的西進軍事。周文／周章原字分存；吳廣已被田臧殺，不把破逐其兵當章邯親殺吳廣。
- 王離：接合始皇末裨將與鉅鹿圍趙、項羽俘王離的同人；保留〈白起王翦列傳〉王翦之孫的闕代家族 ID，不直接指定王賁為其父，不由被俘補死亡。

身份接合不統一子嬰三月／四十六日在位、始皇弟／二世兄子等來源差異。同書各篇不當獨立見證，未核書影。原文、提及 ID、字元位置與原稱須保持一致；全部引用與衍生資料遷移後撤除六個重複號。
