# 楚世家第二輪核讀

第1–15段已核讀。第1段重黎被誅庚寅日，火正與祝融命名分記；上古譜系保留傳統性。第2段陸終六子明示第一至第六排行，不將昆吾氏彭祖氏滅當具名個人死亡。第3段鬻熊子事文王蚤卒的主詞與句讀仍待核，不由熟知世系補受害者。熊繹居丹陽為來源居處，不補現代地名。第5段熊渠生子三年疑讀保留，長中少子不各自補固定順位；三子各封王與後去王分別建時段，不等同死亡。第6段毋康蚤死、熊渠卒、摯紅卒有原文，但其弟弒的受害者與句讀仍待核。第7–12段各君卒、仲雪死、叔堪避難濮、蚡冒子被殺分存。第13段熊通自尊武王37年，原文此前武王17年等追稱與授號時段分開；武王51年卒師中不補地名。第14段蔡哀侯虜後釋不作死，鄧滅不補鄧侯死。第15段熊惲欲被殺而奔隨，不作已死；莊敖被弒有明文。

第16–30段已核讀：宋襄公34年病創死與宋篇14年夏卒互證待換算；子玉誅與晉篇自殺、子反射殺與晉篇子反死分別存來源主張，不改寫原文。第18段立商臣初回述不借46年，成王冬10月丁未自絞。潘崇太師明示授職，蘇從殺身願未實行，許君鄭伯肉袒不作死。第29段郟敖季父、共王之子圍長的世系及排行按原文；莫平夏被殺分開，子比奔晉不作死。

第31–45段已核讀：慶封蔡侯殺、觀起回述殺、祿殺、靈王申亥家死、比及子皙自殺、熊珍生、伍奢尚殺、平王卒分存。常壽過僇字且後續仍參與敘事，不推死亡。申亥二女從死為群體，未擅選人物。第36段釐澤遇饑王不作死地，死地明示申亥家；并葬未指墓址。比王十餘日只存時長，子皙令尹與棄疾司馬有授職；第39段神符故事不改成史實判定。建居城父及逃宋、伍胥奔吳、建母居巣各有來源地點。第43段尚胥的擬議死語與末尾明示死亡分開。

第46–60段已核讀：費無忌誅及郤宛回述殺分存；子常敗奔鄭、夫概敗奔楚、昭王雲夢傷及避隨均不作死。辱平王墓不直接補郢為墓坐標。第51段去郢徙鄀為都邑變動，仍需分人物居處。昭王軍中庚寅卒，城父在前段，跨段證據須另建不借段；請禱移禍未作實死。公子閭許為王後改迎章，立君及退讓須按原句，不把讓位當持有完整任期。第55段建在鄭被殺為回述，子西子綦八年朝殺，白公月餘後殺；惠王欲弒未行且復位。第57段魏韓趙始列侯與年表等異說分存，不能據熟知三家分晉年代直接改原句。

第61–75段已核讀：肅王無子、宣王威王卒及秦惠王卒各按原文。昭陽柱國與令尹、上柱國執珪的制度問答分開；陳軫今君已為令尹為具名用稱，而泛稱破軍殺將何以貴不給昭陽本人授職。懷王置相璽於張儀明示授相；秦宣言張儀免相是計謀措辭，不直接作實退任。第72段屈匄逢侯丑等虜不作死。張儀欲殺被釋、追殺不及不作死亡；第75段二十〈六〉年保留數位校讀，不能先改紀年。

第76–97段已核讀，全97段含另層述贊第二輪已讀，身份版本仍待覆核。唐眛景缺被殺、懷王卒秦、頃襄王秋卒、秦昭莊襄王卒、考烈王卒、春申君殺、呂不韋卒、幽哀王死、項燕殺分存。第78段秦大夫已有匿名人物錨點，沿用既有ID補死亡；原文二十八及二十九年分開。懷王走趙不獲入、欲走魏被追返秦，不當已居魏。第82段齊秦稱帝月餘退王是群體授退號，需具來源成員格式。第86段襄王保陳為避難，先王墓夷陵不可指定某一先王。第88段左徒授令尹與春申君命名有明文。負芻被虜亡國不推死；第97段子圉篡嫡與正文圍字差異保留，不直接指晉懷公圉。

核對第12段蚡冒子及第78段秦大夫均已有匿名人物ID，分別沿子字、秦大夫錨點補死亡候選，無須重建人物。

75項生死與21項地點已入工作分支，沿既有ID及錨點，原文不改。人物JSON已匯出7283份；九組資料檢查通過（112份XML同步），Python完整289項測試通過（295.974秒），JavaScript155項測試及語法檢查通過。尚未接入公開閱讀器。

既有52筆稱號ID及原始證據保留，補三子王號退號及商臣、橫、熊元太子立君六項有據終點。熊渠去王的指稱範圍仍待覆核；不以死亡終止所有官爵。

依卷十四數位年欄補成王、莊王、共王三項死亡的年尺度換算。成王自絞與年表殺王表述分存，不改死因；原曆月日不換算，未核影像。
