# 〈司馬相如列傳〉勇士省稱與所忠

本批保留正文、字元位置及提及錨點，依上下文與古注接合四個重複人物 ID：賁與孟賁、育與夏育、慶忌與〈范睢蔡澤列傳〉所稱王慶忌，以及〈五宗世家〉所忠與既有人物所忠。全部判斷仍為代理暫定，未冒填人工覆核。

《漢書》卷57下顏師古注明釋烏獲、慶忌、孟賁及夏育，與《史記》相應具名段落互證；《集解》卷79引《吳越春秋》另釋慶忌。引用固定 Kanripo 提交、blob、已讀範圍及回應雜湊；未核圖像。原稱王慶忌仍保留為來源用稱，不由王字拆出姓氏，也不與申公弟子闕門慶忌混同。古注所述父系本批只列參考，不補作正文親屬斷言。勇力比喻不產生共同出獵或死亡事件。

《漢書》卷24下顏師古注明言所姓忠名，並逐舉廣川王與相如取書等處為一人。本批據此保存姓所、名忠及跨篇同人依據；近臣、幸臣屬敘述用稱，不增造正式官名或任期。引注不表示已獨立核讀注中提到的每一段《漢書》正文。

覆核人物頁時另發現舜的「十七年」被當成卒年簡示。〈夏本紀〉原文是薦禹後的相對時距，故撤去絕對日期欄位，保留「十七年而帝舜崩」及整段引文；不換算公元年，不刪除死亡來源。

四個舊人物 ID 須於正文、陳述、登記與衍生 JSON 全部更新且通過驗證後撤除，不建立永久轉址。〈司馬相如列傳〉仍有匿名家屬、角色泛稱、古注歧義、相對紀年與重複轉錄待核，不能因本批接合就宣稱全篇完成。
