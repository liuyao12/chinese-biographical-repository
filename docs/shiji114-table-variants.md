# 東越篇與功臣表的原名及異文

〈建元以來侯者年表〉北石、蘌兒、開陵、東成、無錫五列的首位持有人，依爵號、功臣事由及同一東越事件接回吳陽、轅終古、敖、居股、多軍。撤除五個年表局部候選，保留原有五個姓名錨點；功臣事由及終古死的格內另補十一個逐人或稱謂錨點。北石後任首仍單列，不從承爵次序推父子。

原表「建成」與列傳敖分存；漢書顏師古已說傳名敖而疑表誤。本批暫取敖作人物名，建成侯為原有爵號，不把表中建成提升為確證別名。原表居服與傳居股據繇王、斬餘善、萬戶東成侯同事暫接；未核書影，不改原字，也不因此與此前繇君丑合併。

轅終古依漢書顏師古「榬姓終古名也」對讀姓與名，原傳轅、漢書榬各存。蘌兒／御兒／語兒及北石／漢書印石等字形仍分源；表中莊侯是來源追稱，不據此推定封侯當時已有諡。吳陽、居股仍保留完整原名，不以字數機械拆姓。

多軍暫依漢書李奇「多軍名」說整體記名，姓未知；索隱引韋昭「多姓軍名也」另存姓多、名軍的可解析異說與固定引文，未採為預設。在尚無其他姓氏證據時保留原稱與兩說，不補騶氏。姓名依據同時顯示所取來源與未取異說；用戶端按已記錄欄位顯示，不作自然語言辨識。

本批不改傳世文字、表格結構、固定見證或舊錨點位置。籍里、生卒與更多稱號紀年仍待續核；終古死的新錨點讓原格可回查，尚不冒作已完成原表生卒事件模型。
