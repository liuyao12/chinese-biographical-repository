# 卷四十一收錄範圍

保存維基文庫固定修訂2018395的28段正文與1段附載索隱述贊，JSON為編輯來源，XML同步。僅去除段落外緣空白及記錄第17段笔→筆；句踐／勾踐、闔廬／闔閭、呉等古代異體保留，疑句不自行校改。

全29段完成明示人名首輪重讀，共344處錨點、40個新增候選及40項身份判讀。據會稽議和的同一事件，句踐、夫差、種、子胥與嚭各與吳篇既有ID保存5項暫同指，所有原ID及錨點保留。范蠡自謂鴟夷子皮、陶朱公按明文相接；救子故事中的楚王不套入楚威王，未名諸子不補姓名，其他跨篇同指仍待逐項核對。

12項親屬來源主張保存原文明示的子、生育與長男母稱。少康庶子至允常的二十餘世及無彊後七世不補闕代，禹之苗裔不作直接父子，三子不據一家敘事推同母。

17項稱號記錄分開既有用稱、授予與辭印。周元王命伯、漢髙帝復以搖為越王及齊人以范蠡為相保存授予起點；范蠡歸相印保存辭讓終點，日期未定。上將軍、霸王及諸越王用稱不從第一次出現、卒日或入質推造起訖，沒有來源的端點保持未知。
