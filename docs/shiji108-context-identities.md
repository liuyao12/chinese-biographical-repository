# 韓長孺篇的跨篇身份覆核

本次讀完十五段，對讀王恢與越王的同一次出兵、公孫敖的征戰履歷，以及長公主的皇室世代與往來。四組均屬AI暫定判讀，未核底本影像。六個重複ID在全部來源及衍生引用更新後撤除，原文字、提及錨點、判讀ID與引文保留，舊版可從Git回查。

- 大行王恢：本篇與東越、西南夷篇同為大行、同與韓安國出兵、同在越殺王後罷兵，接合為一人。大宛篇的故浩侯王恢到太初元年仍導軍，本篇大行王恢已於馬邑事敗後自殺，另存結構化區分。
- 未名越王：本篇「越殺其王降」與東越、南越篇郢被殺以降是同役，接到既有郢。將相表建元六年「閩越王反」亦依相同年月背景及戰事標記為郢。原本「閩越、東越相攻」與他篇「閩越擊南越」仍各自保留，身份判讀不改國名。
- 公孫敖：失軍贖庶人、封合騎侯、失侯後從大將軍的履歷相合，李將軍篇的同名者接到既有公孫敖。李將軍篇該役官稱中將軍，衛將軍篇履歷後段作校尉；兩者未統一，不據此拼出唯一官職時段或卒年。
- 長公主嫖：外戚篇明記竇姬生女嫖、嫖為長公主，並明大長公主是景帝姊。景帝本紀、梁孝王篇及韓長孺篇的相同世代、竇太后與景帝、梁王之間的長公主角色暫接於嫖，原有子蟜記載隨人物連結保留；不補子女之父，不由公主稱號套用其他時代人物。

壺遂與太史公自序的同名者尚未本批接合；太后、死罪囚及廷尉等未定錨點保留。本文與各篇的官爵、死亡及時間原記載分存，本次不新增親屬斷言或用死亡補全部職位終點。
