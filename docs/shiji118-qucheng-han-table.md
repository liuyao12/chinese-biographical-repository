# 曲城侯與《漢書》曲成列

〈淮南衡山列傳〉七國反時救淮南的曲城侯，依徐廣明釋「姓蟲名捷」、兩表同侯捷的姓名對讀暫定同人。晉灼指為蟲達，顏師古明駁達已先薨、其子名犍；兩位注家的原說與固定連結分存，不改正文爵稱。

本批開始實錄《漢書》卷十六原表，僅選取髙祖功臣表曲成一列及八個原欄題。固定數位版本為維基文庫 2374254；原 HTML 第 1 個 wikitable 第 69 列（不計欄題的第 68 列），其餘 217 列尚未逐處核讀。沒有核讀書影，不標為影像核實，也不宣稱全卷完成。原矦、亖、爲及「位次曰夜矦恒」均保留；後者存未定錨點，不擅造另一人。

漢表蟲達與史表蠱逢依同列三十七人從起碭、三月庚子、圉侯、位次十八及功績辨識；皇柔與皋柔依建元二年嗣侯、汝南太守不用赤側錢受罪同事辨識。兩表的姓名、封免次序與元鼎二／三年差異分存，不能用同人判讀消去紀年矛盾。

原表的子、孫、玄孫各欄相對始封者：捷之父為蟲達；皇柔之祖為蟲達，父不明；宣為蟲達玄孫，中間三代不明。不得因子欄只有捷便補其為皇柔父，也不得把宣強接在皇柔之下。家族根碼共用，闕代以星號表示，前端仍從原始親屬陳述追溯，不從 ID 反推父子。

原生表格直接嵌入既有《漢書》閱讀器，兩種方向保留原欄題與文字；沒有可核的西元年軸就不補年列。人物卡、完整人物頁、原格與返回連結攜帶明確的著作／卷／篇／表／格，不能將漢書卷十六誤導為史記卷十六。不把表格改造成虛構段落。

完整驗證、固定提交及公開驗收狀態以本批 PR 為準。尚待繼續處理稱號各段起訖、紀年首選與其餘全篇指涉，不以原表部分匯入代替全部人物覆核。

## 身份與爵年的未定分層

漢表記文十八年復免、景中五年復封，與正文景三年救淮南的爵稱有衝突；史表後三年復封與漢表十四年復封也不同。不能宣稱年表證明當時在爵。`chronology_caution` 保存本事、三格原文及逐人錨點，明示 `no_tenure_interpolation: true`；身份暫取徐廣、顏師古直接注說，並不表示任期或名字異文已校勘解決。史表十三、垣五保留原字，不暗改為較順的數字。

人物頁的先祖關係按 `ancestor` 顯示為「先祖」，原詞「玄孫」留在來源詳情；不把後裔的原詞反向當作先祖的角色名稱。API 中的關係方向、四代距離與原格文字不變。
