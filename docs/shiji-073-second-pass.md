# 〈白起王翦列傳〉第二輪核讀（進行中）

已重讀固定數位修訂7909285的15段正文。補6項具名者死亡與7項來源地望，原文及既有人物錨點不改。白起郿人與王翦頻陽東鄉人保存為來源出身，不補出生地或現代轄區。

王翦歸老頻陽分記歸程及居所，始皇自馳如頻陽只記行程。白起遷陰密後未能行，不記抵達陰密；已行至杜郵後自殺取為死亡地及行程。咸陽西門十里原文保留，與〈樗里子甘茂列傳〉引語七里不強改一致。

裨將茄、趙括、白起、項燕的明示殺／死及王翦王賁皆已死各分存。王翦王賁秦二世之時皆已死不代表卒於該年，也不代表兩人同年死亡。王離被虜、荊王負芻被虜、秦軍及蒙氏群體死亡不改為具名者死亡。白起昭王五十年十一月保留原紀年，尚待數字年對讀；原月不轉公曆。

稱號時段、紀年、親屬與跨篇身份仍在整理；影像、校勘、匿名者及代詞未完成覆核。

白起昭王五十年十一月卒與年表秦五十年及數位西元欄對照，年尺度暫定前257年，原十一月不作公曆月。秦本紀同年十二月敘事後記白起死，月份時序差異保留。趙裨將茄四十七年被斬暫定前260年，年表無其獨立死亡事件，不冒作同名平行死亡互證。

白起左庶長起點昭王十三年暫定前294年；左更其明年承接十三年，伊闕戰事與表十四年相應，暫定前293年。上將軍起點四十七年長平戰事暫定前260年。國尉、大良造與武安君的時序仍待個別對讀；不把同段全部升授定同年，免武安君明示終止與卒年分開。

趙括死亡以第4至5段連續敘事承接四十七年，暫定前260年，九月原文保留。兩段人物錨點及年表紀年格／數位年格俱存，不把年表長平軍卒記錄冒作趙括獨立死亡互證。
