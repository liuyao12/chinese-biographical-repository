# 〈酈生陸賈列傳〉身份續核

依分封漢中、淮南王反、陳平與絳侯誅呂及淮南厲王殺辟陽侯等平行敘事，接合項羽、黥布、周勃、呂后、孝惠與劉長六組來源局部候選。各篇正文及動機差異保留，未按全域同名替換。

本篇兩處「閎籍孺」明為孝惠幸臣；〈佞幸列傳〉將高祖籍孺與孝惠閎孺分人。《索隱》亦辨此混稱有誤，因而暫定所指為閎孺。正文不改，兩個錨點分別保存首選校讀，原字不成為人物卡通用別名；不合籍孺。獨立《索隱》四庫本的儒字與三家注本的孺字是不同數位見證，不悄改同字。

朱建兩處未名子依《索隱》「下文所謂與太史公善者」暫定同指。兩項來源父子陳述各自保留，不合所有「諸子」，不補子名，也不套用父死年為子卒年。家族分支字元不是排行。

古注核讀來源為[《史記三家註》卷097固定修訂2514767](https://zh.wikisource.org/w/index.php?title=史記三家註/卷097&oldid=2514767)，及[《索隱》卷二十三固定修訂608070](https://zh.wikisource.org/w/index.php?oldid=608070&title=史記索隱_(四庫全書本)/卷23)相應注語；未核書影，不宣稱校定底本或古注結論。
