# 〈殷本紀〉第二輪來源主張

固定來源正文的33段再次核讀，原字與既有人物ID保留。仲丁書保留書篇語境，不作人物錨點；夏王依上下文暫指桀，祖伊引語的維王、今王暫指紂。全篇384處錨點，其中33處未解；氏族、先王及未定官稱不補姓名。

50項親屬主張保留來源。13項兄弟關係補入可解析的先後約束，絕對排行未知；微子啓的長子保存兒子序列第一，辛的少子保存較幼或最幼歧義，不推第二子。

53項生死、13項地點與46項稱號記錄各自保存引句。早期未即位太丁與武乙之子太丁維持不同人物ID；高宗依立廟記為卒後用稱。三公任命分記西伯昌、九侯、鄂侯，未知分職不補造。武乙河渭之閒、紂鹿臺保存死亡敘事的原地名，不補現代轄區。

殷徙河北是集體敘事，未自動轉成本人居住；傅說築於傅險不等同籍貫。成王命周公誅之的代詞範圍未拆成三人必死。爵位、官職與死亡分開記錄，不以卒日推所有稱號終點；未確定的公元年不補造。

第二輪核讀不表示全部身份、匿名者、版本及稱號時段已覆核。數位正文尚未核對影像；商先祖譜系與出土材料對應仍待研究。本批尚未接入公開閱讀器。
