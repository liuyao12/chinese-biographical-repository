# 轅終古的原表死亡與太初改曆

《建元以來侯者年表》蘌兒列明記「太初元年，終古死，無後，國除。」以同格終古逐人錨點、原格全文與固定修訂記為死亡；不抄成正文段落。無後、國除不換算生物子女數，也不自動結束人物全部爵號。

太初元年包含改曆前冬季，不能直接把原年表數位對照104填成確切卒年。本筆採來源限定的公元前105至103年暫定範圍。《漢書》卷六原文保存五月正曆、正月歲首；固定版本復原曆表將太初元年首月標為前一年十一月、末月標為次年一月。僅採年範圍，沒有計算轅終古的死亡月日。

換算以 `calendar_reform_transition_year` 另立明示依據。原表太初元年欄、數位104、復原表首末月與前後年符號各有獨立引用；普通 `regnal_year_crosses_ce_year` 仍只接受相鄰兩年，不能全域放寬。

肖堯、辛德勇研究以參考書目與已閱範圍附在事件 JSON，保留未驗證研究結論的狀態。實際改元施行、史籍追稱與本事件未知月份分開。未核書影，不宣稱復原曆表已經獨立驗證。
