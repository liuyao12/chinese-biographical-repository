# 孔子世家第二輪核讀

全86段已再次閱讀，末段索隱述贊保持另層，不當正文證據。本批來源資料已納入工作分支，不表示全部身份、紀年與版本已覆核。

第1段孔子生魯昌平鄉陬邑為出生地，「其先宋人」為祖先來源，不混作本人籍貫。孔防叔、伯夏、叔梁紇的生子敘事可存出生主張，不補年代；孔子出生依本篇魯襄公二十二年保存。尼丘禱告地不作出生地。叔梁紇死及葬防山、孔子母死、殯五父之衢、與父合葬防各分生死與葬殯，不把殯地當最終葬地。郰人輓父之母與孔子母分存，不因同稱母而合併。

孟釐子病且死及「吾即沒」為預期，至「及釐子卒」才是明示死亡；季武子是歲卒另記。孔子年十七是來源年齡，不直接當數字年。弗父何、正考父及戴武宣公為引語祖系或任事，不能直接補任職曆年。第5段官職與去魯、斥齊、逐宋衞、困陳蔡、返魯是概述，後文具體行程不重複當同時事件。第6段孔子與南宮敬叔適周、孔子自周返魯有實行文字；老子送言中的近死與危身非本人死亡。

第8段景公、晏嬰適魯與穆公授五羖政事分當前敘事及引語回述。昭公奔齊、處乾侯、孔子適齊為高昭子家臣分記；景公欲以尼谿田封孔子未成，不作已授封邑。孔子返魯有實行文字。第11段昭公卒乾侯可存死地，季平子定公五年夏卒有明文。第12段防風氏為孔子引語古事，若存死亡須保留引語來源，不借當年；族類與神名不一概造個人。

陽虎欲逐仲梁懷及囚桓子後釋均不作死亡。陽虎定公九年奔齊有實際遷徙；孔子受公山不狃召、欲往而卒不行，不作居費。中都宰、司空、大司寇是先後任職，未知確切日期分存；夾谷攝相事不等於另受相爵。優倡侏儒為群體被誅，不補具名受害者。仲由為季氏宰與公山不狃、叔孫輒奔齊有來源，申句須、樂頎出戰不作死亡。少正卯定公十四年被誅明示；桓子「卒受齊女樂」的卒為終於，非死亡。孔子宿屯為行程，不補現代位置。

孔子適衞、主顏濁鄒家及十月去衞分存居處與時長，不把十月當曆月。顏刻與顏淵分存；孔子誤以顏淵死而顏淵回答未死，不能生成死亡。過匡被拘、過蒲、返衞主蘧伯玉家、去衞過曹等各按實際行程。南子見孔子及靈公同車不改作親屬主張；定公是歲卒有明文。桓魋欲殺孔子未成。適鄭、至陳主司城貞子家、居陳三歲與去陳均有來源；隼死是鳥，不是人物。

公良孺寧鬥而死是意願，不作明示死亡。孔子自蒲適衞有實行，靈公欲伐蒲而未伐不作戰事。佛肸中牟宰與孔子欲往分開，尚無完成旅程。師襄子教琴與文王操的解說保留層次。竇鳴犢、舜華死亡有明示回述，不借孔子旅程當年；孔子至河而未濟、息陬鄉、返衞主蘧伯玉家各分記。復如陳、靈公夏卒、蒯聵六月入戚及居戚有來源；本段魯哀公三年為明示同步，不據孔子六十歲倒推年月。

第39段季桓子預言自己即死與「後數日桓子卒」分開，康子代立、冉求被召將行不自動補任職開始日。第40段孔子自陳遷蔡為實行；蔡昭公欲如吳被公孫翩射殺，不作已抵吳。齊景公秋卒有明文，段首「明年」須核前段紀年語境後再換算。

影像、跨篇同指及數字紀年仍待續核；新資料尚未接入公開閱讀器。

第41–64段已讀：自蔡如葉、去葉返蔡、子貢至楚及孔子自楚返衞各有實行文字。荷蓧丈人「復往則亡」是離去，不作死亡。孔子困陳蔡、從者病不推死亡；昭王欲封書社七百里被子西止，不作已授。楚昭王秋卒城父明示死亡及死地。哀公六年與孔子六十三歲保留來源同步，後文其明年仍須核段落語境。冉有將師、孔子返魯與十四歲離魯時長分存，不能把十四當在位年。公華、公賓、公林被逐不補目的地或死亡。弟子三千、通六藝七十二人為群體，不虛造匿名個人。

第65–86段已讀：泛稱上大夫、下大夫、童子及三人不全造個人。顏淵死置於西狩敘述旁，應保留回述可能，不直接借哀公十四年；子路明歲死衞可存死亡及死地，原曆與跨段語境分開。孔子後七日卒及下一段哀公十六年四月己丑卒指同一死亡，採明確日期並保留兩段證據，不生成兩次死亡。夢奠兩柱不是實葬；孔子葬魯城北泗上、子貢廬冢六年均有來源。

第79–84段孔氏後裔逐項保留生子主張及來源年齡；伯魚先孔子死、鮒死陳下、安國蚤卒有明示死亡，其他只載年若干不擅加死亡日期。伋困宋不作宋人籍貫。子慎魏相、鮒陳王涉博士、子襄孝惠帝博士及遷長沙太守、安國當今帝博士至臨淮太守各分任事與先後，不補具體授任年。子襄為鮒弟，不改作兒子；延年及安國兄弟各用原ID，卬、驩的生子鏈保存。末段索隱述贊的防叔來奔與兩觀等額外說法另層，不偷偷補到正文。全篇判讀仍非身份、影像與稱號全史完成。
