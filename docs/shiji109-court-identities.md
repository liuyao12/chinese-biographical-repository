# 〈李將軍列傳〉漢廷及匈奴身份續核

十二組跨篇判斷保存於 `corpus/shiji/109-equivalences.json`，依既有固定見證的原句、逐人錨點及事件承接，接合張騫、公孫弘、韓嫣、衛太子據、衛青、韓安國、匿名遼西太守、軍臣、伊稚斜、且鞮侯、李陵匈奴妻及元朔五年右賢王。全部為代理暫定判斷，不冒填人工審閱。25個重複候選先更新全部引用，再撤登記與衍生 JSON。

軍臣依馬邑及李廣被俘定位；元狩四年幕北交戰為伊稚斜；李陵五千人出居延、降後四百還漢與嫁女事件則接且鞮侯。不能因同稱單于而混成一人，一度自立的右谷蠡王仍分存。元朔五年的右賢王也不與李廣遭圍的左賢王、天漢右賢王合併。

卷一〇九與一一〇的馬邑後「四歲／五年」及卷一〇九、一一一、一二三張騫出右北平的「後二歲／後三歲／其明年」原句各存，不為身份接合強制統一年份。遼西太守被殺及韓安國敗的相關敘次同樣保留。衛青的回顧用稱不提前軍中拜大將軍的授號日期。

李陵匈奴妻接卷一一〇既有父女組裝，保留兩篇父女陳述。且鞮侯沿兄弟鏈推定父系是既存編輯判讀，不變成卷一〇九明文；女兒的名、生母及排行未知。李敢女愛幸太子不轉作已證實配偶或其他子女生母。

卷四十九褚先生附文、卷一一二班固附文保持原文本層次；身份接合不把後出附文改作司馬遷親撰。原文、來源指紋與錨點位置不變。本篇潁陰侯孫、其他匿名者、代詞、稱號紀年及底本影像仍續核，不宣稱本篇完成。
