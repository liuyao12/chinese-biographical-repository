# 卷八十三〈魯仲連鄒陽列傳〉草稿

保存固定修訂2089252的27段正文，魯仲連至太史公論贊；全部段與HTML篇界已核讀，導覽、索隱述贊及版權排除。鄒陽獄中上書dd按原序。第2湣王、第7待增字，第9使刪字與第25巖改藪提示分存，正文保存增改前形式，巖巖不擅校。未核底本影像或現代研究。

帝秦建議與魯連辭爵不當實授，九侯有子不改女。聊城燕將未名、上書引古與短稱需逐段判讀。人物待標，未完成覆核。

前5段保存10個新候選與66處錨點。魯連短稱先生、平原勝及新垣衍衍按說話範圍暫接；帝秦建議不作實授。後22段及其餘嵌套指代待補。

第6至14段已作明示姓名首輪。秦將卻軍、保聊城燕將及其燕王各保留未名；九侯有子不改作女。梁王烹醢為假設，平原封魯連遭辭、田單欲爵而魯連逃隱，均不作實授。曹子、魯君及陶衛譬喻不依記憶補名；後13段待補。

第15至18段明示姓名首輪已保存。枚生、衛先生、卞和所事楚王及蘇秦所事燕王保持未定；王奢按原文不改為趙奢。鄒陽上書臣、大王與引古太子丹按句群區分，燕尾生譬喻未直接建立尾生人物。後9段待補。

第19至21段已作明示姓名首輪。范睢應侯、孔子孔及墨翟墨保存同句承接；威宣、朱象管蔡、省略主語聖王、季孫及由等短稱保留未定範圍。孫叔敖三去相僅為引古概述，未補造三段曆日任期。後6段待補。

全27段已作明示姓名首輪。隨侯之珠視為物名而不據此新增人物；伊管短稱保持未定。原文秦信左右而殺與堀穴巖巖未擅改。完整指代、身份與官爵證據待補。

已保存13項官爵用稱。引古官職與敘事當時任職分開，鄒陽出獄為上客的省略主語按上書承接保存；未知日期不補造。全篇336處錨點。

以范睢在魏受折脅摺齒及秦封應侯兩項配對事件，建立首項跨篇暫同指，沿既有canonical ID。其他人物跨篇判讀待補。

現存3項跨篇暫同指：范睢應侯、無忌及晉鄙，依受辱授侯、奪軍救邯鄲事件對照既有篇章。另保存九侯有子的父親來源主張，不改原文子為女，性別及姓名未定。
