# 琅邪王氏續讀：王琛、王翊與王翊墓誌

## 見證與核讀範圍

## 親屬與異文

| 項目 | 墓誌所見 | 正史所見及判讀 |
| --- | --- | --- |
| 王奐 → 王琛 → 王翊 | 首部「祖諱奐」「父諱琛，齊故司徒從事中郎」「公諱翊」 | 《南齊書》卷四十九記王奐長子融及「融弟司徒從事中郎琛」，並記二人在都棄市。《魏書》卷六十三稱翊為「肅次兄琛子」。父名與官職相合，支持三代生系。王奐出繼王球仍是上一批另存的承嗣關係。 |
| 王翊之字 | 首部「字仕翔」 | 《魏書》卷六十三及《北史》卷四十二所見數位本均作「士遊」。趙萬里判墓誌所載較可信。逐人 JSON 首選「仕翔」，保留「士遊」連回兩史。 |
| 《北史》父名 | 首部「父諱琛」 | 《北史》本段作「肅次兄深子也」，末又作「子琛」。前一句與《魏書》同一敘事位置，加上墓誌及《南齊書》的父名、官職，支持將「深」作王翊父名的異文。末句另有子代姓名差異，《魏書》作「子淵」。子代留待另核，不與父琛混接。 |
| 卒年與報齡 | 末部「春秋卌有五」，「永安元年歲在戊申十二月壬午朔廿日辛丑終於位」 | 《魏書》作「永安元年冬卒，年三十七」。《北史》該段只記「卒」。墓誌與《魏書》的年號和季節相合，原報齡為四十五與三十七兩說。趙萬里採墓誌報齡。逐人 JSON 保存兩項原數，首選四十五，生年留空。 |
| 葬期與葬地 | 末部「二年歲次己酉二月癸未朔廿七日己酉窆於洛陽西鄉里」 | 年號承前文永安。永安元年、二年的年度對照分別為西元 528、529。十二月卒日與次年二月葬日為兩筆事件。本文尚未換算西曆日。 |
