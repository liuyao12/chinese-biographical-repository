# 〈扁鵲倉公列傳〉開篇跨篇人物

十三組判讀接合趙簡子、董安于、扁鵲、秦穆公、公孫支、子輿、晉獻文襄昭諸公、高后及兩處有具體辨識依據的齊王。趙世家同一病夢的重複ID一併接合，不把夢中帝作現實君主或補夢中血親。

昭公時的年代疑點依索隱分層；齊桓侯依裴駰暫指田和子桓公午，傅玄是時無桓侯之疑並存，不與小白合。曾為陽虛侯的齊王僅接該處局部ID，與齊孝王將閭楊虛侯前後封號對讀，陽楊原字分存；其他齊王各處仍待核。

晉世家子襄公歡立明示父子，補文公至襄公父系；既有桓叔捷、惠伯談、悼公周沿來源鏈遷入同根。趙世家襄公曾孫周與直接父祖鏈的悼公周接合，曾孫主張保留，不另留闕代替身或重複祖先。

秦越人與淳于意按篇首姓秦氏名越人、姓淳于氏名意記可解析姓名，複姓不拆。身份接合及姓名呈現不補壽命、任期或病案絕對年；古注、正文、夢言及醫書引稱分層。全篇醫案及人物仍未完成覆核。
