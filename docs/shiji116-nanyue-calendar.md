# 唐蒙所稱南越王與建元六年

唐蒙上書的南越王接胡，依據是相同討越事件，不只共用王號。〈西南夷列傳〉以建元六年、王恢擊越與郢被殺起敘；〈南越列傳〉先記尉佗建元四年卒，續記孫胡為王、郢侵邊及被餘善殺，後段又直接稱胡。身份判斷保存兩篇原文與前任卒年引用，仍標 AI 暫定，不把黃屋左纛當姓名。

補標〈南越列傳〉「胡為南越王」的王號及下一段「往諭意南越王」，三處均指同一人物，不造新 ID。人物頁以來源中的南越王、胡組成標題，另列文王謚號；姓未由這兩段補定。

郢死亡的建元六年未記月份，改存十月歲首下前136至135年的範圍，保留原紀年與數值年。段首王恢大行、郢王號、唐蒙番陽令的用稱也有同一來源年範圍，但任期端點不變。唐蒙返報上書所稱胡的王號只記用稱，不把背景年作即位年；其他未明紀年的死亡亦不補年。
