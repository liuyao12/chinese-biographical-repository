# 〈田叔列傳〉死亡、紀年與任期約數

新增趙午、高后、田叔、田仁正文、田仁褚補及任安褚補六項死亡來源。田仁兩筆各存署層與原句，不把平行記載當獨立事件。高后死亡依既有本紀七月崩及年表對照前180年；田仁、任安依《漢書》卷066征和二年同事皆要斬，另以將相年表原紀年及編者西元欄換前91年。原段無明年，日期作編輯暫定，原文與date_expression不添加年份。田叔、趙午本批不猜卒年或死亡地。

漢中守十餘年保存排他下界十年，京輔都尉月餘後遷司直保存排他下界一個月，精確值與上限未知。年、月原詞及計數方式分存，不由時長推起訖，不由死亡終止全部官爵。驗證擴充年數餘字及不帶居的月餘，保留原有月數規則。

六處新增標記為文帝語中的先帝、田仁司直段三處上、趙禹曰吾及武帝曰吾；上書、上籍、河上等不標人物。既有籍貫、居留及少子父子陳述核查後保留，不重建。全篇仍未完成古注、版本與人物覆核。
