# 〈陳杞世家〉第二輪核讀紀錄

第1–8段核讀。
- p1 舜後為祖先主張，不補胡公滿至舜的缺代；舜媯汭居住有原句，非現代籍貫；舜崩明示死亡，封陳不是胡公籍貫。
- p2 胡、申、相、孝、慎公卒各分記，申相兄弟與相立申子不誤作父子。幽公前任慎卒無年。
- p3 周厲奔彘不作死亡，可保存遷徙目的地。
- p4 幽卒23、釐卒36、武卒15、夷卒3及周幽被殺分年次；秦始列諸侯為國家敘述，不憑此補某人授爵。
- p5 平卒23明示。
- p6 蔡女母子與文公妻分記，長子桓鮑可保存1，但須核既有親屬紀錄；文卒10。
- p7 州吁被殺在陳桓26、魯隱被弒在33，勿改成被殺者本人年次。
- p8 桓卒38正月甲戌己丑兩日赴告保存疑義，不擅定一天；五父與太子免遭殺各分記，勿借桓卒日。佗之母蔡女需和p6來源辨認，不按氏稱全庫合併。

第9–16段核讀。
- p9 敬仲完生厲2有年次，卜辭姜姓太嶽後保留引語預言，不據此補直系。
- p10 厲妻蔡女與p6文妻蔡女不按同氏合併。躍林杵臼長中少在免之三弟組，不能把躍作父親全部兒子序1。厲被殺7、利立五月卒、莊卒7各分時長／年次。
- p11 楚武卒陳宣3，陳女后為周惠王娶后；不把國名當出生地。
- p12 御寇被殺宣21、完奔齊；卿為辭任提議非已授，工正明授。齊懿仲欲妻為婚姻提議，卜辭未來五八世不補實際親屬世代。
- p13 陳轅濤涂被執不作死亡；申生被殺宣37。
- p14 宣45、齊桓穆5、穆16、楚成共6、秦穆共11、共18各卒分記，商臣弒父明示；未知死亡地不由城濮借址。
- p15 楚莊即位陳靈元，戰爭不造死亡。
- p16 泄冶殺靈14、靈射殺15、孔寧儀行父奔楚、午奔晉有據；夏姬御叔妻及舒母原句，不作君臣淫亂所生子。夏徵舒自立陳侯保存自立方式。

第17–33段核讀，32段正文及另層索隱述贊皆已讀。
- p17 徵舒誅成元冬；楚縣陳後復陳，午從晉迎立，封邑不是籍貫。靈死亡回述不重複新增。
- p18 楚莊卒成28、成卒30；楚喪罷兵不造其他死亡。
- p19 郟敖弒陳哀28。
- p20 哀34三月師遭殺、哀自經，四月陳使者被殺未名群體，不新增虛名人物；招卒立留的卒是終於，不當招死亡。留奔鄭，棄疾陳公明授。長少姬、長少妾分組排行不能直接合成子女序。
- p21 吳奔晉；太史趙祖系引語保留預言層，不補缺代父親；悼太子死亡回述不重複新增。
- p22 楚靈弒與管蔡篇異表述保留，陳惠追溯哀卒為元，空籍五歲不作實際已在位。
- p23 惠卒28依追改元年，不混成實際在位年數。
- p24 懷如吳、被留卒吳保存卒地及囚留；四年為出行起點，未知卒日不補。
- p25 楚昭陳湣13卒城父、齊簡21遭弒、子西子綦23遭殺、白公自殺分記；孔子適陳為訪行，在陳另有居處用語。
- p26 陳湣24被殺、孔子是歲卒，不由陳被滅推其他個人死亡。
- p27 杞東樓為禹後苗裔，不造直接父子或全部缺代。
- p28 杞武47靖23共8德18桓17孝17文14平18悼12釐19湣16哀10出12死亡分記；隱七月被弒，簡立一年國滅未明死亡。謀娶以前只生子不造卒年。
- p29–32評語及國滅不作個人死亡；契后稷皋陶伯夷伯翳垂益夔龍後裔保留祖系範圍，不補缺代。
- p33索隱另層，後虜非死亡，句踐田和評述不混正文事件。

稱號核對：67筆既有稱號包含工正實授、陳侯自立及復立，不重複新增。太子午p17迎立成公可另判太子終點；留p20太子至陳君在同段可保存來源事件終點，但不得借哀公死亡日。其餘死亡不批量終止爵位。惠公追改元年與真正復立起點分開。
