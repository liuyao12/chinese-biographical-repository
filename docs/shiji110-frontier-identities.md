# 〈匈奴列傳〉邊將身份續核

全61段重新通讀後，以具體職爵、軍役及家世接合四組人物，非全庫同名替換。韓說依太初三年游擊、五原外列城，以及橫海擊東越、龍頟侯／按道侯與弓高侯家世，接卷九十三韓嫣之弟。衛伉依長平侯繼爵接衛青長子；路博德依衛尉、伏波將軍破南越及後為彊弩都尉屯居延，接同一人物；右將軍建依與趙信并軍三千餘騎、軍敗身脫，接卷一一一明名蘇建。

四組判斷保存逐人錨點、原句與代理暫定狀態，更新引用後撤六個舊ID。韓說原未決案件保留案號與歷史說明轉為已接合，漢貴人、未名太子與弔使右賢王三案仍未決。元鼎六年任橫海與元封元年冬入東越各存；第60段後二歲及巫蠱、降匈奴的敘次問題不改原文或強作連續任期。

衛伉的D只是分支字元；長子排行一來自卷一一一原文，不改成第四子。宜春侯與長平侯分開，死亡、軍敗、贖為庶人與失侯不相互替代；居延駐屯不改為路博德籍貫或死亡地。

開篇周秦晉趙人物及其他指代、紀年與書影仍續核；淳維至頭曼千餘年不可次的世系不補造。全篇仍未完成學術與版本覆核。
