# 〈李斯列傳〉皇帝立號、即位與二世死亡年

依本篇具體事件對讀固定《六國年表》原格與分開的數位西元欄，補始皇尊皇帝前221年、胡亥襲位二世皇帝前210年、二世被劫令自殺前207年。保存全文、原始事件字串、原表格ID與西元對照欄ID，數字年以天文年編碼另存，僅精確至年，仍為AI編者暫定；未核書影，不改正文。

胡亥襲位在三十七年格，二世元年則為下一格前209年，不能混成同一事件。〈秦始皇本紀〉同段九月修飾葬始皇，不補即位月。胡亥太子之立由改書政變而來，保留既有來源事件但不在本批另補年月；二世皇帝的事件種類改記即位，兩個皇帝稱號歸帝號類別。
