# 卷四十九收錄範圍

維基文庫固定修訂7903610共44段史文，取得時HTML與固定版本一致。全篇已核讀；第1至34段為篇文，第35至44段自褚先生曰起標附載層，數位分節欄題不作古文段落。只去外緣空白，未轉換字元；保留（寒）［暮］、［及尊］、（子）［一］及號日等原字與校勘字樣。

全44段明示人名已作首輪，共465處錨點、98個新增候選與98項身份判讀、48項親屬來源主張、63項稱號與6項跨篇暫同指。群體、代詞、未名親屬與制度稱號保留未解，不宣稱全人物完成；complete保持false，進度接續卷五十。涂山、有娀等氏族／人物指向未定；薄氏未名父親與薄案暫分候選，不補姓名。武帝趙人王夫人與景帝王皇后分開，代王按文帝及少子武的局部敘事分指。

親屬按子女、父母、兄弟姊、祖孫與婚姻分型，不把臧荼與臧兒祖孫改父子，不由後宮收養敘述補生父母。榮太子、薄皇后與陳皇后的明示廢黜記終點事件，其餘死亡不終止全部稱號；追尊薄案、竇后父及王仲標死後用稱，褚先生為郎屬回敘。授予事件沒有可核日期時只保存事件位置，不換算任期。娙娥、娙何、容華、婕妤秩比原語不作每個人物都曾任各級的證據。

與文帝、景帝、孝武本紀逐段對讀迎代王、薄昭封軹侯、廢栗太子為臨江王、王夫人立后及其子繼位，保存6項跨ID暫同指。各已發ID保留，同指不代表篇文互為獨立見證，不由本紀日期補此篇或擅定來源優先。尚未核影像、可靠底本或現代研究，未宣稱人工審閱。

第29段青三子與第36段附載衛青四子原語各留位置，不調和或改寫；第42段武帝年七十及昭帝立時年五歲亦保留，不換算年代。褚氏文字與其中鐘離生問答不另作獨立見證。其餘親屬、婚姻、諸侯封號、后妃稱號及授予／廢除須續作覆核，死亡不代替爵位終點。
