# 《史記》分類閱讀器

既有 ren-wen 網址的空白首頁提供文獻入口；原有 `#eccp-...` 及其他見證錨點仍開啟原 ECCP 閱讀器。`shiji.html` 列出全130篇，按本紀12、表10、書8、世家30、列傳70分類，而不是固定數量分組；篇名引用有版本的維基文庫全書目錄。未匯入正文者仍列目並明示狀態。

目前112篇原樣匯出 CBR 標註 JSON，兩張年表另接連續表格介面。閱讀端按 Unicode code point 使用已保存的人名錨點，不作重新辨識或全域同名合併。人名下劃線、懸停及鍵盤聚焦身份摘要、點擊來源段落及完整人物 JSON 入口均由一般 JavaScript 執行。段落、提及及人物 ID 不更動。未定指稱保留點線，不假裝已識別。

`data/corpus/shiji/` 是 `corpus/shiji/` 的原樣公開副本，`data/corpus/persons.json` 只供身份摘要，不取代 `exports/persons/` 完整有來源的 JSON；人物面板連到 GitHub 完整資料。`scripts/reading_catalog.py` 可重建分類索引及副本，`--check` 檢查同步。執行人物匯出腳本時一併更新閱讀器資料。所有後續資料修改需先重建，再跑同步檢查；請勿直接改公開副本。

程式及編輯來源保留於 CBR，ren-wen Pages 以明示 CBR 提交發布；不建立新公開網址。首頁按篇目導覽，《史記》頁提供分類、篇名／卷號搜尋、來源固定版本、篇目 JSON、相鄰篇切換及可分享段落連結。手機仍可操作分類及人名，英文模式只翻譯介面，不改史料或篇名。

實際 HTTP 驗收：`tests/browser_historical_reader.py --url <網址> --output <暫存目錄>`，包含首頁、五類篇數、秦始皇127段、人物身份與來源、年表轉置及合併格、末端搜尋、年份跳轉、語言、手機及舊 ECCP 深層連結。

本次驗證：九項既有驗證、112 份 XML 同步、閱讀器副本及表格驗證、163 項 JavaScript 測試與語法、7,310 份人物 JSON 匯出及 353 項 Python 測試（430.246 秒）通過；新增及既有發布瀏覽器驗收均通過。
