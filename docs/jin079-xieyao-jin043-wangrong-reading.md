# 謝瑤支與王戎本傳逐人閱讀

本批接續已凍結的謝氏、鍾氏資料，新增來源身份及逐人標記，不將標記完成視為親屬、稱號與紀年的全部整理完成。人工覆核為否，未作影像校勘。

## 《晉書》卷七十九謝瑤支

固定維基文庫修訂2645985，補入羊曇哀謝安、瑤與該模承伯、澹奉謝安祀三個完整原段，共23處人物標記，21處定指。新增瑤、該、模、承伯、澹五位來源人物；既有謝安、謝琰、羊曇、曹植、劉裕、桓玄、王謐重用原有身份。

「無子，弟光祿勳模以子承伯嗣」分開保存模之子與該的嗣續語義，不把承伯改為該的生子。「該弟澹」與其他段落「從兄護軍淡」尚無足夠同人證據，保留分立。琅邪王友中的王尚未定指，不由官稱自動填人。

## 《晉書》卷四十三王戎本傳

固定維基文庫修訂2618531，從王戎傳起至從弟衍附傳前止，十四原段、198處標記，其中188處定指、10處未定指；不代表全卷已覆核。新增25位來源人物，重用30位既有人物。

魏明帝幼年觀戲、平吳及居喪時武帝、惠帝八王亂分屬不同敘事時域。戎父涼州刺史渾與王濟之父太原渾分立。博士王繇與東安公司馬繇分立；武帝問孝的劉毅與劉裕時護軍劉毅分立。裴頠以卷三十五固定原文及遇誅事件交證既有秀子頠，不將「裘頠」候選逕行合併。

末段萬、庶子興、從弟愔及愔子各有來源身份；不補愔子名字，也不把奉嗣與生父混同。「母」未升格為已知生母；女、從子、趙王倫子保留原文限定。鐘會、季劄、𦃩、報嘗及原缺閉引號照錄。

## 待接續名錄辨識

《古今同姓名錄》卷上王渾條的「一戎父（晉人）」先前因缺本傳而未定指；本批王戎傳已有父渾涼州刺史的完整原段。後續應將戎及父各作精確人物跨度接合，群組題頭「二王渾」仍保留未定指群組，不能連成一位人物。此處僅記待辦，不宣稱該名錄標記已完成更新；名錄不反向取代本傳的父系證據。
