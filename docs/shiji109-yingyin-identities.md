# 潁陰侯祖孫：正文、古注與年表

〈李將軍列傳〉「故潁陰侯孫屏野居」不把屏當作姓名。《史記三家註》卷一〇九《集解》《索隱》的數位轉錄均釋「灌嬰之孫，名強。」固定修訂2514779，回應指紋保存於身份判斷之引用。兩注在同一數位見證中，不計作兩份獨立史料；未核書影。ctext本篇存取回應403，沒有以搜尋摘要冒充核讀或繞過限制。

按該注及卷九十五「子平侯阿代侯……子彊代侯」，暫接故侯為灌嬰、未名孫為彊。古注強、正文彊保留原字，原文及原有錨點不改。祖父原斷言仍存；現有兩代父子鏈可由阿追至嬰，不新造父親。另一「灌嬰孫賢」仍為不同人物，父親未知保留缺代，不因同為侯孫或續爵而混人。

〈高祖功臣侯者年表〉潁陰列的彊與賢，各按同列爵系、有罪失侯、臨汝續封及行賕除國連結卷九十五原段。年表「元光二年」與傳文「元光三年」分存；平侯「何／阿」尚未核定，不為整齊而改字或合併其候選。既有年表原格、人物錨點、紀年及版式均保留。
