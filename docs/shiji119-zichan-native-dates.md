# 子產原生年表標記、授卿年與卒年取捨

《十二諸侯年表》鄭欄七處子產各自建立人物錨點，另解季札引語中的兩處受話人子、子孔作亂與子成止之。原季札錨點保留；不標整格，不改原表文字、欄序或編者西元欄。

子孔依鄭簡公時同一內亂與誅子孔敘事接本傳。子成僅依原格獨立登記，沒有足夠證據接齊國崔成、子皮或正文匿名公子或；不補姓名成分、親屬或生卒。升格原生表格證據的人物須收齊全部表內既有提及，不能只索引本批新格。

授卿記錄保留本傳「十二年」，按原表「十二子產為卿」與另列數位西元對照換為前554年。它是授卿事件，不是相的任職始年；卿的終年仍未知，「治鄭二十六年」不倒算任期。列大夫原說明誤留他人三月為相、三得相三去相的語句，本批只修正編輯說明，來源引文不變。

本傳「聲公五年」與年表鄭欄「五子產卒」按數位對照同指前496年，保留為來源日期。另以《左傳》昭公二十年病卒、孔子聞卒敘事暫取前522年，參考固定提交 `dc3dc18e0039e05679d98bc650c2f980f8dcabac` 卷十第10452至10527行，並以原表魯昭公二十年與數位西元對照換年。兩種日期都有機讀數值、原引文與來源，首選另存決定，不改收到的紀年。

昭公二十年只定到年；沒有本次核讀所得的確切卒月日，不補十二月，不由病數月推算。公元前數值與天文年編碼分別保存，前522年為天文年負521。數位西元欄是編者對照，不當作古籍原字，也不將《史記》同書兩處記載當獨立票數。

文字來源未核書影，所有身份及日期取捨仍為代理暫定。其他年表提及、〈伍子胥列傳〉事件年代及版本校勘仍在續核，並非全篇或全表完成。
