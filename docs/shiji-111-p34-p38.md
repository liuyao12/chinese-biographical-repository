# 〈衛將軍驃騎列傳〉第34至38段

續標蘇建、趙信、張騫、趙食其與曹襄五段，正文與字元錨點同步保存。蘇建杜陵、趙食其祋祤保存傳首出身地；蘇建冢在大猶鄉、張騫冢在漢中保存葬地，不推現代位置。蘇建卒、張騫為大行而卒明記死亡，年份未定，不從任官地或使通目的地補卒地。

「亡翕侯」承前段趙信降匈奴，不能記為死亡。趙信小傳武帝立十七歲與前段定襄軍役的紀年仍需對讀，暫不強換算。

蘇建游擊、右將軍軍役按[《資治通鑑》卷19](https://zh.wikisource.org/wiki/資治通鑑/卷019)元朔五、六年的同人同事件，分別暫換算前124、前123年。只取年精度，原篇後四歲、後一歲保持原字，不串算。平陵侯與博望侯的小傳重述追加既有授爵記錄的用稱；贖為庶人保存明示失爵事件，確切終年續核。

「曹參孫」先保存為祖先後裔主張。已對讀[〈曹相國世家〉](https://zh.wikisource.org/wiki/史記/卷054)參—窋—奇—時—襄的序列，不把孫直接解成兩代祖孫，不在本篇補造父親。新曹參來源候選保持自己的ID，與他篇同指及曹氏父系組裝仍待具體證據決定。

本批未核影像，姓名初標與身份覆核並非同一狀態；第39段以下尚未標註，新卷篇未接線上閱讀器。
