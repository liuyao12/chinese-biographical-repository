# 西南夷篇的任官安排與日期範圍

「約為置吏，使其子為令」保存唐蒙與夜郎侯多同的任官安排，實授與履任未另記；不把約定當已持有官職，也不反推明示未實行。移除原 th-shiji116-009 的實授判斷，另存 tp-shiji116-duotong-son，保留其子人物錨點、父子來源與原句。約詞與職稱用獨立字元錨點，不將令字冒作人物。

唐蒙的「乃拜蒙為郎中將」有實拜原詞，原年建元六年依固定年表及十月歲首保存前136至135年範圍；不補公曆月日。段末司馬相如使西夷不沿用唐蒙的背景年，另保原用稱、未知始末。〈司馬相如列傳〉治道二歲道不成後才敘使西夷，是另一次任務；本批不因此另定確切年份。

人物頁分列任官安排（實行情況未載）與原有明記未實行的稱號提議。資料仍可由一般程式處理，沒有運行時自然語言分析。固定數位正文《史記》卷116修訂7903636、原年表卷22修訂2607038，未核書影。
