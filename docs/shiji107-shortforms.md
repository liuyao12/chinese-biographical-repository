# 〈魏其武安侯列傳〉回稱與合稱補標

本批在固定見證的原28段及原提及範圍不動的情況下，續補79處人物錨點、13項有具體篇段與提及證據的身份判斷。資料仍由程式直接使用，閱讀時不做 AI 辨人。

籍福先說武安侯，將軍指田蚡；後賀魏其侯，君侯指竇嬰。不能因同段就維持同一受話者。高遂對魏其的將軍指竇嬰。田蚡為相後宴飲、求田、廷議的丞相及規諫引語中的君，按當前說話者及受話人分別連結，不將所有官名當人物。

兩處程李各分成程不識與李廣的相鄰單字錨點，不造一名程李。其同段姓名、李將軍及既存跨篇接合可回查；《集解》引如淳辨李將軍為李廣另存，固定數位見證為[卷107修訂2514777](https://zh.wikisource.org/w/index.php?title=史記三家註/卷107&oldid=2514777)，未核書影。

灌夫請復往與將軍壯義之的將軍接潁陰侯灌何，太尉對讀〈吳王濞列傳〉接周亞夫；誓語所欲取頭的未名敵軍將軍不接灌何。吳王依同次吳楚之亂及平行篇明稱接濞。沒有由誓語生成死亡事件。

太子傅是竇嬰的官名，不把內含太子二字拆成皇儲；另兩處獨立太子指栗太子。景帝遺詔中的論上與武帝敘事中的聞上分開，前者仍接景帝。淮南王安前朝的王、大王只作回指，不用後來謀反案的紀年倒填太尉任期。

本批沒有新增人物、親屬、官爵任期或生卒。第七段太后仍保留王太后與竇太后兩候選；原文、來源指紋與既有錨點不改。所有新身份判讀為 AI 暫定，未宣稱全篇完成或人工核定。
