# 〈田儋列傳〉其餘戰役人物

依田榮助陳餘反趙、楚漢間彭越梁地活動、酈食其弟酈商及攻齊共同戰役，接合十組身份，撤除十三個候選 ID。龍且高密戰、田廣與其相田光及膠東田既、華無傷／華毋傷歷下軍、田解、田吸千乘戰各有對讀引文。

齊守相田光與燕國刺客敘事田光保持分人；田廣仍依本傳為田榮子，不由齊王稱號推父系。華無傷／華毋傷原字分存，不宣稱書影校勘。相／守相、斬殺及俘獲戰功各篇各存，身份接合不消去事件敘事差異。

同書跨篇不當獨立見證，未核書影；安期生、篇末署名、匿名人物、生卒與紀年仍待逐項覆核。
