# 〈樂毅列傳〉第二輪核讀

全20段依現有數位正文核讀，來書、答書的說話者及先王指代各按篇內範圍辨識。趙武靈王、魏昭王、齊湣王、秦昭王、趙惠文王按沙丘、兩帝去號與合兵伐齊事件逐項接合；原文及字元錨點不變，同書不當獨立史實見證。

〈伍子胥列傳〉另一夫差候選另以兩篇太子夫差伐楚取番、楚去郢徙鄀事件及闔廬使立太子夫差原句接合；所有親屬、家族與來源引用先同步，再撤除舊ID。引古段的伍子胥、闔閭、夫差另依本傳伐楚及浮江事件接合，共撤除九個重複候選，人物6606→6597。不同篇年序分存，不因同指調和。

樂羊為樂毅先祖，不補直接父親；樂毅之孫樂叔保留闕代，樂乘為樂閒之宗不補兄弟。河上丈人至蓋公為師承，不作血親。伍子胥引古首吳王為闔閭，後吳王為夫差，不全域替換。樂毅五歲／其他篇六歲、騎劫戰敗與死亡等差異分存。

魏文侯、樂羊與其餘引古人物、匿名角色、完整稱號時段及底本影像仍待覆核，不宣稱全篇人物完成。所有跨篇判讀仍為代理暫定，未冒稱人工審閱。
