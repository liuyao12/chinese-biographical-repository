# 卷六十七〈仲尼弟子列傳〉逐段標註中

固定數位修訂7869003，152段正文已核讀保存；頁首ws-header中的弟子導覽名單、後附索隱述贊及現代版權告示不混入正文。保留髙、歳、衞、漆彫、曾蒧等原字；尚未核底本、影像與現代研究。

第1至152段明示人物首輪有734處人物或未解錨點，134個新增候選及134項篇內身份判讀；全庫3992個候選。首段師、參、柴及字稱以後文姓名解說作證，既有ID與判讀ID保留。

季孫與季康子暫分候選，不斷言異人。石乞不按同名接伍胥篇人物。冉雍父、商瞿母與公西赤母保存未名。原憲字子思不接孔子後世子思；第71段子貢所稱夫子指原憲，第90段夫子指代未定。第83段田子莊何與楊何的短稱何依句位分辨，傳易次序不是世系。

引古羿、奡、禹、稷保留傳說性。未名家屬、群體、代詞及宰我與田常作亂等版本疑點仍待覆核。已保存10項來源親屬陳述及26項稱號記錄；其餘親屬、稱號時段及跨篇身份尚待補錄。

全152段明示姓名首輪已保存，來源陳述與身份覆核尚待接續；人物首輪不等於全篇覆核。

以其子妻之與以其兄之子妻之分存兩位未名配偶；修正五丈夫子中的夫子誤標，五子保留群體未解。

已保存5項跨篇同指判讀，孔子、宰予、端木賜、顏回與仲由按共同師生敘事核對；南宮括與南宮敬叔尚未合併。

本批13項檢查通過，含165項Python測試及155項JavaScript測試；人物首輪之後接續卷六十八，全篇覆核未完成。
