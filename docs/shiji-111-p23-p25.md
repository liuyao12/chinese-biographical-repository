# 〈衛將軍驃騎列傳〉第二十三至二十五段

本批新增21處人物錨點、三筆親屬陳述、三項跨篇暫定同指、衛青死亡記錄與十一筆官爵／謚稱用稱，並補三侯明示失侯終點。本篇仍為首輪整理，尚非完成身份、版本及官爵覆核。

## 衛青三子與褚補四子

第6段具名青子伉、不疑、登；第23段明記長子宜春侯伉及伉弟二人陰安侯不疑、發干侯登。伉保存 `birth_order.ordinal: 1`，範圍限兒子；兩弟各記與伉的相對先後，不定彼此第二、第三子或同母。

〈外戚世家〉第29段正文說青三子，第36段褚補說四子及長子伉的三弟封侯。兩層原文並存。暫將本篇三個具名候選接到褚補的長子伉、陰安侯及發干侯候選；褚補額外匿名宜春侯 `5dd_l1c_6g8_C` 不與伉合併，保留人物 ID、原文與父子主張。

`ft-shiji-wei-extra-son` 暫採三子作預設，從 `preferred_relations` 排除 `a-shiji049-045`，原始 `relations` 仍保留。此為可撤回的局部判讀，未宣稱額外候選必不存在。人物索引為此候選標「來源候選；預設不接父系」；ID中的來源家族路徑不能代替預設世系判斷。

## 官爵與日期

第23段原文未明年號。平行記載提供年精度的暫換算：

| 事件 | 參考 | 暫定年份 |
|---|---|---|
| 伉失宜春侯 | 《漢書》卷18元鼎元年坐撟制不害免 | 前116年 |
| 不疑、登同次坐酎金失侯 | 同表不疑明記元鼎五年；本篇明記兩人同事 | 前112年 |
| 衛青卒 | 《漢書》卷55元封五年青薨；徐廣注同年 | 前106年 |
| 伉嗣長平侯 | 《漢書》卷18太初元年嗣侯 | 前104年 |

換算保存原篇事件引句、平行事件與明示紀年引句，以及《資治通鑑》對應數位年標，`date_expression` 不把參考年號抄成原篇文字。後五歲、後二歲、其後四年、十四年保留原語，不強改或當精確公曆長度。第25段六歲失侯是伉的長平侯任期，與先前宜春侯失侯分開；源年數保存為6，終年未定，不以算術補年。侯表五年闌入宮另存為對讀參考。

衛青烈侯記身後謚稱。第25段尚平陽長公主記婚姻，不推她為三子的生母，也不據婚姻敘事倒定承爵年份。第23段冠軍侯國除承嬗絕後敘事，不另作霍去病死亡。

## 修訂嬗承爵年

上一批暫將嬗承爵放在父卒元狩六年。侯表明記元鼎元年哀侯嬗嗣，故改為前116年的暫換算：死亡與實際承爵是不同事件，不自動同年。正文居六歲仍保存6；侯表七年薨另存參考，未強解計年差或修改正文。
