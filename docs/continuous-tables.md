# 史料表格的連續閱讀

閱讀器應將同一張史料表跨頁的內容呈現為可連續捲動的表格，避免讀者必須逐頁翻閱才能追蹤人物、世系或年代。目前已有《十二諸侯年表》及《六國年表》的完整數位表格試點；發布狀態見閱讀器部署記錄。

確認接續的表格預設使用連續閱讀；翻頁不是繼續閱讀的必要操作。保留「按原頁檢視」選項，讓讀者對照版本。此功能列為側項，不改變本紀、世家、列傳優先收錄的次序；實作時先以一張實際核讀的跨頁表作為試點。

## 原文與閱讀呈現

原書頁界仍是來源資料的一部分；連續閱讀只改變呈現，不刪除頁碼、重排史料次序或改寫原文。每列與每個儲存格保留穩定 ID，並可追溯至著作、卷、篇、版本、原頁及影像連結；尚未核對的影像位置保持未定，不補造座標。

跨頁的重複欄題可在閱讀模式中收起，欄題固定顯示以便長表閱讀；仍能查看各頁原有欄題。原頁起點保留可見的頁碼標記，點擊儲存格可開啟其來源位置。寬表另提供橫向捲動，不為配合螢幕寬度而改變欄序。

只有確認屬於同一張表、且欄位對應明確的頁面才接續。接續判斷及依據保存於資料，閱讀器以一般程式套用，不呼叫 AI；不確定處顯示接續未定，保留分段。原始頁片段可隨時查看。

## 表格收錄要求

同一版本中的一張表有穩定的表 ID，下屬原頁片段各自保留 ID 及來源。另存片段的閱讀次序、接續方向、欄位對應及判讀依據，避免假設下一頁必然是往下追加的列；寬表可能在下一頁接續右側欄位。不同版本的表不直接拼接。

儲存格分別保存原文、原頁位置、原始跨列／跨欄範圍及人物提及。連續顯示位置是派生資料，不取代原頁位置。跨頁拆開的同一儲存格，只有在來源足以核定時才建立接續記錄；不靠相同文字自動合併。

欄題是否重複、是否可收起也須有明確記錄。欄題改變時顯示新的欄題，不為追求單一表頭而隱藏差異。頁碼標記不應插成資料列，亦不應截斷跨列儲存格或支系連線。

## 世系表的特殊要求

空白、合併儲存格、跨列跨欄、世代層級及支系連線都須保留；空白不推定為缺名人物，視覺相鄰不推定為親屬關係。跨頁接續不能自行補上父子關係或闕代。表中人物提及連到人物 ID；關係判讀仍須有獨立的來源陳述與證據。

## 驗收

- 同一表跨頁可連續捲動，原文次序、欄位及支系結構不變。
- 連續閱讀為已確認接續表格的預設；到達原頁末端不需要點擊下一頁。
- 向下接續的列與向側方接續的欄各按已記錄的對應呈現；不同版本不混接。
- 任一儲存格可定位至原頁；來源連結可分享並直接開啟對應位置。
- 重複欄題的收起不丟失原始內容；可切回原頁分段檢視。
- 未定接續及不規則欄位不被靜默合併。
- 手機上可縱向閱讀與橫向查看寬表；固定欄題不遮住內容。
- 長表按需載入時，搜尋、跳轉及回到既有錨點仍能到達尚未載入的列。

## 2026-10-12 連續年表試點

`shiji.html` 的篇目閱讀區讀取 `data/historical-tables/index.json` 與各表 JSON，635 個年列全部連續呈現。提供縱向／橫向時間軸、固定欄題、按年跳轉、原文搜尋、儲存格來源詳情、可分享錨點及 JSON 下載。轉置只交換格位及跨列／跨欄跨度，不複製或改寫儲存格；《六國年表》末段合併八欄保留。

西元欄保留維基文庫固定版本的編者年份對照及原始數字，儲存數字年份、BCE／CE、天文紀年和年精度。不把紀年對照當作精確公曆月日，也不引用來源欄的維基百科外連作權威。文本的異體不轉換。每格保留原始數位列、儲存格次序、合併範圍與穩定 ID。

目前兩表各來自一張完整數位轉錄表，印本頁碼及影像位置未知；這不表示任意跨印本頁的接續已核定。一般多片段資料只有同版本、同欄題且明示確認的列方向接續可合接；未定接續、不同版本、欄題改變及尚未實作的橫向片段接續會拒絕，不猜測拼接。世系表及更多版本的原頁比較仍依上列要求後續收錄。結構匯入不等於人物標註或逐格學術覆核完成。

資料驗證：`python3 -m scripts.historical_tables validate`。模型與瀏覽器驗收包含原字不變、跨欄轉置、末端搜尋及跳轉、BCE／CE、未定接續拒絕與手機捲動。

西元對照只顯示一次：縱向置於第零欄，橫向置於第零列，明示「編輯補充」，不標記為傳世原文。橫向不另複製年份表頭；原文儲存格 ID、文字及合併範圍保持不變。

年表與本紀、世家、列傳共用《史記》篇目導覽；直接選取卷十四或卷十五即可閱讀與切換時間軸，無須離開閱讀器。舊 `tables.html` 連結轉至對應篇目，保留方向與儲存格錨點。正文與年表均從網站部署的 CBR JSON 讀取，不即時向維基文庫取文。固定轉錄版本仍須於首輪後對照可信底本覆核；異文、校改依據及原轉錄保留，不把數位轉錄當作完成校定。
