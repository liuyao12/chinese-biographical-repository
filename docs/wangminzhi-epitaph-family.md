# 墓誌人物接入琅邪王氏

《王閩之墓誌》明載誌主為彬之孫、興之之元子。保留兩項原始親屬陳述；興之為彬子另作相鄰世代的編輯推導，標 `contextual_provisional`，不偽造墓誌直接父子原句。未親見原拓的資格不變。

興之接為 `7r6_k52_qji_ABDBC`，閩之接為 `7r6_k52_qji_ABDBCA`。彬原有彭之、彪之及其後裔完整保留，分支字母C不表示興之排行第三。現有王氏組裝由77增為79人，全部人物總數不變。施氏及三弟維持原身份；弟稱只支持各自年幼於閩之，不指定共同父母或同母。

人物頁由資料追溯父、祖、曾祖：誌文明記祖彬優先顯示，同時保留經父興之推導的路徑及資格。興之的父系推導在頁上標為暫定，不混同直接原文。上代既有推導資格不因接合而消失。

目標樹原生驗證及76項墓誌／祖先回歸測試通過；83份受影響人物資料局部重建，12次桌面／手機人物頁驗收通過。彬的原兩子及新接興之皆可導航；三弟未獲無據父母。四個退休JSON在工作版本均回傳404，生成JSON／Markdown無舊引用。完整批次匯出與公開發布仍須另行驗收；尚未更新正式網站。

尚待下一批：墓誌所記父贛令、祖尚書左僕射／特進／衛將軍及妻吳興籍望。有效期間未知，不用誌主卒年填任職起迄，也不把祖官稱一律當生前實任。
