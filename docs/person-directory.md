# 人物目錄

公開入口為 [CBR 人物目錄](https://liuyao12.github.io/ren-wen/cbr.html)。目錄以現行人物登記為計數單位；異名與舊索引入口不另算一人。

姓名排列沿用 jiapu-mp：`稱號〔籍貫〕姓＋名`，字、號置於較小的楷體括號內。缺載部分省略。姓名沿用人物頁的結構化姓名共識及逐筆字形判讀；原文稱呼、引句及來源不改寫。未能可靠拆分姓名時保留人物標籤，不以字串切割猜姓氏。稱號僅顯示已有明示選擇或既有單一姓名記錄中的稱號，不按官階任選一職。

側欄提供朝代、姓氏、籍貫複選。同一組選項取聯集，不同組與搜尋條件取交集。各選項的人數套用搜尋及其他兩組條件，保留本組所有可選項；同一人物在單一選項只計一次。跨朝、多籍貫的人物可出現在多個選項，故各項人數之和未必等於總人數。尚未有據分類者列為「未載」。搜尋、分頁及已選篩選保存在網址，介面語言切換保留狀態。

朝代沿用已錄紀年對照的原標籤，不在目錄另猜同名政權；這是有據紀年的目錄對照，不是國籍、效忠或唯一政治歸屬。只採本人結構化生平及可用持職紀年的明示朝代，不由史書成書年代、祖先、親屬或引古文字推斷；追贈及未決紀年不自動擴大分類。籍貫僅採已有籍貫／傳首出身欄，不把出生地、居住地、葬地當作籍貫，也不換算今日行政區。

目錄由已匯出的人物資料生成一份精簡 JSON；瀏覽時不逐一下載全庫人物頁、不使用 AI，也不從文句推斷缺失欄位。來源定位保留於目錄資料，完整引文由人物頁查閱。資料增補後須重新產生目錄，並以既有閱讀器同步檢查驗證。

## 部分人物更新與目錄重新生成

`table_person_profiles.build(root, person_ids=...)` 保留原有部分更新契約，只寫所選人物與 profiles 索引，不自動掃描或改寫全目錄 metadata。部分更新完成後，如需同步人物目錄，明確執行 `python3 scripts/person_directory.py`（或 `person_directory.run(root)`）；此步只讀已匯出人物 JSON，不重新 bundle。正常全量 `table_person_profiles.build(root)` 仍在全部 profiles 完成後自動更新 metadata；原正常 exporter 的 calendar → reading_catalog → profiles 次序不變。
