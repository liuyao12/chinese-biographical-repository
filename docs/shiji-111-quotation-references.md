# 卷一一一末段引語指代

第47段「蘇建語余」的余連到本段太史公來源候選，蘇建引語的吾連到蘇建，願將軍的將軍連到受勸的衛青。末句「驃騎亦放此意，其為將如此」的其承驃騎連到霍去病。第48段「身尚平陽」的身承青連到衛青，仍保存索隱附載文字層。

上述五處以字元位置、原詞及來源人物 ID 保存，均為局部上下文的暫定判讀。登記表內原詞只記錄特定提及，不能把余、吾、其、身當作可全域匹配的人名。太史公未在本批改為司馬遷；父子皆可使用該稱號，須另核敘述者證據。

「彼親附士大夫」的彼尚待語法覆核，不強定為竇嬰或田蚡。「人主」「人臣」「古名將」為泛稱，沒有新增具名人物；「勉之哉」的之未作人物錨點。全卷指代與版本覆核仍未完成。
