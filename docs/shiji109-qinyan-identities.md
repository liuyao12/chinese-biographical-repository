# 〈李將軍列傳〉秦燕人物接合

依卷一〇九開篇的秦將、追逐燕太子丹事件，對讀卷七十三及八十六，接合李信；燕太子丹另對讀卷七十一燕王喜遣其入質秦及歸燕敘事。兩項判斷、原句與逐人錨點保存於 `corpus/shiji/109-equivalences.json`，屬代理暫定判讀，未冒填人工審閱。

李廣「其先曰李信」仍是未知世數的祖先主張，不轉作父子，不強接李廣與李信的家族根。卷七十三「卒破得丹」及卷八十六「燕王乃使使斬太子丹」原字分存，接合同一人物不等於判定死亡行為人。卷七十一入質與歸燕也不據此校改其敘次或年份。

三個重複人物登記在全部引用更新後撤除，不保留舊 JSON 入口；段落、提及與原關係斷言 ID 保留。未變動原文、表格、紀年或來源圖像覆核狀態。〈李將軍列傳〉的單于分期、公孫弘、韓嫣、衛青、太子及匿名人仍續核，本篇未完成。
