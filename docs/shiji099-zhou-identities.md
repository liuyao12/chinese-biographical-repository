# 〈劉敬叔孫通列傳〉引古周先身份覆核

依本篇劉敬說都關中的完整引語，對讀〈周本紀〉棄號后稷、封邰，公劉居豳，古公追尊太王，西伯昌為文王，太子發為武王，周公輔成王與營洛，太子誦為成王及釗為康王等原段。八組來源局部人物接回既有ID，保留每處原字、錨點與逐項引文；成康仍為兩個單字人物錨點。

同書對讀不視為獨立史實票數，身份辨識不確證傳說性周先的歷史真實、世數或絕對紀年。本輪未核書影，不新增譜系或爵年。本篇其他引古、楚懷王、秦二世及匿名人物尚待核讀，未宣稱全篇完成。

八個舊人物ID已在所有可編輯引用中遷移後撤除，原身份判讀及提及ID保留。資料已重建，全部資料驗證通過；771項完整Python測試（637.697秒）、222項JavaScript測試及語法檢查通過，八組人物卡與跨篇人物頁完成桌面／手機真實HTTP驗收。本批既有網站發布待完成。
