原有黥布整詞仍指英布，不能拆出布接欒布。原格、既有提及ID及「亖」等原字不改；未核書影。侯表較具體授爵與除國日期及本傳概述分存待核，本批只補逐人標記，沒有倒推父子生卒或官爵起訖。
