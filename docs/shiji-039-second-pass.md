# 晉世家第二輪核讀

已核讀第1–15段。第1段叔虞出生及命名存傳說敘事性，不把夢中天作具名人物。第2段武王崩；唐在河汾之東為封地描述，不直接當籍貫。第3段明示父子世系，不由繼位補父子；無其年數保留。第7段仇、成師兩次出生有穆侯七年、十年原紀年；少子不給固定排行。第8段穆侯卒及周宣王崩有紀年；襲殤叔而立不能只由襲字推死亡。第9段幽王被殺。第10段文侯卒。第12段昭侯弒及潘父誅，桓叔還歸曲沃不作死亡。第13段桓叔卒、孝侯於翼被弒；數位正文「子胛桓叔」疑讀保留，不自行校改。第15段鄂侯卒，莊伯走保曲沃為遷居／避難，不作籍貫。

第16–25段已核讀：莊伯卒、魯隱公弒、韓萬殺被虜哀侯、小子侯誘殺、齊襄公弒、武公代晉二歲卒各有明文。第20段伐緡滅之兼有滅國可能，不僅憑滅字推死亡。第21–22段曲沃即位37、通年38、代晉2與通年39分存，不混作同一任期。第23段惠王出奔居鄭櫟邑可存來源居處，非籍貫。第25段諸公子盡殺及後群公子奔虢的敘事張力保留，群體不補個人姓名。

第26–40段已核讀：奚齊、悼子出生，齊姜早死不可借獻公十二年；申生新城自殺、杜原款誅、小臣中毒、獻公卒、奚齊悼子殺及荀息死有明文。第30段驪姬妾自殺為條件威脅，不作已死。第33段重耳被命自殺但踰垣逃走，不作死亡。第34段虢公丑奔周及虞公被虜不作死亡。第39段兩子被殺為前段回述，暫不重複建事件；第40段裏克伏劍有明文，四月禮晉不直接當死亡月。

第41–50段已核讀：申生改葬未明示實葬地，鬼神顯現及新城西偏預告不作改葬位置。第42段邳鄭殺及七輿大夫群體死亡，裏克為回述；豹奔秦。第46段慶鄭誅，重耳被謀殺而逃齊不作死。第47段圉、妾出生為梁時回述，不借惠公八年；梁伯女妻及兩子各依原文。第48段滅梁不作梁伯死亡。第49段惠公十四年九月卒。第50段狐突殺、懷公高梁殺有明文，盡滅其家是懷公命令，不直接當每家均已死亡。

第51–65段已核讀：伯鯈叔劉、盾出生及管仲隰朋死分存；居狄五歲／十二年、留齊五歲及去狄惠公七年與前第46段六年敘事分開，不以時長直接倒推曆年。第54段侍者被殺；重耳、咎犯殺語未實現，不作死亡。第57–58段叔瞻、子玉殺議未行，不作死亡。第60段懷公死為前第50段同事件重述，留較詳細月日作後續互證。第61段呂省郤芮河上被殺，不指定現代河段。第62段介子推至死不復見，不添焚死、死亡地或母親死亡；第63段綿上山中為隱居地，不作已葬。第65段帶殺有四月原紀年。

第66–80段已核讀：三軍諸將、御戎及右與四年趙衰為卿均須按明示職事分存；第70段五月丁未周王命伯及受命，不能按死亡推出爵號終止。第71段子玉自殺有明文但不借五月；第76段叔瞻自殺；第77段文公九年冬卒與鄭伯是歲卒分記。第79段三秦將被虜後放歸，不作已被戮；遂墨以葬文公未記墓地，無地點不補。第67段衛侯居襄牛為居處，第74段振鐸與唐叔的後代為祖先主張，不補直接父子。

第81–95段已核讀：四人皆卒分別存各人主張，趙盾代執政非血親；陽處父殺為回述，不借襄公七年。第83段先蔑隨會奔秦、第84段隨會被執歸晉分存。第86段宰夫殺與鉏麑觸樹死，匿名者照既有錨點。第87段示瞇明亡去不作死亡；犬敖死亡不收人資料。第88段靈公桃園殺，董狐歸責趙盾與敘事趙穿殺分開，不抹異說。第93段成公卒、第94段陳靈公殺及夏徴舒誅。第95段荀林父請死但免，智罃被虜均不作死亡。

第96–125段已核讀：解揚欲殺而被歸、景公受王號提議但讓，均不得當死亡或授王。魏文子請老與郤克執政可補職事交接。巫臣族滅不補每個具名者；趙同趙括誅分存。景公十九年夏立太子後月餘卒，不直接把夏作死亡季節。第112段三郤襲殺須具來源成員引用，不任選一人；胥童殺有閏月。第113段厲公囚六日、死十日及正月庚申原句分存，不修補數位紀日。第114段捷、談客死周是回述，未填悼公元年。第119段平公欲自殺被止不作死亡，欒逞死及群體滅族分開。第120段齊莊公殺，第123–125段各君卒崩有明文。

第126–143段已核讀，全143段第二輪閱讀完成，身份及群體等仍待覆核。魯昭公乾侯居住、趙鞅晉陽與范中行朝歌避難按來源；欲殺午不作已死。頃公、簡公、孔子、定公、出公、忌、知伯、哀公、幽公、烈公、孝公死亡有明文。出公奔齊道死不把齊直接當死地；忌蚤死為回述。第141段靜公遷家人與晉絶不祀不作死亡；三家授侯第139段與亡國第141段分開。第143段為另層述贊，重述不再添加死亡。
