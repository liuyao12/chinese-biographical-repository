# 卷八十二〈田單列傳〉草稿

保存固定修訂2529471的9段正文，田單至王蠋敘事；全部段與HTML篇界已核讀，人物導覽排除。太史公論後法章君王后及王蠋兩段按原序保存，不擅截斷。未核底本影像或現代研究。

諸田疏屬與宗人不補具體父母；假神師為未名卒，燕將未名不盲接騎劫。誘王蠋授將封萬家被固謝，不當實授。人物逐段待標，未完成覆核。

全9段明示姓名首輪保存16個新候選與119處錨點。法章與襄王依君序復國事件接，嬓女君王后按明示，假神師卒未名。宗族、誘授及未知任期不補，親屬官爵跨篇身分待續核。

已保存3項親屬來源主張及9項官爵用稱，另以田世家48至50段保存田單、法章襄王、太史嬓／敫及君王后4項跨篇暫同指。藏法章私通立后、即墨復齊封安平君各有原段錨點；父名敫／嬓差異保留，田世家未敘火牛與神師不因同指當獨立確證。

跨篇暫同指增至8項，補樂毅與燕昭惠、騎劫及既有田單襄王配對。首輪狀態已整理，仍非全部人物與學術覆核完成；既有4637個人物逐項保持原樣。下一卷〈魯仲連鄒陽列傳〉，匿名指代、版本及任期列為後續工作。
