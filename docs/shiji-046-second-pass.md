# 田敬仲完世家第二輪核讀

全56段已再次閱讀：55段正文含太史公評論，末段為另層索隱述贊，不當同一來源正文。本批候選已逐項核對人物錨點並納入工作分支；影像、身份及版本未全部覆核。

陳完出生、敬仲生稚孟夷、稚孟夷生湣孟莊、孟莊生須無、須無生無宇、無宇生開與乞均可保存來源出生敘述，不虛造日期。兩位蔡女及陳、姜齊、田齊同稱桓公分存。厲公被誘殺與第2段末回述不生成兩次事件；蔡女數歸未明示目的地，不補。完奔齊、辭卿而受工正、娶懿仲女各分事件；宣公［二］十一年的校勘符號不暗改。

晏嬰卒後為先後關係，不給確切卒年。景公原太子死、芮子生荼、荼受太子及即位，陽生奔魯、國惠子奔莒、昭子被殺各分保存。晏（孺子）［圉］奔魯仍有版本疑讀，不與荼直接合併。陽生匿田乞家、受立、荼遷駘及被殺、田乞相齊各有明文。田乞四年卒需核君主語境；悼公被鮑牧弒、子我與監止被追殺、簡公被執徐州後殺均有來源。田常欲亡而未實行不記遷徙；子我為監止宗人不改作父子。

第16段盡誅鮑、晏、監止及公族強者保留群體及回述層次，不推出所有族人死亡，也不重複生成監止死亡。田常七十餘男為群體，不虛造個人姓名或生母。田常、襄子盤、莊子白死亡及繼任相齊分存，襄子兄弟宗人盡為大夫不補官員姓名。宣公五十一年卒及次段重述不當兩次事件。康公遷海上不映射現代地名。田和列諸侯的康公十九年及自身元年分清，和二年卒、午六年卒與康公是歲卒各按來源。

即墨大夫封萬家、阿大夫被烹與左右群體被烹分存；不借即墨大夫姓名補匿名身份。騶忌見三月受相印與居朞封下邳成侯是相對時長，不把三月當曆月。檀子守南城、未名子守高唐、黔夫守徐州可存治所，種首備盜賊不補地點。牟辛三十三年被殺、威王三十六年卒有明文。田忌三十五年奔無目的地，不補楚；次段召復故位另記，未知原官名不補。

宣王二年馬陵殺龐涓及太子申被虜分存，不把虜作死。稷下六位具名士賜列第、為上大夫有共同來源，不能把七十六人補成全部個人。魏惠王卒的明年語境需另核；宣王十九年卒、田嬰湣王三年封薛有明示事件。張儀與韓馮計畫出兵的引語不當本人已遷徙。涇陽君質齊、歸秦，薛文入秦相秦、亡去分保存。主父二十九年被殺不補死地。

齊湣王東帝、秦昭王西帝與共同去帝復王有明示起訖，三十六年不借後篇月份。蘇代自燕入齊可存行程。宋王出亡後死温可存死亡及死地。湣王奔衛、被接納、去衛、走鄒魯未獲入、走莒及被淖齒殺，逐項區別實行與未獲居留。法章變名姓為庸於莒太史敫家，不補變更後名字。君王后受立、生建有明文，父終身不睹不推斷具體失和日期。

襄王在莒五年後入臨菑、田單安平君封授、襄王十九年卒各存來源。君王后王建十六年卒與後段回述不重複計次。荊軻三十八年被殺有明文，燕王喜滅國及代王嘉被虜不推死亡。王建四十四年被虜、遷共不補死亡或現代位置；后勝相齊、賓客入秦與受金不臆補具名者。

數位見證的笔、称及校勘括號已有原字記錄；後續處理須同步偏移及正規化紀錄，不暗改原文。紀年換算、稱號全史及跨篇異說仍待續核，新資料尚未接入公開閱讀器。
