# 相如、莊忌的姓名成分與古注差異

司馬相如的完整姓名與「更名相如」共同支持複姓司馬、名相如；「字長卿」與「故其親名之曰犬子」分別記字和初名。姓名組件以 `zi`、`former_ming` 保存，原始別名仍為原字串，閱讀器按明示欄位加「字」「初名」標籤。不以姓名反推更名年，也不在多次官職中任選一個無時段的官名作全生涯標題。

《漢書》卷五十七上顏師古說嚴忌本姓莊、當時尊尚號曰夫子，並釋避漢明帝諱的嚴字。本次暫以有具體尊尚說明的尊號解作顯示預設；《史記集解》徐廣「名忌字夫子」另存為未採納的名、字成分說，不把兩說混成一致結論。嚴忌作來源避諱書寫，不記本人改名事件。

顏師古另明釋相如所慕藺相如為六國時趙人，補入既有接合的參考。維持暫定辨識與中等信心，不把古注與兩史平行傳承當獨立史事票數。
