# 卷六十九〈蘇秦列傳〉人物首輪

固定數位修訂2621145，全67段正文已核讀保存。頁首弟名導覽及空段、後附索隱述贊與現代版權告示不混入正文。原文雒、衞、嘑、敎、㕹等字及數位標點疑點保留；未核底本、影像、出土縱橫家材料或現代研究。

目前436處人物或未解錨點、62個新增候選及62項篇內判讀，全庫4081個候選。各國遊說與蘇代書信的王稱依敘事與引語範圍分辨，周天子不按年代記憶接周顯王；蘇代初見燕王、過魏魏王齊王及書信秦楚王等另存候選，不斷言必為異人。

湯武只取引古，不取湯沐；軒轅在車樓語境，韓段武器名不補人物。鬼谷先生的傳承及身份未核定。燕太子與易王、易王母與文侯夫人依本文暫接。秦惠王女及蘇秦嫂母、遠吏故事夫妻私者妾與尾生所期女子分存未名。

蘇代與蘇厲的短名按弟兄敘事取，子之與蘇代婚不補成兩人配偶。書信穰侯舅與太后母局部暫接，未補姓名及秦王世系。西帝北帝中帝屬擬議，未當已授稱號。

太史公明說異時相似事件附於蘇秦，身份同指不等於時序與全部事件已確證。來源親屬、稱號時段、跨篇身份、匿名者代詞及傳世出土版本覆核尚未完成，進度留在卷六十九。

已保存10項來源親屬陳述；第42段大王修正為燕易王，另述齊王仍為齊宣王。

另保存17項官爵／用稱證據，包括成的相與奉陽君、蘇秦的從約長、相六國、武安君與客卿、子之的燕相及書信中的涇陽君、高陵君、穰侯與太后。明示授予保存為來源事件，單純用稱不補任期起點；昭王不當即位時授予的諡字，擬議三帝不建立已持有記錄。全部終點仍未定，未因被刺或卒而補造。

另與燕世家逐段核對5項跨ID暫同指：蘇秦、燕易王、齊宣王、易王母／文侯夫人與燕噲。共同事件不當獨立見證，也不消除傳世篇文的時序問題。
