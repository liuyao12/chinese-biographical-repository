# 〈蒙恬列傳〉死亡、地望與相對年序

補十三項死亡原語（含敘述與引古），四項地望（蒙恬祖先齊人、軍事居上郡、蒙毅死亡地代、蒙恬死亡地陽周）。兩死亡地以同段使者所至、宣令及實際被殺／吞藥的連續敘述判讀，不只以囚地推定；其先齊人仍限定未知先祖，不定本人出生地或現代行政區。

趙高當高罪死而後被赦、蒙恬疑而復請及屬吏、罪百里奚、虜楚王，均不作當段實際死亡。引古的李牧、秦穆公、白起、伍奢、伍子胥、關龍逢及比干不套秦二世背景年；三良等群體不補個人名號。蒙驁始皇七年卒對讀年表蒙驁死，記前240年；始皇沙丘崩對讀年表記前210年；蒙恬拜內史依明示始皇二十六年記前221年，年表只作原年序與數位西元對照，不假稱王賁滅齊是蒙恬受職的平行事件。

項燕〈蒙恬列傳〉二十三年被殺記前224年，〈秦始皇本紀〉二十四年自殺記前223年。暫定預設前224年，理由為蒙恬篇明示紀年與年表把殺項燕／虜負芻分列二十三／二十四年相符；原本紀紀年及死法不刪。這是事件層可撤回的資料預設，不以同書篇數投票，不宣稱學界定論；未核書影或現代校勘。

「蒙恬弟毅」保存為蒙恬早於蒙毅的機器年序約束，兩人的絕對排行未知。蒙恬、蒙毅頂部姓名依同段家族、全稱及短稱配對暫分蒙／恬、蒙／毅，稱號內史、上卿只供人物辨認，不前推持職時點，不當獨立姓氏考證。

另接合秦穆公、百里奚、白起、楚平王、伍奢、夫差、伍子胥、周成王、周公九組引古身份，撤除十個重複登記。周公為武王病代命與蒙恬引成王病沈書等故事分存，不因同人整成同一版本。秦穆公新標單字「繆」，保留原字及「死……故立號曰」的引述依據；立號解釋不作已核諡法，年月未知。
