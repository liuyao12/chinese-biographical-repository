# 相如篇開篇身份接合

開篇六組來源候選依逐項證據接合。景帝、梁孝王接本紀及梁世家已有身份；鄒陽、莊忌、枚乘／枚生有齊、吳、淮陰籍里及同客梁的共同人物組合。莊忌夫子的原稱保留，這批未將夫子拆作名、字或官爵。所慕藺相如依前代人物語境暫接趙臣，本段沒有重敘完璧等事，僅存中等信心，不宣稱另有同事件明證。司馬相如與藺相如仍為不同人物。

全部來源引用與衍生檔案更新後撤除六個重複人物ID；提及錨點與原文位置保留。這不是以同名全域合併：當朝天子的候選仍須區分敘事、奏疏與賦體一般君道，子虛、烏有、無是公及賦中齊王亦不造歷史人物。

逐書進度移至本篇第三段續核；〈西南夷列傳〉仍保留夜郎後段稱謂、王統概述及書影等未解工作，不稱全篇完成。

依已核讀正文將六個顯示標籤改為孝景帝、梁孝王武、鄒陽、藺相如、莊忌、枚乘；不沿用早期候選的來源括註。沒有另拆無據姓、名成分，原始氏稱、尊稱與來源證據保持原樣。
