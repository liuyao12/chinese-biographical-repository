# 六國年表人物閱讀介面

〈六國年表〉的人名現在使用固定來源儲存格內的字元錨點，連到可閱讀的人物卡片與 `person.html#人物ID`，而不是把 JSON 當成閱讀介面。兩種時間軸共用標記；西元年仍只在第零列或欄，並保留編者對照的身份。

人物卡片可由滑鼠停留、鍵盤聚焦或點擊開啟，列出來源稱號、地望與出現篇章。完整人物頁列出紀年對照、稱號的可展開原文證據、親屬原詞、年表原格及同一人物的其他篇章入口。跨篇入口取自既有 CBR 人物包中的明示同指，不作即時姓名配對。頁面不呼叫 AI。

原格正文、換行、跨度、年列與西元對照均逐格核對為原樣。省稱與單字回指只在其原國別、年月及敘事範圍內判讀。年表的「晉哀公忌」「晉出公錯」「衛悼公亹」「晉孝公傾」等異文均保留；暫定 ID 不代表修改世家姓名或消除不同紀年。

十五個尚未確定跨篇身份的具名者放在 `data/historical-tables/person-candidates.json`，使用固定的字母數字 ID 與原格引句。這是來源局部的身份候選；後續納入人物登錄時須沿用其 ID，或明記同指與別名，不重新發號。卡片清楚標示來源局部候選，其跨篇、稱號、親屬及紀年陣列留空。`景座` 的指稱類型及 `太子相子之` 的原格分讀仍待校讀，沒有虛構人物對應。

機讀欄位：每格 `person_mentions` 包含固定 ID、起訖偏移、原詞、人物 ID、暫定狀態及判讀說明。`data/corpus/profiles/index.json` 提供每一人物頁 JSON 的路徑；各檔保留年表原格、既有人物包的跨篇入口與證據。這些是可重建的展示資料，不取代 CBR 原有證據與決定。

CBR 人物包匯出會同步重建人物頁資料；亦可單獨執行：

```sh
python3 scripts/table_person_profiles.py
python3 -m scripts.historical_tables validate
```

驗收包括原文與幾何逐格一致、所有標記有本地人物頁、來源局部候選不虛構跨篇連結、張儀確有第五／四十／七十卷入口，以及桌面與手機兩種時間軸的人名卡片、鍵盤開啟及篇章跳轉。
