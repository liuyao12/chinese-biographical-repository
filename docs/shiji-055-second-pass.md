# 《留侯世家》第二輪核讀

全31段已逐段核讀，第31段索隱另層保存。本批來源事件、地點與稱號修訂已納入工作分支；第一輪姓名標記不代表身份與來源覆核已完成。

第1–4段：其先韓人是祖先來源，不直接改作張良個人籍貫。開地為大父、平為父有明文；平悼惠王二十三年卒，卒二十歲表示卒後二十年，不是享年二十。弟死不葬是未名弟弟的死亡，不能補姓名。學禮淮陽、亡匿下邳與居下邳分存；博浪沙行刺未殺秦皇帝，更名姓未記新名。老父是圯上老人，不是張良父親；黃石即我屬神異敘事，不能強併一般石物與人物。太公兵法為著作署稱。項伯殺人之受害者未具名，不按熟知人物補名。

第5–9段：景駒自立楚假王、沛公拜張良廄將、項梁立楚懷王及韓成、授良韓申徒依實行分存。欲往景駒未成，不錄成已到留。橫陽君成與韓王成依本段同指。薛、潁川、雒陽、轘轅、陽翟、宛、武關、藍田、咸陽、霸上及鴻門保存原名與相應行程主體；國土、受封與居處不混同。秦將屠者子為未名父子來源，不補姓名；秦將欲襲咸陽與沛公意欲留秦宮未實行。楊熊軍敗、子嬰降不當死亡。鯫生不擅指劉敬；沛公與項伯結賓婚保留來源婚盟，不補未見女兒。

第10–13段：漢元年正月漢王任號，巴蜀領土不當永久居處；張良送襃中與實至韓有前後支持。韓成由王降侯及被殺彭城分存，韓王不遣之國不錄成已到國。成信侯為張良明示授予。彭城、下邑及歸漢行程按原語保存；黥布、彭越、韓信被推薦不當此次受任，反叛與被擊不推死亡。張良多病不是死亡或免官。

第14–17段：復六國之後是未實行策略，不造六國授印事件或未知後裔。湯、桀、武王、紂、商容、箕子、比干在引古語境中另分敘事層；制死命、得頭是論證及條件，不當項籍死亡。漢四年授韓信齊王印為實際授予。其秋與陽夏南、固陵保持本篇原文紀年關係，不能為迎合他篇年表默改正文或直接換年。

第18–21段：漢六年正月張良受留侯、雍齒受什方侯有明文；自擇齊三萬戶未受，不當齊地居處或已封。雒陽南宮為高帝所在，欲殺雍齒未成；丞相與御史無名，不自行指蕭何。都雒陽與都關中之建議分開，實行是高帝即日西都關中及張良從入關。左右大臣山東人為群體，不批量推每人籍貫；地勢議論不作發言者遊歷。杜門歲餘不是留侯任期。

第22–25段：欲易太子未成，不終止太子任號或造如意登儲。戚夫人子如意為來源母子；建成侯呂澤與此前章篇身份依證據另核。四人至、客建成侯所為實行居留，山中不加具體山名。東園公、角里先生、綺里季、夏黃公在第24段明示，前後四人可作局部群體同指，不能改寫原文成四個人名。年皆八十有餘須保留超過八十的界限與原詞，不記精確八十歲或倒推生年。漢十一年高帝親征及灞上、曲郵行程、叔孫通太傅與張良行少傅事可錄；建議太子為將軍不作已授職。破布軍不是黥布卒；以死爭與欲為太子死不是已死。呂后真而主是預言，不作當時即位。

第26–29段：張良從上擊代及馬邑下有行跡；立蕭何相國為來源任事回述。欲從赤松子游是願望，不當已去、死亡或確定神異接觸。高帝崩有明文，但此句未明示數字年份。後八年卒為張良死亡，其計年錨點與首尾年法仍待判讀，先保留原詞，不因通行生平直接填西曆。謚文成侯為死後命名；子不疑代侯是父子承爵。後十三年從高帝過濟北及見穀城山下黃石是回述行跡，不能用第3段預言替代實行證據。并葬黃石冢保存葬石於冢的原句，不擅立名為黃石冢的正式墓地或推定今日位置。孝文帝五年不疑坐不敬國除是封國終止，不作人物死亡。

第30–31段：太史公、孔子與子羽依引語身份保留；狀貌如婦人好女是比況，不造女人人物。高帝自評為回述用稱，不當新授任事件。索隱的橫陽、申徒、赤松願游等不覆寫正文或補未實行事件。
