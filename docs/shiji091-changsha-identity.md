# 〈黥布列傳〉長沙王身份與稱謂差異

本篇誘走英布的「長沙哀王」，按高祖崩時〈呂太后本紀〉明記吳芮子臣為長沙王，及〈索隱〉明辨成王臣，暫接吳臣。更新引用後撤除舊候選，不與番君吳芮或後嗣哀王回混合。

正文「哀王」保留；古注更正與集解所存「芮之孫固」異說分層記錄，不將注家所據本當親見版本。年表成王臣與《資治通鑑》同事件配置支持辨識，《漢書》英布段仍稱哀王而吳芮段區分成王臣、哀王回；兩書未正式匯入。
