# 南越尉事、舊職與篇末辨識

「即被佗書，行南海尉事」只記趙佗代理尉事，以 `appointment_role: acting` 和原稱保存；任囂南海尉分為另一人另一筆，不補正式授任或年月。

蘇弘的「故校尉司馬」記舊職用稱，不拆作兩項授任，不以司馬為姓。《漢書》顏師古「校之司馬若今行軍總管司馬也」分層引用固定數位提交、348–350行及局部回應指紋；該見證作蘇宏，原字與本篇蘇弘並存，未核影像。

索隱述贊「嫪後內朝，呂嘉狼戾」按本篇樛太后準備入朝、呂嘉抗拒事件暫接同一樛氏，保留原提及ID、字形及述贊文字層。這是語境辨識，並非親見原刊後改字的校勘，也不把嫪後當她在世所用別名。不能接嫪毐或秦太后。

趙佗「建元四年卒」未記月日；按太初前十月歲首，改存西元前138至137年範圍，保留原詞，分列年表年號起點、四年原年字、數位137及曆法引文。父祖死亡不推子孫即位的確定西元年，也不替全部爵位補終點。路博德、楊仆兩項授將原日期保留元鼎五年秋；秋季不改作整個漢年的起點或推現代月日。

漢十一年、孝文帝元年與年表不同帝號寫法的換算，以及長沙王的更細身份辨識仍待續核；本批不表示全篇覆核完成。
