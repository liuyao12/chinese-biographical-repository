# 〈樊酈滕灌列傳〉後半篇王號及人物邊界

依七國之亂、誅呂清宮、迎立代王與灌嬰擊匈奴後罷兵等事件，接合趙王遂、東牟侯／濟北王興居、後少帝、齊哀王襄與呂祿。〈齊悼惠王世家〉清宮段的少帝亦接合同一後少帝，與此前幽殺的少帝分人。

景帝時酈寄欲取的平原君，採《集解》引蘇林的辨識為王皇后母臧兒，對讀〈外戚世家〉；不是戰國趙勝。古注作參考分存，不把武帝即位時的授號倒填為景帝時授號；未核書影。

「王自殺」「賜立」分別縮至「王」「賜」；「灌嬰孫賢」拆為祖父「灌嬰」及孫「賢」，親屬詞「孫」保留正文但不作人名。既有錨點 ID 保留，正文不變；賢的闕名父親不補造，保留缺一代路徑。六組身份接合後撤除八個舊候選 ID。
