家系與人物辨識以正文和逐項斷言為依據：司馬氏接入既有司馬鈞近系組裝，現有一百二十名來源成員；王朗、王肅、王元姬接在同一父系。晏的未名長子依原文父子敘述補入，名仍留空。周氏之父恢由同一覃的生母、母系祖父兩項原文合讀，保留 `contextual_provisional` 與推導輸入；周恢的跨篇同指亦有資格限定。生父、生母、承嗣、配偶與撫養分存，ID 字母不代表排行。

既有十九個司馬氏人物及王元姬完成家族 ID 更新，王淩的重複登記接合；現役正文、斷言、人物反查、家系及年表使用更新後端點。原 MID、斷言與判讀 ID、原引文保留。舊號預留僅供撤號稽核，不提供別名或舊人物 JSON 入口。來源所列范、義、幾等角色仍保留可能同人或傳誤的限定，沒有把暫分角色數當作已證不同人物數。

明載紀年保存數值年、原紀年詞、引文及換算依據；報齡保留其敘事時點，不倒推出生年。稱號區分領土爵名與帶諡用稱，受封年不作授諡年，未知終點留空。虨追封南陽王的年度承同段永康元年，原文「四月」保留，數值年仍為中國曆年度三百年。

這些資料是 AI 整理，`human_reviewed` 保持為假。卷五十九的兩段有已取得的固定修訂原始文字；其餘節選依實際取得的網頁轉錄記錄資格，頁尾所報修訂號不冒作已取得該固定正文。各節選實際印本未核定、書影未核；所報後出校記另存原引與編者摘要，沒有採改正文或冒稱親見原校本。圖像保留外部來源連結。

## 來源驗證結果重用

本批重新覆核目前程式集合與實際來源讀取閉包後，更新來源群組驗證的程式集合校驗值。候選只改一個校驗值，原驗證器、精確且有序的呼叫資料鍵、實體檔案雜湊、目錄成員檢查及回退策略保留。量測到的五組來源驗證讀取五百一十二個來源檔案；所有程式檔亦納入閉包檢查。

原有十九項測試與八種真實冷暖／擾動情境在隔離候選通過：同一資料能重用，呼叫資料變動、必需 fixture 等長改寫或刪除、來源目錄成員增減及非標準讀取均回到原完整驗證。這是目前資料與控制流的覆核；新程式集合仍採保守回退，發布驗收另由正式匯出與測試記錄提供。
