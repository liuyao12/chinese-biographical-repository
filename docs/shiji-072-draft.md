# 卷七十二〈穰侯列傳〉草稿

保存固定數位修訂367921的10段正文，自穰侯魏冉者至太史公論贊。頁首人物及百科導覽、索隱述贊與現代版權告示不混入正文。固定HTML與取得時版本一致；「願君［王］之」另存數位改讀提示，正文保留改讀前君。羋、于、鄉、獘、癕等原字及胡陽、代齊疑點不改。

全部正文已核讀，人物待逐段標註，篇與進度均為整理中。宣太后弟的異父、同父與昭王弟的同母各須按明示保存，不補父親姓名。任相反覆起訖、謝病免相與授封穰陶分存；須賈內嵌魏王話語、蘇代書信的王稱逐範圍判讀。胡陽與他篇胡傷不按記憶校改，范睢張祿先生依明示相接。底本、影像及現代研究未核，下一位置為第1段。

前3段已完成明示姓名首輪，新增15個候選與71處錨點。魏冉穰侯與宣太后羋八子按明示相接，武王后與武王分別標註。仇液公稱與內嵌樓緩受話公稱分範圍。異父、同父、同母親屬回指暫留待建立來源陳述，不補父親姓名。後7段待標註，下一位置為第4段。

第4至5段已接續，累計20個新增候選與98處錨點。呂禮禮、壽燭燭及白起武安君按明示相接，反覆任相、免相與封爵時長原語保留，不由人名同指推出各任日期。秦齊稱帝複數國稱主語留待稱號來源證據處理，未補齊王名字。後5段待標註，下一位置為第6段。

第6段須賈遊說已接續，累計29個候選與136處錨點。內嵌魏長吏向魏王的王稱與外層穰侯君稱分範圍；梁惠王、子良引古分存，暴子未按記憶接暴鳶。湯武是假設復生引古，魏長吏保存未名。後4段待標註，下一位置為第7段。

末4段已接續，全10段明示姓名首輪累計36個新增候選與181處錨點。齊襄王與書信敝邑之王暫接，秦王另指秦昭王；范睢自謂張祿先生依明示相接。胡陽與他篇胡傷不校改，暴鳶與暴子未按記憶合併。免相國、出關就封、卒與收陶須分存，親屬、稱號時段與跨篇身分尚待補核，篇級仍在整理中。

已保存7項來源親屬陳述，異父長弟與同父弟各以宣太后為參照，同母弟以昭王為參照；限定原語留在每項證據，不補父親名字。昭王母宣太后與武王母惠文后分存，原文宣太后非武王母保留作反證；繼位不作父子。

已保存22項官爵與用稱，樓緩、魏冉、壽燭及相國穰侯的5項明示免相終點逐筆限定。魏冉復相秦六歲而免與免二歲後復相分兩筆，未合成連續任期；壽燭相職終點不推客卿同時終止。未知日期與所有未明示終點保留未定，卒及收陶不作全部官爵共同終點。

已以〈秦本紀〉共同事件保存6項跨篇暫同指：魏冉、樓緩、白起、公孫喜、暴鳶與芒卯。樓緩免相接魏冉、伊闕斬首二十四萬虜公孫喜、暴鳶走魏入三縣及華陽芒卯被破各有逐篇引文及錨點。胡陽／胡傷與十萬／十五萬差異各留，不因芒卯同指而校改；暴子未按記憶接暴鳶。同書篇章不視為獨立見證，身份對應不確證紀年或全體敘事。
