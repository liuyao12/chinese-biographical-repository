# 卷一〇四〈田叔列傳〉整理範圍

固定版本8739534保存九段正文、七段署褚先生補文及一段索隱述贊，新增三十四筆人物候選，209處錨點。來源原字、標點及次序保留，未核底本影像。

田仁依少子仁與田叔形成家族路徑，少子排行數字未知，不自動判為末子。比喻如子為父、弟為兄不生成人物關係。

正文與褚補對田仁受誅及梁案回報相關異說分存。官爵、地點、跨篇同指、未定先帝及匿名群體仍待整理；人物候選與初步標註不表示完成覆核。

已補四項跨篇暫定同指與四項出身／留居地點證據；田叔趙陘城、任安滎陽與其長安及武功留居各自附原句。齊田氏苗裔不當作田叔本人齊籍。

另存三十三項官爵、俸秩與任務，三項明示免職終點。護北軍及護邊田穀保留任務字面，二千石分記俸秩；未知年、坐法失官未具官名與卒日不補造官爵起訖。
