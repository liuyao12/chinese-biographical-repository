# 卷六十一首輪收錄

固定修訂2621133共9段正文，全部已核讀並作明示人物首輪；排除註釋版連結、維基百科及文言維基大典兩段導覽，無索隱述贊。取得時HTML與固定修訂一致，只去外緣空白；閒、軼、采、絜、蚤、蹠、儻、徇、馮與堙等見證原字保留，未核底本或影像。

目前85處錨點、21個新增候選及身份判讀、2項父親主張、6項稱號與8項跨篇暫同指，全庫3698個人物候選；既有3677筆人物逐筆確認未改。本篇首輪已存，complete仍為false，人物區分、未名者、版本、現代研究待接續。完整13項檢查已通過（165項Python、155項JavaScript測試），跨篇身份與全文引用一致，下一篇為管晏列傳。

堯舜禹、許由卞隨務光與神農保存傳說敘事性；引歌虞夏所指暫留未解。由光短稱只在所聞由光義至高處取，不標行不由徑或同明相照中的普通字。孔子仲尼子夫子與顏淵回按評論及引語局部暫接，子曰只標子字，不把曰納入人名。賈子、太公與太史公未補全名。

伯夷叔齊為孤竹君二子按明文各存父親；後段其中子保留未名候選，不補姓名、固定子數或排行關係。二子不擅改為三子，也不以父欲立或兩人逃去推已受君爵。西伯昌、西伯、文王依西伯卒與武王載木主號為文王敘事暫接；父死不葬引語中的父不接孤竹君，木主不造另一人。

太史公、孤竹君、西伯、武王、太公及文王稱號各存。前五者只作來源用稱，制度未定保持未分類；文王保存西伯卒後明示用號事件及死後用稱，不當生前已持王爵。任期起訖、死亡與首次提及不自動連成有效區間。盜蹠所述殺人及壽終、讓天下與饑死均保存為來源敘述，不作獨立確證。

新增8項跨篇暫同指，分別為吳太伯、孔子、顏淵、伯夷、叔齊、文王、武王與紂，逐項引用既存正文及本篇錨點，不改任何已發ID。孔子採五帝本紀既有代表ID，顏淵回有孔子世家引語佐證；賈子與太公仍待進一步比對。
