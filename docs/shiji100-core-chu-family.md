# 〈季布欒布列傳〉核心身份與楚平王一系接合

本篇十二組核心人物依共同事件、時代與具體官爵對讀；單于遺書呂后與匈奴列傳冒頓為書遺高后為同一事件，不按單于泛稱通配。伍子胥與荊平王依鞭楚平王墓事件接合，荊平王與周平王分開。各篇人物原稱及引文保留。

連帶核讀宋、吳、楚及伍胥各篇，整併平王、太子建、昭王、白公勝及秦女、蔡女來源角色，共十七組同指、二十二個舊ID遷移。楚太子建現為`q8m_d0c_kq3_AEB`，白公勝為`q8m_d0c_kq3_AEBA`；父系依次連平王、共王，分支字母不是年序。既有父子斷言與段落錨點保留，沒有因遷ID補造父親。

珍／軫保留兩篇原字，依父母及繼位事件接合為楚昭王。秦女只合平王自娶原擬太子婦、所生昭王的特定人物；蔡女及另一篇未名母親只按已辨同一太子建的母子端點接合，不將所有秦女或蔡女視為同人，不補未載姓名。返楚地點巣／鄢及年數等原說分存，不因同人整併而改正文。

本篇丁公母弟的兩種古注及既有暫定首選未變，季心弟／子異文、長事袁絲與弟畜灌夫籍福的禮遇用語亦保留。灌夫、籍福與趙同仍待續核，未宣稱全篇完成。數位底本未核書影。

112篇原文、十表原格、所有提及ID、表面文字及字元位置不變，只遷移人物指向。二十二個舊ID的資料及JSON已撤除，原判斷ID、引文與來源錨點保存；歷史回查使用Git。
