# 卷八十〈樂毅列傳〉草稿

保存固定數位修訂2089316的20段正文，樂毅至太史公師承論述；全段與HTML篇界已核讀，上書dd按原序。未核底本影像或現代研究。

樂羊先祖、樂叔孫及樂乘宗族不補直接父親；燕王稱依君序及引文說話範圍處理，反間王齊不作授爵。長期居燕、往來客卿不補精確爵期。人物逐段待標，未完成覆核。

前3段保存13個新候選與51處錨點。樂毅、樂羊、魏文侯及各國王稱按段落辨識；樂羊先祖不作父親，樂氏子孫保留群體。趙嚪唐眛原字保存，樂毅答語王限燕昭王。後17段待標，下一位置樂毅留徇齊及燕惠王代將。

全20段明示姓名首輪目前45個新候選、244處錨點。另存2項明示父子主張及17項官爵用稱，樂毅上將軍以騎劫代將為明示終止；昌國君、望諸君與趙授相國印各自保存，未明日期不補。樂閒居燕三十餘年不當精確爵期，樂乘代廉頗是事件未作官名。先祖、孫、宗及師承不補父親。
