# 〈魏其武安侯列傳〉身份與親屬覆核

本批保留全28段正文、提及範圍與見證指紋，接合八組跨篇身份：竇嬰、條侯周亞夫、孝文皇后竇太后、趙綰、申公、程不識、潁陰侯灌嬰及田蚡岳父燕康王嘉。逐項同役、同職、親屬或古注證據見 `corpus/shiji/107-equivalences.json` 的 `eq-shiji107-context-001` 至 `008`。身份判斷為 AI 暫定，非人工學術核定。

「孝文后從兄子」分解為竇嬰之父與皇后同輩、父系旁親且年長；不把竇嬰當皇后從兄，不補共同祖先或親等。父世觀津不把世當父名。《索隱》「以言其累葉在觀津，故云『父世』也」作古注詞義參考，實際引文字形另存關係記錄。兩家沒有足夠代數證據，故不造父系接點。

田蚡婚宴所稱燕王女，據《索隱》明指劉澤子康王嘉之女，再與〈荊燕世家〉「傳子嘉，為康王」對讀；不能按當時在位王定父。未名女子的來源父女及夫妻關係均保留，移到嘉的家族根，分支字母不表示長幼，姓名仍未知。
