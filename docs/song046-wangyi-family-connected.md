# 王懿近世父系接合

《宋書》卷四十六王懿傳明記祖宏、父苖、子正脩；採宏以下四代為近世家族，分別為 `qsd_v11_ya1`、`qsd_v11_ya1_A`、`qsd_v11_ya1_AA`、`qsd_v11_ya1_AAA`。人物字元不代表長幼。

苖接宏由同段父與祖的相鄰世次編輯推導，以 `parent_between_consecutive_ancestors` 保存兩條來源斷言與全文引文；不另造「原文明言苖為宏子」的父子斷言。王懿父、祖及正脩父的原斷言保留；父苖一條僅補明父系資格 `lineage: paternal`，其原詞、引文及識別碼不改，以符合連續父系祖先模型的明示資格要求。

兄叡、姊王氏仍保持來源所記兄姊關係，不為湊共同根而指定其生父。姊王氏嫁郭逸的跨家族婚配仍可追溯；不因此推為郭逸兩女的生母。自言王懋七世不接入近世父系；降魏齊郡太守王懿的暫定異人判斷不變。現存傳文為後補傳本文字的資格亦保留。
