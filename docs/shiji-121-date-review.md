# 儒林列傳紀年核查

第19段原文：「何以易，元光元年徵，官至中大夫。」何承接楊何；元光元年修飾徵召，不足以指定中大夫授任年。

紀年對照參考：《資治通鑑》卷十七數位編輯年標「元光元年（丁未，公元前一三四年）」。參考固定版本：https://zh.wikisource.org/w/index.php?title=資治通鑑/卷017&oldid=1511464 。此年標只供紀年換算，不當獨立徵召證據，尚未核影像。

徵召事件已記的日期值：`era: BCE`、`era_year: 134`、`year: -133`、`year_numbering: astronomical`、`precision: year`，並附本篇第19段原文及楊何提及ID。一般人物事件格式已新增徵召類型，保存於 `121-person-events.json`，驗證人物錨點及日期；人物資料包透過 `person_events` 和 `date_normalizations` 提供，與生卒及官爵任期分開。兩項回歸測試確認匯出與錯誤人物、年編號拒絕。

張湯死后六年、兒寬九年而以官卒等相對時間需先核對各自來源事件，尚未換算。完整任官起訖仍未完成。
