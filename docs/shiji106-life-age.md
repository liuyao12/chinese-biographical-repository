# 〈吳王濞列傳〉死亡與報齡

保存十五筆來源死亡、三筆直接報齡，以及末段八處分人王號／將軍錨點。死亡事件與爵位終年分開，不由死亡自動終止官爵。

吳太子僅記「孝文時」，不補單年。齊王將閭飲藥死保留本篇早置發兵段的敘次，與〈齊悼惠王世家〉解圍後的敘述分存。七國之役年段引用同篇發兵紀年、表中原紀年、數位西元對照與漢初建亥歲首規則；只作前155至154年的保守跨年範圍，不推確日。荊王劉賈之死及濞二十歲原紀年「高帝十一年秋」保留前197至196年跨年範圍。

「三月不能下」「圍趙十月」為時長；末段「正月起兵，三月皆破，獨趙後下」的三月為月名，不把趙王之死強置三月。「太后、太子皆死」不補兩人死因。周丘未至下邳而死，不補死亡地。原文報齡不推虛歲或生年，少子不按稱號併入子華、子駒。未核書影。

八處新增標記依本段人物及事件承接：並列「膠西、膠東、菑川王」與「膠東、菑川、濟南王」各分人，共用末尾王字不把整句合成一人；酈將軍依既有酈寄身份，趙王依既有遂身份。別稱只綁定這些來源錨點，不用於全庫字串辨識。
