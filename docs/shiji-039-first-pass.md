# 〈晉世家〉首輪標註

來源為維基文庫《史記》卷三十九固定修訂 2588534。保存142段正文及分層的1段索隱述贊；未核讀古籍影像，數位轉錄不等於版本校定。JSON為編輯來源，XML同步保存行內人物錨點。

本批保存279項身份判讀、58項親屬來源主張、32項稱號記錄、7項人物區分及3項跨篇暫同指。太王／古公亶父、文王／西伯昌、呂省／呂甥均以兩篇具體引文記錄候選同指，保留既有ID及錨點，不按同名批量合併。

## 原文限制

「子胛桓叔」在同版原始標記亦如此，保留疑文及未解錨點，未補字或由此建立莊伯父子關係。莊伯、哀侯等記事與衛篇的弒君對象不同，兩篇原文並存。前段獻公八子、後段九子，以及黑臀的親屬用語均不自行改寫。

僅去除段落外緣空白；鲁、隐、绖分別轉為魯、隱、絰並記錄。郤臻、郤鉤、示瞇明、西乞秫、欒逞、倶酒及原文校勘括號保留。周國、王宮、萬民不當作人物短名。古代異體不全域正規化。

## 稱號與未完成工作

明示命晉君、命伯、為卿、邢大夫、遷家人與敘事職稱分開。將中軍等保留原詞作任事描述；不由初見、死亡、出奔或被俘推定全部稱號起訖。景公拒絕尊王沒有建立王爵授予。日期只記原文連續字串，保留所在段落的紀年上下文。

首輪尚未完成匿名者、代詞、全部稱號與有效時段，也未完成影像、版本及現代研究覆核。冀芮／郤芮、魏壽餘／魏讎餘、欒逞／欒盈及文公秦女夫人等仍需逐項證據，不依常見世系補名。全篇維持未完成狀態，下一篇為卷四十〈楚世家〉。
