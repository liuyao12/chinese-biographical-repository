# 《漢書》卷四十一周氏交叉核讀

以維基文庫固定修訂2342290錄周惞傳文三段，段內具名、上字稱謂、官爵、父子、出身及明示死亡分層記錄。古代篇名仍用〈樊酈滕灌傅靳周傳〉，不把現代網頁小標作古篇；節內穩定段ID讓日後補前文不必重編錨點。其餘傳與贊未錄，本卷與全書皆未完成；完整目錄未建齊，不混用百篇與百二十卷作已核數量。只核數位文字，未核書影。

《漢書》明分周惞子應、應子仲居；《史記》仍記緤子居，原文及父子陳述保留。首選以應為仲居父，與功臣表先應後居相配，但表的繼侯次序不是獨立父子證據。昌、應、仲居共享周緤根，分支字元不作長幼；三代顯示沿首選關係追溯，不另存祖先清單。同書版本與兩書互見不當獨立證實。

數位本「糨城侯」保留原字，以固定Kanripo WYG轉錄「䣙城侯」作暫定校讀，並列來源與未核影像限制，不取代《史記》另一寫法「蒯成侯」。人物JSON的 `preferred_title_readings` 以持職、決定及人物錨點ID連起來源原字與首選讀法，使用端毋須NLU。十二年改封保留前196至195年範圍；周惞孝文五年薨記前176至175年，兩者均依太初前歲首與年表對照，原句分存。應卒年未明，不沿用父卒年；仲居太常坐罪、國除不作死亡。

功臣表九個局部候選接入傳文人物，原「靖／精」「周惞／周緤」「中居／仲居」字形分存，新增八處逐人標記。既有居分支改依首選父系置於應下，更新引用後撤除舊ID；不留永久相容入口。

跨作品目錄及閱讀入口顯示目前所錄範圍，正文從儲存庫靜態JSON按篇載入，人物卡逐人載入，毋須先拉全庫人物表。人物卡、出現篇章、最多提及來源與返回連結使用實際作品，不能把《漢書》卷四十一連到《史記》卷四十一。《史記》原閱讀器與內嵌連續年表沿用。姓名組件保留出處與編輯拆分理由，缺生卒等欄位仍省略。
