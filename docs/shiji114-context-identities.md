# 東越篇的跨篇身份與原稱

逐段重讀十一段，依滅秦分封、救東甌、閩越與南越用兵、吳王濞敗亡及東越戰役，接合漢廷人物、濞與子駒、句踐及作者司馬遷等身份。十六組決定保留各篇原句、提及錨點與暫定理由；十九個舊ID全部引用更新後撤除，不留轉向。

「武帝」璽為餘善刻璽自號，與漢廷天子分開。太尉未足與計指田蚡，大行指王恢，大農指韓安國，奉郢頭前後的六處王指郢；新加十一個不重疊錨點。建元三年太尉田蚡與魏其武安侯傳二年免太尉的時序差異分存，韓安國篇兩越國名差異亦不改寫。

福父成陽共王與齊悼惠世家章之子喜、景紀城陽共王及王子侯表海常列相互辨識，接入既有父系。原文成／城分源保存。表中海常、繚嫈的劉福接同一人，山州劉齒接本篇齒；六個既有表格錨點及短稱不改字、不改位置。海常侯蘇弘另為一人，不能同爵合併。姓名劉福、劉齒據原表，王溫舒與酷吏篇王温舒保兩源字形。

丑與居股不只因同稱繇王合併；句踐之後、禹之餘烈不補世距或強接父系。集解固定數位見證亦有「將軍率」「與其率從繇王」等疑句，本批不以不順即改字；未核書影。齒父系的跨格結構、廣武侯望及更多稱號時段仍待後續，不稱本篇全部覆核完成。
