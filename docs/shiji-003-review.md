# 《史記》卷三首輪標註紀錄

本輪錄入〈殷本紀〉33 段正文。2026-10-09 取得維基文庫 [固定版本 7909145](https://zh.wikisource.org/w/index.php?title=史記/卷003&oldid=7909145)，再次以版本 ID 讀取確認內容相同；移除現代節標題與註號，只將「弃」轉為「棄」，逐段核對 JSON 正文一致。中𤳹、筑、犇等來源字形保留。未核讀影像，不稱點校定本。

## 本批內容

- 348 個連結人物的提及及 36 個未定、氏族、群體或職稱錨點。
- 新增 79 個永久人物 ID，前三卷合計 156 個；包含三位依本文辨認的匿名女性，不補造姓名。
- 10 項跨卷暫定對應及 12 項同篇異稱判斷。
- 50 項來源親屬主張，區分父母、配偶、兄弟與祖父；父子只據明示「子」等語境，不據單純繼位。
- 3 項有原文證據的人物區分記錄，保留同字不同人的判斷。

太丁（湯子）與太丁（武乙子）分開；湯在征夏敘事所稱武王與周武王分開；夏啓與帝乙之子微子啓分開。「帝太甲／太宗」「武丁／高宗」「祖甲／帝甲」「辛／帝辛／紂」保留同篇證據，不將稱號作全域識別字串。

「伊尹名阿衡」保存本文的同指用稱，但不據這一句解決阿衡的姓名／職稱性質。「中𤳹」保留來源字形，未按熟知別稱擅改為仲虺。「巫咸」與「巫賢」各依敘事建立，未補兩者關係。管叔、蔡叔、周公、成王等不在本篇補入未見的本名。

《湯征》《女鳩女房》《仲丁書》《盤庚》《高宗肜日》等書篇名稱中的字不作個人提及。「湯征諸侯」的句首湯則是人物。「益收」「益廣」「益疏」是普通用詞，不連到舜時的益。傅說的說只在本段有個人指向的位置標註，不按字面通用於其他說字。

## 待核查

`historical_tradition` 表示人物由歷史敘事錄入，並不表示已與甲骨、金文、考古材料或現代研究逐項互證。簡狄的玄鳥生契敘事另標示傳說性；既有上古人物原有標記不因新增一卷而被改成已確證史實。

王名、世系、異稱、官稱、代詞及文本版本仍需複核。本篇所述「祖丁崩，立弟沃甲之子南庚」與前文世系的銜接須另考；本批只記南庚是沃甲之子的明示主張，不增添祖丁與沃甲的兄弟關係。太丁（湯子）的太子稱呼保存，未另據此補外丙或中壬的父親。

本批未新增現代研究結論，不聲稱查閱了最新專門研究。稱號有效期間仍待與姓名／稱號模型協調。資料可在庫內 JSON、XML 及證據檔案查閱，尚未投影至人文閱讀器目錄。
