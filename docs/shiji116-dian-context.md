# 滇王的敘事連續性與資料更新

〈西南夷列傳〉後段五處滇王按同篇使事連續性暫接嘗羌：前文嘗羌接待王然于等、助求身毒道；後文同一使者往諭，又以始首善回顧其態度。《漢書》顏師古釋初始以來常有善意，提供語境參考，不作獨立史事的另一票。原段未重出姓名，不能排除未記載的王位更替，故保留中等信心及 AI 暫定狀態。篇末楚苗裔尚有滇王概述王統，夜郎侯亦未在這批強行接合。

新增的滇王用稱不把賜王印、復長其民當初次即位。明紀元封二年前的兩處稱謂沒有日期；其後三處依十月歲首保存前110至109年暫定範圍。兩個任期端點均未知，不補生卒、世系或授號起點。

人物頁生成器改直接讀取權威人物登記。舊流程先生成頁面、再刷新閱讀索引，可能令新身份說明留在索引而未進人物頁。回歸案例以過期索引與當前登記不同的姓名、歷史性和不確定性說明驗證，舊程式會失敗。
