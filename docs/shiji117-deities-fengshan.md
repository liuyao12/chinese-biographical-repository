# 神話專名與封禪書的受頌君主

《大人賦》第53段靈媧、馮夷、屏翳按固定《漢書》古注登記具名傳說角色：服虔釋靈媧為女媧、馮夷為河伯字，應劭釋屏翳為天神使。姓名組件、親屬、生卒、任職均不從神話描述補出。本篇鼓瑟與《漢書》鼓琴各存；女媧是古注明釋的顯示名，不把它偽造成本篇原稱別名。

封禪遺札經取書、奏天子的框架以及古注明指武帝祠五畤，將第59、60、62至64段陛下、天子及君的11處個人指稱暫接武帝。其中9處原為未定，2處君字為漏標；君子保持普通詞。第63段舜已有正確錨點，套用前檢查拒絕重建，沒有新增第二次提及。底本的重複句仍保留，校讀另案處理。

大司馬未具名，不能據同時官員補成衛青或霍去病；第64段帝依古注為天帝，保持既有非個人判讀，不因同句我君為武帝而合併。神話角色及文學問答不生成歷史出行、朝會、祭祀或官職事件。風伯、雨師、玉女、西王母仍未定，不憑飛廉等同字合併。
