# 城陽王子齒與福的原表父系

〈建元以來王子侯者年表〉山州列及海常列的父系欄各記「城陽共王子。」，姓名則分在同列首位「侯劉齒元年」「侯劉福元年」格。兩個原格分開保存全文、人物錨點與固定版本，不拼成傳世正文句子。

城陽共王據〈齊悼惠王世家〉「子喜立，是為共王」接既有人物喜；不是吳王濞之父、代王喜。齒由此接入喜的同一父系，更新全部引用後撤除舊根ID，成為 `yqp_nlb_p1p_ABFAC`。福原有〈東越列傳〉父系主張保留，另增加原表主張。分支字元不表示長幼，不補生母、同母兄弟或未見的生卒。

跨格模型只接受明示父子、同一列父系欄及首位持有人；若前欄已有持有人，或同格先記前任侯元年，不能把後代承爵者當原王之子。來源修訂、兩格全文、父子逐人錨點、父系路徑與原斷言ID均須相符。人物JSON收兩格，卡片與人物頁各自引用並連回兩格。三代仍由人物關係即時追溯喜、章、劉肥，不儲存展平祖先欄。

原表作城陽共王，東越篇作成陽共王，漢書古注作城陽恭王；分源保留字形，不改正文。授爵年月與失侯、死刑年份另待紀年覆核，本批不由父子或父卒填爵位起訖。
