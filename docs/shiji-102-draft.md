# 卷一〇二〈張釋之馮唐列傳〉整理範圍

固定版本1753957保存14段正文與1段索隱，首輪187處人名錨點，新增37筆候選。已記7項親屬與3項來源地點。馮唐祖父、父親、本人與馮遂採同根明示代際，張摯亦採張釋之子ID。仲只記兄，不補共同父親。

明記一處释轉釋，原古字及校勘符號保留。未核底本影像；官爵任免、跨篇同指、漢興徙安陵主體、七年紀年、匿名與來源版本仍待整理，不表示完成覆核。

另保存31項官職爵位用稱與授官、2項明示免職終點。魏尚削爵不直接等同雲中守免職，原任終點未知，復任另記。嗇夫上林令諫止不記已任。另保存7項跨篇同指與馮唐楚相授官公元前157年的換算，原文七年與本紀後七年及許名瑲研究參考一併保留。其他紀年、身份與官爵覆核仍待續。
