# 公孫弘敘事前九段

第二至九段續標姓名、省名、部分帝王與詔答指代。連同開篇共13名來源候選、88處人物及6處未定錨點；管仲、桓公、晏嬰、景公等引語典故人物仍分來源保存，尚未按同名跨篇合併。太常及淮南、衡山、三王、文武的具體指涉待核。

明示子度保存公孫弘父子關係與來源父系路徑，分支字元不表出生排行；不補生母。請歸侯印、乞骸骨未獲准，不作失爵；恐病死不作死亡。

16筆官爵／用稱分別記錄原詞、用稱位置與授免事件。兩次博士授任不合併任期。建元元年、元光五年、元朔三年及元狩二年暫換公元前140、130、126、121年；數位年標只供曆年對應，未補月日。左內史「二歲中」不作精確兩年；度任山陽太守「十餘歲」不補精確十年或失侯年份。公孫度嗣侯依本段明示事件承年，不只據父親死亡推定。

三筆死亡事件保存後母、公孫弘與本段所言主父偃。公孫弘元狩二年終於丞相位暫定前121年，其餘兩筆未定年份。死亡不自動終止所有官爵，不補死亡地點。

《漢書》武帝紀元光元年記對策有公孫弘；本篇復徵明記元光五年，兩者不直接互相覆寫。其餘指代、跨篇身份、完整任期及底本影像仍待核。
