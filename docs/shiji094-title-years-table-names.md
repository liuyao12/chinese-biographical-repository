# 田氏王號紀年與月表省稱

依〈秦楚之際月表〉同人同授王事件，記田儋、田市、田都、田安、田榮、田廣七項起點及田市徙王的一項齊王終點公元年。原日期字串仍為空，另列本傳事件、月表事件、年首、曆月與數位年欄。只換算年，不由在位月序換算曆月；表中另有後九月，也不能用現代年月差反推月份。

田市原稱王，另記所王地膠東，不改正文為連寫的膠東王。田榮本傳先殺田安後自立，月表六月田榮始、七月殺安，兩個次序分存，年份對照不代表月份已調和。死亡不自動補滿王號終期。

月表五格補十處省稱／異稱：田儋、田榮、田橫的同格承接，以及臨濟、田市膠東、田安濟北、田榮平原事件中的儋、榮、橫、市、安與項籍。每處按實際字元位置連到既有人物，不作全域字串替換。表格原字與結構不變，未核書影。
