# 《曹相國世家》第二輪核讀

全19段已逐段閱讀，第19段索隱另層保存；本批資料已納入工作分支。戰役敘事、封爵任事、家屬世系與原曆日期仍待逐項核對人物錨點。

第1–4段：曹參沛人為明示籍貫，沛獄掾、中涓及七大夫、五大夫、執帛、建成君、戚公、執珪、建成侯、將軍、中尉各保存原稱與授予／遷任，不按數字爵名推漢爵標準等級。蕭何主吏有來源用稱。公、夷、趙賁、楊熊、齮、章平、內史保等區分人名與官稱，「司馬夷[1]」保留數位註記，不默改人名。李由及項梁明示被殺，秦候一人、秦司馬及御史各一人為可分辨角色候選，虜不當死亡。

曹參軍事行程按每項實行原地名保存，食邑寧秦不當居處；景陵守二十日為屯駐時間，不作中尉任期。凡二歲包含漢中至滎陽的將軍中尉敘事範圍，不經判讀便掛單一官號。秦滅不按群體推所有官員死亡。

第5–8段：高祖（三）［二］年原校勘不改，假左丞相的代理任事與右丞相分存。夏說、戚將軍、龍且明示被斬；孫遬、王襄、豹、周蘭、田光、許章、田既被擊或被虜不推死亡。魏王母妻子保留群體／角色，不依熟知家屬補姓名。參歸漢相印與齊相國任事為官職變動，高祖六年列侯平陽侯與除前食邑分存；取消食邑不推廢全部軍職。項籍已死為明示死亡回述。二王三相六將軍等功績總數不補全體人物。

第9–11段：孝惠元年除諸侯相國法、改齊丞相為制度與個人稱號變動，齊相九年涵蓋相國／丞相稱呼，不誤掛單一任期。蓋公為具名學者，黃老言為學派用語，是否含黃帝／老子人物提及待語義覆核。舍蓋公是住宿安置；諸儒、長老群體不分造姓名。惠帝二年蕭何卒有明文，曹參去齊與代何漢相國分開。後相與舍人是否單指依本段角色辨認，後相未具名不擅補熟知繼任者。

第12–15段：郡國吏、卿大夫、賓客及從吏仍為群體，斥去吏不推曹參罷相。相舍後園與吏舍為居處／官署原語，不擅補現代地址。窋為曹參子及中大夫有明文；歸、入侍無具體城名不補目的地。惠帝、上、朕、陛下在本段對話局部對應，先帝／高帝與當朝分開；高帝新棄群臣保留死亡婉語判讀，不以免冠謝當免官。

第16–19段：參為漢相國出入三年、卒與謚懿侯分存，三年不是年月日精確任期；謚名不當生前授號。窋、奇、時、襄與宗逐代來源父子及母親依明示保存，尚公主為婚姻，生子明示出生但不推生年。孝文帝立免為侯只終止窋御史大夫任事，不廢平陽侯。二十九、七、二十三、十六年按來源持爵年數，不倒推曆日；宗征和二年中坐太子死與國除明示。太子仍需局部身份證據，不按熟知案件直接補名。第18段信已滅與第19段衍氏既誅不另當具名死亡；田溉與正文田既疑讀不默改，尚主平陽的代際敘述不覆寫正文。
