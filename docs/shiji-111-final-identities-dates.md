# 卷一一一末段身份與紀年續核

第47段魏其、武安分別與卷一〇七竇嬰、田蚡建立有證據的身份對應；各篇原始人物 ID 保留。

據《資治通鑑》卷二十、二十一並記事件，路博德伏波將軍軍役暫定公元前112年，彊弩都尉居延軍役暫定公元前102年；趙破奴浞野侯復封暫定公元前108年，浚稽將軍軍役暫定公元前103年。數字日期、原篇全文引句、並記事件、數位年標及代理判斷均保存於卷篇官爵 JSON。這些換算尚未經人工審閱或影像核讀。

浞野侯同一復封事件可暫定授爵年份。其餘三項僅定軍役用稱日期，不由出征紀年反推授任日；官爵終點仍未定。原文「後二歲」「後六歲」保留，不連續加算以強行消除紀年差異。「彊弩」「強弩」各見證字形分別保存。
