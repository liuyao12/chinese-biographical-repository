# 〈酈生陸賈列傳〉死亡、報齡與紀年續核

先依稱號與共同事件接合義帝、成安君與辟陽侯，分別連到楚懷王心、陳餘與審食其；正式引用更新後撤除三個來源局部候選。各篇遷殺義帝、井陘之戰及辟陽侯被殺的行事、動機與紀年不因此統一。

新增十三項原文死亡主張，包括引語中回顧的死亡；引語仍是本篇來源，不成為獨立見證。死亡主體明分酈食其、武遂侯平、陸賈、朱建母、朱建、朱建子及其他已辨人物。求誅、當棄市、欲自殺、卒不誅及陸生卒拜均不另作已發生死亡。病死不改為執行棄市，死匈奴中不補為單于殺之，所死家之約不作死亡事實。

武遂侯平「元狩元年中」與年表原年欄及獨立數位西元前122年對照分列；依太初以前歲首，死亡月未知，記前123至122年的數值範圍，不取單端為確年。曆法參考為[《曆書》索隱固定修訂2514838](https://zh.wikisource.org/w/index.php?title=史記三家註/卷026&oldid=2514838)的漢始建亥、太初改建寅注。高梁列表的同年病死只作事件平行記載，不能由前列侯勃補出平與勃的父系。其餘本篇未明死亡年份不強填，文帝即位、前段漢三年秋與父死年均不直接套給後續卒日。

酈生囑騎士轉述「年六十餘」，另存直接自報年齡：數字下界60，開放，上界未知。原文不補歲字，不作確切享年，不反推出生年。驗證器支援這種原詞格式，並拒絕把年序詞任意顛倒作報齡。
