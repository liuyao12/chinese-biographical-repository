# 鄭世家第二輪核讀準備

全60段含分層述贊已再次核讀，53項生死、17項地點與三項太子立君終點已納入正式資料；7283份人物JSON已匯出；九組資料檢查、112份XML同步、Python289項測試（546.220秒）、JavaScript155項測試（268.44325毫秒）與語法檢查通過。第1段初封鄭、授司徒與東徙民分開，太史伯的建議居地及桓公未實行的南行、西居不作實際居處。第2段幽王驪山下死與桓公并殺分記，不能直接將并殺之地當已明示。第3段寤生難產與叔段易生分記，武姜偏愛不補所有孩子生母；武公疾不代死亡，27年卒另存。第4段段京、鄢、共以及武姜城潁有實行遷徙，母子黃泉故事不作墓地。第5段周桓王射傷非死亡；衛桓公弒與宋繆公卒、孔父殺各按原文。

第6–17段：昭公忽與厲公突交替立君、出奔及復位需要分次事件，不能以一個連續任期取代。雍糾殺祭仲計畫未行，祭仲殺糾實行；單伯死於櫟有上下文。髙渠彌射殺昭公於野與齊侯殺子亹分存，髙渠彌本篇亡歸不改成他篇死亡。鄭子二子為群體，未選具名個人；原自殺與甫假誅另記。惠王奔温、居櫟及王子穨立殺各有文字，厲公28年包含在櫟17年，不能當連續君位。

第18–29段：子蘭出生、太子授位及繆公立君各分事件；叔詹自殺明示，文公五寵子蚤死是群體，不虛造人名。重耳過鄭不作籍貫。晉文公、周襄王的立君與遷徙為來源所載往事。解揚將被殺後獲赦，不作死亡；霍人可作來源籍貫，字子虎與上卿授予分存。靈公弒、子家卒、襄公卒均有文字，去疾拒立不作既有君位；第26段繆氏群體大夫不擅套全族每位人物。

第30–44段：悼公、成公、釐公、簡公卒各有明文。繻短期立君及成公復歸分次，繻被殺另記。釐公藥殺與對外暴病卒是敘事與通報兩層，不把兩者改成同一死因。子駟、子孔殺與子産卿授職分開；六邑授而只受三邑不記成實受六邑。第40段閼伯、實沈遷徙及金天氏後裔是子産引語的上古敘述，保留傳統性，不與當時人物敘事混同；叔虞出生與夢授唐不同。第43段棄疾弒靈王的本篇表述與楚篇保留分歧，不改來源。

第45–60段：建殺與勝奔呉、定獻聲哀共幽繻各君生死及子陽殺有明文。子産聲公五年卒與其他篇紀年可能不合，原文不校改，換算另列來源及待覆核狀態。三晉滅知伯可存本段表述，不由亡國補每位君主死亡；韓滅鄭亦不推乙死亡。太史公評論與索隱述贊各自保留來源層次，甫假／甫瑕、叔詹／叔瞻等異寫需沿已有證據核對，不能全庫按同字串合併。

53項生死候選已逐項對到原文及既有人物錨點（48項死亡、5項出生），已入正式資料；43項附原文日期表述，其餘日期仍待核。叔虞出生原文用單引號，沿來源字形，不重造引文。

候選原曆日期已逐項核定；武公27年不得借給本段回述的寤生、叔段出生，莊公43年亦不得借給太子忽出生。齊殺魯桓公用本段是歳回述；原、甫假死與祭仲卒暫不拼接月日。孔子卒與子産聲公五年紀年仍待跨篇對照。

17項地點候選已對到既有人物錨點，含幽王驪山下、段至京／奔鄢與共、武姜城潁、馮奔鄭、忽奔衞、厲公櫟、昭公野、惠王温／櫟、襄王鄭／氾、蘭晉、解揚霍及建、勝出奔。建來奔鄭依本篇上下文，不作籍貫；已入正式JSON；其他上古引語地點及遷徙仍需續核。

26筆既有稱號已核對；準備忽、蘭、商臣三項太子立君終點，及子蘭授太子四十三年的原曆起點。祭仲授卿、髙渠彌授卿為回述，不借段首年份。太叔出奔不自動當退號，死亡不終止全部官爵；文公等諡稱不直接換成在世受爵。已納入正式稱號資料，保留既有ID及原始證據。
