# 〈汲鄭列傳〉後續身份接合

本批將七個重複來源身份接到六個既有人物，另辨識一處未定太后。全部仍為代理提出的暫定判斷，未經人工或書影覆核；全篇未完成。

- 〈絳侯周勃世家〉王信及〈汲鄭列傳〉蓋侯信，接〈外戚世家〉王仲之子信。王仲父系保留，不移入田氏。〈絳侯周勃世家〉記周亞夫死後封侯，〈外戚世家〉於立后立太子段合敘，沒有因此補定授爵年。
- 輔少主的比擬中「賁」「育」，依《漢書》同句顏師古注解為孟賁、夏育。正文不擴寫，也不生成兩人在武帝朝任職或存世的事件；少主仍是未定的假設稱呼。
- 袁盎是汲黯所慕的前代直諫者；《漢書》平行句作爰盎。接本傳身份，不把引古作同時交往。
- 莊助為汲黯請告，《漢書》同事作嚴助，連到已有莊／嚴助身份。兩書原字保留，不推生前改姓年月。
- 鄭當時所救張羽，依服䖍注梁孝王將及梁世家、韓長孺篇接梁將張羽。楚相之弟只作古注所言；未辨定其兄，不補兄名或援救日期。兩書同引服䖍不算兩項獨立親見證據。
- 太后弟武安侯蚡的太后，按〈魏其武安侯列傳〉田蚡為孝景后同母弟及〈孝武本紀〉王太后母子關係辨識；不因最近時段另有竇太后便改連竇氏。

逐項來源段落、原句及判斷保存在卷57、卷120身份資料。王信卡片的蓋侯、王、信有篇內明文，未補任期。
