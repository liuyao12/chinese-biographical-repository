# 〈呂不韋列傳〉第二輪核讀

全16段固定數位正文已核讀，未核書影。本批先以昭王五十六年薨與安國君繼位、夏太后始皇七年薨、莊襄王取不韋姬生始皇名政等特定事件，接合昭王、夏姬及未名子政母三項身份；登記6537→6534，現行引用更新後撤除三個舊ID。

真母夏姬與所母華陽分開；本批未接華陽。085匿孕與006秦莊襄王子各存，不選定唯一生物學父系。006第10段太后仍未解，不以本批決定自動補號。未名死太子不補本名、仲父不作父親；王齮與王齕、四公子及荀卿等待續核。芷陽與茝陽原字保留；徙蜀命令不當已赴蜀，免相國不等失文信侯。第16段不韋及嫪毐封文信侯句法與版本待核，不把爵位授給嫪毐。原文、段落與人物提及錨點不變；身份接合不表示官爵、生卒或版本已完成。

第二批地望：陽翟篇首出身；河南洛陽食戶；夏太后杜東、帝太后茝陽、莊襄王芷陽、華陽與孝文王壽陵葬地各自保存。原字與同葬原語不改，不補現代行政區或精確墓址；食戶不當人口或居住時長。

第三批：所母華陽補為獨立非生母關係，真母夏姬不變；安國與政立王改記繼位，帝太后明記薨後謚名及始皇十九年原日期。仍未補西元年、跨篇華陽身份或官爵未明端點。

第四批：七項死亡陳述及十項稱號起點、一項免相終點補年尺度數字；每項保存本篇原句與固定〈六國年表〉秦格、西元附加欄證據。呂不韋歲餘不當明示年，用卒事件對讀。數字年為數位編者對照、未核書影；不補出生年、享年、月日換算或全部爵位終點。
