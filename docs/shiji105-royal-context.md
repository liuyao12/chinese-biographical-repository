# 〈扁鵲倉公列傳〉王侯稱謂與年表接合

問醫諸王中的吳王限本處接劉濞，依漢初倉公活動與〈吳王濞列傳〉封王、文帝時不朝相合；趙、膠西、濟南、濟北、菑川等稱謂仍須依具體醫案核時，不能全篇統一。

「齊王故為陽虛侯」及「因事侯。侯入朝」接將閭；〈齊悼惠王世家〉明記將閭以楊虛侯為齊王。陽、楊各依來源，不改原字。「陽虛侯國」為地名，侯國內的侯不另拆成人名。

〈漢興以來諸侯王年表〉文帝十六年列補將閭、志、辟光、賢、卬、雄渠六人本名及舊侯號共十二處標記。引用固定052篇本名與封爵敘事；「平昌侯／昌平侯」「扐侯／勒侯」異文保留，不改成同字。同列西元164為數位編者對照，不當傳世原文或所有醫案的日期，亦不據之補出病案絕對年。

本批沒有完成全表或全篇的人物辨識、稱號起訖及版本覆核。
