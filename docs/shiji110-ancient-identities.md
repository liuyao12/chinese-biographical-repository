# 〈匈奴列傳〉開篇周秦晉趙人物續核

依卷二至四段的具體遷徙、王室政變、和戎、攻代、北征與刺秦事件，對讀本紀、世家及列傳，接合33組身份；全部有原句、來源篇段及逐人錨點，為代理暫定判斷。42個重複ID先更新全部引用，再撤登記與公開JSON，不保留舊入口。秦舞陽採秦開祖孫的既有家族根，缺代父親仍未知；昭王在武王卒後承立、母為宣太后的幾篇候選接同一節點，避免母后人物頁重複列兒子。

同人不等於所有敘事一致。卷110公劉失稷官與卷4不窋失官、卷110穆公八國與卷5十二國、北擊胡十萬與卷6、88三十萬各存原字。王號以國別、時代及事件分辨，不混周武王與秦武王、周穆王與楚穆王，或田齊與姜齊桓公。惠后仍為襄王後母，不補成生母；淳維至頭曼千餘年世傳不可次，不補千年父系。

〈秦本紀〉第64段王冠及第66段王游北河、王會梁王三處主語，依惠文君元年、連續紀年及惠王卒承接惠文王；只新增這三個人物錨點，梁王保留未定。原文、舊錨點及文字指紋不改。用稱不提前授予帝號；秦王引語的其相李牧不轉作主傳授相事件。

卷73攻楚所稱蒙恬另待古注辨讀，不憑同名併入蒙氏主傳；義渠戎王也不按爵名併入較早義渠君。年表只隨已錄同指更新既有連結與證據引用，表文、紀年與版式不變。使者、南越／大宛王、烏孫婚配、稱號日期及書影仍續核，未宣稱全篇辨識完成。
