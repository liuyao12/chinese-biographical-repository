# 《史記》跨篇身份接合

本批接續太史公作者身份整理，核對〈太史公自序〉的跨篇指稱、相關篇章的朝臣與褚先生署稱。按完整原段、明示異名、共同事件及人物往來判讀，再更新現役人物端與來源端。目錄內的「候選」標籤不是另人的證據。

本批撤除263個重複登記，接回237個現役人物；人物總數由8315降為8052。437個既有正文人物錨及4個既有年表人物錨改接現役人物。這些數目直接比較合併前後的完整原生資料，沒有相加各批可能重複改接的錨點。另辨明《晉書》王坦之文中「羲農」的「羲」，沿用原有錨並接回伏羲，保留傳說人物標記。238個已標記篇章的正文、文本層、錨點與字位，以及年表的原文、紀年和欄位，均予保留。

## 必須分開的身份與判斷

- 司馬錯接回已存在的司馬氏家族根。司馬靳、司馬昌、司馬無澤、司馬喜、司馬談、司馬遷的六個後裔ID及原有缺代位置保留。
- 「武信君」依事件分指武臣或項梁；〈太史公自序〉「慶」依救趙事件及古注指宋義，原字仍作「慶」。
- 「孫子臏腳」指孫臏；孫武另存。韓安國與汲黯同字長孺，亦各存其人。
- 田蚡與其子田恬先後涉及武安侯封號，按段落與時序分辨；白起的武安君另存。
- 魏相敘事中的掾陳平，保留其所屬時代及來源；不因同名接到漢初丞相陳平。
- 褚先生署稱接回同一人物，正名褚少孫另列古注依據。補文是否親筆、何時成文及篇章真偽，各自保留判斷範圍。
- 子嬰與楚懷王心的身份接合，不用來補造有爭議的生父或中間世代。伏羲同指不證明傳說的史實性。
- 自序「燕丹」接燕太子丹，以本傳東保遼東為具名對照；〈朝鮮列傳〉盧綰反後衛滿亡命的年代起因另存，不斷言丹與滿同時在場。
- 田儋列傳的題引人物接田儋，不把同段後續城陽戰事倒灌成田儋本人在場。「子長國之」指高祖之子劉長，不當作司馬遷的字。
- 自序司馬卬與殷王司馬卬同指，保留既有玄孫四代的缺名槽位；「歸漢」「虜殷王」「擊降殷王」原措辭各存，同指不新增自願投漢判斷，也不提高司馬氏遠祖說的可信度。
- 自序司馬氏趙支中的蒯聵，不僅憑同名接到衛莊公。太任、大任各原記錄不同的歷史性限定完整保留。董生首選指董仲舒屬有資格的上下文判讀，不宣稱引語已驗為董氏原話。
- 自序第七十七段的「孫子」題引仍涵蓋孫武、孫臏的可能範圍，未為清空候選而強接其中一人。

## 資料保全與存取

既有來源錨、陳述與身份判斷的識別碼保留。待撤號記錄的別名與證據合入現役人物；額外的 `identity_note`、`review` 等欄位保存在現役記錄或以原始MID綁定的審讀資格中，不覆蓋保留者原有的不同限定。當前候選名單同步去重，固定歷史捕獲的例外限定到既有檔案及雜湊。

發號保留名單同時讀取 `annotation-chain.json` 與 `retirement-*.json` 收據，逐筆驗證其現役身份判斷。判斷索引只在同一次讀取中共用，下次呼叫仍重讀來源。測試另查庫內全部收據，確認每個已撤號均被保留、不能重新發出；刪除舊JSON並不單獨證明發號器已完成這項保護。

重新產生匯出後，可從[人物JSON索引](../exports/persons/index.json)查詢各人的完整資料，或在[人物目錄](https://liuyao12.github.io/ren-wen/cbr.html)開啟人物頁。舊人物JSON及舊號相容入口撤除；最小撤號收據僅供防止重用，並非查詢轉址。線上內容以已完成的Pages發布版本為準。

後續仍須整理各篇未決指代、稱號時段與版本異讀，以及有獨立參考支持而尚未原生採納的身份。本批未包含黃子／黃生、左丘／左丘明的新研究，也未把「衛頃」非人物首選納入本次資料變更；此處只記錄本批已採納的身份範圍。
