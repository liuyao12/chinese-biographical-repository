# 朝鮮篇的原表日期與正文背景年

本傳元封三年夏明記右渠被殺；段內後續合敘五人受封，不能把段首夏紀年當每筆授爵及用稱的確年。本批撤除五筆此類日期，保留授爵事件與原引文；另存四筆原表首封：王唊三年四月丁卯、韓陰三年四月、參三年六月丙辰、最四年三月壬寅。按原欄題元封與固定年列換算，前三者為公元前108年、最為107年；未換公曆月日，也不補韓陰未載的干支。

裨王長與涉何只記元封二年，未明月，保存前110至109年的暫定範圍。右渠被殺的三年夏保持前108年，改用固定原年列參照。成巳之死在王險城未下之後，不沿用前文右渠的死亡日期；事件與誅成巳原詞保留。

涅陽列太初二年格補最的逐人錨點與原表死亡事件。格首二字計數與侯字各保原詞，不把它們當姓名、任期計算或年月；原表明記最死，未知月份依正月歲首保前103至102年範圍。無後、國除不推生物子女數，也不自動結束全部稱號。

《漢書》現行數位表文有幾侯姓名及最的卒年異說，尚未完成固定見證取讀與表格書影核對，列於研究草稿續核；本批不以未核文字改寫《史記》原表，也不強接幾侯表名。原文與既有錨點位置不改，仍有姓名、地望及版本工作未完成。
