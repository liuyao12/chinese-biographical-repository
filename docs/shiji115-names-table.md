# 朝鮮篇姓名古注與原表人物

衛滿姓衛依《索隱》明示，正文王滿不補姓；路人之名依如淳「路人名也」，不拆姓路名人。右渠之子首選名長，據顏師古明言，徐廣引表長路另存。原文長降、長［降］校記不改，也不將王子與先被涉何殺的裨王長混為一人。

最據《索隱》「路人子也名最」，原表子最仍保字面。頂端溫陽侯依本傳辨認，涅陽侯依原表及古注另列異稱，不能把表內康侯追稱推作授爵時已具諡號。

原表平州、荻苴、澅清、涅陽四列，以官稱、封國與降漢功事接王唊、韓陰、參、最。五個原姓名錨點更新指向，功事格新增六處逐人官稱、姓名與親屬代稱；路人與其子最分開。四個原表候選在更新引用後撤除。保留韓陶、秋苴、張阍等尚待續核的來源異文，未憑名稱字形強接幾侯列。

路人漁陽地望須以古注本身作可解析來源另錄，不能用未載地名的正文引句冒充。生卒、授爵紀年與公孫遂許／誅異說仍續核，本批不稱全篇完成。
