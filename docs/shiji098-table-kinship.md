# 江陵王異名與月表父子來源

〈傅靳蒯成列傳〉江陵王被得後致雒陽、因定南郡，對讀本紀臨江王驩及荊燕、韓信盧綰篇的共尉，皆在劉賈、盧綰攻臨江的事件中。《索隱》引孔文祥云共敖子共尉，作另層古注參考；驩與共尉原字分來源保留，孝景、郅都語境的另一臨江王不接入。

《秦楚之際月表》原格「臨江王驩。始，敖子。」明記父子。新親屬陳述直接指該格完整原句及驩、敖兩個人物錨點，包含表、著作、卷篇、來源、固定修訂 ID；不抄成虛構列傳段落。共敖為家族根，共尉使用其子分支，並非由繼位推父子。三處新表格標記逐人連結，原格文字保留。

既有十表的著作、卷篇 ID 納入正式目錄。人物 JSON 的 `table_passages` 提供原格與來源，正文 `passages` 維持正文；人物卡、祖先追溯與人物頁的表格親屬引文可直接回到閱讀器原格，不需 NLU。
