# 南越將領的漢武紀交叉核讀

續錄《漢書》卷六既有固定維基文庫修訂2631854的第133個正文段，保留該見證字形、標點與五個姓名錨點。原有六個不連續節錄段保持不變；目前七段，非全卷收錄或校勘完成。

嚴、甲、遺依同一南越用兵、戈船出零陵下離水、下瀨下蒼梧與馳義侯發夜郎兵的職掌及路線，接回《史記》已有三個官稱人物ID。這是可撤回的編者判讀，並非人工審定。只記來源單名，不補姓氏；嚴不按同字併入嚴助或嚴安。下厲／下瀨保留各自見證，不改寫正文。

另核Kanripo《前漢書》卷六固定提交683113d4baf6febecaf2ccb7913df87c4d68d454，399–435行；人物紀錄附423–435行網址、原引、blob與回應指紋。兩個數位見證不當作兩份獨立史事證據，未核書影，未宣稱全卷可靠。鄰段蛙蟆文字有轉錄疑問，本批未錄入或暗改。

六條稱號分辨「為」所示授任與既有職爵用稱。所錄段未帶年號，不由孤段補元鼎五年或任期終點。〈南越列傳〉文王、明王的「薨，謚為」另記明示諡名事件，不以死亡結束全部王爵。霸陵、邯鄲記來源地望；「郟壯士」只記人物地域稱語，籍貫或居所未明，不推生地、死地、現代行政區。
