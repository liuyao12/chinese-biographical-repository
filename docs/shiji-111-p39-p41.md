# 〈衛將軍驃騎列傳〉第39至41段

韓說、郭昌與荀彘三段姓名初標，新增郭昌、荀彘、弓高侯及衛太子四名來源候選，不按同名自動跨篇合併。樓船將軍保留未解錨點，待朝鮮列傳同事件對讀。郭昌雲中、荀彘太原廣武保存傳首出身原詞，不定現代位置。

弓高侯庶孫保存為祖先後裔主張，保留庶孫原詞；所指姓名、世代距離與庶出所屬代仍未核，不補父親或兩代路徑。新增17筆用稱；龍頟侯小傳回顧追加前段授爵見證與酎金失侯事件，不重複授予。郭昌奪印保存拔胡將軍撤任事件，不作死亡。

明示年號元鼎六年、太初三年、元封四年，依[《資治通鑑》卷20](https://zh.wikisource.org/wiki/資治通鑑/卷020)及[卷21](https://zh.wikisource.org/wiki/資治通鑑/卷021)年標暫換算前111、前102、前107年。年標是數位編輯曆年對應，不作獨立任官證據。

荀彘本篇左將軍明記元封三年，暫換算前108年；通鑑元封二年前109年已記荀彘出征，另保存敘事紀年差，不默改原篇。荀彘死亡依通鑑元封三年同一朝鮮役後被誅事件，暫前108年，未由授任年推死亡。

韓說死亡按[《資治通鑑》卷22](https://zh.wikisource.org/wiki/資治通鑑/卷022)征和二年同一太子宮巫蠱事件，暫前91年。太子殺之與客格殺說兩篇的表述各保留，平行參考不改成本篇原字；未因卒年終止所有官爵。

本批僅核數位正文，未核影像。跨篇身份、庶孫、失侯及奪印年份仍待核；第42段以下未標註，新卷篇未接線上閱讀器。
