# 〈魏公子列傳〉第二輪覆核草稿

核讀現存固定修訂的全17段正文，不宣稱已校對影像或完成全部身份覆核。保存底本「魏昭王子少子」疑文，不暗改正文。

親屬方面，原「公子姊」陳述誤用 brother，改為 sister，保留已發陳述 ID。另存安釐王年長於無忌、公子姊年長於無忌、惠文王年長於平原君三項相對約束，均不補確切排行。異母弟明記不同生母，不補兩位母親的身份。少子記較幼或最幼的未定語義，不指定序號。

新增七項已實行的死亡：昭王、如姬父、匿名父仇、晉鄙、侯嬴、無忌、安釐王。晉鄙與侯嬴用第9段實行敘事，不以前段條件式或自殺計畫當死亡。無忌「飲四歲」不是享年或持職期限，安釐王「其歲」保留相對年。按〈魏世家〉與〈六國年表〉逐項對讀，昭王卒暫換前277年、無忌與安釐王卒暫換前243年；原紀年、相對年及空值保留，換算附固定修訂、事件原句與年表儲存格引用。未知曆日不補。

侯嬴第4段「年七十」另記來源報齡；不指定計歲方式、不反推生年、不當死亡享年。

來源地望另存七項：侯嬴大梁夷門任事、晉鄙鄴卒地、無忌居趙與曾在大梁、鄗湯沐邑、信陵供奉及居趙十年。鄴卒地依同段事件位置判讀；不補現代定位。湯沐邑與供奉新增 fief 類型，未獻五城不當授邑；居趙十年記 residence_year，不當官爵任期。

信陵君授爵按〈六國年表〉安釐王元年同事件暫換前276年，與昭王卒年前277年分開；爵位終點未明。上將軍原有授印與代將終點保留，授印敘事在三十年出征句之前，不把戰役年強行作授印年，去職亦不當信陵爵終止。
