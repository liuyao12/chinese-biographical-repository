# 〈田叔列傳〉古注明名與太子事件

依固定《史記三家註》卷104修訂2514774指定注語，魯王好獵的魯王為魯共王，與〈五宗世家〉魯共王餘接合；御史大夫杜為杜周，與〈酷吏列傳〉接合；兵事太子為戾太子，參照《漢書》卷037相同田仁司直事件及〈外戚世家〉衛皇后子據，接合據。

左相原ID保留，依集解徐廣與《漢書》卷066明名辨為劉屈氂；暴君原ID保留，辨為暴勝之，君為稱謂。卡片標籤顯示古注辨識的具體姓名。古注與平行記載附於身份判斷，不冒充本文原稱，也不補任官絕對年。

褚補所記暴氏奉命責丞相，與《漢書》所記暴勝之阻丞相擅斬田仁不同，保留原文及分歧。車千秋上變仁與訟太子冤的差異仍待進一步整理。本批不將杜氏父兄子弟補成具名世系，也不據古注都城補死亡或葬地。
