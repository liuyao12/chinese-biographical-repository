# 卷九十四〈田儋列傳〉草稿

固定版本2171897全13段傳世正文含太史公論及1段分層索隱述贊已讀、存。全篇明示姓名首輪，其餘指代、親屬排行官爵地點同指待整理。龁轉齕明記，田間田閒及博（陽）原字保留，未核底本影像。

目前38名新增候選、195處人物錨點；田儋傳首狄人及死亡地臨濟下各存一筆來源地點主張。匿名者、代詞及版本複核仍待續辦。

新增9條親屬與相對排行、28條官爵、12項跨卷暫定同指。從弟與弟各存，田間田閒仍分候選；田都被殺與亡走楚兩說分存。擬封與拒受不作實授，田假被逐與田市徙膠東記原齊王號終點。新增紀年年尺度換算及從親結構欄位，始皇出生與死亡年份保留原引句，公元前年份採天文編號與時代年雙存。13項完整檢查通過，含173項 Python 測試及155項 JavaScript 測試。
