# 卷一〇六首輪範圍

來源：[維基文庫固定版本405869](https://zh.wikisource.org/w/index.php?title=史記/卷106&oldid=405869)。保存二十段正文含書信、制詔與太史公論，以及一段索隱述贊，原字、標點及次序保留。未核底本影像。

新增六十四筆候選人物、225處所選錨點；十項親屬、三筆籍貫／死亡／安葬地點、三十四項官爵及四項跨篇同人判讀。袁盎、晁錯、竇嬰依任命與請斬錯事件連到卷一〇一；周亞夫依拒救梁、守壁及吳軍東南奔襲而備西北的事件連到卷五十七。保留候選 ID 與各篇敘事差異。

劉仲—劉濞、絳侯—周亞夫及明載子嗣連入局部家族；張羽弟於匿名楚死事相，保存相對長幼。少子序號未知。被殺太子與起兵太子分候選；少子、起兵太子、子華、子駒的彼此同人仍待判讀，ID 分立不證明歷史上必為不同人。

劉仲代王廢為郃陽侯記明示終點與降封，吳王東帝自稱不作漢廷授予。韓安國與張羽任將軍依並列句，許賞封侯不記實授。未知時段不以死亡補終點。

劉仲受封代王的高帝七年暫對公元前200年，數字、原句與[教育部紀年對照](https://dict.revised.moe.edu.tw/appendix.jsp?ID=2&la=1&powerMode=0&ver=0)同存，只記年精度，不推公曆日。已定天下七年的紀年解讀仍為代理暫解；吳王受封的正文十一年秋與注家十二年十月辛丑分存待核。

核讀[三家注數位文本](https://www.chineseclassic.com/content/953)作參考：徐廣稱德侯名通、父廣，裴駰引漢書則稱德侯廣；正文未補姓名，未宣稱已核漢書該本。索隱引楚漢春秋稱被殺吳太子賢、字德明，僅記引稱，未核原本。古代注家與正文不是同一層證據。

其餘王侯同指、匿名與代詞、書信群體、官爵全時段及紀年、底本影像尚待完成。本篇未完成學術覆核；格式與引用驗證不證明來源敘事全為史實。
