# 卷七十九〈范睢蔡澤列傳〉草稿

保存固定數位修訂2549307的35段正文，范睢至太史公論贊，排除導覽、索隱述贊及版權告示。上書dd按原序，全35段與HTML篇界已核讀。第32段止／足兩項改讀提示另存，正文保留改讀前止、足原語；睢、厀、檐、繆、甐等原字不擅校，未核底本影像或現代研究。

范睢張祿范叔及應侯按明示身分，先生君王稱分說話範圍。韓盧為犬喻不當人物，王慶忌與白公等引古不全域替換。平原與趙王王之弟的說法保留他篇關係差異，虞卿與范睢相印實際去職分存，未知爵位終點不補；唐舉預言與喬松長壽不當已證實。人物逐段待標，未完成覆核。

前3段保存10個新候選與54處錨點。范睢張祿先生按明示更名接見暫接，救范守者未名，欲事魏王仍未定；魏齊魏諸公子族屬不補父親，范詳死不記卒。後32段待標註，下一位置王稽載范入秦。

第4至15段本次新增23個候選，前15段共33個候選、267處錨點。王稽報使外引臣與范自述臣分辨，秦昭王與齊湣引古王曰分範圍；王慶忌整名先定位，王天下動詞與王者泛論未套人物，韓盧犬喻未當人物。文子未強接田文，後20段待標，下一位置范睢收韓之議。

位置覆核：「皆匡君之事」的君指秦王，撤回誤圈之字的個人對應，原錨點ID保留為撤回未解記錄，正確君字另立錨點；正文未改。

第16至23段新增9個候選，前23段共42個候選、467處錨點。范睢范叔張君與應侯按明示暫接，須賈與范互稱君依說話者。田文與文子分存待核，崔杼淖齒合敘王稱未強接，主人翁微行擬托角色未補姓名。後12段待標，下一位置秦昭索魏齊。

短名覆核：第19、20段睢字依范自述及敘事語境補同指，其他王、君、臣範圍不擴張；前23段目前共473處錨點。

第24至31段新增23個候選，前31段共65個候選、669處錨點。王之弟原字保留，平原勝君與信陵公子局部暫接；唐舉蔡澤互稱先生分辨。馬服子不補趙括，商君公孫鞅與管夷吾管仲按本篇暫接，預言長壽不當核定。後4段待標，下一位置蔡澤功成退身長段。

後4段新增18個候選，全35段姓名首輪共83個候選、821處錨點。越王事大夫種與句踐本段暫接，候選更新標籤而保留ID；白公與韓子仍未定，喬松不補個人，范中行族稱不接范睢。預言、擬長為應侯與稱孤不當實授，去相實際事件仍待時段記錄。

已保存8項親屬來源主張及29項官爵用稱。昭母宣、兩同母弟共母及穰華為宣弟只按本段明示；平原王之弟按本篇孝成王敘事保存而不改字，與他篇待核。6項明示去職／廢止分別連到原段：穰相收印、廢太后、范免相、虞解相印與捐侯、蔡歸相印；上卿、應侯及其他爵不自動終止。任相與封應侯相鄰段紀年未直接合定，蔡綱成君只作號稱，黃金印紫綬願望不當實授。

任相表述覆核：虞卿受相印記為相職授任，保留原語作證據，不把印物當官名；去職仍依解相印原句。

已先保存5項跨篇暫同指：范睢／張祿／應侯、魏齊、虞卿、宣太后及高陵君。逐項引用穰侯、白起、平原虞卿、魏公子列傳原段與錨點，以封應侯、白起遷死、魏齊亡梁及昭王母弟配置作證；原稱、紀年與官爵起訖仍分存，其他跨篇人物待續核。

另保存秦昭王、穰侯魏冉、華陽君羋戎與涇陽君4項暫同指，目前共9項。引用秦本紀及穰侯、白起列傳，以逐四貴歸陶、母弟配置、羋戎爵稱橋接與質齊作證；質齊及國政紀年保留各篇原敘，不補爵位終止。卷篇引用驗證通過。

跨篇暫同指增至12項，新增信陵君、侯嬴及平原君，並補虞卿一見賜金璧、再見上卿的原段證據。侯嬴以梁地及同一公子交往圈作暫定對應，未將兩段當成同一事件；平原君王之弟／趙惠文王弟兩種記載分存，不由人物同指調和親屬異說。

跨篇暫同指增至14項，補白起及趙孝成王：以長平、遷死、應侯議論，及虞卿金璧上卿次序作證；趙世家太子丹立孝成王的名號橋接另存引用。白起死因、卒月及平原親屬差異不因同指消除。引用驗證通過，完整檢查待完成其餘收尾後執行。

全35段姓名首輪狀態已整理，仍非全部人物與學術覆核完成。8項親屬來源主張、29項官爵用稱（6項明示終止）及14項跨篇暫同指各存證據；官爵未明日期維持未定。下一卷為〈樂毅列傳〉，本卷引古與匿名者、其餘跨篇對應、版本及現代研究列為後續工作。
