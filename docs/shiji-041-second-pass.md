# 越王句踐世家第二輪準備

全29段含另層述贊已再次核讀。少康庶子到句踐二十餘世為遠祖，不作直接父子。允常卒明示；闔廬且死為將死語，待吳篇實際死亡互證，不把射傷直接作死。句踐殺妻子願及文種阻止不作死。子胥欲自殺被止與末段賜劍自殺分開，後段已殺子胥可互證。呉太子殺、夫差自殺、嚭誅、種自殺各有來源。甬東君百家是未受的安置提議，非已居或已授君。句踐及後五君卒、無彊殺有明文。范蠡上將軍、齊相授任及歸相印有職事時段；朱公、鴟夷子皮為異稱，非爵位。長男欲自殺被母阻止不作死，中男第25段論殺並有喪歸，不與少子混。中男殺人受害者未名不補姓名。范蠡陶老死與居陶及少子出生分記。第16段殺其將為策略條件，不造各將死亡。無彊及楚威王時間與後世研究異說仍待核，原文不校改。

第二輪另已逐項核對16筆生死與10筆地點候選的原文及既有人物錨點；16項生死與10項地點已納入正式JSON，7283份人物JSON已匯出；九組資料檢查、112份XML同步、Python289項測試（298.367秒）、JavaScript155項測試（494.043333毫秒）及語法檢查通過。地點包括會稽保棲、引語中的重耳奔翟及小白奔莒、范蠡到齊與海畔耕作、到陶與居陶、莊生負郭居處、長男至楚、范蠡死於陶。不將湯與文王拘禁地或人質所在混作一般居處；中男死地及少子出生地仍需明確處理跨句上下文證據，暫不補。

核對既有17筆稱號：范蠡齊相的授職及歸印已各有來源事件，保留既有記錄；上將軍只是用稱，不能從首次記載倒推任職開始。六位後代越王的明示立君已補有據開始，日期未載；不以君王死亡自動終止全部稱號。甬東君百家的未受提議不作已授爵。
