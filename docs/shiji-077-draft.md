# 卷七十七〈魏公子列傳〉草稿

保存固定數位修訂367917的17段正文，自魏公子無忌至太史公論贊。人物導覽、索隱述贊及現代版權告示不混入正文；正文與HTML邊界已核讀。未見括號改讀提示，為、釐、籣、埽等原字保留，未核底本、影像或現代研究。

如姬父及仇人保留未名，毛公薛公不補未見姓名。趙王擬封五城但不忍獻不記實授，鄗湯沐邑另存；信陵爵與上將軍任事各別保存，代公子將不能終止所有稱號。魏公子兵法書名不自動當人物。全17段正文已核讀，人物待逐段標註，未完成覆核。

前3段保存8個新候選與42個錨點。魏公子無忌與信陵君、安釐王與魏王按本段明示暫接，趙王田獵仍未名，陰事客單存不補姓名。後14段待標註，下一位置為侯嬴夷門監者。

全17段明示姓名首輪已存，本次新增20個候選，全篇共28個候選、400處錨點。魏公子兵法保留書名未解錨點，偽賀魏王只作無忌擬立王稱不作實授；軍令父子兄弟、五霸及夫人有德泛稱均不補人物親屬。親屬、完整官爵時段與跨篇身分仍待補。

已保存6項明示親屬主張及13項官爵用稱：無忌父昭王、異母弟關係、平原夫人的兄弟及夫婦、平原君兄惠文王與如姬父未名。異母不補兩母。上將軍授印與後代公子將保存授任與明示終止，不終止信陵爵；五城不忍獻不記實封，晉鄙將軍僅任事用稱不由領軍事件補授官。

已保存12項跨篇暫同指，逐項引用魏、趙世家、秦及高祖本紀、白起及平原列傳原錨點。魏公子無忌／信陵君沿既有canonical ID，魏昭王與安釐即位、晉鄙奪軍、芒卯華陽敗與高祖擊黥布均按共同事件。無／无、篇間紀年及數字分存；田獵趙王、反間秦王與被虜魏王不自動合入。全篇仍為姓名首輪，未完成學術覆核。

時段覆核：上將軍授印先於安釐王三十年出征句，未直接繫年，授印日期保持未定；明示被代將終點仍保留。十三項完整檢查通過後，此處去除過度繫年另以來源／引用驗證複核。
