# 〈季布欒布列傳〉趙同及交往人物接合

本篇曹丘生所事趙同，與袁盎篇及佞幸篇的文帝時宦者、參乘趙同接合。固定Kanripo《漢書》卷三十七在同一曹丘段寫趙談，李奇注明宦者趙談；另列徐廣所報漢書異名與避諱解釋。只合漢文帝時此人，與春秋趙同分開。原文趙同不改為趙談，古注與正文分層。

灌夫、籍福依季心與袁盎、郅都的同時代脈絡，兩人在魏其武安篇成對交往及汲鄭篇汲黯善灌夫等網絡線索暫定接合。沒有直接跨篇明言同人的句子，判斷限於上述交往網絡，遇反證需重審；不是原文明言的同指，不由弟畜建立兄弟、不推生卒或父母。

三組同指遷移後撤除五個舊ID，保留來源提及與判斷ID。身份判斷加入跨篇引文與參考，人物頁可在名物辨讀中查看理由、古注與限制。漢書僅核指定數位引句，保存固定提交、葉碼與內容指紋，未核書影、未整卷匯入。本篇仍須續核生卒、官爵與泛稱，未宣稱完成。

資料已重建；14項針對性Python測試、805項完整Python測試（663.406秒）、222項JavaScript測試、語法與各項資料驗證通過。三組行內標記及三個人物頁名物辨讀區均通過桌面／手機瀏覽器檢查；38段受影響正文及既有錨點位置不變，只遷移五個舊人物ID。既有網址發布待前一批發布及線上驗收完成後依序進行。
