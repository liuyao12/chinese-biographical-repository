# 〈張丞相列傳〉漢廷人物與指稱

依改立太子、周昌護趙王、擊陳豨及誅諸呂立文帝等連續敘事，接合十二組已發身份，遷移全部引用後撤除十六個重複 ID。包括太子／孝惠、戚姬、如意、呂后、留侯張良、項羽／項籍、陳豨、絳侯周勃、漢初陳平、曹窋、呂祿及第十九段今上。

補兩處漏標：第八段「周昌令王稱疾」之王限定如意；第十段任敖隨高祖東擊的項籍為項羽。原文字串與既有提及 ID、範圍保留，僅增兩個人物錨點。

高祖欲以如意為太子是未實行的改立提議，不添如意已任太子的持職。太子、孝惠及曹參篇惠帝依同一君主前後身份接合；如意卡片可沿既有來源關係顯示生母戚夫人，不將呂后當生母。

曹窋接曹參子窋及高后時行御史大夫事的平陽侯，保留正文括注「（不）」未定，不因身份接合裁定其是否參與誅呂。曹參、曹窋及後世曹時不因同平陽侯合人。呂祿不合呂產，周勃不合周亞夫。

篇末漢初相臣陳平與後段魏相時掾陳平分人。第十九段今上由景帝後任相名單及第二十一段孝武承接，限定武帝；不套用後載宣、元帝敘事。後段太史公署稱與作者傳承仍待可靠底本覆核，不據此核定為司馬遷。
