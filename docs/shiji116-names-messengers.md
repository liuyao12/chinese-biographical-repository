# 西南夷篇的使者、姓名與來源分層

柏始昌、呂越人在西南夷與大宛篇的重複ID依姓名、共同使者與求道區域接合；王然于／王然於已有同一ID，不另造人物。元狩初遣與南越破後多批遣使是不同任務，年月與使團集合遇害記載不合成兩人的個別卒年。兩個舊ID在全部可編輯引用及每人匯出更新後撤除。

顏師古注明言多同其侯名、當羌滇王名，宋祁報《史記》嘗字。人物卡保存夜郎侯、多同與滇王、嘗羌；姓未詳省略，當羌另列。後段夜郎侯、滇王未定指稱仍不據爵稱強接。

唐蒙任番陽令的任事地、張騫回報先前居大夏的居地分存，不作籍貫或出生地，不由回報年推居留起點。莊蹻王滇只記來源王號與所王地，不冒作楚王授予或已知始末。

《漢書》所見嘗破與《史記》常頞分存，不任斷為另一姓名或普通詞；朱一新《拙盦叢稿》只保疑是人姓名的意見，僅閱網站摘頁，不補出版年、頁碼，不驗證其論證。其引漢書作常破亦與本次Kanripo嘗破分開。

《索隱》楚莊王弟為盜者與正文苗裔分層保存。機讀的未採納弟說有同輩數值0及長幼方向，但不加入親屬陳述或家族邊，不補莊蹻父系。原文、古注、後出考證的讀法不互相覆寫；所有來源均未核書影。
