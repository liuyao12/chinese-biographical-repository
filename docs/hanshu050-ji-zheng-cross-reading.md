# 《漢書》卷五十與〈汲鄭列傳〉對讀

本批只錄汲黯、鄭當時及篇內翟公九處節錄，72處人物與7處未定稱呼錨點，為24個已有人物補上來源；沒有新建人物。張釋之、馮唐與其餘傳文、贊未匯入，卷50與《漢書》都不標完成。

來源是[文淵閣四庫本《前漢書》卷50固定數位檔](https://github.com/kanripo/KR2a0007/blob/683113d4baf6febecaf2ccb7913df87c4d68d454/KR2a0007_050.txt)，提交與Git blob、原檔及節錄指紋均保存。全檔349行已讀，只有明列九處節錄錄入本篇。原行、頁標、圓括號夾注及首尾抽取位置在來源欄，可回查每字。沒有補標點或簡繁轉換，未核書影。

正文與夾注分離，保留所見注語與後出校語原字；卷末考證未當作班固正文。跨頁注語原來分作多組括號者照存，不算不同注家或獨立證據。卷末考證轉引《公卿表》的官職年份未冒作本次親見該表。

本見證有十世、居淮陽十歳、姊子、大司農、大吏，《史記》相應的七世、七歲、姑姊子、大農令、太史都保持原樣。世數、任期或稱號差異未以一書直接覆寫另一書；不因同一故事平行出現就計為獨立歷史見證。

同句朋友及宗正職對讀，將劉棄疾接到既有宗正劉棄，人物頁可用有據的宗正、劉、棄疾；不接楚平王棄疾或補父系。傅伯／傅柏、嚴助／莊助、爰盎／袁盎、荘／莊分源保存，不補改姓年月或把伯當作已確證本名。

三條親屬記錄各保存本書原句：仁為黯弟、偃為黯子、司馬安為黯姊子。最後一條用`maternal_uncle`表達司馬安的舅為汲黯，母系、客體較主體早一代，母親ID為`null`；不補母名、丈夫或缺代人物。《史記》姑姊子的原字與待解範圍分存。

以嚴見憚的嚴是品行詞，太子洗馬及太子舍人是職名；假設少主與泛稱主保留未定。大父行是交遊年輩，不作祖父；昆弟、十人或六七人不生成未名個體。一死一生是翟公署門引語，不作卒年。人物、親屬、生卒地望及官爵任期仍須接續覆核。

籍貫另存傳首「汲黯字長孺濮陽人也」及「鄭當時字荘陳人也」的濮陽、陳，保留某地人也原詞；不推為出生地、任所或現代轄區。
