# 《商君列傳》第二輪：全十一段

已逐段核讀本庫固定數位轉錄，修訂 8764712；未核印本影像。原文「秦封之於、商十五邑」的缺字疑點、厀、朞及筑（都）等字樣保留，不憑記憶補字。

## 生卒與地點

六項死亡為公叔座、龐涓、五羖大夫、祝懽、秦孝公、商鞅。五羖大夫與祝懽在趙良引語中，證據保存其引語範圍；商鞅被殺與車裂合存一事件。未執行的殺令、公子虔刑劓、公孫賈黥、太子申與公子卬被虜不是死亡。滅商君之家不逐人生成姓名或死亡。

六項行程／死亡地／籍貫地址為商鞅西入秦、去魏、復入秦、走商邑、死亡地鄭黽池，以及五羖大夫荊籍貫。人物錨點指向相應敘事；秦自雍徙都不是每人遷居。另以第七項 `polity_lineage_affiliation` 保存篇首衛公族地望，讓人物 JSON 可直接辨認政體宗族關聯；不強轉本人籍貫、出生地、居地或具名父母。

龐涓死亡暫對照西元前 341 年，秦孝公與商鞅暫對照西元前 338 年。定年依固定版本〈六國年表〉相應事件欄，數位編者西元欄另存引句與儲存格 ID，精度僅年，未核影像或曆表。鄭黽池與年表彤地保持來源差異，不因定年改寫死亡地。

## 稱號及身份

二十一筆既有稱號 ID 保持。商鞅相秦十年保存原數詞及持職年數；五羖大夫相秦六七年保存相鄰數詞約數，精確值為未知，不取六、七或六十七，不設嚴格界限。兩項持職年數均不推完整任期總長或精確起訖。另對讀〈秦本紀〉十年大良造與圍安邑、二十二年封列侯號商君及〈六國年表〉對應事件，保存大良造任用暫定西元前 352 年、商君授封暫定西元前 340 年，均僅年尺度與編輯暫定。左庶長三年／居三年敘事有歧義，任用年不補；所有任期終點保持未知。公子虔杜門八年、行令十年不是官職任期；後五月不直接換作曆月。

公叔座與他篇未名公叔未見足夠同指證據，既有身份範圍保持。商君、衛鞅、公孫鞅沿用篇內身份判讀，缺字封地不補；秦太子立不當秦惠王諡號已被授予。匿名者、跨篇身份、版本、紀年與完整稱號時段仍待覆核。
