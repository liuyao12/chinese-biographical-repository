# 〈秦始皇本紀〉第二輪核讀

本輪核讀全部127區塊，即111個主段及16個嵌入刻辭／引文區塊。原文字未改寫，823處既有標記及ID保留；186處未連到個人人物，包含群稱、匿名者、普通詞誤候選與未定指代，不宣稱辨識完成。

本篇保存64筆生卒見證、125筆地點主張（含原有3筆）及84筆稱號。相同人物的正文、賈生引文與附載班固文字的死亡回述分存，不代表同人死了多次；使用端可依段落的text_layer讀取來源層次。班固建立來源限定作者ID `gxd_15x_9d0`，附載文字不當司馬遷正文。

開篇秦質子及秦王指代限於語境。上會稽的上是登山動詞，保留未連人物的候選錨點並說明。荊王在昌平君被立前後有不同主體，不合併被俘者。泰皇為未採用提議，皇帝及始皇帝、太上皇追尊分開；胡亥立太子的詐書不當始皇真實授予。從職名並列不推董翳亦為長史，左右丞相按明示用稱分記。爵制分類仍待專門覆核。

扶蘇長子原已保存為兒子中第一；胡亥少子原已保存較幼或最幼、名次null，本輪核對未改。趙成為趙高弟另保存出生先後約束，不給絕對名次。

巡行、為質、死亡地、葬地及籍貫分開。望祀九疑山不當親至；求仙目的地不當已到達；阿房施工或復作不當始皇或二世已居。原文徐巿、茝陽、酈邑及各葬位字形保留，不補現代位置。若干省略主體段落的行跡仍待跨段引用整理。

卷末世系與〈秦本紀〉的父子、異稱、享國年數與葬地差異分存。出公自殺與前篇出子被殺保留；二世生十二年而立與前文元年年二十一不一致，不默改或倒推生日。畢公／哀公、憲公／寧公、靜公／竫公及韓終／韓眾等同人仍待證據。

數位見證尚未影像校勘；目前為AI代理核讀，不冒稱人工審閱。尚待原紀年轉西曆、稱號完整任期、未決人名及各篇相反主張的編輯選擇。127區塊第二輪通讀不等於全篇人物收錄完畢。
