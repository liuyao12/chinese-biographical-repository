# 韓世家第二輪核讀

全36段正文及末段太史公評論已再次閱讀。本筆記保存來源判讀，生死、地點及稱號補充已納入工作分支；不表示全部人物身份、紀年與版本已覆核。

韓武子受封韓原與「後三世」韓厥分存，不補造缺代父子。第2段趙盾已死屬回述；誅趙氏的群體敘事不據以補每個人的死亡。韓厥卿號獻子、獻子老與卒、宣子代及徙州，各分事件。第6段宣子伐鄭的晉定公十五年不直接借作宣子卒年；宣子卒、貞子代與徙平陽各按原句保存。貞子、簡子、莊子、康子的卒與繼位相承，不臆補年份。

景侯九年卒、列侯十三年卒、魏文侯是歲卒、文侯十年卒、哀侯六年被韓嚴弒、懿侯十二年卒、申不害昭侯二十二年死、昭侯二十六年卒都有明文。第13段聶政殺俠累可存具名死亡；第20段「韓姬弒其君悼公」身份與紀年有疑，不逕同昭侯或其他國君。預言昭侯不出門不當二十五年實際死亡。申不害相韓八年有授任敘事；公仲擬往秦而止，不作已實行旅程。

第24段宣惠王二十一年卒；第25段秦武王卒在襄王五年敘事。屈丐、唐眛等敗軍不等於將領死亡；斬首人數不生成匿名個人。太子嬰十年朝秦而歸、十二年死分存。公子咎與蟣蝨爭太子不等於兩人均已受任；蟣蝨質楚與竟不得歸韓保存實際狀態，蘇代建議及楚王欲納不作完成返國。咎在第28段明示立太子，至第29段襄王卒、咎立釐王可建太子終點。

第27段公孫昧入韓有實際行程；司馬庚三反郢與甘茂、昭魚遇商於為引語所述，不借本篇年度。羋戎為秦太后弟按來源保存，公叔伯嬰的恐懼與求質子建議不當已執行事件。第30段公孫喜被虜伊闕不作死亡；暴捐走開封可存遷徙目的地，齊湣王出亡無具名目的地不補。

第31段釐王二十三年卒、桓惠王繼位；陳筮見穰侯未明示地名，不依熟知政治背景補秦地。第32段桓惠王十四年「殺馬服子」有具名死亡，四十餘萬卒為群體；二十二年秦昭王卒另記。第33段桓惠王三十四年卒。第34段王安五年韓非使秦、被留及殺有明文。第35段王安被虜、韓亡不推出王安死亡。
