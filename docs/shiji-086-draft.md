# 卷八十六〈刺客列傳〉草稿

固定版本2388562的38段正文已實際核讀。索隱述贊另層待收。數位縣異文提示另存，普通括號衆保留，異體原字不擅校。匿名人物、嵌套指代及跨篇身份待標註；未核影像與現代研究。

前5段明示姓名首輪已存，曹沫與曹子跨篇待證；王序與伍子胥伍員按局部承接暫接。後33段待標註。

前11段明示姓名首輪已存，公子光闔閭依自立敘事暫接。專諸子、豫讓妻友未名，母老子弱及范中行氏不補名。後27段待補。

前19段明示姓名首輪已存，聶政政與姊榮按同一事件暫接，母與榮夫保留未名；韓君俠累季父語境仍待核定，未與哀侯直接合併。後19段待補。

前30段明示姓名首輪已存。荊軻、慶卿、荊卿依正文異稱明示暫接；魯句踐保留完整姓名，被虜韓趙王及狗屠、主人均未補名。後8段待補，授上卿與懸賞邑萬家須分別處理。

全38段明示姓名首輪已存。蒙嘉與代王嘉分開；徐夫人未推定性別，所待客、宋子家丈人及董生保留未名或氏稱。篇末太史公否定荊軻傷秦王之說，保存公孫季功、董生經夏無且的口傳鏈，尚未獨立核實。稱號、跨篇身分與匿名代詞覆核仍待補。

新增12條有來源親屬陳述與19條稱號記錄。保存吳王僚父系為本篇主張，仍待跨篇異說覆核；授上卿與秦王購首邑萬家分開，後者不作授爵。年月保留原文相對表達，不以死亡補任期終點。

新增6項跨篇暫同指：曹沫／曹子、荊軻、燕丹、秦王政、樊於期及蒙嘉。逐項列實際段落與提及ID；保留體解／左右殺軻、劍／匕首、亡地數量及刺秦修辭差異，不自動調和或補為確證。
