# 卷七十六〈平原君虞卿列傳〉草稿

保存固定數位修訂7909284的19段正文，自平原君趙勝至太史公論贊。人物導覽、索隱述贊及現代版權告示不混入正文；正文與HTML邊界已核讀。三項括號刪讀提示另存，正文保留改讀前以爲韓魏不救趙也而王之軍必孤有以、何、彊原語，不當已校定；第12段數位饱轉繁體飽有明示記錄。爲、檐、槃、説等原字保留，未核底本、影像或現代研究。

趙諸公子不補父親姓名，平原君三去相三復位不合連續任期。取勝普通詞與勝姓名、遂副詞與毛遂短名按局部判讀。公甫文伯母妻論為引古，不補配偶與自殺女子姓名；李同父李侯不得改為李同追贈。全19段已核讀，人物待逐段標註，篇級整理中、未完成覆核。

前3段明示姓名首輪保存10個新增候選與77處錨點。平原君趙勝與毛遂先生按明示暫接，取勝不是趙勝人稱；躄者、美人及門下前對者保留未名。趙諸公子不補父親，食客人數不補成員，三去相三復位仍待時段整理。後16段待標註，下一位置第4段。

第4至10段已接續，累計22個篇內候選與204處錨點。楚王與舉平原之趙王暫留未名，毛遂遂短稱與遂副詞分開，相士非任相。李同父李侯按同段父稱暫接，不改為李同追贈；親戚與子孫不補世系。後9段待標註，下一位置第11段。

末9段已接續，全19段首輪累計37個篇內候選與362處錨點。長平至魏從的趙王依前後明示孝成王暫接，秦齊兩王未名，樓昌昌、趙郝郝與樓緩緩樓子限定本篇。公甫文伯母相室保留引古，母妻評語不補配偶，萬戶侯卿相複合語待核。親屬、時段與跨篇身分仍待補，篇級整理中。

已保存2項來源親屬主張：李同父未名及公甫文伯母未名；不從平原諸公子補父親，不從母妻評語補配偶。14項官爵／用稱分存，李侯受封者是李同父，毛遂上客按明示任用，虞卿再見趙孝成王為趙上卿保存授官。平原三去相三復位僅存任事用稱，未知各次起訖不補；鄭朱貴人不當后宮官爵，虞卿擬請平原封地不作實授。

已保存8項跨篇暫同指，引用秦本紀、趙世家、魏世家及白起、孟荀列傳實見人物錨點。平原君卒年十四／十五各留；春申與信陵短稱不回填未見姓名，鄒／騶原字保留。身份對應不調和紀年、戰次或太史公動機評論。全19段僅為姓名首輪，學術覆核、匿名角色及完整時段仍未完成。
