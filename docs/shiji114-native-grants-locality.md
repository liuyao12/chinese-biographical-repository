# 東越諸侯的原表首封與人物地望

北石侯吳陽、開陵侯敖（原表姓名建成）、東成侯居股（原表居服）、無錫侯多軍各以原表封國、功臣事由、首封年格三份證據記錄，保留原字，不改正文異稱。北石列的後任首不因此推為吳陽之子。

北石列元封元年正月壬午保留干支，僅換算公元前110年；開陵、東成列閏月未明閏幾月，保留公元前111至110年範圍。無錫列只記元年，依欄題元封保存分欄紀年，也保留111至110年，不補月份或干支。東成事由的「功侯，萬戶」保留原句，不當居處資訊。

正文「錢唐轅終古」記為來源所記人物地望，並非確定出生地或現代戶籍。地名錢唐與人物原名保持原樣，不換現代轄區；《漢書》軍卒／榬與《史記》將軍率／轅的異文仍分存。

原表、正文與既有逐人標記不改；死亡、太初改曆與完整爵位終點仍須分別續核。
