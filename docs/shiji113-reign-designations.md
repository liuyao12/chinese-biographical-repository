# 同一君主的來源紀年稱謂

〈南越列傳〉「高帝已定天下」之後的「漢十一年」，與《漢興以來將相名臣年表》的「高皇帝元年」下十一年對讀；「孝文帝元年」與表「孝文元年」對讀。兩處原紀年不改寫，數字各存前197至196、前180至179年的保守範圍：太初前以十月歲首，原事未載月日。

`regnal_year_table.era_name` 保留表內帝號，`source_era_name` 保留本篇紀年稱謂。`reign_designation` 保存同篇已辨人物ID、提及錨點、限定語境及可撤回理由。驗證須核對實際錨點的篇、段、人物與原稱，不能僅提供任意別名字典。現只接受本批兩組經核語境；未知帝號對照須另列證據與擴充規則，不能通用推算。

兩份來源分列年號起點、原年字、數位年格及曆法原句。數位表格不是另一項人物事件證據；不以死亡補爵位終期、不把即位當父子、不倒算月日。原始事件、引用與逐人JSON仍能分別查核。

路博德、楊仆兩項元鼎五年秋授將的單年數字不變；改以固定修訂2607038的元鼎起點、五年及數位112格配合曆法原句作參考，不再只引未固定版本的數位年標。

《漢書》本紀p133的六項官爵用稱，與〈南越列傳〉同一用兵的原稱、路線和元鼎五年秋另作事件對讀，六項用稱數字年記前112；只有「為戈船」「為下瀨」兩件明示授任另補授將起點數字。所有《漢書》原日期欄仍空，平行原事件、原紀年及數位年格分列。伏波、樓船與侯爵的既任用稱不因此變成授爵，未知始終仍未知。
