# 〈衛將軍驃騎列傳〉第42至48段

末七段保持原次序，正文與附載索隱贊分層保存。全48段已有姓名／稱呼初標，106名來源候選；這不是全部身份、代詞及版本覆核完成。

霍去病軍功總述的最為總計，不解析成最高等級官名。校吏六人、將軍二人、衛氏五侯等保留群體錨點，不據數字補造個人。太史公、魏其、武安新增來源候選，具名跨篇同指仍待核；索隱贊姊、皇極、平陽、嫖姚依本篇語境暫解，未當正文或獨立婚姻證據。

路博德平州人、趙破奴故九原人照原字保存傳首出身，不推現代位置。路博德屯居延不直接轉成卒地。趙破奴生為虜所得、遂沒其軍不是死亡；後坐巫蠱族記主語死亡，未單獨補安國死亡，卒年仍未知。

趙破奴其太子安國保存父子原句與來源家族路徑，未補生母或排行。太子用稱暫未分類，不推皇族或立國。樓蘭王與圍趙破奴左賢王另設來源候選，不按爵稱合併更早軍役人物。

新增16筆官職及其他用稱；符離侯、從驃侯的小傳回顧追加原授爵用稱與明示失侯事件，不重複授予。浞野侯復封與從驃侯分開，益封不補戶數，被俘與死亡不自動終止全部官爵；任官、失侯相對紀年仍待核。
