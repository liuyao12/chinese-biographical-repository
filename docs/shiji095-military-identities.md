# 〈樊酈滕灌列傳〉軍將平行戰役接合

依碭東、東阿濮陽、雍丘、開封曲遇、陽城宛、還定三秦與彭城敗還前後的戰役敘事，接合司馬夷、章邯、李由、趙賁、楊熊、章平、南陽守齮、王武與程處九組身份。全部引用更新後撤除二十八個候選 ID，原文字串及提及位置不變。

李由採李斯子分支 ID，保存已有父親與長男主張；《漢書·高帝紀》固定修訂2647884的雍丘段明稱「斬三川守李由」，另存跨書參考。本批不是《漢書》全文正式匯入。相鄰司馬名作「司馬镛」不以字形推同司馬夷。

章平在〈高祖本紀〉為雍王弟，《索隱》另稱章邯子，保存古注參考而不覆寫正文親屬。南陽守齮欲自剄不當已死亡；不接王齮、桓齮。程處各篇戰場與王武事件排列差異保留，不把跨篇同人擴大成每項事件紀年均一致。

未定西丞、楚周將軍、項他／項佗、程縱等不因外形相似補名或接合；全篇仍待其餘身份、生卒、地望及爵期覆核。未核書影。
