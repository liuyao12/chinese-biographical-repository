# 〈扁鵲倉公列傳〉死亡與齊文王

十三項死亡來源包含敘事所述、醫案實際結果及倉公明言的轉聞。預言死亡與未死、病癒的結果分開，不把虢太子、成開方或淳于司馬記作已死；預期三十日與實際二十餘日、預期十日丁亥與實際十一日分存，不據病程猜絕對年。

醫案文王依集解徐廣明指齊文王，與齊世家太子則立及十四年卒對讀，接既有人物。其死為倉公不見病而後聞的主張。古注文帝十五年及諸侯王年表同年齊欄十四薨無後、另列數位前165年相合；太初前漢歲首跨西元年，保留前166至165年範圍，不推日月或據未滿二十猜生年。本文無原年字串，date_expression保持空值，平行事件與曆法依據另列。

馮信既有兩字標記、登記及錨點末界均正確，不作修改；補李筱穎等2023年《秦漢時期醫德文化內涵》為姓名切分參考，未把研究概括改作正文或採其未經原文支持的其他生平結論。
