# 《蕭相國世家》第二輪核讀

全18段已逐段閱讀，第18段索隱述贊保留另層；尚未新增正式資料。原文版本、既有人物ID與錨點待再次核對。

第1–5段：蕭何沛豐人為明示籍貫，沛主吏掾、泗水卒史事、丞與丞相依各段授任／用稱分存。秦御史監郡者為單指未名官員，欲徵而得毋行不當已徵召入朝。高祖繇咸陽及沛公至咸陽、蕭何先入收圖書為行程，屠燒咸陽不推所有官員死亡。何守關中、治櫟陽可存居處；太子未具名仍須核局部身份，不按熟知人物直接補名。巴蜀任事與封地、住所保持區別。

第6–9段：鮑生為具名說者；子孫昆弟能勝兵者及舉宗數十人是未分辨群體，不依數字補造個人。漢五年殺項羽為回述，歲餘功不決使封酇侯不直接繫漢五年，須保留授爵原語與延後敘事。曹參平陽侯、鄂君關內侯與安平侯分授予或用稱；鄂君原姓與名字不擅拆。帶劍履上殿、入朝不趨為明示禮遇，可與官爵區別，不改成普通職名。父子兄弟十餘人封邑仍是群體，不自行建立全體未名家屬。

第10–12段：高祖漢十一年至邯鄲、淮陰侯被誅與何拜相國有明文。召平故秦東陵侯與〈齊悼惠王世家〉齊相召平不得按同名合併；秦破為布衣是稱號／身份轉變，長安城東種瓜為所在地，不推現代位置。疑心、禍自此始及客說君滅族不久皆不是已發生死亡。蕭何讓封勿受與從其計保留，益封五千戶不可逕當無爭議已受。漢十二年秋黥布反是起事紀年，不在本段借作黥布死亡。客有說為單指未名者，所述入關中十餘年不是相國任期。蕭何廷尉械繫與數日後赦出為拘禁事件，不推廢相國；王衛尉有具名官稱但「王」是否姓須留來源用稱。桀紂為比況歷史人物，系治句中的李斯分清秦皇帝與當前高帝。

第13–18段：百歲後、臣死不恨為臨病對話，不作本段死亡；孝惠二年相國何卒才是明示死亡紀年，文終侯為諡，未混成生前授號。何居窮處只存原詞，不補未說出的城市。後嗣失侯四世與天子復求何後續封為未分辨後人與泛稱天子，不按熟知封爵名單補人。第17段淮陰、黥布誅滅為回述，與前文具名者需局部對應；閎夭、散宜生有名字但比功不生成蕭何親屬。第18段索隱亦非獨立死亡記載。

後續逐項核定原曆換年、匿名者與官稱身份、稱號授受／有效時段、行程和死亡；全文已讀不等於全部人物覆核或收錄完成。新卷篇尚未投影至公開閱讀器。
