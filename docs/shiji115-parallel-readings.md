# 朝鮮篇的姓名與平行讀法

《漢書》卷95固定 Kanripo 提交683113d4baf6febecaf2ccb7913df87c4d68d454第443至444行，顏師古注明言長者裨王名也；裨王長卡片按稱號與名分呈，姓未詳，不與右渠子長同名合併。

涉何授遼東東部都尉及裨王用稱皆在元封二年敘事內，月份未明，保存前110至109年的可能範圍；來源用稱與授任分開，死亡不補任期終點。後段其秋不反推此前事件在秋。

另保《漢書》固定正文四項對讀：韓陶／韓陰、成已／成巳、涅陽侯／溫陽侯、許遂／誅遂。原正文、人物錨點、原表不改。最後一項是行動記載差異，非人物改名；清代考證主張許字誤是另一層校說，不代表本次親見其引述的通鑑版本。均標未作書影校勘，不把數位轉錄當可靠底本的保證。

人物卡與人物頁將已記日期的來源用稱另列，附原紀年、公元範圍與固定來源依據；不將用稱年冒作授官始年。合併同名同任期的稱號顯示時，各來源的用稱紀年仍保留；無日期不顯示空欄。
