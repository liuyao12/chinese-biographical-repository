# 《楚元王世家》第二輪核讀

已讀全11段，末段索隱述贊另層，未稱全部身份覆核完成。庫外備妥18筆明示死亡候選，原句與本段人物錨點已核。

第1–3段：交為高祖同母少弟，伯長兄、仲次兄保留來源相對排行；伯蚤卒有明文。封信與王仲於代是授號，巨嫂不補姓名；太上皇與既有人物跨篇同指待證據整理。交都彭城有明文，禽韓信不作被殺。二十三年、四年為在位敘述，不當出生年。

第4–6段：張尚、趙夷吾被殺及戊自殺分存，吳王走不作死亡。攻梁與至昌邑南為實行；薄后服私姦不直接借其他篇的卒日。德侯子續吳被拒不作授爵，禮拜楚王有明示。文、安、襄王卒及純地節二年自殺分存，國除不推其他宗室死亡。

第7–9段：幽王憂死、高后崩與明列呂祿被誅有來源，諸呂群體不全拆個體。辟彊十三年卒、福一年卒及無子絕後分開，未名子不補造。建德王悍被燒殺、遂自殺均明示，邯鄲城守可存居處與死地，同段相距七月為圍守時長，不是曆月或王爵任期。

第10–11段：楚戊刑申公不當殺申公，反事及述贊滅韓信不據單字建立獨立死亡。穆生與韋孟僅在索隱層明示，各按來源層次。既有29筆稱號仍待逐項起訖及來源時長整理。

另備妥六筆來源地點候選、七項來源在位年數及兩項明示即位起點。王戊立二十年為在位第二十年的時點，不作完整任期；邯鄲相距七月為圍守時長，不放入王爵月份數。夷、文、安、襄、哀等可能為追諡用稱，未以其名直接冒稱即位時已授諡號。

18筆死亡與六筆地點候選已逐項核對原句、篇段ID及人物錨點，29筆既有稱號ID、原證據與用稱錨點保持。候選尚未納入正式資料；地節二年的數字年另待原始紀年參考核對。

另核《漢書》卷八宣帝紀數位正文（https://zh.wikisource.org/wiki/漢書/卷008）：地節元年冬十一月記「楚王延壽謀反，自殺」，而本篇為王純及地節二年。暫保留本篇原名與原紀年，不自動把純與延壽合併，不冒稱已核影像；此差異已加入死亡候選說明，數字年暫待決。

第2段其母依巨嫂羹事、伯子不得封及高祖答太上皇的連續敘事，候選暫連伯妻既有ID，未補姓名；別名及人物提及證據同步。索隱太后仍留待定，未直接借正文竇太后錨點。正式資料仍未改動。

第2段再次核讀，另補兩處叔與一處某的單字指稱錨點：限高祖過嫂家及高祖本人答太上皇的局部敘事，暫連同段高祖ID。原文與舊錨點保持，人物別名和提及證據同步；不以全域字串替換判定叔或某。

全11段候選人物提及已逐項核對Unicode code point範圍、原詞、人物別名與登記證據的雙向一致；新增叔、某與其母不改既有文字、來源指紋或人物ID。正式安裝與完整驗證待上一批測試結束。

七項來源任期數字與各自人物錨點已核對：交23、郢4、禮3、道22、注14、辟彊13、福1；原數詞與完整引句俱存，來源計數方式未定。不依後代繼位或卒日消除差異，也不推精確任期日。

候選已納入工作分支，18筆死亡、六筆地點、七項來源在位年數與兩項即位起點保存為JSON。四處局部人物指稱及登記雙向同步，原文指紋不改，29筆稱號ID與原證據保留；XML已重新同步，卷篇引用驗證通過。全套驗證與人物匯出進行中。
