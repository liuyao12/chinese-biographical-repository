# 〈韓信盧綰列傳〉子代詞性修正

「其弟說……卒為案道侯。子代，歲餘坐法死」中的子是韓說之子，代為承襲用語。初稿誤以代為名，現撤除韓代名標籤，人物 ID 與已保存父子關係保持不變。

正文一字不改；原人物錨點只覆蓋子，代還原普通正文。原文未名，人物卡省略名欄，不由此刪除失名的歷史人物。徐廣〈集解〉報名長君以結構化參考另存，未把古注姓名偽裝成正文名，未據注家報說替孫曾補父。

數位三家注頁固定連結為 https://zh.wikisource.org/w/index.php?title=史記三家註/卷093&oldid=2514763 。已讀文字，未核書影；AI判斷未經人工審閱。

同批接合孝文、孝景、大夫種、范蠡及伍子胥五組帝諱與引古身份。孝文十四年及孝景中六年依漢初時位分接兩帝，不用年題當生年；種蠡「身死亡」保原語，不創同案被殺，伍子胥引古不創韓王信與之會面。篇末作者及古注所涉褚氏說法仍待釐清，不在此批合併。
