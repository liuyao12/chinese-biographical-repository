# 〈樊酈滕灌列傳〉跨篇漢廷人物

完整讀本篇三十五段後，以鴻門劍舞、樊噲攻燕召還、至陳取楚王、韓王信入胡與參合、陳豨軍事群組，以及彭城救孝惠等共同事件，接合十七組身份。更新全文標記、官爵、親屬與衍生引用後撤除十八個候選 ID，不留替身 JSON。

楚王韓信與韓王信分人，同段切換依楚王取陳／代晉陽參合判定。呂須／呂嬃依呂后女弟、樊噲妻與伉母配置接合，原字各存，不推未知父系。陳平奉詔欲斬噲、他人告噲欲誅戚氏如意等，不當已執行死亡；王黃被斬與生得的來源敘述亦不調和。

同書跨篇不當獨立見證，未核書影。本批未處理全部軍將、紀年、官爵時段、他廣父系指控或其他未定人名，不宣稱全篇完成。
