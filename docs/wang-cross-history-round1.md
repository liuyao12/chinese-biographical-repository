# 王氏跨史家系：本輪範圍與未決項

本輪接續《晉書》既有人物，錄《宋書》卷六十六王敬弘傳完整九原段、《南齊書》卷三十二王延之及子倫之完整七原段，並選錄《南史》卷二十四十一個完整原段。後者為跨史比較選段，不是全傳或全卷完成。三書保留各自固定數位修訂、原字、人物錨點與原句；均未親核底本影像。

## 家系及身份

王敬弘子恢之、瓚之、昇之及女兒，延之、倫之與秀之、峻、琮、昕等依各段父子及同段祖父記載接合。瓚之至敬弘以秀之的父、祖父兩項原句作編輯父系推導，舊有兄弟證據保留為佐證，不捏造直接父子原句。家族分支字元不表示排行。

倫之／綸之依父延之、官職及琅邪城與全景文等二十一人同受議處接合同人，原字分存。王粲之與王瓚之仍是兩個未決身份，未決案件可從兩人的資料取得；同代、字近或名單未列另一兄長不能單獨證明同人，秀才與後來官職亦不能單獨證明異人。出繼伯父粲之另記，不改生父昇之。

王峻「下官曾祖」經峻、秀之、瓚之、敬弘的來源路徑指王敬弘；謝仁祖據《晉書》謝尚字仁祖辨名，另存敬弘之外祖關係，不入父系祖先，亦不補未名母親。繁昌主與始興王憺接同一父系 ID；其與王琮婚姻及其後離婚分存，年月未知。

## 日期、報齡與官爵

王敬弘「明年」承元嘉二十三年，存447中國曆年度；奏中「年向九十」為446年的趨近報齡，確歲及出生年不補，與447年卒時八十八歲各存。禮年七十不作本人報齡。王延之「其年卒」承永明二年，存484年及原報六十四歲；倫之及昕等未知卒年不據仕歷或報齡推定。

追諡文貞公，《宋書》昇明二年為478，《南史》升明三年為479；暫取前者具體詔令敘事，保留兩筆原文。進號鎮南將軍，《南齊書》建元二年為480，《南史》建元元年為479；暫取前者本傳，保留鎮／鎭原字。這是逐事件暫定首選，不給某書永久優先權。

已將本輪逐段核讀的任用與未受任分開。任職起年只在可明確承接年號時存數字；後文「轉」「尋」而未明年者不一律套前一年的日期。死亡不自動終止所有官爵。王倫之永明中侍中免官與建武中再任分筆。外兵尚書外兵部的連寫職名仍待版本覆核，沒有據此補造標準官名。

## 狀態與後續

人物身份、日期及來源取捨均為 AI 暫定，未作人工審閱。其他同卷本傳、未選《南史》原段、完整府主職官結構及有疑版本仍須續核。各項剩餘工作不因本輪測試通過而視為全書完成。

每人 JSON、閱讀器及索引為衍生資料，須在來源驗證後統一重建。改號更新全部端點與引用，撤除舊號，不發布永久舊新對照或轉址；外部查詢重新搜尋並選取當前身份。史料與身份判斷證據保留，過往資料由 Git 回查。
