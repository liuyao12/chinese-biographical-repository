# 卷八十四〈屈原賈生列傳〉草稿

固定修訂1568305的33段正文已核讀。兩項數位改讀提示另存，正文保留投與微；曰括號按來源保留。铦、鸮轉為銛、鴞並明記，腳註納另存。索隱述贊另層待收，未核影像或現代研究。人物標註待補。

前5段明示姓名首輪已保存，屈原名平與屈平暫接，王稱與嵌套指代仍待逐處核定。後28段待標註。

第6至11段已作明示姓名首輪。唐眛原字保留，子蘭令尹與頃襄王按王序敘事暫接；漁父匿名，聖人眾人泛稱未補姓名。後22段待補。

第12至22段已作明示姓名首輪，賈生名誼、吳廷尉吳公按同段承接；重華、湯禹等引古原稱各存。絳灌短稱與東陽侯未補姓名。後11段待補。

全33段明示姓名首輪已存。楚懷王與梁懷王分開，斯短稱未補名；淮南厲王四子與賈生二孫保留未解群體，不造姓名或闕代。篇末賈嘉孝昭時附述層次待覆核。

已保存4項明示子弟來源主張與13項官爵用稱。長沙太傅先述與授任可能同一任期，議任公卿未實現不記已授，孫稱不補闕代。未知起訖不補造，賈嘉孝昭九卿附述層次待覆核。

已按楚世家唐眛戰事、懷王會武關與子蘭勸行，保存3項跨篇暫同指；勸阻者昭雎／屈平異說不調和。懷沙、弔屈原賦與服鳥賦段落按來源次序保留，尚未完成版本及篇末附述覆核。
