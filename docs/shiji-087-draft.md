# 卷八十七〈李斯列傳〉草稿

固定版本2364605的38個非空正文區塊已實際核讀，含諫逐客書與督責書；索隱述贊另層待收。只去外緣空白、空段，原字及上書區塊保留。子嬰世系、任相年數、趙高中丞相及嵌入引古差異待逐項核定；未核影像與現代研究。人物尚待標註。

前5段明示姓名首輪已存。辭師秦王未定與入秦後秦王分開；引古黃帝標示傳說性，未以引述確證其事。後33段待標註。

前11段明示姓名首輪已存。三川守李由與由按明示長男承接，諸男、女、公主及秦諸公子保留群體，未補未名婚配。諫逐客書寶名與樂名不作人名，稱號與諫書發言者承接仍待逐項覆核。後27段待補。

前18段明示姓名首輪已存。趙高短稱高限局部且排除功高；奉偽書使者保留未名。衛君父未補名，齊桓引古身死敘事暫不強合；擬任蒙恬相及偽詔不轉為已實任。後20段待補。

前26段明示姓名首輪已存。公子高與趙高分開，趙高之高排除高枕，吳廣之廣不套入廣欲。督責書韓子商君及申韓短稱保留未定，堯禹傳說性分存。後12段待補。

全38段明示姓名首輪已存。始皇弟暫依子嬰既位承接，與其他篇世系及立三月等異說分存；其子、妻子指代未補世系婚配。中子、太卜、上林行人保留未名；韓玘等引古原字不擅校。親屬、稱號、跨篇身分及版本仍待覆核。

新增5條有來源父子陳述與32條稱號記錄；兼行符璽令、偽詔所稱裨將與政變立太子分別說明。假御史謁者侍中與擬授蒙恬相不記實授；獄中自述三十餘年不推算任期，不以死亡補爵位終點。

新增9項跨篇暫同指，列人物端點、原文與提及ID；子嬰世系及三月／四十六日、趙高中丞相、李斯自述三十餘年與刺殺執行者差異分存，未由同指調和。
