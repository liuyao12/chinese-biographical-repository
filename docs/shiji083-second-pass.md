# 〈魯仲連鄒陽列傳〉第二輪核讀

全27段固定數位正文已核讀，未核底本影像、全部身份與稱號日期。

本批依長平、邯鄲、自稱勝、湣王逃鄒魯與栗腹敗軍後趙圍燕事件，接合趙孝成王、秦昭王、白起、平原君趙勝、齊湣王與栗腹。全部引用同步後撤除六個候選ID，人物6578→6572。正文及錨點保留，同書不作獨立史實見證。

核讀範圍與待辦：

- 平原君自稱勝，篇內姓名與邯鄲圍相接，可核076趙勝。
- 秦王與秦昭王同段有明示，核白起長平事件；非始皇。
- 鮑焦引古人物死亡不可作魯仲連蹈海死亡；後者為條件誓言。
- 魏王與魏安釐同段君序，晉鄙與新垣衍是不同將軍，勿按將軍全域替換。
- p007秦王烹醢梁王為假設；九侯鄂侯死亡與文王被拘是引古，不能移作當時梁王死亡。
- p010至014聊城燕將是匿名一人；書信公指該將，吾／臣說話者魯連；燕王未名不得只按二十餘年推算強配。
- p013曹子三敗與劫桓公可核曹沫來源；不能因曹字連到曹參或曹劌。
- p014聊城燕將自殺是實述；魯連拒爵逃隱海上未敘死亡。
- p009平原欲封魯連三辭與p014欲爵逃隱是拒受，不造有效爵位任期。
- p015梁孝王為獄中上書收信者，大王指孝王，臣指鄒陽；勝是羊勝，不能連到平原趙勝。
- p016昭王是秦畫長平引古的秦昭王，不能與上書收信者梁王混同；衛先生未具名不按職業推定他人。
- p018樊於期與王奢並列不是同人，且未由此等同桓齮；蘇秦相燕不是燕尾生名號，白圭取中山不可按同名接商人白圭。
- p019昆弟、胡越為昆弟為論喻，不造血親；孔墨雖省稱須各承孔子墨翟。
- p020比干之後及孕婦為未名群體，不補人物姓名或生父；田常之賢為反面引述，不直接轉作評定。
- p021桀狗吠堯與蹠客刺由為論喻假設，不能作堯或許由死亡事件；七族及妻子未具名不補個人。
- p022伊、管省稱需篇內／他篇引古語境另核；不按一字同名批量接合。
- p023秦皇帝與蒙嘉荊軻之說的引古敘事須核086；秦信左右而殺原句保留，不直接推定秦始皇被荊軻殺死。
- p026卒為上客是鄒陽獲釋後實述，區別前文欲殺與見禽；上客不是死亡卒。
- 全27段收到的數位正文已核讀，未核底本影像、全部身份與稱號日期。

梁孝王、羊勝、公孫詭、鄒陽依〈梁孝王世家〉同一梁廷賓客群及王名武接合；僅支持人物身份，不算入獄上書的獨立見證。曹子劫盟段魯君按曹沫三敗、魯莊公及柯盟復地平行事件接合，共撤除五個候選ID，人物6572→6567。未由此等同曹劌或調和失地五百里／遂邑。

秦皇帝依蒙嘉先言、荊軻與匕首發的具體事件，對照〈刺客列傳〉暫接始皇，與本篇長平秦昭王分開。撤除一個候選ID，人物6567→6566。保留「秦信左右而殺」，不造始皇被刺死亡，不改疑文；086刺殺未成及殺軻另存，仍待底本校勘。

燕丹／太子／丹依荊軻與樊於期首的事件接燕太子丹，再撤一候選，人物6566→6565。白虹貫日與太子畏之未在所讀086平行段獲證，不把並讀當成全部細節互證；蘇秦所事未名燕王仍保留。086p026秦王政明名另列始皇身份證據。
