# 卷八十一〈廉頗藺相如列傳〉草稿

保存固定數位修訂8735558的27段正文，廉頗至太史公論贊；全部段與HTML篇界已核讀，導覽、索隱述贊及版權告示排除。只去外緣空白，爲、原、繆、脱、盆鮓、許暦及桓齮原字不擅校。未核底本影像或現代研究。

繆賢敘話嵌套臣君按範圍辨識，燕王未名不強接昭王。括母與代將者、單于及李牧早年所事趙王保留未定；死亡被俘不自動終止所有爵位。人物逐段待標，未完成覆核。

前5段保存8個新候選與79處錨點。藺相如短稱按完璧敘事暫接，繆賢交往燕王未名及持璧從者分別保存；和氏璧物名不拆人名。嵌套臣君與後22段待續核。

全27段明示姓名首輪目前40個新候選、404處錨點；另存4項父母來源主張，以明示子孝成、趙奢之子括、括母及子悼襄作證。括母未名不補姓名或由妾自稱判定婚姻身分；其餘指代及官爵時段待補。

保存36項官爵用稱與任將來源記錄；廉頗長平代括、後樂乘代頗及李牧北邊他人代將3項明示去職分存。第17任將與第18追述復用是否同次任職待核，不算獨立見證；李牧末次代令但不受命，未只憑命令閉合實任。太子擬立王不作實授，病與卒不自動終止爵位。

保存13項跨篇暫同指，以趙世家平邑、閼與、長平及李牧宜安番吾代將，燕世家與樂毅傳廉頗破燕、樂乘代頗及孝成悼襄君序作證。趙括死／降、同名趙衰子括、趙怱／蔥、顏聚亡／虜及栗腹禽／殺各留；暫同指不決定所有版本敘事。引用驗證通過。

已整理全27段姓名首輪狀態，仍非全部人物與學術覆核完成。既有4597個人物逐項保持原樣，新增40；嵌套引語與匿名者、其餘跨篇對應、完整任期及版本研究列為後續工作。下一卷〈田單列傳〉。
