# 《齊悼惠王世家》第二輪核讀

全篇45段已逐段核讀並記錄事件判讀；尚未新增正式資料，人物對應與資料欄位仍待逐項核定。

第1段劉肥為高祖長庶男，出生排行一與庶出分開；曹氏為明示母親，外婦不擅改正妻身份。高祖六年立齊王為授號，食七十城不當全為居處，也不推生日。第2段孝惠帝兄保留相對年齡；齊王入朝及辭就國為實行，且誅而未誅不生成死亡，內史勳按來源具名者。城陽郡湯沐邑不等於魯元公主本人已居。

第3段悼惠王十三年與惠帝六年卒為同一死亡記載，既有王號可能追諡，不把子襄繼位當生年或即位時已授諡。第4段孝惠帝崩有明文，哀王元年與呂后稱制分存；呂臺為兄子及酈侯轉呂王均有來源，濟南奉邑不擅推本人住所。

第5段章及興居宿衛長安可存居處，朱虛侯與東牟侯明示封爵分記；後四年的語境仍須核，未借別篇年份。呂祿女妻章為來源婚姻，不補女姓名。第6段劉澤瑯邪王授號與哀王八年為來源日期，不把齊國封地割讓當劉澤出生或住所。

原曆換年、異稱、相對排行與稱號時段待逐項存資料；未稱全篇已覆核。

第7–16段再次核讀：友幽死於邸可存死亡及死地，其明年的承接須核段落年代；三趙王皆廢與後文齊王書殺三趙王分開，不按群體造三名人物。章酒吏有明示任事，諸呂一人被斬是單指未名者；二十歲不倒推生日。高后死亡、呂祿上將軍及產相國、二人居長安有明文，欲立齊王為帝未成不作登極。召平自殺與駟鈞相、魏勃將軍、祝午內史分存明示事件。瑯邪王馳見齊王及被留是實行，祝午詐稱不當真實身份。

第11–12段劉澤說適長孫為說辭，需保存來源身份主張及未定嫡庶；不當經外部確證。哀王書中的父親薨、惠帝崩及高后崩為回述，不重計本篇前段死亡；署自臣與寡人可連襄，皇帝春秋富仍須局部身份證據。第13–14段灌嬰屯滎陽、齊王屯西界、劉澤從齊至長安可存行程居處，誅呂祿呂產為明列者，諸呂群體不全拆個體。第15段議立齊王未實行，迎立代王另存。第16段魏勃罷職有明示，先任舍人及悼惠王拜內史與後來將軍分開；無名父與舍人各按來源角色待整理，不補姓名。第17段起待續核。

第17–30段再次核讀：文帝元年齊哀王卒、次年封城陽／濟北與濟北反被誅，原相對年分開。罷軍等七人群體不補全名，文王十四年卒無子不推未名兒子。將閭、志、辟光、賢、卬、雄渠與城陽諸王明示分封，楊虛侯轉齊王另存。路中大夫被誅是來源單指人物，路不先當姓；漢破吳楚的口述戰報不推各王死亡。齊孝王飲藥自殺與四國王咸誅滅明列主體，濟北志徙菑川不是被殺。壽二十二年卒及景繼立分開。

第27–30段紀太后母親、紀氏女后、紀翁主姊與婚姻依來源，姦的指控不當獨立核定。徐甲具名宦者，修成君與娥母女明示，主父偃女未實入後宮不造任事；齊王求娥婚姻遭止不作成婚。燕王新坐死是回述，須核與定國同指及日期；徐甲使齊、返漢與主父偃至齊為實行。厲王飲藥自殺在29及30段重述只記一次，主父偃被囚與後誅分開。第31段起待續核。

第31–45段核讀：厲王立五年死與前兩段飲藥／憂死合併同一死亡，毋後不創未名子。第32段臨菑東冢園為明示墓園位置，葬地欄位須保留「冢園」原詞與判讀，不改作明示葬於句；割邑與祭祀不當菑川王居處。第33段章斬呂產於未央宮可補呂產死地，章增封戶數與城陽王授號分開，立二年卒保留來源在位年數。

第34–35段喜徙王淮南、還王城陽是王號變動，不單憑徙王推本人遷居。三十三年、延二十八年、義九年、武十一年、順四十六年、恢八年均按來源年數記錄，不擅指定統計口徑；［建］延原文異字保持。景建始三年卒可另核原曆換年，十五歲是年齡，不作在位十五年。

第36–37段太仆嬰與同名異人須局部對應，少帝廢位與文帝登極各存事件。興居濟北王授號有孝文二年；許趙／梁地的未成安排不作封王事實。章死為前述回述；文帝太原、灌嬰與軍隊歸長安有實行語句。興居被虜後自殺與第21段被誅說法並存，不能抹去不同敘述。

第38–43段志、辟光、賢、卬、雄渠孝文十六年授王號明示，前封侯爵須保留前後稱號關係。志徙菑川與凡立三十五年不可誤作菑川單一任期；建二十年、遺三十六年、終古二十八年、尚五年各按來源年數存。橫建始三年十一歲卒同景，年齡不推生年；辟光、賢、卬、雄渠明示被殺，與第26段四國王誅滅相互連結但不重複死亡。第44段史公論贊不增人物事件，第45段索隱另存層次，膠東／濟北及雄渠／辟光並列不拿來覆寫正文國別。

庫外已備33筆具名人物死亡候選，回述合併並保留各段引文；29–30段厲王局部指稱另備對應，尚未改寫正式人物登記。另備14筆來源在位年數，保留73筆既有稱號ID。喜跨淮南／城陽的三十三年與志跨濟北／菑川的三十五年暫不掛單一王國任期，待設清楚來源範圍；景十五歲與橫十一歲不作稱號時長。數字換年、未名個體、地點及稱號起訖仍待整理，候選尚未正式納入或全套驗證。

另備19筆來源地點候選：長安宿衛／居處、趙王幽死之邸、滎陽屯駐、齊西界屯兵、澤從齊至長安、路中大夫至被圍臨菑城外、主父偃齊人及赴齊、徐甲至齊、悼惠王臨菑東冢園、呂產未央宮死地、文帝從代來及幸太原、灌嬰歸長安。冢園葬地為保留原詞的判讀，不冒稱來源有「葬於」句；未名邸不補地址，徙王不直接當本人遷居。全部仍為庫外候選。
