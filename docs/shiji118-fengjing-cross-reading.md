# 馮敬跨篇辨識

〈屈原賈生列傳〉列馮敬為短賈誼者，〈淮南衡山列傳〉列典客馮敬及臣敬。兩篇同處文帝朝廷；漢書卷48顏師古釋馮敬時為御史大夫，如淳更以奏淮南厲王之事說明，故依具體事件暫定同人，不以同名全域配對。

固定Kanripo版本及所讀行段、實際引文、校讀理由均附身份判讀。原姓名與提及錨點不改，更新全部引用後撤除重複ID及匯出；Git保留歷史，無永久轉址。

如淳稱馮無擇子，宋祁引功臣表反對；尚未核所指原格，只列具署名參考，不接父邊。名忠直等未標點字串不逕拆姓名。代理御史大夫、典客與注家所言御史大夫各有來源，不由同人接合填成無縫任期；七年說不作未核的精確授職日期。
