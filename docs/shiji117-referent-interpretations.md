# 〈司馬相如列傳〉三項指稱異說

陽子、纖阿及鄭女曼姬保持未連人物的正文錨點；本批保存古注所述不同解釋，不新增人物、生卒、親屬或共同出獵事件。

- 陽子：《漢書》所引張揖以為伯樂，姓孫名陽；《集解》所引《漢書音義》以為仙人陽陵子，韋昭稱古賢。伯樂只列候選，不把陽陵子倒字接成陵陽子明。
- 纖阿：《漢書》所引郭璞稱古之善御者，《集解》所引《漢書音義》稱月御。兩種描述不等於已證不同人，也不據此補性別或家族；保留纖、纎、孅在各見證的原字。
- 鄭女曼姬：文穎解鄭國美女與曼澤容貌，顏師古採其說；如淳分解夏姬、鄧曼，《集解》郭璞解曼姬為鄧曼。本批保留群體與人物典故讀法，不把四字整體配給一個人。

參考為固定 Kanripo 提交的《漢書》卷57第162–163、181–183行及《集解》卷117第112–113、123行；未核圖像。原始排版記號隨確切引句保留，解釋另列。個別人物候選不窮盡，也不因已列一位便自動合併。

新資料模型讓零個人物候選的泛稱或傳說讀法亦能保存。正文外的編者異說與人物頁候選來源可讀；伯樂 JSON 保留相關原段，但不把陽子算作已確認提及。完整驗證與線上驗收完成前，不宣稱此批已發布。

## 卓氏婚與篇末其妻

第45段與卓氏婚依第2段文君婚姻及第35段卓王孫女尚長卿的連續敘事，暫接文君，信心中等。第35段只稱其女，另存為上下文參考，不假造文君的已具名提及來迎合驗證。其他卓氏家族用稱不全域改連。人物頁姓卓、名文君的組件採此氏稱與開篇明稱，說明它是上下文判斷，並非正文直說姓卓名文君。

第56段其妻仍不連人物；文君列非窮盡候選且容許未知身份，不因唯一已知配偶自動解案。此處不新增親屬或任期，不新增亡妻等無據推斷。

## 「二后」指稱

第58段保留單一正文錨點「二后」，不把注文候選拆成正文未見的「文王」「武王」兩個標記。《文選集釋》卷二十三轉述諸家以二后為文王、武王，朱珔又提出夏、商說；兩說各存為未決判讀。此頁是清代編者及其數位轉錄，僅作注釋史參考，未核底本影像，也不據此決定採哪一說。

指稱異說的 `references` 可記兩種可追溯來源：固定版本的程式化文字見證仍須提交、blob、行範圍及回應雜湊；一般外部出版物則用 `reference_type: external_publication`，記書名、網址、引文、來源類型、提供者、存取日及影像核驗狀態，不得虛構 Git 修訂資訊。

## 人物卡互動修正

實際瀏覽器連續展開古注註解後，舊的通用 pointerout 事件會累積多個隱藏計時器；即使新卡片開啟並取消最後一個計時器，更早的計時器仍可能將它關閉。現在只對人物連結與卡片的移出排定關閉，排定前取消前一個計時器；關閉亦取消計時器。合成事件回歸在修正前確實失敗，修正後通過；不能以忽略原失敗或放寬卡片斷言冒稱修復。
