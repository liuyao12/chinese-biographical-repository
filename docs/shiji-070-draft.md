# 卷七十〈張儀列傳〉草稿

保存固定數位修訂2621148的59段正文。頁首人物導覽、索隱述贊及現代版權告示不混入正文，4項數位改讀／補字記錄另存。成對改讀保留改讀前字，未核底本影像或現代研究，不稱已校定。

目前第1至10段明示人物首輪，16個新增候選、94處人物或未解錨點；後49段待標註。張儀短名、蘇秦與蘇君依局部敘事暫接；楚相失璧與後文檄告暫接，妻與舍人保留未名。欲王、王隨之及王業不是人物名，不取王字作人物錨點。趙王暫留未解，周天子、魏王不按年代記憶補名。引古桀紂與鬼谷傳承仍待覆核。

本篇蘇秦齊相與前篇客卿各有原文，不以身份同指消除時序或官職異說。擬議婚姻、質子及授封不能當實受；親屬、官爵有效時段、跨篇身份、版本、代詞與匿名者尚待處理。下一工作位置為第11段。

第11至23段已接續首輪，累計25個新增候選與209處錨點。魏襄王與哀王按本文王位轉換分存，楚懷王、秦惠王及鄭袖段的嵌入引語分範圍判讀；韓申差、陳軫、屈丐與靳尚各依明示稱名。秦女、美人、子母與未名將軍保留未解，不補婚姻或姓名。後36段待標註，下一位置為第24段。

第24至45段已接續，累計35個本篇候選與316處錨點。楚、韓、齊、趙受話王稱按段落與引語分辨，韓王、趙王及趙先王不按年代記憶補名；蘇秦謀齊段的燕王與齊王另存候選，尚未證同或異。孟賁與烏獲是比擬人物，紂屬引古；秦楚太子質子及秦女婚姻保留擬議未解。後14段待標註，下一位置為第46段。

第46至51段已接續，累計43個候選與406處錨點。趙襄子姊及代王故事分存，秦惠王卒後的武王與太子按局部敘事相接；馮喜說齊王時嵌入的秦王約語分範圍，不全段套用同一王。後8段待標註，下一位置為陳軫附傳第52段。

末8段已接續，全59段明示姓名首輪累計58個新增候選與541處錨點。犀首、衍、公孫氏與公孫衍依本文明示暫接，公孫氏只取個人姓氏語境；莊舄與卞莊子故事分開，楚王莊舄故事不接外層秦惠王。子胥曾參屬引古，李伯之下為地點。尚待補親屬、官爵時段及跨篇身分證據，篇級進度仍在整理中，未稱完成覆核。

已保存3項配偶／姊弟來源陳述及17項官爵用稱。第10段秦相授官以第12段東還而免相作明示終點，只作用於該任秦相，不推終止客卿、秦將與武信君。擬議秦女婚姻不建配偶關係，時長原語不自動換算任期日期。

與秦本紀逐段核對4項跨ID暫同指：張儀、司馬錯、韓申差與屈丐。申差戰事的敗軍／俘獲與斬首數字差異保留；屈丐在秦本紀為虜，本篇為殺，同指不抹平相反死亡記載或確證死亡。各篇原文、提及與已發ID均保留。
