# 王閩之墓誌來源首輪

納入林宗閱〈「漢魏南北朝墓誌釋註計畫」簡介〉所刊完整八十四字古代錄文（《臺大歷史系學術通訊》第3期，2009年5月，印頁39）。來源為[臺大歷史學系官方刊物](https://homepage.ntu.edu.tw/~history/public_html/newsletter/public_html/09newsletter/03/newsletter3_09.pdf#page=3)，固定PDF SHA256及所選錄文字位另存；儲存庫不收入PDF、圖像或現代文章全文。

這是現代排印校錄見證，已核排印頁，未親見1980館編拓片、1972原刊或誌石。排印號1至9中第6號空白，只記排印布局，不冒充原石九行。保留「琅耶」「冶民」「塼」「于」；PDF相容碼位對照另列，不正字。林氏轉報1980本作「冾民」只列未親校異讀，不採改正文。

十五處逐人／群體標記涉及七人，六人為新來源身份。王彬以完整《晉書》卷七十六官歷及特進、衛將軍等組合暫接既有身份；墓誌「左僕射」與傳文「右僕射」的差異保留。興之及三弟嗣之、咸之、預之不因姓名相近與他人合併。原文群頭「弟」不任指一人。

本輪只有來源及身份，不含結構化親屬、排行、紀年或家族改號。死亡日期原句可回查；「葬于舊墓」未另具葬日，不把卒日當葬日。未倒算生年，未採現代文章遠祖圖或有爭議的稚容判讀。

作品為單方《王閩之墓誌》，全文容器的卷號為空值，不虛設卷一。已修正人物來源頻次排序對無卷號作品的處理，實際王彬的正史及墓誌混合來源測試通過。

目標工作樹原生驗證、二十六項墓誌／人物來源測試，以及桌面與手機兩次實際全文、人物卡、人物頁與來源引用驗收通過；七人物作局部衍生重建。尚未全庫匯出或公開發布。

## 後續結構化資料

來源首輪後，已另附父興之、祖彬、配偶施氏及三弟各自年幼於閩之的六項親屬陳述。元子記父之子序一；不給三弟彼此順序、共同父母或生母，也未把興之至彬的父子推論充作原文直載。七人的姓名構件按原文明字保存，施氏字女式而名未知。

卒年依原「升平二年」及教育部年號表換算為中國曆年358；原「三月九日」及其字位另列，不換算西曆月日。廿八為來源報齡，計歲法未明，不倒算生年。籍貫與葬地分存，葬句日期仍空。

此後續批已在目標樹通過原生驗證、五十項相關測試及八次桌面／手機人物頁驗收；父祖、配偶與父親反向子女連結可查，未知生年與生母未顯示。十人物作局部衍生重建；未親見原拓的資格不變，完整發布另行驗收。
