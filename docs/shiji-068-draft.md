# 卷六十八〈商君列傳〉人物首輪

固定數位修訂8764712，全11段正文已核讀保存。頁首題名及導覽、h2索隱述贊以下後附評論與現代版權告示不混入正文。保留厀、朞、筑、（都）等字；秦封之於、商十五邑照錄，未補字或校定邑名。

目前240處人物或未解錨點，27個新增候選與27項篇內身份判讀，全庫4019個候選。篇首名鞅公孫氏、入秦公孫鞅衛鞅與封號商君按敘事暫接；魏惠王與梁惠王、秦太子立後秦惠王局部暫接，未補秦王名。公叔座不按同稱合併孫吳篇公叔。

趙良問答夫子指趙良，五羖大夫與引古人物不當同時代人；五羖大夫不補未載姓名。公子驩的驩按交好語境處理，未另造人名。商君開塞耕戰書屬書名語境，不作商君本人錨點。徙木者、客人保存未名，未補姓名。

親屬主張、稱號時段、跨篇身份、其他匿名者代詞及底本影像、現代研究尚待覆核。人物首輪不等於全篇完成，人物首輪之後接續卷六十九，全篇覆核仍未完成。

已保存21項稱號記錄。左庶長、大良造的官爵性質暫未分類；封商君、授將與用稱分存。相秦十年及六七年保留來源表述，不補精確起訖。

已保存7項跨篇同指判讀，商君、景監、甘龍、杜摯、秦孝公、魏公子卬及秦太子按秦本紀共同事件核對；秦魏公子卬不按同名合併。
