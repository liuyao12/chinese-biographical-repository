# 《荊燕世家》第二輪核讀

已讀全12段，第12段索隱述贊保留另層；第二輪資料已納入工作分支，全套驗證進行中。

第1–5段：劉賈諸劉不知何屬不補宗族分支或父親。漢王元年起兵與授將軍、漢四年渡白馬津及漢五年南渡淮圍壽春為原曆行跡；與彭越相保不作親屬。共尉已死有明文，不憑戰役被擊推其他人死亡。韓信廢楚王及被囚分存，不能推死亡。劉賈荊王、劉交楚王、肥齊王為明示授號，封地不等於居處。劉賈十一年秋走富陵後被殺有明文；破布不作黥布死亡。濞十二年授吳王及原沛侯分存。

第6–9段：劉澤遠屬不補父子鏈。郎中、將軍、營陵侯、瑯邪王及燕王各分授號或用稱，王燕二年薨與諡敬王分開。田生齊人、歸齊、如長安、假宅居數月有來源，所求萬戶侯不當已授。呂產封呂王及王代的地理陳述保留原校勘。田生與澤之國及出關為實行，追止未成不當被留。高后死亡為回述，澤至梁及驅長安有明示；欲誅諸呂不生成群體死亡。

第10–12段：定國與父康王姬生男、奪弟妻及子女三人只保存來源範圍，不補全部未名者。肥如令郢人被格殺與定國自殺有明文；元朔元年直接繫告發，不直接當自殺年，議當誅與實際自殺分開。嘉繼王不憑代際推具體死亡日，國除不推嘉或他人死亡。太史公卒南面中的卒是終於，不另生成劉澤死亡。索隱亡於郢人不當郢人再死。實行、計畫、授號、封地與來源指控均分存。

原曆數字換年、身份消歧及全部稱號時段待逐項整理；全文已讀不等於收錄完成。

庫外備妥六筆明示死亡候選，逐項核對人物錨點、原句及原曆表述；太后崩與共尉已死未借所在段其他事件的年，定國自殺與議當誅分開，嘉繼位不補其死亡。候選尚未正式安裝。

另備妥12筆籍貫、行程、居處及死地候選，逐項連來源人物錨點；劉澤燕封、劉賈淮東封地未當實際居處，代王從代至只存明示出發地，不補省略目的地。候選尚未正式安裝。

26筆稱號已再次檢視，候選補營陵侯授予、楚王明示廢黜、沛侯轉吳王及瑯邪王徙燕王的相應終點；保存燕王來源二年時長，不借死亡日終止其全部稱號。敬王明示諡號，康王繼位稱號可能追述，未混作即位已授諡。既有ID與原證據保持。

六筆死亡、12筆地點候選已逐項核對完整引句與人物錨點；26筆既有稱號ID、原證據及用稱錨點一致。郢人昆弟與定國子女為未分辨群體，不能按數目補造個人；肥如令郢人按本文具名個體保存，不拆作來源未名官員。萬戶侯為勸說利益，未作張卿或田生已授爵。

第7段另補六處局部指稱候選：其子連田生子，四處卿連遊說對象張卿，臣為田生自稱；人物別名與來源提及同步，不以全域單字替換。原文及舊錨點保持。

核讀《漢書》卷六武帝紀（https://zh.wikisource.org/wiki/漢書/卷006），元朔二年秋記燕王定國自殺。本篇元朔元年直接連郢人昆弟上書，候選原把它延伸至死亡的日期已撤為未知，保存全部原句及跨篇參考，避免把告發與自殺一律同年。數字死亡年待另設跨篇事件紀年依據；未冒稱影像核讀。

定國死亡候選新增平行事件數字年：公元前127年（天文年-126），依《漢書》元朔二年同名自殺事件及數位元朔元年對公元前128年的換年參考。原篇告發年不改作死亡日期，定年依據、原句與來源分層保存，影像未核且編者暫定；正式驗證待完成。

第10段三處單指未名者已備人物候選：康王姬、定國弟妻及所生男一人，保留來源角色不補姓名；兩名婦人不自動合併。男孩依本文直接父子列同家族後綴AAA，群體子女三人未拆分；另補明示出生，生死候選共七筆。來源指控仍不稱獨立核定，候選尚未正式納入。

未名男孩另備明示父親定國及生母康王姬兩項關係，依原句生子存來源主張；不由此補婚姻，也不把一人當排行一。母親保持自己身份，家譜顯示應從孩子資料讀取生母，而非另作母系家族ID。候選待正式驗證。

全12段候選已核對人物錨點字元範圍與登記別名／提及證據的雙向一致，兩項新增父母關係的主客體均有同段人物錨點及原詞支持。三名未名者、七筆生死、12筆地點及稱號候選尚待正式安裝與全套驗證。

候選已正式納入工作分支，三名未名者、六處指稱、七筆生死、12筆地點、兩項父母關係與稱號時段保存為JSON。男孩後代ID另附父親來源路徑，引用驗證通過；XML重新同步，全套檢查及人物匯出進行中。
