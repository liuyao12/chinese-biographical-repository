# 中國曆年與公曆投影分存

事件的 `chinese_civil_year` 明示 `calendar: chinese_civil`、天文年編號、`era`、`era_year` 與年度精度。它是中國曆年的西元數值標籤，不表示已換算確切公曆月日。`source_expression` 保留原紀年，`original_quote` 與 `evidence` 保留本筆事件原句；`context_evidence` 列明承接紀年的原文位置。

既有 `normalized_date_range` 若以 `regnal_year_crosses_ce_year` 為依據，表示該中國曆年在另一種公曆投影下跨越兩年。它不與中國曆年標籤構成互斥史料異說。兩者分存，不能取跨年範圍任一端點冒作已核定年份；未有新欄位的舊記錄保持原來表示，不批量移動一年。

初例為楚王戊死亡（`le-shiji106-008`）。〈吳王濞列傳〉本段保存「楚王戊軍敗，自殺」，前文明書「孝景帝三年正月甲子，初起兵於廣陵」。〈漢興以來將相名臣年表〉同列記三年「吳楚七國反，發兵擊，皆破之」，數位編者西元欄為西元前154年。中國曆年欄位因此記 `era: BCE`、`era_year: 154`、`year: -153`，而原有公曆投影範圍保持原樣。這是附證、未經人工覆核的編者判讀；不由發兵月日補死亡月日，也不宣稱書影已校。

`year_equivalence` 分列固定表格的著作、卷篇、來源與修訂，以及起元欄、年序欄、同列事件、數位年份的 cell ID 及原字。數位西元欄明示為編者對照，不當傳世正文。驗證核對見證、同列關係、原紀年與起元名稱、前文次序、數值年編號及證據範圍；它不代替對事件同指與敘事時間的學術判斷。

目前模型支援有段落證據的生卒與人物事件，原紀年依據須在同篇本段或前文。不同著作的平行事件須另建有明確範圍的證據模型；原生年表事件保持既有模型，不默套此段落格式。未知日期或不支援的引文形式保持未知，不補年數。

每人來源包在 `life_events` 或 `person_events` 原記錄保留此欄位，另以 `chinese_civil_year_normalizations` 提供帶事件 ID 的機讀索引；紀年上下文與對照表列入來源包，不計入人物被提及次數。`time_policy` 明示欄位名稱及局部覆核狀態。人物頁優先顯示有據的中國曆年標籤，原始引文、表格對照與舊公曆投影仍可展開，閱讀器不使用 AI 或 NLU。
