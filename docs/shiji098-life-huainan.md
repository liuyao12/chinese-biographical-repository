# 〈傅靳蒯成列傳〉生卒與淮南王辨識

傅偃案的淮南王，以陽陵侯表元狩元年國除及〈淮南衡山列傳〉安案限定；〈魏其武安侯列傳〉又與淮南篇同記太尉武安侯霸上迎王、上未有太子與厚遺金財物。依共同事件接合劉安，不能按所有淮南王稱號全域合併。兩個劉安舊人物ID於正式引用更新後撤除，回查使用Git。

魏其篇原明示高祖孫，仍保留祖父斷言；淮南篇明載劉長有子四人、子安為阜陵侯，家族預設依此父子路徑，不再保留未名父親的佔位。淮南篇的高祖／高皇帝依平黥布與立子長、起豐沛等事件與高祖本紀接合，另撤除一個高祖重複ID，使直記祖父與沿父追溯祖父不重複顯示；孝文時的上不改指高祖。這是補入已讀來源的明示父系，不是由王爵或繼位推父子。人物卡的父祖由關係追溯，不另存祖先清單。

本篇新增六項死亡主張，各引用自己的來源段落及人物錨點。傅寬孝惠五年、靳歙高后五年、周緤孝文五年依將相表紀年欄、數位編者西元對照及索隱所述太初前建亥歲首，分別記前191至190、前184至183、前176至175年的範圍。數位西元對照不作傳世原文；未知月不給單一公元年。

傅精二十四年、傅則十二年、傅偃三十一年保留原語，未核定絕對卒年。傅偃表中國除年不自動當卒年，六項死亡也不自動補作所有官爵終點。同書互見不當獨立史實票數；未核書影。
