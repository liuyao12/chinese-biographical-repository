# 〈季布欒布列傳〉君主稱謂

依全篇敘事補19處「上」「陛下」：購布、赦布與欒布為彭越辯護等段落14處指高祖；季布任河東守受召及進諫段落5處指孝文帝。後者以段首孝文明示身份，不因相鄰高祖敘事而誤接。

「上將軍」「殿上」「上客」分別為官稱、方位與賓客待遇，不拆出「上」標成君主。兩組身份判斷保留逐段完整引文與確切提及ID，屬上下文判讀，未核書影。未新增人物、親屬或紀年，正文與既有錨點不變。
