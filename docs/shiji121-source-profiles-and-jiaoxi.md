# 〈儒林列傳〉人物姓名、終職與膠西王

本批接續四十組跨篇身份覆核，未宣稱全篇或《史記》完成。

仲由、顓孫師、澹臺滅明、卜商、端木賜、商瞿、吳起、孟軻與孔子的姓名分欄，依弟子篇、專傳或世家明文，保留複姓、完整名及明書字號。七處明書「字」另存為 `zi`，閱讀器直接標示字，不以 NLU 重解原文。稱號未知就留空，不由字號倒造未見本名；分姓、名是附證的編者判讀，原文不改字。

王臧太子少傅「免去」、申公太中大夫「疾免以歸」、轅固清河王太傅「久之，病免」，分別記此職的明示終職事件，沒有確切年份。不因免職或死亡終止所有前職，也不把「久之」「數年」換成精確年數。

董仲舒敘事在今上及公孫弘活動的武帝朝脈絡。《五宗世家》明記景帝子端於七國之亂後為膠西王；《齊悼惠王世家》前一膠西王卬在七國之亂已被殺。兩處王號接合劉端，保留「繆西王」原字，不把背景段落當作直接提及劉端的證據。排除候選及背景引文分列於身份判斷的 `context_evidence` 與 `excluded_candidates`，直接提及引文仍列於 `evidence`。

人物頁用《五宗世家》明書的「膠西于王端」分稱號與名；劉姓明示依既有、具來源的景帝父系作編者判讀，不宣稱原句連寫劉端。既有景帝父親、程姬生母及家族組裝保留；不補新配偶、子女、排行或授爵起訖。頁首諡稱用於辨認，不冒作生前即有的稱號。
