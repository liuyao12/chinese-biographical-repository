# 楚死事相與張尚

〈楚元王世家〉記「其相張尚、太傅趙夷吾諫，不聽。戊則殺尚、夷吾」，〈吳王濞列傳〉記「楚死事相弟張羽」。同一七國之役、楚相與死諫背景相合；集解徐廣「楚相張尚諫王而死」，正義「按：羽，尚弟也」提供明確身份支持。正文引句與古注分層保存，張羽較幼之相對年序保留，不補出生排行或父親姓名。
