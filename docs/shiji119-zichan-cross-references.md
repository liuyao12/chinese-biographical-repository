# 子產跨篇身份與人名邊界

本批接合《吳太伯世家》《孔子世家》《伍子胥列傳》《仲尼弟子列傳》《滑稽列傳》《太史公自序》的鄭子產來源提及，連至 `qjs_3hl_6ck_A`。逐項身份判斷存於各篇 `*-identities.json`，保留原文、來源提及 ID、完整敘事引文及暫定理由。

吳、鄭兩篇的季札訪鄭敘事對讀；《吳太伯世家》又明言「季札封於延陵，故號曰延陵季子」，據此將鄭篇延陵季子、季子接回季札。這些判斷不能推廣為全庫稱謂替換。

《伍子胥列傳》收到文字仍是「鄭定公與子產誅殺太子建」。此處識別原文意指的名字，不採信子產確實參與此事，不延長生卒，不新增事件參與事實。該故事年代另待校讀；未因身份接合而宣稱矛盾已解。《孔子世家》的形貌比擬亦不提取為子產的體貌數值。

《仲尼弟子列傳》「冉季字子產」屬另一人物，字保留二字；《呂太后本紀》「子產為交侯」則是親屬詞子加呂產之名，《齊太公世家》「崔杼生子成及彊」是親屬詞子加成之名。後兩處只縮正人物錨點起點，保留原文與原提及 ID，移除由誤分詞生成的全局異稱；不將這種縮界套用到真正字號。鄭國年表的子成仍不據同字合為齊國崔成。

七個來源局部重複人物更新全部引用後撤除，歷史版本可由 Git 回查。無人工審閱、無書影校勘；卒年取捨、七處原生年表標記與其他未解指代仍為後續工作，不宣稱全篇完成。
