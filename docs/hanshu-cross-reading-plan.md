# 《漢書》交叉核讀順序

2026-10-13 使用者要求：在適當階段開始《漢書》，利用與《史記》的顯著重疊交叉查證人物身份。毋須等待《史記》全部第二輪覆核才啟動。

啟動點為本批舊格式 ID 撤除與核心跨篇身份引用整併驗證後。先核讀〈高帝紀〉及與既有《史記》漢初人物重疊的功臣列傳，再延伸皇室、外戚與其他世系；《史記》逐篇第二輪與未解候選仍保留進度，不視為已完成。

兩書各存固定見證的原文、work／book／chapter ID、Unicode 提及錨點與引文。逐項比對姓名異稱、前後稱號、親屬、任職時段及共同事件，再判斷是否同人；同名不是合併依據，同一文本傳承也不當獨立史實證據。已確認同指使用唯一現行人物 ID，各來源的紀年、父母與其他異說保留在來源陳述，不因身份整併抹除。

未開始《漢書》轉錄或標註；底本與數位來源須先核讀選定。來源局部候選只有足夠上下文支持同指時才合併，引用更新及驗證完成後撤除舊人物 ID；不重新建立永久別名入口。

待核讀的底本候選：[Kanripo 前漢書 KR2a0007](https://github.com/kanripo/KR2a0007)，其目錄標示文淵閣《四庫全書》版本。尚未核對卷一正文、版本影像或轉錄許可，不把目錄查得當作底本校勘完成。
