# 〈汲鄭列傳〉六組核心身份與姊妹方向

依本篇完整敘事與各篇固定來源接合景帝、武帝、田蚡、衛青、衛后及淮南王安。景帝崩後太子即位與《孝武本紀》相合；武安侯蚡按太后弟的外戚及魏其同案辨識；大將軍青與姊皇后除具名家事，另有《衛將軍驃騎列傳》明記衛夫人立后；淮南王謀反說丞相如發蒙與淮南篇具體事件對讀。不按同名、同爵或最近出現的帝王全域接合。

本篇回述鄭君時的高祖、孝文與武帝主敘分開；少主是輔政假設，不補一位新皇帝。以莊見憚的莊、太子洗馬的職名與上不能的上不改作人物。太史公論贊與附錄《索隱》述贊原層次保留。

`sister` 的主體是姊妹本人，原 `a-shiji120-003` 反向端點修為衛后至衛青。保留陳述 ID、引文及本篇衛后較長的相對年序；其他篇衛青較長的原主張仍存，不補絕對排行、同母推論或生年。

本篇專項檢查核對主體、客體與原引文的具體指涉。來源關係也可能以相反視角記錄，例如「呂后兄周呂侯」可記呂后是周呂侯的姊妹；單個兄、姊字不足以判斷所有記錄的主體，不據此套用全庫方向規則。

六個來源局部重複人物更新全部引用、索引及匯出後撤除，不留永久轉址。來源提及 ID、原位置與文字保持。

衛后人物頁依《外戚世家》「衛皇后字子夫」「家號曰衛氏」分別記皇后辨認用稱、衛氏與字子夫，名未知；去除過時的外戚世家候選標籤。依衛夫人立后與同段武帝稱謂補記配偶關係，沒有以立后年填始婚年月，也不據配偶關係指定其他子女生母。
