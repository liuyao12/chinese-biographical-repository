# 主父偃、徐樂與嚴安上書

第十至二十段逐段初標，保留33名新增來源候選；全卷目前前20段共有46名來源候選、155處人物與20處未定錨點。其餘11段待標，這些數字不代表全部身份已覆核。

引語按說話者及受話者分層：成進引語的陛下指向高帝，其後主父偃的陛下回指當朝。司馬法是書名，弘游燕之囿的弘未連公孫弘。秦王與秦皇帝、陳涉與陳勝按同一篇的歷史敘事暫同指，尚未跨篇合併；先帝另設來源候選。五伯、六卿、七國等群體不補成員。

尉[佗]校字片段保留未定，尉佗、屠睢、監祿分存來源候選，不補現代姓名或親屬。主父偃齊臨菑人、徐樂趙人、嚴安齊人保存出身原詞，不換現代行政區。

新增四筆用稱：衛將軍、成進御史、秦王及皇帝；保留未知起訖，不以奏書年反推歷史人物任期。秦皇帝崩另存死亡事件，卒年與死亡地點未知，死亡不自動終止所有稱號。

全部資料仍為代理初步判讀，代詞、跨篇身份、官爵時段、版本及影像覆核未完成。新卷篇尚未接入線上閱讀器。
