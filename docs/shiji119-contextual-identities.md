# 〈循吏列傳〉語境辨識與來源年數

本批按完整敘事單元將楚莊王、楚昭王及晉文公的十六處提及，接至〈楚世家〉、〈晉世家〉已登記身份。篇內「王」「文公」及論贊「楚昭」「晉文」承接各自敘事，不以最近出現的人物全篇配對。身份接合不等於證實所有政績故事或取得確切事件年。

石奢段兩處「殺人者」以「相追之，乃其父也」「殺人者，臣之父也」接至已登記的同一未名父親。提及錨點與原字保持，不新增犯罪者姓名，也不改原有父子主張的主客方向。

子產「治鄭二十六年」記為來源持職年數26、原數詞「二十六」及原詞全文；計年方式未定，不推起訖、生卒年。相一年至五年是任內相對年序；孫叔敖三得相、三去相不是三年，三月為相不逕當曆月三月。

「鄭昭君」保留本篇來源身份，未改為昭公或簡公。《索隱》卷二十七已指出子產不事昭君、無徐摯作相之事，以「太史記異」解釋；這是具署名古注，不是編者已校定君名。原文徐贄、大宮子期原樣保存，不因另一見證的徐摯、太官子期而靜默改字。

子產父系另有衝突：〈鄭世家〉作鄭成公少子，杜預注《左傳》則明言「子産子國子」，並以注連明公子發、子國及子產父。三段杜注現已作有層次的來源節錄導入，編輯世系暫採子國父系並遷移家族ID；《史記》成公少子的原斷言不改，保留為異說。詳見[子產父系來源與採擇](shiji119-zichan-parentage.md)。
