# 〈田儋列傳〉攻齊人物身份

依歷下進軍、酈生遇害、蒯通計、龍且高密戰與平齊敘事，接合韓信至淮陰侯，不混韓王信；酈生依遇害與弟酈商接合酈食其。曹參與灌嬰各依本傳及共同戰役辨識，灌嬰的短稱嬰仍指同人。

卷九十五第22段明引灌嬰，第24段末嬰遷御史大夫，第25段續以御史大夫將郎中騎兵東屬韓信。續段無灌嬰顯名，另存原段敘事參考，不把三年或職稱偽標成姓名。田光俘獲與龍且戰功各篇各記，不以同指整併消去敘事差別。
