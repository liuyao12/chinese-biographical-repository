# 三國兩晉南北朝跨史家族優先計畫

2026-10-18 使用者調整工作重點：優先整理三國、兩晉、南北朝士族，將分見多部正史的記載接成可追溯的家族樹。收錄歷代正史與《資治通鑑》全部人物的總目標不變；《史記》與《漢書》未完成的覆核繼續保留，不標為完成。

主要閱讀工作已轉入中古家族，不再按《史記》篇次擴大新批次。工作以家族為問題單位、卷篇為轉錄與證據單位；不必等一部史書全部完成才跨書查核同一世系。

## 起步次序

1. 潁川荀氏：先核《三國志》卷十荀彧、荀攸傳的完整敘事與裴注，再尋《後漢書》《晉書》相關傳文。作為跨史接合的第一個試點；具體祖孫、支系及親屬距離須讀原文後決定。
2. 琅邪王氏：由《晉書》王導、王敦等相關卷篇起步，往前後史書逐項追蹤有直接證據的親屬。不得把太原王氏或其他同姓支系按姓氏自動合入。
3. 陳郡謝氏：由《晉書》相關列傳起步，續讀南朝史書中的具名親屬；不把「從弟」推成已知父親或固定堂親距離。
4. 上述試點穩定後，依跨史重疊、世代連續性及來源取得情況，安排陳郡袁氏、潁川庾氏及北朝相關家族。此為待選閱讀佇列，不代表已確認彼此系譜。

每一家先形成有證據的父系骨架，再納入原文明示的母親、婚姻、子女、收養、排行與稱號時段。女性即使未記本名也保留來源身份；婚姻連結須能導向配偶的實際家族，不建立截斷的同人副本。不因郡望相同、同姓或後世族譜聲稱而強行接祖。

同一家內先處理能銜接兩部史書的中間世代、身份重複及關鍵親屬，然後擴展旁支；不以著名人物的數量取代世系連續性。遇缺代或矛盾，保存斷點與相競記載，另排待核項，不為畫成完整樹而補造人物。

## 本輪來源範圍與接合邊界

本輪工作分支已收錄《三國志》卷二十八王凌完整敘事及相關注、《晉書》卷八十九嵇紹本傳、卷八永和五年完整年段與卷七十七殷浩本傳；《後漢書》卷九目前只收傳首及中平六年、初平元年的完整年段與所附古注，不能稱全卷完成。《後漢書》卷六十二荀氏相關單元亦改以完整來源呈現，舊摘錄保留為可追溯的封存片段，不在閱讀畫面重複正文。

殷羨、殷浩、殷涓依明示父子關係同根；殷融的叔父關係另存，不補未名共同祖先。陳氏接合保留實際缺代，七世祖不能改作直接父親；王凌本傳中單固母親的記載不移接王凌。異名與同名判斷均保存來源上下文，不能依單字或同姓批量合併。

可由[逐人 JSON 索引](../exports/persons/index.json)查現行人物及檔案路徑。官爵、生卒、地望及紀年的逐項補充仍在覆核；本段記錄工作分支的來源範圍，公開內容以既有人文網站實際部署為準，不表示上述全卷、全族或跨史工作已完成。

## 每批交付

- 固定版本的繁體原文及 work／book／chapter ID，正文、裴注等古注與後人考證分層。
- 逐人而非逐格標記，保存原稱、短稱與官爵指代的具體上下文。
- 來源親屬斷言與編輯身份判讀分開；不同史書的矛盾可選有理由的首選，但不抹去另一來源。
- 同人只存一個現行身份，更新全部引用與人物 JSON 後撤舊號；缺代保留，不造中間父親。
- 人物頁由 JSON 推導祖先與子女，核對跨書導航、配偶家族與缺欄隱藏；爵號不當姓名，未定年份不填估值。
- 優先採核讀的傳世正文與墓誌；數位正文不稱影像校勘。墓誌的刊本、出土報告及可公開影像分別記來源。
