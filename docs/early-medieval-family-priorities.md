# 三國兩晉南北朝跨史家族優先計畫

2026-10-18 使用者調整工作重點：優先整理三國、兩晉、南北朝士族，將分見多部正史的記載接成可追溯的家族樹。收錄歷代正史與《資治通鑑》全部人物的總目標不變；《史記》與《漢書》未完成的覆核繼續保留，不標為完成。

主要閱讀工作已轉入中古家族，不再按《史記》篇次擴大新批次。工作以家族為問題單位、卷篇為轉錄與證據單位；不必等一部史書全部完成才跨書查核同一世系。

六朝逐族整理的範圍、逐傳覆核門檻與當前批次見[六朝逐族傳記整理](six-dynasties-reading-run.md)。

## 起步次序

1. 潁川荀氏：先核《三國志》卷十荀彧、荀攸傳的完整敘事與裴注，再尋《後漢書》《晉書》相關傳文。作為跨史接合的第一個試點；具體祖孫、支系及親屬距離須讀原文後決定。
2. 琅邪王氏：由《晉書》王導、王敦等相關卷篇起步，往前後史書逐項追蹤有直接證據的親屬。不得把太原王氏或其他同姓支系按姓氏自動合入。
3. 陳郡謝氏：由《晉書》相關列傳起步，續讀南朝史書中的具名親屬；不把「從弟」推成已知父親或固定堂親距離。
4. 上述試點穩定後，依跨史重疊、世代連續性及來源取得情況，安排陳郡袁氏、潁川庾氏及北朝相關家族。此為待選閱讀佇列，不代表已確認彼此系譜。

每一家先形成有證據的父系骨架，再納入原文明示的母親、婚姻、子女、收養、排行與稱號時段。女性即使未記本名也保留來源身份；婚姻連結須能導向配偶的實際家族，不建立截斷的同人副本。不因郡望相同、同姓或後世族譜聲稱而強行接祖。

同一家內先處理能銜接兩部史書的中間世代、身份重複及關鍵親屬，然後擴展旁支；不以著名人物的數量取代世系連續性。遇缺代或矛盾，保存斷點與相競記載，另排待核項，不為畫成完整樹而補造人物。

《新唐書》〈宰相世系表〉對魏晉南北朝及隋唐親屬關係屬後出編纂見證。可據表尋找人物、墓誌及較早傳記，也可分錄原表的世系主張。只有表證的接合保留待核，預設父系須另有可定位的證據。若表文似出同一傳記、墓誌或家譜，記明來源關係，避免視作兩份獨立證詞。有歧異時逐條比較同時代墓誌、較早傳記及其傳承，保留各自原文與判讀依據。

## 工作分支進度（尚非全部發布）

潁川荀氏已進入《三國志》《晉書》《宋書》的跨史整理。王謝試點已接合王覽、王導、王洽、王珣、王弘與謝裒、謝據、謝朗、謝重、謝晦等具名世系，並另存王胡之與謝重的外祖關係；固定資料可查 [PR #528](https://github.com/liuyao12/chinese-biographical-repository/pull/528)。公開版本以既有人文網站的部署提交為準。

目前工作分支已補入荀崧本傳十二原段、荀蕤與荀羨附傳，並續核鄭阿春母系婚姻。四庫數位平行選段的「子籍」明文另立來源／篇 ID，荀籍接荀蕤；元帝六男的父親與各別生母、鄭阿春父祖亦已錄入初步資料。成帝本紀傳首另立篇章，支持其父明帝並連結荀崧傳中的指代；劉寔／劉實已依本傳太常、司空官歷接合；經師單姓保留待核。婚姻、撫養、稱號紀年及版本判讀仍在整理，不表示本批已發布、整卷或整族已完成。

## 本輪來源範圍與接合邊界

本輪工作分支已收錄《三國志》卷二十八王凌完整敘事及相關注、《晉書》卷八十九嵇紹本傳、卷八永和五年完整年段與卷七十七殷浩本傳；《後漢書》卷九目前只收傳首及中平六年、初平元年的完整年段與所附古注，不能稱全卷完成。《後漢書》卷六十二荀氏相關單元亦改以完整來源呈現，舊摘錄保留為可追溯的封存片段，不在閱讀畫面重複正文。

殷羨、殷浩、殷涓依明示父子關係同根；殷融的叔父關係另存，不補未名共同祖先。陳氏接合保留實際缺代，七世祖不能改作直接父親；王凌本傳中單固母親的記載不移接王凌。異名與同名判斷均保存來源上下文，不能依單字或同姓批量合併。

可由[逐人 JSON 索引](../exports/persons/index.json)查現行人物及檔案路徑。官爵、生卒、地望及紀年的逐項補充仍在覆核；本段記錄工作分支的來源範圍，公開內容以既有人文網站實際部署為準，不表示上述全卷、全族或跨史工作已完成。

## 北朝與曹氏的後續整合範圍

後續整合分支另已收《魏書》卷三十八王慧龍至王松年的本傳、附敘及相關論贊九個完整單元，《晉書》卷九十曹攄本傳三完整段，以及《三國志》卷九曹休、曹肇、曹纂及相關裴注八個分層單元。清河崔氏收《魏書》卷二十四崔玄伯、簡、恬、徽等選定完整單元，並另存《北史》卷二十一崔宏完整短傳；不表示上述各卷、崔浩全傳或整族已完成。原文、逐人標記與版本可查各篇 `source` 與段落欄位。

盧遐妻「崔浩女」與「寶興從母」保留兩條來源陳述，但同人或異人尚未決定，家族卡片以一個未決組呈現。曹攄只明祖父肇，不能由先記肇子興便推攄父為興；曹休未名父、祖父各保來源身份，不將「太祖族子」改成曹操的直接子孫。《魏書》《北史》對崔悅官職左／右長史等異文各存原詞，不以後一來源靜默覆蓋前一來源。

原生資料已進入整合分支，家族改號、人物 JSON／閱讀目錄重建與瀏覽器驗收仍須各自完成。這些後續內容不包含於 [PR #546](https://github.com/liuyao12/chinese-biographical-repository/pull/546) 的固定版本，亦不由本節推定已發布。

## 並行查核

陳郡謝氏續讀《南史》卷十九謝晦及兄弟附敘。謝重五子用同段「重生絢、瞻、晦、㬭、遯」逐一繫證。《宋書》謝瞻本傳的「第三兄」與《南史》的「次兄」分存，共同支持瞻年長於晦。㬭的生母郭氏僅繫於本人。下一步可沿本卷謝澹附傳核對父瑤、祖安。[《南史》卷十九](https://zh.wikisource.org/w/index.php?title=南史/卷19&oldid=1531762#謝晦) · [《宋書》卷五十六](https://zh.wikisource.org/w/index.php?title=宋書/卷56&oldid=1996689#謝瞻)

清河崔氏先對讀崔光、崔鴻在《魏書》《北史》的親屬記載，再核〈臨淄北朝崔氏墓〉的崔鴻、崔混兩誌。[《魏書》卷六十七](https://zh.wikisource.org/w/index.php?title=魏書/卷67&oldid=468068) · [《北史》卷四十四](https://zh.wikisource.org/w/index.php?title=北史/卷044&oldid=2183262)

- **荀氏與陳郡袁氏。**《晉書》荀崧傳明記外祖袁侃及侃弟奧。《三國志》正文「渙子侃」，裴注引《袁氏世紀》「渙有四子，侃、㝢、奧、準」，分層錄原文。兩書的陳郡及侃、奧兄弟線索相合。愍帝紀另記荀籓、荀組為其母舅，生母未名。袁侃、袁奧的現行 ID 沿用，兩條父子關係可從人物 JSON 查到。[《三國志》卷十一](https://zh.wikisource.org/w/index.php?title=三國志/卷11&oldid=2373044#袁渙) · [《晉書》卷七十五](https://zh.wikisource.org/w/index.php?title=晉書/卷075&oldid=2645530#荀嵩) · [《晉書》卷五](https://zh.wikisource.org/w/index.php?title=晉書/卷005&oldid=7904721)
- **謝氏。**《南史》明載謝澹父瑤、祖安，兩條原證入庫。其與謝晦的「從叔」原稱照錄，親疏代距留待另證。[《南史》卷十九](https://zh.wikisource.org/w/index.php?title=南史/卷19&oldid=1531762#謝晦)
- **崔氏待錄。**崔混誌錄文給出卒日和遷窆日，卒前敘事有疑字。兩史另載其為叔父所殺。後續分錄日期及所述死亡經過，原發掘報告為〈臨淄北朝崔氏墓〉，《考古學報》1984年第2期，圖版仍待核對。[墓誌錄文](https://guji.10huan.com/Article/7147_7165.html) · [《魏書》卷六十七](https://zh.wikisource.org/w/index.php?title=魏書/卷67&oldid=468068)

## 每批交付

- 固定版本的繁體原文及 work／book／chapter ID，正文、裴注等古注與後人考證分層。
- 逐人而非逐格標記，保存原稱、短稱與官爵指代的具體上下文。
- 來源親屬斷言與編輯身份判讀分開；不同史書的矛盾可選有理由的首選，但不抹去另一來源。
- 同人只存一個現行身份，更新全部引用與人物 JSON 後撤舊號；缺代保留，不造中間父親。
- 人物頁由 JSON 推導祖先與子女，核對跨書導航、配偶家族與缺欄隱藏；爵號不當姓名，未定年份不填估值。
- 優先採核讀的傳世正文與墓誌；數位正文不稱影像校勘。墓誌的刊本、出土報告及可公開影像分別記來源。
