# 卷八十五〈呂不韋列傳〉草稿

固定版本2027911的16段正文已實際核讀，索隱述贊另層待收。父系敘事、養母生母、仲父號稱與篇末封號歧義分存，未核影像或現代研究。人物待標註，未完成覆核。

前5段明示姓名首輪已存。死亡太子與安國君分開，華陽夫人姊及子政母未補姓名；王稱與太子嵌套指代仍待覆核。

前10段姓名首輪已存。孝文王安國君、莊襄王子楚與政按王序暫接；四公子並列不視為同時在世，守者吏與主腐者吏各保留未名。後6段待補。

全16段明示姓名首輪已存。太后兩子保持未解群體，吾夫吾子與先王回指待核；篇末封號文信侯原句歧義不作嫪毐實授。完整時段、身份及版本待覆核。

已保存18項官爵用稱與相國明示免職終點。日期保存原語其四十二年，不補王名入原日期；仲父不作親屬，免相不終止文信侯，死亡不推定全部時段終點。

現存22個本篇候選與205處錨點，6項親屬來源主張、18項官爵記錄及6項跨篇暫同指。秦本紀孝文與莊襄王序、始皇本紀政立王及免呂不韋迎太后事件作為證據；父系、刑罰、封號及任期差異不調和。第6段未名夫人兩處錨點已補。
