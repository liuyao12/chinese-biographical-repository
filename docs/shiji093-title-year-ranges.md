# 授爵紀年與跨年範圍

韓王信五年春剖符、盧綰漢五年八月燕王暫對照公元前202年。穨當弓高侯與嬰襄城侯的本傳十四年記降漢，不作授爵年；依侯者年表同人授侯元年十六年六月丙子，首選前164年，襄城／襄成原字保存。

他之亞谷侯孝景中六年未明月份，按本傳自身紀年暫存前145至144年範圍。侯者年表中五年四月、它父及綰子另存參考，與本傳中六年、他之及綰孫的日期、姓名、世次差異不抹平，仍待對讀。原紀年、原句、原年欄、數位公元欄及曆書正朔引文分存；未核書影。

跨年用 `normalized_date_range`，earliest／latest 各有 era、era_year、year，天文年編號；precision 為 `year_range`，basis 為 `regnal_year_crosses_ce_year`。不與單年 normalized_date 同時採用，不暗補某個確定授爵年。人物頁顯示範圍及紀年來源，前端不需要 AI 或自然語言處理。原文及未知爵位終期不改。

年表韓頹當、韓嬰逐人標記依本格爵號與父系接入本傳身份，保原字，撤除兩項表內候選；亞谷侯的名字、世次及年份差異保留未決。

年表兩格中的韓王信及太子另補三處逐人標記，依明示父系連到本傳，太子不作長子。

驗證：599 項 Python 測試通過（557.974 秒），192 項 JavaScript 測試通過，五名人物及五處年表標記合計十組桌面／手機本機驗收通過。112 篇正文與標記位置、十表原字及表格結構未變，兩個表內候選引用及舊 JSON 已撤除。
