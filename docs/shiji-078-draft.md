# 卷七十八〈春申君列傳〉草稿

保存固定數位修訂2089016的22段正文，自春申君黃歇至太史公論贊。人物導覽、索隱述贊及現代版權告示不混入；上書dd引文區塊按原次序保留，HTML邊界與正文已核讀。第6段铚轉銍明示記錄，為、彊、谿、免等古字原留；未見改讀括號，未核底本影像及現代研究。

上書引古人物與當時敘事人物分開，文王莊王未補名字。禽芒卯與他篇走芒卯各留。李園女弟及其子先保留來源稱呼，敘事血緣不當已核定史實；擬任朱英郎中與稱楚王的評論不作實際授爵。全22段正文已核讀，人物待逐段標註。

前3段保存11個新候選與53處錨點。黃歇歇臣按明示與書信範圍暫接，秦王稱先排除越王；文王莊王與越王引古不補未見名字。後19段待標註，下一位置第4段。

第4至12段本次新增8個候選，已保存前12段共19個候選、171處錨點。完／考烈按明示繼位暫接；楚更立太子假設不接完，太子傅未名單存，陽文君兩子群體不補姓名。關內侯方案不作實授，三公子稱只記本篇未核跨篇身份。後10段待標註，下一位置趙使珠履故事。

後10段新增14個候選，全22段姓名首輪共33個候選、338處錨點。李園女弟與所生太子幽王按敘事暫接，未當血緣已證實；實楚王評論指春申，君子為王與王長反政是假設，朱英郎中方案未行。先君善秦仍未定，更立君後的君未接春申。親屬、時段與跨篇身分待補。

已保存4項親屬來源主張及20項官爵用稱。幽王母系與本篇黃歇父系敘事各連明示段落，父系標明待版本研究覆核，不當核定血緣。頃襄父懷、李園女弟兄李園只存明示；完繼位不單憑次序補父子。春申相與爵同存考烈元年實授，荀蘭陵令與呂相爵依明示紀年；呂廢只終止相位，未終止文信侯。朱英郎中、實楚王及關內侯方案未列實授，李園舍人用稱不補授任日期。

已保存16項跨篇暫同指，逐項引用秦／始皇本紀、楚趙世家與白起、孟荀、平原、魏公子、孟嘗列傳原錨點。完／熊元、幽王悍與父系敘事、禽／走芒卯、呂廢九／十年各留，不由同指定版本取捨；現代研究待核讀後另存，未捏造優先結論。
