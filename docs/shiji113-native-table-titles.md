本批從《建元以來侯者年表》直接保存龍亢、成安、將梁、安道、隨桃、湘成、海常、臨蔡八筆首封。封國、功臣事由、持有人錨點、年號欄及日期格各自保留，沒有把表格稱號偽造成正文段落。七筆已明正月至九月的原日期以西元年作數字精度；臨蔡元封元年閏月未明閏幾月，保留前111至110年範圍，不猜公曆月日。

本傳海常、臨蔡原先沿段首元鼎六年填授爵年，本批撤除此推定：冬季戰役與後來授爵分開。原句、原授爵事件與錨點仍在，原表日期另列來源；不由父親死事把爵位授給父親，也不由死亡結束所有爵位。

安國少季的姓名組件另有古注分歧。漢書師古注作姓安國字少季，索隱作安國姓也少季名也；暫沿前者為預設，API另存名少季的來源主張，人物頁並列引文及取捨。不再把本傳未明本名說成所有來源皆未記名，也不推兩次在世改名。
