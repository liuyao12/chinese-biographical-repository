# 〈管蔡世家〉第二輪核讀紀錄

全43段已第二輪核讀；本批先保存75筆死亡主張，仍在進行中。
- p1 文王十位同母兒子排序須保留同母範圍，冉季載最少只在此組；伯邑考前卒與文王崩不同時，不借武王即位年。
- p2 管蔡等封邑不當籍貫，康叔冉季未封不生造早期爵位。
- p3 武王卒、武庚誅、管叔殺、蔡叔放逐分記；康叔司寇與冉季司空明舉任。
- p4 蔡叔遷後死未明地，胡魯卿士後蔡仲復封時段分開，不借父卒年填授官日期。
- p5 仲荒宮厲卒逐項，不從順序倒算年；周厲王彘出奔非死亡。
- p6 武侯卒與夷侯二十八年卒分年；p7周幽王釐侯三十九年死。
- p8 釐共戴侯各卒年分開；p9蔡宣桓侯與魯隱公死亡分國紀年，哀侯弟不補子。
- p10 哀侯十一年被虜、留九歲、凡立二十年卒各語義不同，不從九歲留囚推生年；楚卒地明示。
- p11 繆侯女弟與齊桓公婚姻，歸而不絕不是立即離婚；嫁其弟事件與之後齊征蔡分開。繆侯被虜後歸不當死亡，二十九年卒明示。

第12–26段已核讀。
- p12 齊桓公楚成王秦穆公蔡莊侯死亡分不同蔡莊侯年次，繼位不是血親。
- p13 夏徵舒殺與蔡文侯卒分14／20年；p14楚莊王元年卒、蔡景侯49年弒另時。
- p15 郟敖、陳哀公、蔡靈侯分楚蔡陳君ID；蔡靈侯被殺申地明示，士卒70人不補姓名。
- p16 楚靈王弒與復陳蔡分事件；廬少子保持年幼／最幼歧義，滅蔡三歲是時長。
- p17 平侯9年卒、隱太子友回述被殺與悼侯3年卒分記；東國攻平侯子不直接當殺死，匿名平侯子保持錨點。
- p18 昭侯留楚3年非死亡；子常相官稱、獻裘後歸蔡赴晉分遷徙。
- p19 子常奔鄭、昭侯州來遷、昭侯及賊利死亡不同主體；遷蔡是集體事件，昭侯私人許不當已遷，正文因遷才完成。
- p20 齊簡公與蔡成聲元侯死亡分紀年；p21蔡侯齊亡及絕祀不單憑亡推死亡。
- p22 伯邑考後封不知、成叔冉季後世無所見，不補血親缺代；管叔誅死為回述見證。
- p24曹叔封曹與p25曹叔、太伯、仲君、宮伯、孝伯死亡逐項存；太伯脾不連吳太伯。
- p26周厲王彘出奔非死亡。

第27–43段已核讀；全43段第二輪閱讀完畢，尚未入庫。
- p27夷伯卒省略主詞需前段錨點；幽伯被弟蘇殺與戴伯三十年卒分記。
- p28周幽王死與p29惠伯卒、石甫弟武殺石甫不同年，三十六原文無年字不默加。
- p30繆公卒；p31魯隱公、宋殤公、孔父與曹桓公卒分蔡曹國君年次。
- p33–35曹莊釐昭卒各年；p36共公被虜後復歸，不推死。釐負羈宗族閭不是籍貫或新人物。
- p37晉文公、曹共文宣公卒分主體和年次；成公為弟非子。
- p38曹成公被虜釋放與卒分開，晉厲公、楚靈王被弒不同君年；平公校勘須字保持，不以頃字另造人。
- p39悼公宋囚後宋死，歸葬未明墓址，不借被囚日當卒日。
- p40聲隱靖公死亡與兄弟篡立分開；通為平公弟、露為聲公弟不混父子。
- p41神異夢曹叔不作新生平事件；公孫彊司城明授，曹野人非具體籍貫；夢者子亡去非死亡。
- p42伯陽與公孫彊被執歸而殺各具名死亡，宋為方向／歸國語境，卒地須依證據限度。
- p43太史公評語與夢回述保持文本層，未稱獨立史實確證。

原文、人物錨點與既有ID保留。新增9筆出奔、囚留、人質居留與死亡地點；未知墓址不補。既有61筆稱號核對，司寇、司空、魯卿士及司城授任已有來源起點，保留原ID與證據，不重複新增。其餘官爵時段、排行、數字紀年仍待完成；未接入公開閱讀器。來源為已保存的固定數位版本，未核影像，未冒稱人工覆核。
