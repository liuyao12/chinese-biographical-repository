# 〈儒林列傳〉跨篇身份覆核

本批合併楚王父子與申公三組、秦漢人物十二組、孔門及戰國學者十二組、傳易三組、其他明示身份十組，共四十組重複身份、一百三十三處既有來源提及，不代表全篇完成。原文、提及錨點及引文不改字。

〈儒林列傳〉以劉郢與申公共師、劉郢為楚王、太子戊繼位而刑申公的連續敘事，辨識楚夷王劉郢及其子楚王戊。與〈楚元王世家〉交、郢、戊三代及既有父子斷言對讀，接入已有楚元王父系；既有首選家族組裝維持不變，兩篇父子來源均保留。不是從單純繼位推造父子。

〈楚元王世家〉篇末楚王戊刑申公，與〈儒林列傳〉同一事件及師承背景相合，申公接到已有跨篇身份。陳申公、申公巫臣不是此人；師承亦不轉成血親。

人物頁將楚夷王、劉、郢及楚王、劉、戊分欄。子戊的劉姓依明示父子與漢宗室上下文記為編者判讀，不宣稱本段逐字寫作「劉戊」。太子戊保留為來源稱呼。頁首稱號用於辨認，不表示人物一生所有時點已有王爵或諡號。

固定來源、段落、提及錨點、身份理由保存在 `corpus/shiji/121-identities.json`；未作書影校勘，未宣稱人工審閱。舊四十個人物 ID 須在全部引用與衍生輸出更新、檢查通過後撤除，不設永久替身 JSON。

## 帝王稱謂與學者字號

漢初高祖、惠帝、文帝、景帝與今上依敘事先後及專傳辨識，竇太后不混王太后；二十二處今上、上、天子及陛下逐項核讀，普通上書、十八已上及引古泛論天子不作武帝。

子路、子張、澹臺子羽、子夏、子貢與商瞿各以弟子篇明名與字號對讀。田子方、段干木、吳起、魏文侯、孟子及荀卿依本篇學術與戰國脈絡接合專傳。漢王商字子夏及魯昭公夫人孟子保持分開；吳起師承原說不改字，傳易六世不當父系世數。

傳《易》的田何、王同、楊何另以籍貫與上下師承對讀六處提及。子中／子仲原字不改；元光元年徵召與元朔中任漢中大夫是不同事件，不直接視為互斥紀年。

孔子、周幽厲、田齊威宣、王臧及湯武桀紂十組身份，另核四十五處原標記；王臧合孝武、萬石張叔、魏其武安與儒林四篇同事，不合太常臧。引古評論不作新事件，不按武王等稱號全域替換。
