# 〈衛康叔世家〉第二輪核讀紀錄

第1–8段核讀。
- p1 康叔與武王同母少弟，冉季最少須保留同母組及相對次序，不造所有兒子絕對序。
- p2 武王崩、武庚與管叔被殺，蔡叔放逐不同；康叔河淇間故商墟居住原句，受封不作籍貫。
- p3 康誥酒誥梓材為篇名，勿當人物；康叔之國非死亡。
- p4 成王舉康叔司寇，與管蔡篇周公舉任不同主體表述須分存來源，不悄然選改。
- p5 康叔康伯考伯嗣伯偼伯靖伯貞伯卒各分記，原異體偼保留。
- p6 頃侯受侯命與卒立十二年分授爵／時長，不用諡號補授爵日期。
- p7 周厲出奔非死，釐卒42，共伯餘太子立君可作身分終點。
- p8 共伯羨自殺與葬釐旁明示，墓名只保留原詞；和襲攻不直接當共伯被殺，後共伯諡與君爵區分。

第9–20段核讀。
- p9 周幽死亡在衛武42，武55卒；平王授公爵與即位為侯不同階段，不當諡公授予。
- p10 陳女生子蚤死、完母死、莊23卒各分記；齊女是養母，完母為陳女女弟，不能同母。完立太子到桓公可作來源事件終點。
- p11 桓16被殺，州吁濮被殺；段不勝亡及州吁出奔非死亡。晉於邢迎立保存遷徙起點。
- p12 魯隱衛宣7、宋殤與孔父9、晉哀10被弒分記，曲沃莊伯敘事主張與跨篇異說須保留。
- p13 夷姜死、壽及伋盜殺、宣19卒分記；18年初的回述不給所有事件同日起訖。壽為朔兄及伋異母弟是相對排行；宣奪齊女與原太子婚姻提議分開，正夫人齊女非夷姜。
- p14 惠奔齊，黔牟立；攻惠非死亡，任君廢黜與原用稱分開。
- p15 左右公子誅分兩個已辨者；黔牟奔周、惠復立，亡8年不作死，合計13與實任分期不同。
- p16 周惠奔温、惠31卒；周與衛惠不同人物，立穨不當惠死亡。
- p17 懿9被殺。
- p18 惠後滅為群體，勿逐個造死亡；戴申元卒。
- p19 文奔齊後入衛原語序保留；楚丘築城為衛國集體記，不無據作個人籍貫。
- p20 伋子又死、昭伯與黔牟已前死分存未知日期；戴卒為p18回述不重複新增。無子不造不存在人物。

第21–30段核讀。
- p21勤政評語不造新授官。
- p22齊桓文17、衛文25卒分記，重耳過為訪行。
- p23成奔陳、如周，鴆得不死不造死亡；元咺誅、晉文7秦穆14齊懿26成35死亡分記。二歲為在外時間非第二在位年。
- p24夏徵舒被殺穆2、穆卒未明年，不能借11年；定卒12。
- p25獻奔齊，齊置聚邑可存居處與目的地；妾笞非死，孫甯如宿為訪行。
- p26林父奔晉、獻齊居如晉目的地；殤甯被執非死亡。亡外12為出亡期間，不能作死。
- p27甯喜誅後元、獻後3卒，後元日期分復位；季子過訪不作定居。
- p29襄9卒，元生日期回述未明，不借9年；康叔夢話保留神異，不作新人生事件。
- p30靈42夏卒；郢少子可能較小／最小，不自動序末。立郢提議被辭，不作已持太子爵；蒯聵子輒立君非靈子。

第31–42段核讀。
- p31 蒯聵入宿而保，六月乙酉原曆保留；受攻不得入非死。
- p32 齊孺子被弒出公4、齊悼被弒8，與齊篇主體不同各存本篇主張。
- p33 孔子自陳入衛、反魯有方向，入非定居全部時期。
- p34 孔文卒回述初，不能借出公12年當確定卒年。蒯聵在宿、良夫蒯聵舍外圃暫宿，輒奔魯目的地；悝母與伯姬同段辨認，婚姻許諾不作已婚。宦者羅與欒甯不同人物。
- p35 子路結纓死出公12語境；孔悝被劫與假設雖殺不作死，子羔出非死。太子蒯聵立莊可作身分終點，孔叔／孔悝暫同指須依本段。
- p36 欲誅大臣止，非實際死亡。
- p37 孔丘卒莊2可核年尺度。
- p38 莊出奔、斑師虜非死，立起事件不作斑師必死。
- p39 起奔齊、輒自齊復歸，與p34魯目的地不同事件不覆寫；出公立21卒與亡4／後元分期不簡算。黔攻出子非明示死亡。
- p40悼5卒；p41敬19卒；p42昭6弒，三晉屬不推爵位消滅。

第43–54段核讀，全53段正文及另層索隱皆已讀。
- p43 懷11弒，穨與周穨分人。
- p44 愼42卒，父適祖敬明示不補缺代；p45聲11卒。
- p46鞅入秦遷徙，成侯16貶侯與原追稱成侯不當此前已持侯；p47成29卒。
- p48平8卒；p49嗣5貶君、42卒，濮陽為國土不無據當個人籍貫。
- p50懷31魏囚殺，朝魏與囚留／死亡分開；元為嗣弟非懷子。
- p51元14徙衛野王是集體遷國，個人遷徙須明記推斷；25卒。
- p52角被廢庶人非死，衛絕祀非全部家人死亡；始皇帝稱號授予與秦國主體需核既有明名／未定錨點。
- p53評語死亡回述，不重複新增三位太子；p54索隱另層，不當各事件獨立新證。
