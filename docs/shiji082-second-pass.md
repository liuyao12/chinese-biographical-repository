# 〈田單列傳〉第二輪核讀

全9段固定數位正文已核讀，包含太史公論後法章、君王后與王蠋敘事；未核底本影像。

第三段「燕人士卒」與「所得齊卒」的卒為群體，不是自薦神師的一卒。兩處保留原字元錨點，改為未解群體，撤除匿名神師人物登記的錯誤引用；一卒、卒曰、臣與神師的個人指代仍保留。

齊湣王與淖齒以燕破齊、湣王逃莒被殺及法章嗣立事件接合〈田敬仲完世家〉，兩個重複ID同步引用後撤除，人物6580→6578。本篇淖齒堅守距燕與世家共分齊地各存，不因同指改寫敘事。太史嬓／敫與其女已有跨篇判斷，保留異體。

燕將、群體宗人及疏屬不補姓名或直接父子；王蠋引古、未授成的燕將萬家與未名人物、精確官爵紀年及版本仍待覆核，不宣稱全部身份完成。
