# 魏晉南北朝列傳首批對讀

2026-11-19。這批按三國、兩晉、南朝、北朝分工，從傳首、附傳與傳末的親屬詞尋找本傳，核讀相關段落。下列記錄是數位見證的讀書成果。已收篇章標出段落 ID，其餘提供具體傳名與數位見證。尚未校影。讀書紀錄與現行人物斷言、公開人物頁分開。本批未將待匯入篇目計作已入庫。

## 《三國志》：吳郡陸氏、顧氏與范陽盧氏

- **陸遜 → 陸抗 → 陸機、陸雲**。《三國志》卷五十八〈陸遜〉「次子抗襲爵」，附〈陸抗〉「晏及弟景、玄、機、雲、分領抗兵」。裴注另記「景弟機，字士衡，雲字士龍」。續讀《晉書》卷五十四〈陸機〉「祖遜，吳丞相。父抗，吳大司馬」，〈陸雲〉記「少與兄機齊名」。裴注引文所說的「晉書」保留原題，現存唐修本另作見證。[《三國志》卷五十八](https://zh.wikisource.org/w/index.php?oldid=2131313) · [《晉書》卷五十四](https://zh.wikisource.org/w/index.php?oldid=2605147)
- **顧雍 → 顧裕／穆 → 顧榮**。《三國志》卷五十二〈顧雍〉正文「次子裕有篤疾」，裴注引《吳錄》「裕一名穆，終宜都太守。裕子榮。」《晉書》卷六十八〈顧榮〉「祖雍，吳丞相。父穆，宜都太守。」名字、官職與父子關係相合。裴注同段另有顧徽之子裕（字季則），需各保其身份。[《三國志》卷五十二](https://zh.wikisource.org/w/index.php?oldid=2085149#顧雍) · [《晉書》卷六十八](https://zh.wikisource.org/w/index.php?oldid=2581578#顧榮)
- **盧植 → 盧毓 → 盧欽、盧珽；盧珽 → 盧志**。《三國志》卷二十二〈盧毓〉正文「父植有名於世」（`c-sanguozhi-022-luyu:p001`）與「毓子欽珽」（`c-sanguozhi-022-luyu:p007`）分別記父子。《後漢書》卷六十四〈盧植〉亦稱「子毓知名」（`c-houhanshu-064-luzhi:p008`）。裴注引《續漢書》「植有四子毓最小」（`c-sanguozhi-022-luyu:p002`），引《世語》「欽字子若珽字子笏」（`c-sanguozhi-022-luyu:p008`），同段引虞預《晉書》記「珽及子皓志並至尚書」。唐修《晉書》卷四十四〈盧欽〉「祖植，漢侍中。父毓，魏司空」，下記「欽弟珽，字子笏，衛尉卿。珽子志。」正文與各家古注分存，盧植至盧毓、盧毓至欽與珽已有原生紀錄；盧志之子盧諶留作下一次接續。[《後漢書》卷六十四固定數位見證](https://github.com/kanripo/KR2a0009/blob/6db36b6dcbe843b825354c22e9be9193d0137c04/KR2a0009_094.txt)[《三國志》卷二十二固定參校本](https://github.com/kanripo/KR2a0012/blob/214fcafa79894355909c9d8c2c1533089e7791c6/KR2a0012_022.txt) · [《晉書》卷四十四](https://zh.wikisource.org/w/index.php?oldid=1775345#盧欽)
- **王昶 → 王渾 → 王濟（既有接合覆核）**。《三國志》卷二十七〈王昶〉正文「其子渾字玄冲深字道冲」（`c-sanguozhi-027-wangchang:unit005`），裴注「渾子濟字武子」（`unit018`）。唐修《晉書》卷四十二〈王渾〉「父昶，魏司空」（`c-jinshu-042-taiyuan-wang:line011`）、「次子濟嗣」（`line025`）。兩代都有既存斷言。[《三國志》卷二十七固定參校本](https://github.com/kanripo/KR2a0012/blob/214fcafa79894355909c9d8c2c1533089e7791c6/KR2a0012_027.txt) · [《晉書》卷四十二](https://zh.wikisource.org/w/index.php?oldid=2180524)

## 《晉書》：王導、褚裒、謝玄及其後裔

- **王謐 → 王球（父子）**。《晉書》卷六十五〈王導〉附〈王謐〉「三子：瓘、球、琇」（`c-jinshu-065-wangdao-family:line102`，既有斷言 `a-jinshu065-phase3-011`）。由此查《宋書》卷五十八〈王球〉傳首「父謐，司徒」，傳末另記「十八年，卒，時年四十九」及「無子，從孫奐為後」。末句是宗祧承繼線索，不補生子。宋傳是後續匯入入口。[《晉書》卷六十五](https://zh.wikisource.org/w/index.php?oldid=1756144) · [《宋書》卷五十八](https://zh.wikisource.org/w/index.php?oldid=1996691#王球)
- **褚裒 → 褚歆 → 褚爽 → 褚秀之 → 褚湛之 → 褚淵**。《晉書》卷九十三〈褚裒〉有「子歆，字幼安」（`c-jinshu-093-chupou:line059`），〈褚爽〉有「祖裒，父歆」「爽子秀之、炎之、喻之」（`c-jinshu-093-chushuang:line092`）。續讀《南齊書》卷二十三〈褚淵〉「祖秀之，宋太常。父湛之，驃騎將軍」。《南史》卷二十八明記「湛之字休玄，秀之子也」，下敘「子彥回」。所核《宋書》卷五十二數位正文作「秀之弟湛之字休玄」，數位小標題卻作「秀之子 湛之」。保存正文的「弟」作異文，以《南史》《南齊書》兩條證據支持父子讀法；待核〈褚叔度〉的其他異名。[《晉書》卷九十三](https://zh.wikisource.org/w/index.php?oldid=1548000) · [《南齊書》卷二十三](https://zh.wikisource.org/w/index.php?oldid=1545488#褚淵) · [《南史》卷二十八](https://zh.wikisource.org/w/index.php?oldid=1511857#從子) · [《宋書》卷五十二](https://zh.wikisource.org/w/index.php?oldid=2190655)
- **謝玄 → 謝瑍 → 謝靈運（兩代父子）**。《晉書》卷七十九〈謝玄〉「子瑍嗣，秘書郎，早卒。子靈運嗣」（`c-jinshu-079-xielang-family:exp-xiexuan-p013`）與《宋書》卷六十七〈謝靈運〉「祖𤣥晉車騎將軍父瑍生而不慧為祕書郎蚤亡」（`c-songshu-067-xielingyun:p001`）對讀。兩書已共用人物身份。宋傳並可由「我乃生瑍瑍那得生靈運」確認中間世代。[《晉書》卷七十九](https://zh.wikisource.org/w/index.php?oldid=2645985) · [《宋書》卷六十七](https://github.com/kanripo/KR2a0016/blob/e80c057667e3c8684f11d5088251e10244d5a264/KR2a0016_067.txt)
- **庾亮 → 庾羲 → 庾准 → 庾悅**。《晉書》卷七十三〈庾亮〉「三子彬、羲、龢」（`c-jinshu-073-yuliang:line073`），後敘羲「子准」及「准子悅」（`c-jinshu-073-yuliang:line078`）。《宋書》卷五十二〈庾悅〉列「曾祖亮，晉太尉。祖羲」及「父准」。該處數位校記指祖名「羲」、父名「准」據《晉書》校改，這兩個名字不計作獨立旁證。晉書父子已有紀錄，宋傳待匯入。[《晉書》卷七十三](https://zh.wikisource.org/w/index.php?oldid=2296501) · [《宋書》卷五十二](https://zh.wikisource.org/w/index.php?oldid=2190655)

## 南朝列傳：王弘、王曇首及相關附傳

- **王珣 → 王弘（父子）**。《宋書》卷四十二〈王弘〉明記「父珣，司徒」（`c-songshu-042-wanghong:p001`）。依此回讀《晉書》卷六十五〈王導〉附〈王珣〉「珣字元琳」（`c-jinshu-065-wangdao-family:line078`）。王弘傳是這條父子關係的直接證據，《晉書》附傳是祖先本人的閱讀入口。兩篇正文已收。[《宋書》卷四十二](https://zh.wikisource.org/w/index.php?title=宋書/卷42&oldid=1478172) · [《晉書》卷六十五](https://zh.wikisource.org/w/index.php?oldid=1756144)
- **王曇首 → 王僧虔（父子）**。《宋書》卷六十三〈王曇首〉末記「少子僧虔，昇明末，為尚書令」（`c-songshu-063-wanghua-tanshou:line039`）。續讀《南齊書》卷三十三〈王僧虔〉，傳首原字作「王僧䖍」，明記「父曇首右光禄大夫」（`c-nanqishu-033-wangsengqian:p001`）。兩篇正文已收。另循同段「子僧綽嗣，別有傳」查《宋書》卷七十一，傳首「左光禄大夫曇首子也」（`c-songshu-071-wangsengchuo:p001`）；兩子分別有據。[《宋書》卷六十三](https://zh.wikisource.org/w/index.php?oldid=2118589) · [《南齊書》卷三十三](https://github.com/kanripo/KR2a0017/blob/787dd9a7da495542e8f17c26c96900ce37b2c211/KR2a0017_033.txt) · [《宋書》卷七十一](https://github.com/kanripo/KR2a0016/blob/e80c057667e3c8684f11d5088251e10244d5a264/KR2a0016_071.txt)
- **王弘 → 王僧達（父子，同書追傳）**。《宋書》卷四十二「弘少子僧達，別有傳」（`c-songshu-042-wanghong:line093`），接卷七十五〈王僧達〉傳首「太保弘少子」（`c-songshu-075-wangsengda:line010`）。兩傳已收；本次核對的閱讀器資料未見從卷四十二該句出發的既有互見連結。[《宋書》卷四十二](https://zh.wikisource.org/w/index.php?oldid=1478172) · [《宋書》卷七十五](https://zh.wikisource.org/w/index.php?oldid=1997722)

## 北朝：從《魏書》附傳續讀《周書》

- **崔孝芬 → 崔猷（父子）**。《魏書》卷五十七〈崔挺〉附〈崔孝芬〉先記「有子八人」，列「長子勉」，再記「勉弟宣猷，司徒中郎，走於關西。」《周書》卷三十五〈崔猷〉記「崔猷字宣猷」「父孝芬」，亦明記祖挺。據父祖、字及關西事跡連讀兩傳。[《魏書》卷五十七](https://zh.wikisource.org/w/index.php?oldid=1501656#崔挺) · [《周書》卷三十五](https://zh.wikisource.org/w/index.php?oldid=2432543#崔猷)
- **崔楷 → 崔謙、崔說（父子）**。《魏書》卷五十六〈崔辯〉附〈崔楷〉記「士元弟士謙、士約，並歿關西。」《周書》卷三十五〈崔謙〉記「崔謙字士遜」「父楷」，〈弟說〉記「說本名士約」。崔說的本名有明文。「士謙」與「崔謙」的接合據共同父親、兄弟組合及關西背景，保留各書原稱。[《魏書》卷五十六](https://zh.wikisource.org/w/index.php?oldid=1501654#崔辯) · [《周書》卷三十五](https://zh.wikisource.org/w/index.php?oldid=2432543#崔謙)
- **崔孝暐 → 崔昂（父子）**。《魏書》卷五十七〈崔挺〉附〈孝暐〉「子昂，武定中，尚書左丞、兼度支尚書。」《北齊書》卷三十〈崔昂〉記「祖挺，魏幽州刺史」及「伯父吏部尚書孝芬」。父子明文出自《魏書》，《北齊書》本傳可核祖父、伯父及身份。[《魏書》卷五十七](https://zh.wikisource.org/w/index.php?oldid=1501656#崔挺) · [《北齊書》卷三十](https://zh.wikisource.org/w/index.php?oldid=2432523#崔昂)
- **楊津 → 楊愔（父子）**。《北齊書》卷三十四補列傳〈楊愔〉「父津，魏時累為司空侍中」。《魏書》卷五十八〈楊津〉「順弟津，字羅漢，本名延祚，高祖賜名焉」及「侍中、司空如故」可核楊津身份。此傳只說「津有六子」而未列愔名。另循《北史》卷四十一「謐弟愔，事列於後」至愔傳。補列傳與《北史》的來源關係須另核，先保留兩處文字。[《北齊書》卷三十四](https://zh.wikisource.org/w/index.php?oldid=2432527#楊愔) · [《魏書》卷五十八](https://zh.wikisource.org/w/index.php?oldid=2087998#順弟津) · [《北史》卷四十一](https://zh.wikisource.org/w/index.php?oldid=11123026)

## 接續卷篇
