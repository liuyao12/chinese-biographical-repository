# 〈樊酈滕灌列傳〉跨篇人物與家族

本批依共同事件、爵地、宮廷人物及明示家族接合十二組身份、撤除二十五個重複 ID：陳勝、蕭何、魯元、項梁、鐘離眛、塞王司馬欣、殷王司馬卬、冒頓、白登閼氏、平陽公主、欒布與末段單稱曹的曹參。原文、錨點及各篇差異保留，不將同書跨篇當獨立見證。

平陽公主僅接合曹時配偶與〈外戚世家〉人物，保留曹時、衛青兩段原有婚姻，曹襄生母只據〈曹相國世家〉。本篇夏侯頗配偶及李延年段同號女子保留獨立候選；《漢書》夏侯頗妻另號孫公主的引文與三個候選 ID 存入未決身份案件，人物 JSON 直接匯出，不推三嫁。另以〈外戚世家〉王太后長女及次為三女原句補三女母親與兩條相對年序約束；不把本段長女補成王太后所有女兒的全局第一，不與褚先生另記民間女混同，不據母親推父親。

欒布採已有子賁分支的家族根，原文俞侯、兪侯等不校字。白登閼氏只接〈陳丞相世家〉、本篇及〈匈奴列傳〉白登段，保存其配偶冒頓。〈匈奴列傳〉原已將頭曼所愛閼氏／冒頓後母、送予東胡的女子及白登閼氏分三人，本批維持這一區分。不推三人姓名或子女。

陳平反間宣言、趙高指控仍為來源敘事，不當已證通謀。未核書影；未宣稱全篇身份、生卒、地望、爵期或版本覆核完成。


人物頁的「身份待考」列候選人物、各篇原文及《漢書》引文連結；卡片不展開長篇考證，沒有未決案則省略整欄。
