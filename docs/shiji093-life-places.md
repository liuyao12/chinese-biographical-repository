# 〈韓信盧綰列傳〉生卒與事件地望

依傳世正文新增王喜、韓王信、韓說未名子、盧綰、盧綰妻、陳豨六項死亡記載；穨當出生記載及穨當城出生地、韓王信參合死亡地另存。所有事件有原文、人物標記及篇章來源，地望不補今日位置。

韓王信十一年春暫定公元前196年，天文年為-195；沿用漢興年表紀年對照，與淮陰侯韓信分人。漢初十月歲首，七年冬、十二年冬不可機械換成單一年；歲餘保存相對期間，未推確年。

盧綰妻段本庫正文為高祖竟崩，三家註數位正文為高后竟崩。此次再讀三家註全文及固定修訂版頁尾，確認數位文字差異，但未核書影，正文不改；不據異文替妻補卒年或燕邸死亡地。來源：https://zh.wikisource.org/w/index.php?title=史記三家註/卷093&oldid=2514763 。古注及數位正文不是新增的原文事件。

子代沿用承襲動詞判讀，死亡歸韓說未名子，不新造韓代。王黃段斬與生得的敘述仍待釐清，未加入確年死亡事件。高祖與盧綰同日生仍須日期關係格式，未以排行欄代替。
