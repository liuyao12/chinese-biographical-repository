# 〈淮南衡山列傳〉報齡、姓名與徙王

原文皆七八歲保存為相鄰數詞約數，四名兒子各有報齡來源與共同具名範圍。七、八不是個別確歲或嚴格上下界；不推生年、虛歲或周歲。孝文八年及同次五月授侯已有固定年表依據，報齡紀年保存前172年及原句，並不將此數字當出生年。

緩依《漢書》顏師古名緩、不言姓之釋暫取，正文樓緩與原提及ID保留，不接戰國同字人物。南海王織依同一獻璧燔書事件的《漢書》正文辨爵稱與名，不以王當姓。枚赫依兩部固定數位正文同人同事短引暫取，收到兩處救赫不改，姓名全稱另存而未拆姓、名。各案固定引文、原排版與判讀分列，未核書影。

勃由衡山徙濟北、賜由廬江徙衡山，新增兩項徙王事件並明示終止前王號；保留同人、前號ID與原稱錨點。王濟北保存王字與所王地，不在原文重排成濟北王。景四年月份未載；年表四月己巳屬立太子，故只按十月歲首保存前154至153年的範圍。原年格的四字有單獨來源跨度，原整格不刪。年表另補賜、勃、貞王三個逐人標記，十二是原王年續數，不作新國元年。

長的厲王改記明示追尊，孝文十二年保存前169至168年的範圍；原歌中淮南厲王仍作作者回溯用稱。勃的及薨、賜諡貞王未載確年，不能借此前徙王年補死亡或得諡日期。未記的終期留空，不以死亡自動填滿所有持職終點。

本批保持全部段文、原格、人物ID與提及ID；人物JSON、閱讀器資料及索引須同步重建。全篇仍非完成：城陽王喜的前後徙王鏈、馮敬行御史大夫事句讀、曲城侯姓名與世系異說、其餘匿名者及完整稱號時段仍待續核。
