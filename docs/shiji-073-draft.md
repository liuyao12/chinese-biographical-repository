# 卷七十三〈白起王翦列傳〉草稿

保存固定數位修訂7909285的15段正文，自白起者至太史公論贊。人物導覽、索隱述贊及現代版權告示不混入正文；來源HTML邊界已核。保留龁、筑、阬、沈、甐、于、怚、圽等原字，未見全形括號改讀提示。未核底本、影像或現代研究。

本篇華陽斬首十三萬，〈秦本紀〉十五萬、〈穰侯列傳〉十萬各留來源，不作全域校改。武安君免為士伍、遷陰密與賜劍自殺分事件；反閒、假設功賞三公與真實授予必須區分。王翦子王賁與孫王離依明示，不補王離父親。全15段已核讀，人物待逐段標註，篇級整理中、未完成覆核。

前3段明示姓名首輪保存13個新增候選與35處錨點。白起武安君與馮亭華陽君按明示暫接，穰侯、客卿錯與平陽平原諸君不按記憶補名；東徙陳楚王保持未名，三晉將群體留未定。後12段待標註，下一位置第4段。

第4至5段長平敘事已接續，累計18個新增候選與62處錨點。王龁龁、趙括馬服子與白起武安君按明示暫接，反閒敘事不當事實確認；應侯未補姓名，四尉與二尉群體保持未名。後10段待標註，下一位置第6段。

末10段已接續，全15段首輪累計45個篇內候選與233處錨點。秦昭王與秦始皇敘事分範圍，兩位未名趙王分候選；周召引功不補全名，魏公子與應侯不按記憶補名。李信與王翦將軍受話分辨，王氏蒙氏、子孫、使者及匿名說話者保留未定。親屬、官爵時段及跨篇身分待補核，篇級仍為整理中。

已保存2項明示親屬來源主張：王賁父王翦、王離祖父王翦，不補王離父親。24項官爵／用稱分存，武安君爵在免為士伍處保存明示降等終點；士伍降等另記。左庶長授予保存昭王十三年，未知日期與終點留未定；蘇代說辭的三公與秦王王是假設，未當實授。

與〈秦本紀〉共載事件暫接白起、公孫喜、任鄙、芒卯、王龁、司馬梗及王陵；與〈秦始皇本紀〉共載攻趙、荊軻刺秦及攻燕暫接王翦、荊軻與燕太子丹，共10項。王龁／王齕異體、華陽紀年與斬首數、白起新城左庶長／左更及破得丹／得首敘事差異各存，不由同指消除。同書不作獨立見證，不補未核年代或作戰者。
