# 〈張丞相列傳〉官稱與跨篇身份續核

本批依共同事件、任官及明確姓名接合十六組身份，更新二十四個舊候選的全部正式引用；不以同名本身作合併依據。包括晁錯／鼂錯、賈誼、申屠嘉、陶青、劉舍、薛澤、莊青翟、于定國、魏相、邴吉、黃霸、韋玄成，以及〈佞幸列傳〉四位漢帝。韋賢與韋玄成仍為父子兩人；鼂錯未名父親仍獨立保存。

補六處裸稱「丞相」指申屠嘉的逐人標記；「丞相府」不作人物。竇廣國的丞相只是文帝擬任而未實行，另存 `title_proposals`，不產生實際官職或任期。〈將相年表〉申屠嘉之「嘉」及鼂錯之「錯」各補版本固定、附原文的身份證據。

〈袁盎鼂錯列傳〉另存申屠嘉「發病死」、鼂錯父「飲藥死」及鼂錯「斬東市」三項來源死亡記載。申屠嘉與本篇「歐血而死」並存；不推定醫學死因。欲誅、請誅、以誅錯為名均不另作已發生死亡。父死後十餘日的事件次序不補為確年；本批新增三項事件暫不強制換算日期。

〈平津侯主父列傳〉篇末班固附記仍維持獨立文字層，後世官員不混成史遷正文。張廷尉尚未核定，保留來源局部候選與未解說明，不由官姓推定張釋之或張湯。
