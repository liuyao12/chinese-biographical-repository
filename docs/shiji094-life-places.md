# 〈田儋列傳〉死亡與地望

錄入十二項死亡記載，包含狄令、田儋、項梁、田市、田安、田榮、酈食其、龍且、田廣、田既、田吸、田橫。田廣是田橫聞死的消息，保留轉述層次；田儋欲殺奴不當已死亡，漢滅項籍也不僅據滅字建立本篇死亡。二客與五百人不拆造具名或可分辨個人。

本傳未明死亡日期的欄位仍為空。田儋、田市、田安、田榮依月表同人同事暫對照公元前208、206、206、205年，分列原事件、年首、曆月欄及數位年欄；只換算年，不換古曆月日。二十四、六、八等在位月序不作曆月，十月歲首按實際月欄核對。原文與不同來源次序不改寫，未核書影。

新增五處死亡地及田橫島居，與既有田儋狄人、臨濟下死亡地分存。田橫自剄於尸鄉廄置，不以死亡地推葬地；海中居島不補為今日島名。沒有出生年或年齡便不補，死亡不自動填滿官爵終期。
