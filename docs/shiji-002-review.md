# 《史記》卷二首輪標註紀錄

本輪錄入〈夏本紀〉35 段正文，保留維基文庫固定版本 [7903612](https://zh.wikisource.org/w/index.php?title=史記/卷002&oldid=7903612) 的段落及文字；2026-10-09 重新讀取該版本的 API 正文，按明記規則移除註號及現代章節標題，轉換「内」為「內」，逐段比較一致。保留啓、荆、惪、辠等來源字形。未核讀影像，不稱影像校勘或可靠定本。

## 記錄與判斷

- 198 個連結人物的提及，37 個未定、氏族或群體錨點。
- 新增 20 個永久人物 ID，與卷一合計 77 個。另保留草稿已分配的號碼，不重用空號。
- 17 項跨卷暫定身份判斷，每項列兩卷的精確原文；4 項同篇異稱判斷。
- 26 項親屬來源主張，區分父母、配偶、兄弟、祖父、曾祖父與祖先。不是預先接好的權威世系。

「禹／文命」「桀／履癸」有原文明示對應；「塗山」依娶妻、生啓及啓母敘事暫連到「塗山氏之女」，不補「女嬌」等本文沒有的姓名。「胤」保存為出征者稱呼，不把書篇「胤征」中的字當作人物提及。「羲、和」不按字面併到堯時的羲仲、羲叔、和仲、和叔。「豢龍氏」不從熟知故事補出董父。

## 尚待核查

上古人物及譜系標為傳說敘事。首輪明示名字標註不等於全部指代已覆核；代詞、匿名群體成員、若干職官、氏族與單個人的區分，以及版本與專門研究仍待處理。作者署稱「太史公」沿用卷一的未定狀態，待另附自述與書目證據。

卷二的親屬主張是本文所載；不憑其他傳說修補這份原文。不從任一王的繼位推出父子，不由卒日推定所有稱號終止。稱號時段草稿尚未發布。本輪未新增現代學者意見，不聲稱核查了最新研究。

XML 由 JSON 產生，可逐段還原原文。程式檢查只證明引用、字元錨點與格式一致，不證明上古記載為史實。資料尚未投影至人文閱讀器目錄；本輪公開成果可在庫內 JSON、XML 與證據檔案查閱。
