# 〈屈原賈生列傳〉第二輪核讀

累計已核讀全33段固定數位正文，未核底本影像；本批先處理前八段楚秦事件中的屈原、楚懷王、秦惠王、張儀、靳尚、鄭袖、頃襄王七項身份。人物6547→6540，所有現行引用更新並驗證後撤除舊ID。

- 屈原名平、楚同姓與左徒各按原文，楚同姓不作王族直接父系。
- 未名上官大夫不按姓名推為靳尚；屈原被疏與靳尚釋儀各存事件。
- 040勸懷王勿赴秦者昭雎，084屈平，兩篇不調和。
- 商於六百里與六里為欺約原語；秦惠與後段秦昭分開。
- 屈丐與屈匄、虜與殺等異說另待接合及版本核對。
- 懷王稚子子蘭、長子頃襄及其弟子蘭按來源存親屬，不從繼位推父子；子蘭既有ID保留。
- 漁父匿名，寧赴常流是意願，死亡實述在懷石投汨羅；孟夏詩句不作死亡月份。
- 賈生年二十餘與十八為不同敘事時點，不能推唯一出生年。
- 梁懷王不同梁孝王；文末孝文崩孝武立原句有君序疑義，仍保留，不推父子或直接繼位。
- 賈誼孫二人群體與賈嘉提及仍須核，不補缺代名字或強定賈嘉為二人之一。

此批身份接合不代表全部人物、日期、稱號及版本完成。
