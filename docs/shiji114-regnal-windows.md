# 東越篇的原紀年、用稱與授爵

正文「漢五年」藉同段高帝與原年表高皇帝的兩個逐人錨點對應同人，保存本次國號紀年與表內帝號，不將漢一字登記為全書別名。表內高皇帝元年是回溯紀年欄名，不等於實際稱帝或授爵始年。

未明月份的五件授王、授將及三件死亡、十二處文獻用稱，依固定年表的原年字、年號起點與數位年份分列對照。太初以前以十月歲首，保留相鄰公元年範圍。元封元年冬的徇北將軍死亡另保冬字與冬季範圍；元鼎六年秋的授吞漢將軍、用稱及張成／齒死亡，保秋字與公元前111年的年精度。

定年的是各自來源所言的事件或用稱。太尉田蚡、中大夫莊助、大行王恢、大農韓安國等用稱有年，不因此填任官起點；故山州侯、故越衍侯、故海常侯保回述用法。田蚡稱太尉與他篇免職年月的差異仍在，餘善刻武帝璽、漢廷遣將等未明時點不套後來入境冬季。

轅終古授御兒侯的正文未明精確授日，不再把入境段首元封元年當確定公元110年授爵。另以原表蘌兒列的封國、功臣事由、莊侯轅終古元年三格，保存分欄拼成的元封元年閏月癸卯。閏幾月未明，公元前111至110年為暫定範圍；莊侯是表內追稱，不當授爵時已有諡。來源字形與日期分存，死亡不自動填所有稱號終點。

原文、固定版本、舊人物與提及ID及位置均保留。太初元年終古死的改曆過渡、更多原表生卒及地望仍待續核；本批不宣稱全篇紀年或全部稱號史完成。
