# 〈刺客列傳〉第二輪核讀

全38段固定數位正文2388562再次核讀，未核原書影像。第一批以柯盟劫桓公及管仲勸守約，接合魯莊公、齊桓公與管仲；以專諸魚炙藏匕首刺王僚、光立為闔閭及封專諸子，接合專諸、未名子、伍子胥、公子光及相關吳王兄弟父子，共12項。逐項保存雙篇段落、人物錨點與完整引文。呉／吳、闔閭／闔廬、夷眛／餘眛及各篇紀年原語不改，具體人物同指不表示遠祖譜系或全部敘事可靠。

第18段「妾已嫁夫」的未名丈夫原錨點錯落在逗號，保留已發提及ID，將起止位置183–184修正為182–183，表面詞改為「夫」，反向登記與身份證據同步。這是標記錯位訂正，原正文未改；未名丈夫不補姓名。全112篇檢查僅此一處人物錨點完全由標點組成。

第35段「今王」依「代王嘉乃遺燕王喜書曰」解作收信人燕王喜，不以外敘事秦王覆蓋信內稱謂。其他燕喜候選未在本批自動合併。曹沫不接曹劌；專諸話中「母老子弱」不建立專諸的母子；樊於期不憑時序接桓齮，徐夫人不推性別。生卒、官爵、親屬及後半篇候選仍待續核。

本批另以三家分智伯地、聶政刺俠累、荊軻刺秦後攻燕與燕王喜走遼東等事件，接合9項身份，共撤除21個重複ID。045列侯三年與086韓哀侯原敘事不同，不由同人辨識調和君主或年份，也不因此接合086未名韓君。

17項死亡原語及8項地望另存可解析陳述；荊軻衞人與其先齊人分開，高漸離匿宋子不當籍貫。四月丙子及楚平王九年原字保留，西元換算另待逐項核年；無明日期者不逆算。僚與政立王記繼位、光自立與政立皇帝號記自立，稱號未明終點不由死亡補造。

第二批紀年：僚與專諸卒年暫515、俠累與聶政卒年暫397、荊軻卒年227、丹斬年226；僚立526、光自立及封專諸子515、政立王246、立皇帝號221。每項年尺度數字附原句及固定年表格；俠累、聶政保留哀侯與列侯背景異說，按明示年表及韓世家暫採397，不改本篇文字。刺秦及斬丹分年，專諸子授卿不推同日；未核書影或曆表，楚平王九年及秦舞陽十三歲不逆算。

第27段管、晏分成兩個人級標記，原提及ID保留指管，新提及指晏，逗號保持正文。按名臣引古暫接管仲與晏平仲嬰，不把引語人物當同時在場；段落原字不改。

第三批身份：李信追丹至衍水、秦虜韓王安、秦虜趙王遷後進兵燕界，以及嘉在遷被虜後立代王等特定事件，接合五項候選。嘉與遷按043明記悼襄王父子回到同一局部家族；王安按045桓惠王子安接回韓末王父系，不以繼位補父子。073卒破得丹、086燕王斬丹、潁州／潁川原語各存，不調和直接加害者或郡名。其他趙王遷引古、衞元君、韓未名君、樊於期與桓齮等候選不全域合併。
