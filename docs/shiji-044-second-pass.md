# 魏世家第二輪核讀

全70段已再次核讀，以下保存來源判讀及本批取捨。畢公高後裔與絶封庶人為來源族系，苗裔不補直系闕代。畢萬大夫及封魏、魏武子襲封列大夫與治魏、悼子徙治霍、魏絳徙治安邑各分稱號與地點。魏絳僇辱楊干、晉悼公欲誅絳而止，不作死亡；絳卒與昭子諡分記。魏嬴、獻子、侈等明示生子可存來源，孫關係不虛造父。祁羊舌氏誅與知伯滅各保留群體及上下文，不以族滅推所有個人死。韓宣子老不是明示退休日。

文侯元年與秦靈公元年等同步為來源紀年主張，換算另需依據。子擊守中山、趙倉唐傅之及西門豹任鄴有授事文字；田子方泛論去楚越不作本人實際遷徙。子擊生罃25年有明示日期。李克談卜相、魏成子相及翟璜進士保留引語層次，成璜候選不當兩人都授相；所進西河守匿名不補吳起。來源無與无、朝謌等異體先保留，不未經紀錄改字。

第22段文侯卒38年及子擊立，第28段武侯卒16年及罃立有明文。公子朔奔魏與趙篇公子朝用名分存，不能按相似事件直接替字或全庫合ID。滅晉後不推具名晉君死亡。惠王元年回述武侯卒及爭太子，不當惠王元年另一次父卒；韓趙計畫殺魏君未實行，惠王身不死明示。公中緩與罃爭太子不等於兩人都正式受任。公孫頎宋趙韓行程有敘事，但是否居處須分辨。公孫痤被虜非死亡，秦獻公卒與孝公立分記。桂陵魏敗不推魏將死；地名與交戰所在地不全當人物籍貫。

第35–51段已再次核讀：趙成侯、齊威王、龐涓、秦孝公、惠王、襄王、田需、張儀及哀王死各有來源。太子申被虜不作死，龐涓被殺與他篇自殺分來源；太子申上將軍與公子赫太子授任分存，不以被虜直接推廢。商君亡秦歸魏未獲入，不作已居魏或本段死亡。惠王原文36年卒及襄王元年追尊與其他紀年異說需分存，不未經證據改原文。龍賈軍敗不推龍賈死。成陵君免及終身不見有明示退職，但不臆造未載官名。太子果相魏有授職結果，先前謀相張儀犀首薛公不是各人實際受任。

第52–70段已再次核讀，全70段完成第二輪閱讀。秦昭王西帝、齊湣王東帝月餘復王有共同授退號事件，先核具名錨點；不能把月餘當精確日期。宋王死我温明示死地，湣王出亡與楚王徙陳不作死。芒卯敗走及蒙驁敗走非死亡，秦太子質魏死有明文，不以熟知姓名補匿名身份。中旗馮琴述知伯身死國亡為引語回述，不能套安釐王當年。唐雎魏人與年90餘保留來源，不由年齡倒推確切出生年。

范痤被捕圍而未殺、後獲釋，免相是過去事件；不補死亡或免職日期。無忌書中秦太后以憂死與兩弟奪國是引語來源，親屬未名不直接補熟知姓名。晉鄙奪兵不是本篇明示殺；無忌留趙與歸魏分遷徙。太子增質秦與秦欲囚後止分實行與未行。安釐王、無忌、景湣王卒及增、假立有明文；荊軻刺秦王被覺非本段明示死。王假被虜、魏滅與太史公引墟中人降王各保留層次，不推王假死。正文及第70段史公評論保留，無另層述贊。世系、版本、跨篇身份及其餘數字紀年續核。

已對原文與既有錨點核定並保存24項死亡及7項出生記錄，20項附原曆表述。知伯及秦太后死亡保留引語回述層次，不借安釐王當年。

16項地點記錄已逐項核對原文及既有人物錨點：治魏、霍、安邑，公孫頎入趙與韓，徐子外黃，三賢至梁，張儀歸秦及與魏章歸魏，宋王死温，唐雎魏人，無忌留趙及歸魏。商君被魏拒入不作已居，惠王徙梁需另建跨段人物證據，暫不借他人錨點。

52筆既有稱號已核，補入太子果相魏九年授任起點及增34年立君的太子終點。范痤免相、秦齊歸帝月餘的既有終點保留。成陵君免可能指免職而非撤爵，未直接終止其爵號；張儀歸秦也不自動作相魏免職。其餘稱號起訖仍待續核。

已對讀卷十五數位年欄，保存秦孝公、龐涓、張儀三項死亡年尺度換算，附原文與年表參考及未核影像狀態；數字年為編者換算，原文不改。其餘死亡的數字紀年仍待續核。

本批次31項生死、16項地點、兩項稱號起訖及三項死亡年尺度換算已納入正式工作分支，保留70段原文、人物錨點、52筆稱號ID及原始證據。7283份人物JSON已匯出；九組資料檢查及112篇XML同步通過，JavaScript155項測試及語法檢查通過（353.291541毫秒），完整Python289項測試通過（496.587秒）。尚未接入公開閱讀器。
