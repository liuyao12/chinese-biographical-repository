# 游俠列傳初標

固定數位修訂367994（2012-12-31）全文17段，末段索隱述贊另分層。去除Textquality、header2及wikipedia導覽模板，保留原字，未核影像。

62名來源候選、152處人物提及與25處未解錨點，全篇姓名首輪已存。郭解的父、母、姊、姊子與兄子分開；楊季主與未名縣掾之子各有獨立錨點。索隱脫季依正文朱家救季布暫接，附贊不是獨立見證。瞷氏、諸白、姚氏與諸杜等群體未按數字補造人物；王公保留原稱，王孫公子不直接推出王室血親。

8條親屬、14條死亡、25條地點與6條官爵均附原文。父事朱家為禮遇，不記父子；郭解稱姊子吾兒不記親生子。兩名未發布候選按明示父子接家族根，分支不作排行。新增grandmother型別，外孫記母系早兩代，原句未名母親不從別段補寫，不接父系根；兩項回歸測試拒絕誤改父系或世代差。

地點區分傳首地望、居住、遷徙與死亡地，不推現代轄區或出生地。南道、東道僅保留相對地望。官職用稱不作授任日期，孝文時與四百餘年不擅換算單一年，誅族不依此補造每個家屬死亡。

朱家、季布與公孫弘三組跨篇暫同指保存雙篇證據與原始ID。同書敘事不作獨立見證；主父偃與郭解是不同刑獄事件。
