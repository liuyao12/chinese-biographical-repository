# 《晉書》齊王冏、長沙王乂來源首輪

依固定數位見證 WS2650517，納入齊武閔王冏十八段（含鄭方附敘）及長沙厲王乂九段（含子碩）。正文共4935字，383處逐人或未決標記，涉及78位人物，其中37位沿既有身份、41位新來源身份。本輪不是卷五十九全卷完成；親屬、官爵、生卒與地望尚待結構化。

原始數位文字、逐碼投影及獨立數位附註均保留。未核書影，不以數位轉錄覆核冒充圖像校勘。正文「宗子柔之」不改成「宗孫」，也不據此先行決定柔之父祖。

齊王冏與長沙王乂維持不同身份。《王衍傳》「齊王乂」的具體指涉依同一政治事件與完整平行傳記判為冏，正文原字保留，並非把乂加入冏的姓名別名。

孫惠跨篇同指以另存的固定 WS2595541 孫惠完整本傳補強：首段「五難、四不可」之諫對應冏傳；末段助甘卓討周馥及敗走結局對應既錄周馥傳第二十三段。中間秦秘之致越書及仕歷未省略。官稱「前賊曹屬／東曹屬」、「安豐太守／內史」及地名「壽春／壽陽」各保原詞，不補造遷官或校字。具體來源、引文與差異見 `source-evidence/jin059-jiong-yi-source/sunhui071-bridge.json`。

何勖等部分跨篇同指仍屬有時地支持的暫定判讀，不能把官職相容當成已證遷官鏈。未名新野王不補歆；臧劄、蕭霍等未決；楚王瑋的另一來源候選未在此來源批撤號。所有代理判讀均非人工史料覆核。

根目錄原生驗證及三項固定原文／跨篇身份測試通過；完整匯出、全套測試與發布另行驗收。本文件不宣稱本批已公開。
