# 《史記》十表的人物標註工作

使用者要求全部十表在原閱讀器內連續呈現，人物標記只落在每一次人名的字元區段，連到人物卡片與跨篇人物頁；整格出處檢視另留。不得按整格文字推人，亦不得按同名全域合併。西元年只作編輯增補的第零列或欄。

現有第十四、十五卷已結構匯入，第十五卷有人物標註；其他表尚未匯入或逐人覆核。新工作分支從已發布閱讀器整合接續，不取代現有來源資料。

其餘八表完整頁面已取得至研究暫存目錄，未提交原始HTML。版本：十三2606991、十六2607007、十七2607010、十八9484995、十九6359260、二十2607036、二十一2607037、二十二2607038。匯入時須再次核對固定版本與指紋。

第十三卷有三組世系表，不可補未知西元年。第十六卷兩組月表的欄數不同；十九卷四組侯表、二十卷五組表／續補均有不同欄題。原分組須保存，不能把續補當同一列寬直接拼接。十七、十八、二十一、二十二卷也須逐表保存各列、欄及空格；爵號、職稱、人物姓名與世代承襲分別判讀。

先擴充不同表形的連續閱讀及來源驗證，再按原文逐處標記人物、補來源局部未定身份及卡片。完成後執行整體資料／瀏覽器測試並發布至原人文網址；未達成所有十表前不宣稱完成。

進度：十表結構已匯入，共1596表列；多組異欄題分開呈現，原文第一欄不一律當西元欄。真實瀏覽器已逐一載入十三至二十二卷並切換橫向，原文格數保持，無JavaScript錯誤。來源驗證與新增結構／行內人物連結測試通過。人物標註尚待逐表核讀，未發布本批。

首輪補標：十表各有人名區段與可讀卡片，共2268處標記。侯表按本列的封侯姓名建立來源局部候選，已知跨篇人物保留既有ID；不同列的同名者不合併。短名只在本列「侯」所引的省稱中連結，未補姓。每個候選有原格、固定版本與原文引句。這是首輪標記，仍有省稱、異文、世襲稱號及跨篇同指待逐處核讀；不可描述成所有人物均已確認。

驗收：十篇表 × 橫直兩方向 × 桌面1400px／手機390px，共40組真實瀏覽器檢查，確認名字開卡、卡片未開整格對話框、人物頁回到各自表篇，頁面無溢出、無JavaScript錯誤。新增同名異人回歸涵蓋兩位太丁、韓王信／淮陰韓信及不同封國劉成。
