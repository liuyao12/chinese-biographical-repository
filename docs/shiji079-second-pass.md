# 〈范睢蔡澤列傳〉第二輪核讀

全35段正文已按現有固定見證重新核讀；本批依第34段蔡澤在秦的事奉序列及燕太子丹質秦事件，與〈秦本紀〉、〈秦始皇本紀〉、〈刺客列傳〉逐項比對。孝文王、莊襄王、始皇帝、燕太子丹接合至既有現行人物 ID，判讀仍為 `contextual_provisional`，保留各篇引文、提及錨點及理由。

不是按同名自動合併；秦君的承接關係、國別、蔡澤所事朝廷與太子丹質秦事件共同限定範圍。四個舊登記及 JSON 於引用與派生匯出同步後撤除，不另留永久別名入口。原文字句與提及 ID 不變。

「卒事始皇帝」指最後事奉，不當死亡事件；「三年而燕使太子丹入質於秦」仍為來源相對時間，不單憑該句補確切西元年份。〈刺客列傳〉的亡歸另存其來源，不把兩篇壓成同一引句。

韓子及其餘引古人物尚待具體判讀。平原君親屬、止／足改讀與篇間紀年疑點保留；本批不宣稱全篇身份消歧、稱號時段或版本影像校勘已完成。

第32段白公另按四子列舉的次序與杜郵賜劍死亡事件暫接白起。《集解》徐廣在白公條下釋為白起，另存短引文及[數位轉錄來源](https://www.chineseclassic.com/content/919)。原字白公及提及錨點保留，未核底本影像；楚白公勝並未接合。引用及派生資料同步後撤除本段原候選ID。

第15段文子兩處與第17段田文一處，按〈孟嘗君列傳〉卷首明示名文姓田氏，以及《索隱》文子條下「謂田文，即孟嘗君也」的釋名，暫接孟嘗君。注家意見、短引文及數位轉錄連結另存於同指判讀；齊湣王伐楚等敘事時序尚未調和。別篇田文子須無等同稱者分開。

人物卡片與人物頁依本傳卷首的明示姓、名呈現「孟嘗君 田文」。原來源中的薛文稱呼仍保留，不以薛地名替代本條姓氏證據；頂部稱號僅作辨認，不斷言全部敘事時點已受封。

本篇卒事另錄八項來源主張：楚懷王幽死於秦、主父餓死、魏齊自剄、王稽坐法誅，以及蔡澤說辭中的商君車裂、白起杜郵賜劍、吳起枝解、大夫種被殺。引古說辭仍是本篇主張，不表示已完成各本傳互證。楚懷王與主父的本篇候選已依〈楚世家〉、〈趙世家〉同一死亡事件逐項接合，遷移判讀與來源錨點另存，不因同名默改人物 ID。段首秦昭王三十六年不作楚懷王卒年；百日與他篇三月餘分存。

范睢、鄭安平的魏籍與蔡澤的燕籍按原詞記錄；蔡澤居秦十餘年保留約數，不改為精確任期。杜郵與秦分別記本篇明示的白起、楚懷王卒地，不從王稽河東守推出卒於河東，也不把范睢先人丘墓當作范睢葬地。無現代地理比定。

應侯授爵起年按本篇秦昭王四十一年及〈六國年表〉秦欄、西元對照暫換前266年；王稽被誅按同表王稽棄市事件暫換前255年，而非自行加減後二歲。原紀年、短引句、固定見證 URL 與表格儲存格 ID 分存；數位西元欄是編輯對照，不是古代正文。其餘卒年、出生年與未知官爵終點仍不補造。

楚懷王與趙主父的本篇候選引用更新後撤除，人物6652→6650。楚懷王卒年依頃襄王三年、年表平行事件暫換前296年；主父依年表趙欄圍殺主父事件暫換前295年，另記本篇沙丘卒地。數位西元對照不當原文，也不調和百日與三月餘為精確曆日。

第17段射王股、擢王筋按《索隱》分釋崔杼射莊公之股、淖齒擢湣王之筋，並對讀〈齊太公世家〉射中公股遂弒與〈田敬仲完世家〉淖齒遂殺湣王，分接兩君，不接秦昭王、不把兩個王稱接同人。正文兩處單字王及錨點保持；注家數位轉錄連結與未核影像狀態分存。本篇崔杼、淖齒候選亦按同一事件接合，引用同步後撤除，人物6650→6648。

第32段商君、吳起、大夫種，按其所事秦孝公、楚悼王、越王句踐及變法、戰功、刑殺事件，與〈商君列傳〉、〈孫子吳起列傳〉、〈越王句踐世家〉逐項接合；三君稱名亦與本紀、世家接合。七個來源候選引用更新後撤除，人物6648→6641。商君本傳先殺後車裂、本篇遂以車裂；吳起本傳射刺、本篇卒枝解；大夫種本傳賜劍自殺、本篇句踐負而殺之，均按篇分存，不因人物同指確證或調和死亡手段。
