# 〈田儋列傳〉開篇人物

依陳王使周市略魏至狄、魏王咎臨濟被圍及項梁東阿救援接合陳涉、周市、魏咎與項梁。秦末楚懷王指項梁所立孫心，不混入秦不反的祖先楚懷王。周市及魏咎同時接合陳涉、魏豹兩篇已連在一起的候選，更新全部引用後撤除八個舊 ID。

田假王、田角相、田間將的三人群組，接續田假走楚、田角走趙、角弟田閒求救趙及田榮請殺三人的敘事，首選田間與田閒同人；間／閒原字各存，未核書影，不能當作古字校勘定論。

拒殺田假語在本篇歸楚懷王、卷七歸項梁；魏咎與魏豹的兄／從弟兩說仍分存，不因同指強定親等或補共同祖先。同書不作獨立見證，其他人物、年代與地望仍待覆核。
