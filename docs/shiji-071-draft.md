# 卷七十一〈樗里子甘茂列傳〉草稿

保存固定數位修訂2621152的20段正文，自樗里子者至太史公論贊。頁首人物導覽、索隱述贊及現代版權告示不混入正文；固定HTML與取得時版本一致，只去外緣空白。樗里／樗裏、于、遯、茍等原字保留。未核底本、影像或現代研究。

正文已核讀，全部人物標註待逐段建立，篇與進度均為整理中。曾參同姓名殺人者須與孝子分存；鬼谷是地形／拘置語境地名，不接鬼谷先生。甘羅為甘茂孫，不補父親。秦迎甘茂而不往與齊授上卿須分辨授官與實任；擬相、未受及請封不當實行。下一位置為第1段。

前6段已完成明示姓名首輪，新增18個候選與83處錨點。樗里子、疾、智囊與嚴君依明示相接；樗裏只取末句人物比擬，不取陰鄉地名。韓女、蒲守、衛君分存未名；異母不補惠王母，預言天子不補漢代皇帝。後14段待標註，下一位置為第7段。

第7至8段甘茂師承、入秦與左右丞相敘事已接續，累計21個新增候選及99處錨點。史舉先生、蜀侯煇、相壯依明示另存，未按同名跨篇合併。後12段待標註，下一位置為第9段，須分辨曾參同名者與誣傳引語。

第9段已接續，累計31個新增候選與164處錨點。曾參同姓名殺人者另存候選，告母引語的曾參是孝子受指控，不將指控當殺人事實；曾參母與告母者分辨，告母者各次身份仍未解。魏文侯、樂羊與秦武王外層敘事分開，先王按張儀事前秦王暫指秦惠王。下一位置為第10段。

第10至12段已接續，累計36個新增候選與257處錨點。宣太后王母與楚女依本文相接，向壽外族不補精確世次。公仲侈短稱公仲與公叔分辨，小令尹另存未名，向壽公稱及秦昭王王稱只取蘇代遊說範圍。後8段待標註，下一位置為第13段。

第13至14段已接續，累計41個新增候選及318處錨點。貧富女故事分存，甘茂妻子與之家保留群體未解；鬼谷保持地名。秦王齊王按蘇代轉述受話範圍分辨，范蜎楚王問答的王與秦王分開。章義之難保留事件未解，不按記憶拆人物。後6段待標註，下一位置為第15段。

末6段已接續，全20段明示姓名首輪累計54個新增候選與405處錨點。呂不韋文信侯與蔡澤剛成君依明示相接，張唐張卿按局部短稱；武安君與應侯暫不補姓名。趙襄王保留原字，不按記憶改成悼襄王，始皇屬本篇追稱，項橐為孔子師的傳說另標。人物首輪已存，仍待來源親屬、官爵時段與跨篇身分證據，篇級進度繼續整理中。

已保存6項來源親屬陳述：樗里子與惠王兄弟及母韓女、昭王與武王兄弟及母宣太后、甘羅祖父甘茂、曾參母。異母不補同母，兄弟不補父親，祖孫不補闕代；燕王使太子未單據此建立父子關係。

已保存21項官爵／用稱，右更起點保留秦惠王八年原紀年；左右丞相、嚴君、甘羅上卿均有明示授予。甘茂齊上卿起點只取齊王即位之而處之，秦以相印迎之而不往不作實任秦相。智囊為用稱，亡去與卒不自動終止全部官爵，未知日期與終點不補造。

與秦本紀逐段保存4項跨ID暫同指：樗里子／摢裏疾、甘茂、秦武王與魏章，分別以左右丞相、通三川伐宜陽及東出魏事件為據。原ID及異體不改，同書篇章不是獨立見證；共同事件不確證所有年代與任職。嚴君疾、蜀侯煇反亂年代及相壯等尚需進一步身分與版本覆核。
