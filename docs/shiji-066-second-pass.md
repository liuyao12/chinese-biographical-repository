# 《伍子胥列傳》第二輪覆核

補十九項明示死亡，伍員自剄及後文回述合存一事件。鄖公弟懷父死亡保留匿名ID與引語範圍，白公自殺保留敘事承接限制。恐平王卒、未執行殺建、句踐不死及群體敗走不補死亡。浮尸江中不當安葬，樹墓遺言不補已葬。

十四項地址分存伍員楚籍貫、建與伍員及勝遷移、申包胥至秦、夫概奔楚、白公居鄢及死山中等明示敘事。不推現代位置或所有同段人物到訪。

悼公／陽生未決身份引用本篇第二十段、齊太公世家第七十四段及田敬仲完世家第十段，保留四個既有ID。本篇殺悼公後立陽生與兩世家陽生是為悼公不一致，不校字、不直接合人。

闔廬死亡對讀吳世家十九年夏、年表吳欄十九伐越傷指以死；數位496年行暫換公元前496年、天文年-495。年欄為數位編輯參考，影像未核，精度僅年；不以列傳後五年作王五年，不補月日。
