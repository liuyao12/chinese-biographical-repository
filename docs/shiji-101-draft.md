# 卷一〇一〈袁盎鼂錯列傳〉整理範圍

固定版本368092全22段正文與1段索隱已核讀，保留古字及校勘符號，未核底本影像。人物與若干匿名者為首輪代理標註；袁盎兄噲不當樊噲，兄子種不指派噲為父，君弟去不作兄弟，太子不推長子。申商、賁育、黃老等合稱未補人物。

本輪新增46筆人物候選，全庫5632筆；本篇311處人物或未定錨點、9項親屬陳述、49項稱號記錄、9項地點陳述及8項跨篇同指判讀。五組明示父子採同家族ID；兄子種的具名父親仍未知。

集解引徐廣「先即先生」，索隱亦釋為張恢先生，故姓名標張恢，正文的先另記尊稱。註文參考網址及判讀存於姓名決定與稱號記錄；未核底本影像。同師劉禮與元王子禮可能同指，另存未決候選，不僅依同名合併。

四筆授官起點與鼂錯東市死亡事件保存公元前154年的編輯換算、原句、景帝紀跨篇證據及許名瑲〈漢初月朔考索〉參考。未知起訖不補造，建元中不強指定單一年份。

跨篇核對同時修正卷十p023的m023-0149：立其子三人為淮南王中的淮南王指兒子，原先誤連父親長，現保留提及ID並改為未定指代；原文及文本指紋不變。全部版本、匿名者、官稱時段及身份複核仍未完成。
