# 卷六十六〈伍子胥列傳〉人物首輪

固定數位版本為維基文庫修訂 2621138。全24段正文已核讀並保存，425處人物或未解錨點，新增53個人物候選及53項篇內身份判讀；全庫3858個候選。JSON 為權威文字與位置資料，XML 同步產生。

公子光與吳王闔廬、軫與楚昭王、勝與白公按本文明示暫接；吳王僚、闔廬與夫差的王稱按敘事轉換分辨。王子綦佯充昭王的王稱歸於王子綦，不當作實際授王號。前段王子綦與後段司馬子綦暫分候選，尚未判定同人或異人。

第20段「齊鮑氏殺其君悼公而立陽生」照錄，悼公與陽生暫分候選，待核版本及跨篇證據。鮑氏群體不直接等同鮑牧。伯州犁之孫伯嚭不得補成父子；未名父子保存未名身份，不以熟知姓名補造。

已保存14項來源親屬陳述、27項稱號記錄及5項跨篇同指判讀。其餘親屬陳述、稱號有效時段、跨篇身份、代詞與匿名群體仍待補核。尚未核讀可靠底本、影像或現代研究；未完成全篇覆核，全篇覆核仍未完成；人物首輪之後接續卷六十七。

本批13項檢查通過，含165項Python測試及155項JavaScript測試；引用與XML同步驗證通過。
