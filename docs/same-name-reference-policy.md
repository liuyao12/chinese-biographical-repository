# 同姓名錄的使用

《古今同姓名錄》及後來的同姓名錄、補錄，可供逐篇辨識人物時查找同名候選與原始出處。它們的個別判斷須與編纂年代、版本及所據材料一同記錄，不因收入此類書即視為身份已確定。

《古今同姓名錄》四庫提要記梁元帝原撰、唐陸善經續增、元葉森增補，並說明現存本由《永樂大典》輯出。不能將現存本所有條目一概標成梁代證言。余寅《同姓名錄》、周應賓補錄與王廷燦相關續補，另按實際著作及版本登記；「續編」不是足以唯一識別著作的書名。

參考：[《古今同姓名錄》提要](https://ctext.org/wiki.pl?chapter=5173380&if=gb)、[《同姓名錄》提要](https://ctext.org/wiki.pl?if=gb&res=913404)。這裡核閱的是數位文字，未宣稱親見刻本圖像；提要對諸本的評價也屬後出考證。

## 採納方式

- 條目提示某姓名有數人時，建立候選，逐項核對時代、事件、親屬、官職與地域；不得只依條目數拆分或合併現有人物。
- 記錄編者的辨識意見時，保留作者、版本、卷次、原文與判斷理由。原書記載與後出辨識分層，不以後出姓名錄替代原始引文。
- 能追到所引正史或其他材料時，連結該材料的固定見證及相應位置。同一段史文經姓名錄轉引，不算另一份獨立證言。
- 某人未被收錄，不構成「無另一同名者」的證明；分列的條目亦可能重複或有訛誤。爭議保留候選及未定狀態。
- 不因古書正文已屬公有領域，就推定數位網站的整批資料、圖像或轉錄成果可以任意下載再散布；實際匯入前另核版本與使用條款。

本文件確立輔助參考的處理方式，尚不表示已完成這些著作的逐條匯入或校勘。
