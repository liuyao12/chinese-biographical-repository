# 魏其武安篇爵職的月份平行記載

《漢書·武帝紀》後三年正月景帝崩後，明記「三月，封皇太后同母弟田蚡、勝皆為列侯。」對讀〈魏其武安侯列傳〉後三年封武安侯、周陽侯，將同一受封事件及兩個既有人物錨點附於爵年換算參考。列侯是《漢書》本句原詞，具體爵名仍由《史記》提供，沒有把爵名補入《漢書》正文。

將相年表建元六年相位格明記「五。六月癸巳，武安侯田蚡為丞相。」與專傳同人同官的授任相合；將格號、人物錨點及固定見證附於拜相紀年。三月、六月位於十月歲首年的後半，保留原前141／前135年的年精度；不換算公曆月日。曆法依據、原文月份、既存現代研究書目分列，不宣稱驗證研究的月朔論證。

同列的孝景太后、昌、田蚡、青翟、安國五處逐人標記，以專傳建元六年太后崩、昌與青翟免、蚡與韓安國授官為身份證據。孝景太后指竇氏，不是王太后。青翟的兩種職稱保留各自來源，沒有由改任或免職推定全部稱號終止。

年表原格「正月，閩越王反。孝景太后崩。。昌免相。」全文保留，包括雙句點；不將句首正月附給太后死亡。閩越王仍待另核，這一列不宣稱全部指稱完成。
