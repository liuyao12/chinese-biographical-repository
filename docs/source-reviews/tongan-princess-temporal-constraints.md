# 同安公主死亡年界限：來源核讀

**狀態：來源核讀完成；資料已加入目前工作分支，尚未合併至 main。** 原文、篇章定位與逐條時間約束現存於人物語料及人物 JSON 匯出；本文件保留句法與推導界限，並非 API 資料本身。

## 《新唐書》卷八十三

識典古籍所錄《新唐書》卷八十三〈諸公主〉「世祖一女」同安公主條作：

> 同安公主，高祖同母媦也，下嫁隋州刺史王裕。貞觀時，以屬尊，進大長公主。嘗有疾，太宗躬省視，賜縑五百，姆侍皆有賚予。永徽初，賜實户三百。薨，年八十六。裕，隋司徒柬之子，終開府儀同三司。

定位：新唐書，唐書卷八十三，列傳第八〈諸公主〉，〈世祖一女〉，同安公主條。數位來源：[識典古籍固定章頁](https://www.shidianguji.com/zh/book/SK0724/chapter/1l9yzol1jlk4q)。該頁所示文本含「薨，年八十六」；部分轉錄省略「薨」後逗號，未在本文件合併異文。

- 「年八十六」直接支持卒年時報齡為八十六；不因此倒推出生年，計歲方式亦未明。
- 「永徽初」在句法上直接修飾「賜實戶三百」。緊接「薨」可供編者判讀其卒年範圍，但本句沒有「永徽中薨」或「永徽某年薨」這類直接日期表述。因此，不應把永徽元年至六年的死亡範圍標成 `source_attested`；若採納此讀法，須標 `editorial_provisional` 並保留理由。

## 《舊唐書》卷四

《舊唐書》卷四〈本紀第四·高宗上〉永徽三年冬十月條作：

> 冬十月戊戌，幸同安大長公主第，又幸高陽長公主第，即日還宮。

定位：舊唐書，卷四〈本紀第四·高宗上〉，永徽三年冬十月戊戌條。數位來源：[維基文庫固定卷頁](https://zh.wikisource.org/wiki/%E8%88%8A%E5%94%90%E6%9B%B8/%E5%8D%B74)。

皇帝親臨同安大長公主府第，按敘事語境可暫推她在永徽三年仍在世。這是對事件和受訪者身份的語境判讀，不是原文明言「公主在世」或「未薨」；相應死亡下界應為 `death_year >= 永徽三年`，標作 `editorial_provisional`，引用整條原文並錨定「同安大長公主」。

## 可供消費端計算的條件式約束

若資料編者採納《新唐書》敘事順序表示死亡在永徽年間，則該來源判讀可拆成死亡年 `>= 永徽元年` 及 `<= 永徽六年` 兩條約束；兩條均須標作編者暫定，而非直接明載。另由《舊唐書》永徽三年探視條件式推出死亡年 `>= 永徽三年`。消費端保留三條原始來源約束後，才可計算交集為永徽三年至六年；交集本身不是第三項來源事實。
