# 〈衛將軍驃騎列傳〉第二十二段

本段保存原文及九處人物錨點。嬗使用 `aqs_iqa_d1l_A`，以「子嬗代侯」連到本篇霍去病候選；分支字元不是子女排行。「嬗」「子侯」「哀侯」分別是名、字、謚稱，同指判讀只限本篇敘事。

兩筆死亡記錄各保存明示紀年與原句：元狩六年暫換算前117年，元封元年暫換算前110年。參考《資治通鑑》卷二十數位年標，只取年精度，未匯入其九月等額外日期。原文「四年軍後三年」「居六歲」不強改；後者另記 `reported_duration`，計年方式未定，不能當公曆差值或推出生年。

四筆用稱包括驃騎將軍、景桓侯、嬗承爵的侯、哀侯。兩項謚稱標 `honorific` 與 `posthumous_usage`；「字子侯」不作侯爵，「幸其壯而將之」不作已授將軍。承爵的原詞仍是侯，`inheritance` 另指向霍去病已有證據的冠軍侯授爵記錄；原文與編輯解析分存。元封元年的終點據明示「國除」記為 `abolition`，不是從死亡自動生成。

「陳自長安至茂陵，為冢象祁連山」保留在人物來源包；墓形所象的祁連山不是墓址，葬儀路線也不作死地。尚未新增確定墓址主張。「無子」保留原句，不建立虛構子女。

核讀數位正文：[《史記》卷111](https://zh.wikisource.org/wiki/史記/卷111)、[《資治通鑑》卷020](https://zh.wikisource.org/wiki/資治通鑑/卷020)。本篇正文仍據已存固定版本；未核影像，身份、墓址及其餘段落仍待整理。下一段將核衛青三子與〈外戚世家〉附載四子的來源分歧。

後續對讀侯表已修訂嬗承爵年：不再暫承父卒同年，改按《漢書》卷18明記元鼎元年嗣為前116年。正文居六歲仍保存6，侯表七年薨另存參考；兩筆死亡紀年不因此更改。詳見[後續整理與三子分歧](shiji-111-p23-p25.md)。
