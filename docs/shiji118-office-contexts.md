# 〈淮南衡山列傳〉缺位、帝位與謀議目標

三處上無太子的太子保存為缺位官稱，兩處刻天子璽／求即天子位的天子保存為身分用語；五處原字與提及ID不變，不連到遷、爽或武帝，也不建立新人物。

同段大將軍材能比較及事大將軍按前後明名青辨為衛青；事丞相、說丞相按前段同案公孫弘辨識。各自有完整引文、限定錨點及固定數位見證。這是來源中計畫的目標人物，不表示刺殺、說降已實行。偽造官印及請書清單保留待核，未批量套用身份。

馮敬行御史大夫事另存代理職務、收到句讀、首選分讀及固定《漢書》《史記集解》引文，原標點與典客／宗正各自記錄不動。不借宋祁注語補授官年。人物卡顯示代理任事，人物頁可查分讀依據；代理與未分代理性的同名職務分開呈現。

60項本篇專項測試及67項人物卡測試通過；人物與閱讀器派生資料已同步，九處詞語分類及代理任事人物頁已通過實際HTTP桌面／手機驗收。喜的五處年表、兩處正文卡片、三段稱號及紀年來源差異亦通過桌面／手機實際驗收。完整檢查及發布狀態以對應PR與固定提交驗收為準。城陽王喜前後徙王鏈、曲城侯異說及其餘全篇覆核仍在整理。


喜的原城陽王、徙王淮南、復故城陽分為三段；兩次轉封以同次事件銜接前後時段。初授與末終未知。十二、十六年未知月份，分別保存前169至168、前165至164年範圍，不借同段三子四月授王的月日。

收到「復故城陽」不含連續城陽王文字，故王字只按轉封前原稱標示，返回王地以同人先前城陽王鏈核記。另存52篇八／四及漢書十二／五原句與暫取118篇帝年的理由，不改兩篇正文。原表三個具名格補共王喜、城陽王喜、淮南王喜的逐人錨點；沒有姓名的徙國年格不作整格標人，元年／十三年也不是當時新得諡的證明。


補上喜在〈建元已來王子侯者年表〉兩處既有城陽共王錨點的登記證據與52篇同人引文，與新補017三格一併採正文及原表混合證據範圍。這是補齊既有來源索引，不重發人物或原錨點ID；十表原格文字保持原樣。
