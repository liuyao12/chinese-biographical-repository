# 《絳侯周勃世家》第二輪核讀

全25段已逐段核讀，第25段索隱另層保存。本稿是下一批來源編輯紀錄，本批來源事件、地點及稱號修訂已納入工作分支；第一輪姓名檢視不等於全部身份、版本與任期完成。

第1–3段：周勃沛人是本人來源籍貫，其先卷人徙沛為未指明祖先來源與遷徙，不改本人出生地或補祖先世代。吹簫給喪事不造每名死者。中涓、五大夫、虎賁令、威武侯、將軍、列侯、絳侯各存任事／封授及原用稱。自初起沛還至碭一歲二月為戰事行程總段，不當某一官職任期。項梁明示被殺，擊李由軍不是本句李由已死；秦滅不逐人補死亡。籍已死為項籍死亡回述。泗（川）［水］及潁（陽）［陰］侯原校勘保持；食懷德、絳與共食鐘離不自動當居處。征戰行程、守地與俘獲官員依主體分存，得單父令為可辨未名官員，不當已死。

第4–7段：韓王信與淮陰侯韓信分人，本段反者韓王信之韓信短稱依敘事範圍，不全庫按同名合併。太尉遷任與其前將軍分存。乘馬絺、陳豨明示被斬；宋最、圂、遬、箕肆、勳、程縱、陳武、高肆及抵、偃、陘、弱、施被得不當死亡。相國代樊噲將為周勃任事與接替，樊噲不是本段已殺。郡縣數、相國丞相俘獲總數不補每個匿名人物；諸生說士仍群體，東鄉坐不是籍貫或地名。

第8–10段：高祖已崩、高后崩為明示死亡；以列侯事孝惠及孝惠六年置太尉分存，十歲是來源相對年數，不是高后享年十歲。呂祿、呂產任號及誅諸呂群體分存，不按群體推每名人物死亡。孝文帝立授右丞相、月餘歸印獲准、陳平卒後復丞相及十餘月免相就國分任次，不能合成不間斷一次任期。月餘、歲餘、十餘月保留餘字，不換成精確一月、一年或十月。周勃絳地就國居處、長安獄中審問與河東守尉行縣分主體；獄吏書牘給策是否單人另核。孝文帝女公主為勝之配偶，周勃是父，不把公主錯接周勃為妻。告反、捕治、恐誅不當已死；赦復爵邑依實行保存，拘禁不推全部稱號永久終止。

第11–12段：周勃孝文十一年卒、謚武侯為明示死後命名，勝之代侯為父子承爵。六歲與國除是持爵年數，不作勝之享年或死亡；坐殺人之未名受害者不補熟知名字。絕一歲後封亞夫條侯與續絳侯後不改原爵為絳侯；兄勝之與父勃有明示。許負預言三歲侯、八歲將相、九歲餓死與後文實行事件分層，不以預言作已受任、精確任期或死亡。亞夫言有如卒子當代是條件，不造勝之此時死亡或已知兒子。河內守為官號，不能單憑轄地推居河內。

第13–16段：文帝之後六年宗正劉禮、祝茲侯徐厲與亞夫授將軍、軍霸上棘門細柳分存，軍隊解散及亞夫拜中尉為實行，不以文帝真將軍讚語重授另一職。先驅、軍門都尉、壁門士吏、使者依對話及群體辨認；不得入軍、可襲而虜是假設，不當被俘或死亡。文帝且崩時誡太子與文帝崩後車騎將軍分存，前者非已死。孝景三年中尉轉太尉有明文，滎陽、昌邑與吳王保江南丹徒依主體記行程。梁請救及朝廷詔救未實行，不記亞夫已至梁。越人斬吳王頭為明示劉濞死亡；諸將以計謀為是不是新任命，三月相攻守是戰役時長，不當太尉完整任期。

第17–20段：五歲遷丞相與景帝中三年病免相保留原紀年及相對年數，不倒推完整任期或生年。廢栗太子為儲位終止，不當死亡；王信皇后兄、竇長君死後封其子彭祖有來源，王信此時未封與後文實封分開。南皮、章武侯何人及兩爵用稱依本篇身份證據另核，不以熟知姓氏補名字。匈奴王［唯］徐盧等五人保留校勘與群體，乃悉封列侯為授爵但不造其餘四名姓名。謝病、免冠謝不是死亡或同一次免官；禁中宴會為景帝所在，尚席取櫡的未名官員可依對話辨認，不補姓名。

第21–25段：亞夫子、夫人與買葬器相關役者依明示家庭角色保存，不補未見名字或同父兄弟；買甲楯可以葬不是已葬父親或父親早卒。欲自殺被止未成，因不食五日嘔血而死才是實際死亡；吏指控地下反是審訊話術，不作墓地或真實反叛判定。國除為條侯爵國終止，不據其死終止全官爵。堅為周勃他子、建德為堅子，平曲侯授予不改成絳侯；十九年卒謚共侯與十三年太子太傅依主體分存，後者不當享年。元鼎五年酎金國除不推建德死亡。條侯果餓死為同一死亡回述，不重複計死；王信於死後封蓋侯是後文授爵。太史公的伊尹、周公、穰苴比較與索隱陳豨伏誅、臧荼破國另層保存，不以臧荼破國補死亡。
