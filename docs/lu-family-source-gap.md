# 陸氏跨史整理：全文來源缺口

## 本次核對範圍

本次預定整理吳郡陸氏，以《三國志》卷五十八陸遜、陸抗相關敘事與《晉書》卷五十四陸機、陸雲等傳為核心，並與現有《晉書》及《宋書》陸氏提及交叉核讀。現有 tracked corpus 未收錄前兩篇的全文；目前可見的是其他卷篇中的局部引文或人物提及，不能代替核心傳記。

## 待取得的材料與開工條件

取得可合法再利用、版本可識別的《三國志》卷五十八全文及《晉書》卷五十四更適用的完整數位正文後，應分別記錄作品、卷、篇、見證修訂、底本／版本、權利與全文範圍，再逐段核對人物、親屬、地望、稱號及日期。若採用非武英殿數位見證，須明列版本與限制，不可把它改稱武英殿本。掃描影像只留外部連結；不把影像檔放入 GitHub。

《晉書》卷五十四選段目前只按明文記錄陸機祖遜、父抗、陸雲為機弟、陸耽為雲弟，以及陸機二子；遜至抗相鄰父系世次另標編者組裝，未另造「抗為遜子」的來源斷言。缺少卷五十八全文前，不以模型記憶、搜尋摘要或未查明授權轉錄補造跨篇資料。既有其他篇章來源陳述維持原狀；本缺口是來源取得與整理範圍狀態，不表示該家族資料不存在或已完成覆核。
