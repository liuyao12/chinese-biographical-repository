# 〈酷吏列傳〉開篇身份接合

依景帝本紀、絳侯周勃世家及魏其武安侯列傳，接合孝景、孝文、竇太后、條侯、亞夫及魏其侯六組候選，保留35處原字與標記位置。條侯與亞夫分別依爵號、本名、丞相職位及弗任趙禹的同一敘事互證。

p008的上仍承景帝，p009明言武帝卽位才轉朝；p019狄山引語中的孝文、孝景不與受話的陛下混同。身份判讀為AI暫定、未經人工及影像覆核，原文不改。

尚未完成全篇：周陽侯須區分不同持爵者；杜衍的地望判讀、未名者、親屬、後半身份與紀年仍待整理。

整合續核：武帝／今上／上／天子58處按各敘事與引語區分，武安侯依同朝丞相職位接至田蚡，陳皇后依外戚世家之陳氏皇后被廢事件接合，不補阿嬌為名。周亞夫以孝景本紀條侯周亞夫原句與絳侯世家本名續稱分列條侯、周、亞夫；官職別稱保留來源，不列附加名。本批保留中國曆年試點及原有公曆投影，未改原文、家族組裝或未解候選。
