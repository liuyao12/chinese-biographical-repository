## 每批運作

1. 以一族為一批閱讀線索。主代理依序整合；代理可並行獨立核對同一族的傳本、出土文字或身份。當本族已知的核心傳記讀畢，未解處留具體查核線索，接續下一族。
2. 以[卷目](../data/corpus/chapter-directory.json)逐卷核對固定版本的傳題與起訖。每篇主傳及有獨立傳文的附傳各列一項，同人跨史仍各列一傳。標明已查的卷、排除理由及尚未查完的卷；原始書頁位置與 CBR 篇 ID 相連。無法按族歸類的人物列入逐卷掃尾，確保只見一傳或家世不明者也納入。
3. 分記「傳目已核」「全文已收」「首輪已讀」「逐項已核」。每篇核姓名、親屬、原紀年與可算範圍；無記載及相競說法留具體註記。取得完整固定原文、核過全篇段落與人物斷言並通過引文、索引驗證，才在[篇章進度](../corpus/progress.json)把該篇標為完成。資料以該篇實際覆核範圍為準。
4. 每批推送原證與衍生人物 JSON 至既有 CBR。若按人物增量更新 JSON 索引，執行 `python3 -m scripts.export_person_bundles --reading-indexes-only` 以同步 Markdown 人物表，再核既有人文網站的發布版本。正式完成須核遍主清冊各卷與附傳，補做逐卷掃尾，並把剩餘的身份歧異、版本與未取得材料列入待核清單。

## 清河崔氏續讀

〈崔道固傳〉自「崔道固，清河人也」至「死於虜中」，下接合卷史評。固定修訂的兩段均已核讀。卷內〈薛安都傳〉記「道固遣子景徵、傅靈越領眾，並應安都」，〈崔道固傳〉作「遣子景微、軍主傅靈越率眾赴安都」。父、同行者及目的地三項相合，兩個名字暫接原有的景微 ID。〈薛安都傳〉內另分出傅靈越被俘、答劉勔、遇害及籍貫的一段附敘，末句下接程天祚。[《宋書》卷八十八](https://zh.wikisource.org/w/index.php?title=宋書/卷88&oldid=2069210)

《魏書》載崔道固遣「大息景徽」赴魏闕。《北史》同記景徽襲爵，字分作「文叡」「文睿」，子休纂。北朝兩史可接同人；此人與宋書赴薛安都的兒子是否同人，仍待更多證據。《宋書》的泰始三年繫於陷城；兩部北朝史傳記道固延興中卒，《魏書》並記年五十。[《魏書》卷二十四](https://zh.wikisource.org/w/index.php?title=魏書/卷24&oldid=2021236) · [《北史》卷四十四](https://zh.wikisource.org/w/index.php?title=北史/卷044&oldid=2183262)

崔鴻誌的轉載拓片記孝昌元年十一月廿九日卒，末行另署孝昌二年九月十七日「造」；葬句只記黄山之陰。崔混誌錄文自稱諱混、字子元，家屬行記父鴻、祖敬友，沿用史傳子元的人物 ID。誌載元象元年二月五日卒、其年十一月五日庚申遷窆。卒前飲食句存疑字「？」；魏書的「為其叔鵾所殺」與北史的「為其叔鶤所殺」各附原句。崔混誌的原刊圖版仍待核。[崔鴻誌轉載拓片](https://www.sohu.com/a/259439652_258370) · [崔混誌錄文](https://guji.10huan.com/Article/7147_7165.html) · [《魏書》卷六十七](https://zh.wikisource.org/w/index.php?title=魏書/卷67&oldid=468068)

## 謝裕、謝瞻、謝惠連與謝朗一支

本批在《南史》卷十九覆核謝瞻、謝嚼、謝裕、謝恂、謝孺子、謝璟、謝微、謝純、謝甝、謝述、謝綜、謝緯、謝惠連十三項，並在《晉書》卷七十九覆核何謙與戴逯合敘、謝朗、謝重、謝絢四項。清冊累計定位 102 項，41 項收有相符的固定全文，39 項已作首輪標註，29 項已逐項覆核。《宋書》卷五十二、六十一及《梁書》卷五十的數位傳題已逐題定位。《宋書》先敘褚叔度世系，歷褚秀之、褚淡之兩傳後以「叔度」續敘，清冊將兩處原段保存在同一主傳。[逐傳清冊](../data/corpus/six-dynasties-biographies.json)

- **謝裕**即《宋書》的謝景仁。其祖據、父允各有原句。宋武帝的「安孫」與傳首世系分存。其卒年，《南史》和《宋書》傳文均作義熙十二年，《晉書》安帝紀繫十一年八月丁未，對日另有校記。《宋書》此條的校記又引《晉書》作十年。沿用謝裕和謝綜的現役人物號，新增父子引據。[《南史》卷十九](https://zh.wikisource.org/w/index.php?oldid=1531762) · [《宋書》卷五十二](https://zh.wikisource.org/w/index.php?oldid=2190655) · [《晉書》卷十](https://zh.wikisource.org/w/index.php?oldid=2567072)
- **謝瞻、謝嚼、謝惠連**的姓名、長幼和報齡均逐句繫人。瞻所言「弟年始三十」指謝晦，瞻本人的卒齡為三十五。謝嚼一段殿本起「瞻弟㬭字宣鏡」，與固定數位本「弟嚼字宣鏡」並存。惠連的卒齡，殿本《南史》作三十七，《文選》李善注引沈約《宋書》作二十七。出生年保留計齡假設。[《南史》武英殿本](https://commons.wikimedia.org/wiki/File:NLC892-411999017142-12360_二十四史_第246冊.pdf) · [《文選》卷十三〈雪賦〉題下注](https://zh.wikisource.org/w/index.php?oldid=2082931)
- **戴逯、謝朗、謝重、謝絢**的兄弟、母子和兩代舅甥各有見證。《世說新語》劉孝標注引《謝氏譜》記謝據妻為王韜女、名綏。《宋書》袁湛傳明記謝重為王胡之外孫、謝重子絢為袁湛之甥。謝朗「善言玄理」的「玄」存作詞中字，「名亞于玄」的「玄」另繫謝玄。[《晉書》卷七十九](https://zh.wikisource.org/w/index.php?oldid=2645985) · [《世說新語》文學](https://zh.wikisource.org/w/index.php?oldid=2567461) · [《宋書》卷五十二](https://zh.wikisource.org/w/index.php?oldid=2190655)

下一個清冊接點為《晉書》謝萬、謝韶，《南史》謝朓、謝方明、謝靈運，以及謝超宗子才卿、幾卿及孫藻所在的傳段。謝才卿獄事以《南齊書》卷三十六和《南史》武英殿本逐字核對。謝幾卿撫養姪藻，以《梁書》卷五十「兄才卿早卒，其子藻幼孤」核父子與撫養兩事。

承接 [第十六批](https://github.com/liuyao12/chinese-biographical-repository/pull/753)。新增十九項，累計四十三卷已作卷目調查，登記五百四十四項傳目，三百一十五項備全文，三百一十三項已過第一遍人物標記，三百零九項已逐項覆核。《南齊書》卷二十七、《南史》卷十六、卷二十五先登所核附敘，其餘卷目待勘；《宋書》卷七十六已勘卷目。

| 卷 | 本批覆核 | 原文及校讀 |
| --- | --- | --- |
| 《晉書》卷六十七 | 郗鑒、郗邁、周翼、溫放之、溫式之 | 郗邁為郗鑒亡兄之子，周翼為外甥。郗鑒卒於咸康五年，傳載七十一。溫嶠、式之兩件墓誌各列原物著錄與據拓釋文；放之載喪與其生母分別考證。 |
| 《南史》卷二十三 | 王蘊、王奐、王伷女（長沙王晃妃）、許明達 | 王蘊父有楷、揩二讀。王奐案的武帝詔明言「且奐又出繼」。王奐女所適的殷叡另有《梁書》卷二十七為證。《魏書》另記王秉攜三姪赴魏的時間。 |
| 《宋書》卷七十六、《南史》卷十六 | 各書的王深、王繢 | 殿本《宋書》作「子深早卒子繢嗣」，《南史》明言「深子繢」。王玄謨卒齡在兩書分別作八十一、八十二；本紀記泰始四年二月乙巳。 |
| 《南齊書》卷二十七、《南史》卷二十五 | 各書的王文和 | 「仲德兄孫」在兩書語序不同，均未指名中間一代。另立沈攸之子沈文和，保留王文和仕歷與死亡的各書用語。 |
| 《南齊書》卷二十、《南史》卷十一 | 各書的海陵王妃王韶明、和帝皇后王蕣華 | 《南史》數位目題作「紹明」，兩書正文及兩種刊本均作「韶明」。王慈女韶明與江夏王鋒妃分列。蕣華兩傳明言祖為王儉，未記父名。清錢儀吉《南朝會要》稿本記「帝禪位降為巴陵王妃」，兩部正史后傳作「后降為妃」。 |

《南史》據弘化四年出雲藩刊本卷十一二十下至二十一下，《南齊書》據乾隆四年武英殿本卷二十第四葉下、第五葉上，各錄全兩傳。《古今姓氏書辯證》四庫輯本的四十個卷次據總目固定修訂 1516481 著錄，卷十四王氏條據修訂 636080。
