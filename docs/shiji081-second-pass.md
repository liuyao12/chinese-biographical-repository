# 〈廉頗藺相如列傳〉第二輪核讀

依固定數位版本全27段核讀，尚未核底本影像，不宣稱全部身份、紀年及版本校勘完成。

本批按篇內君主交替及跨篇相同事件，接合趙惠文王、秦昭王、白起、趙括、趙孝成王、栗腹與平原君趙勝。七項同指判斷更新全部來源引用後撤除八個重複候選，人物6590→6582。判斷、引文及提及錨點保留；歷史以Git回查，不設永久舊ID入口。正文及全部字元錨點不變。

惠文王與孝成王依「趙惠文王卒，子孝成王立」分開；長平用將的趙王為孝成王，不將完璧、澠池的趙王全域替換。馬服君趙奢與其子趙括各為一人，不因稱號相近合併。繆賢追述中的未名燕王不按推算年代強配。平原君的跨篇證據僅支持趙勝身份，不算田租對話的獨立見證。

本篇栗腹「殺」與〈樂毅列傳〉「禽」各存，長平「四十餘日」與〈白起王翦列傳〉「四十六日」亦不調和。同指不表示兩篇是獨立史實見證。趙括母未具名，不補姓名或姓氏；廉頗卒死壽春不補確切死亡年。

續核李牧、王翦、郭開、司馬尚等末段人物跨篇身份、匿名趙王與全部稱號時段。ctext存取限制與未完成校讀見docs/ctext-text-review.md。

末段王翦依〈白起王翦列傳〉攻趙王降事件接合；桓齮依〈秦始皇本紀〉扈輒斬首十萬與宜安戰事接合，共撤除兩個重複候選，人物6582→6580。武遂／平陽與取宜安／走桓齮各存；不由同指判定全部戰果，更不推定桓齮為樊於期。
