# 吳王濞授封始期

〈吳王濞列傳〉首段先言高帝十一年秋平英布，後敘乃立濞為吳王；不能把敘事背景年直接當授封年。〈漢興以來諸侯王年表〉高祖十二年列明「更為吳國。十月辛丑，初王濞元年。濞，高祖兄仲子，故沛侯。」以明示授封時間作有據首選，正文不改。

保存本傳授封事件、固定年表2607010完整格文、濞逐人錨點、原年欄與數位西元欄。高祖十二年數位對照前195年；漢初建亥歲首，暫記前196至195年跨年範圍，保留十月辛丑原字，不補精確公曆日。來源日期表述仍空，因本傳授封句沒有此確切日期；平行年表事件與編者換算分層。未核書影。

驗證限制：只支援已核王爵明示初王事件的始期；核同人錨點、格文、固定版本、同列原年與編者西元欄，拒絕鄰列年份或他人事件。原文未知終期繼續留空，不從死亡推斷全部官爵終期。

短卡的有限稱號摘要優先展示有據時段；同一稱號及其他事實相同時，摘要略去未定時段重述，完整頁仍列各來源。沒有把不同任期或官爵事件在資料層合併。
