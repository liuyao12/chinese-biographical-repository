# 〈劉敬叔孫通列傳〉引古與秦楚身份辨識

續以完整敘事與引語邊界，逐項對讀十六組身份，撤除十七個來源局部重複ID。堯、桀、呂望、伯夷、紂的引古各保留來源脈絡；項羽、項梁、陳勝依秦末共同事件接合。後立為義帝的楚懷王接孫心，與入秦不返的祖父楚懷王分開。

第八段二世召博士問陳勝事，與秦始皇本紀胡亥襲位為二世對讀，接回胡亥；第三段周王數百年、秦二世即亡，可能比較朝代傳世長短，解除原先確定人物指向，保留胡亥候選與非個人稱謂的可能，不隨同指整併自動確定。

叔孫通勸高祖的引語內，晉獻公、驪姬、奚齊與廢太子之事對讀晉世家，太子辨申生；外層漢太子仍為惠帝，開頭太子太傅職名中的太子不指派人物。扶蘇、趙高、胡亥據沙丘改書詐立故事接合。冒頓殺父代立的父依匈奴列傳明示頭曼辨識；和親方案中的未來太子、外孫及群母不補為實際個人。
