# 〈汲鄭列傳〉漢初回述與作者署稱

本批按敘事時間及同一事件接合五個重複人物，共八處原有標記。沒有改寫原文、擴充標記範圍或補生卒、官爵年月。各項判斷仍屬暫定、未經人工或書影覆核。

- 鄭君先為項籍將，項籍死後歸漢。〈項羽本紀〉開篇明書「項籍者，下相人也，字羽」，據此接項羽，保留本篇籍字。
- 令項籍故臣直呼籍名的高祖，按歸漢及後續孝文、孝景、武帝的敘事脈絡接漢高祖；不是所有高祖稱呼的全域規則。
- 鄭君死於孝文時，按漢初至孝景、武帝的語境接文帝。原死亡陳述仍不定年，不把整段當作武帝在位時發生。
- 鄭當時因「武安侯魏其時議」而貶，對讀〈魏其武安侯列傳〉開篇竇嬰及第22段「內史鄭當時是魏其，後不敢堅對」，接魏其侯竇嬰。不補被貶年月。
- 篇末「太史公曰」以《史記》傳統作者署稱接司馬遷，對照自序父卒後遷為太史令及承先人之志。這只辨傳統敘述聲音，不證明該段親撰或排除後人增補。自序前段司馬談亦稱太史公，仍是父親的獨立身份，不能按全書同字批量接給遷。

來源及逐項判斷保存在卷120身份資料，引用各卷既有固定數位正文。項籍之死及鄭君之死仍保留本篇未定年陳述；不以人物接合覆蓋其他篇的日期或消除來源差異。鄭君古注父說、傅柏／傅伯、宗正劉棄／棄疾、姑姊子與其他紀年仍待另行記錄，本篇不標為完成。
