# 《晉書》王、謝家世跨讀（整理中）

本批接續已錄《宋書》王弘、謝晦與荀伯子家世，向《晉書》核具名父祖。尚在分階段整理，未宣稱六卷、全族或全書完成。

卷33固定數位修訂2650519：王祥開篇三段及王覽完整附傳五段，保留原字、原行及擷取記錄。`-{字}-`、連結及年號模板只展開顯示字，並未校改「漢未」「乙太中大夫」等可疑原字。未選段另有疑損字，不能因本批逐字檢查就稱全卷已校定。ctext全文讀取403，沒有拿搜尋摘要冒充互校，印本及影像未核。

以王祥父融、祖仁，弟覽及王覽六子裁、基、會、正、彥、琛接合。王融為王仁子、王覽與王祥同父是獨立的暫定編輯推導；原文明載的父、祖、弟各自存來源。王導、王洽、王珣、王弘四人的所有人物引用已遷到同根新路徑，原文、提及ID及位置不改；舊登記、逐人檔及別名入口不作相容保留。歷史回查使用前次Git提交，沒有將王導舊ID重用給祖先。

漢諫議大夫吉之後只是未明世次的遠祖說，另存來源及未採標記，不接王仁以上的未知世系。與《史記》臨邛令王吉暫列未決身份，沒有按同名合併，也不只因官稱不同就稱已證不同人。

朱氏對王祥為繼母、對王覽為母，分開保存；未名之妻各有唯一身份，不指定為未載子女的生母。王覽卒年咸寧四年換為中國曆278年；報齡七十三另存，不倒推生年。王融之死（原文「祥喪父」）及朱氏「母終」只有來源，年份保持未知。廬江是避地目的地，不能當三人的籍貫或出生地。

官職省罷、獲准乞骸骨、授爵與諡名各自記錄。即丘子不以死亡自動終止；「三公」的相刀預言不當已授官爵。初末等模糊紀年原語保留，數值範圍及其他卷傳仍待續核。

卷65新錄四段：王導傳首、二弟與六子名單、王洽完整附傳、王珣附傳末段。正文「導諸子中」「二子珣瑉」「珣五子弘虞柳孺曇首」提供直接父子來源；組裝改選直接證據，宋書原父祖斷言仍保留。章首數位notes將珣誤列為導子，不作譜系證據。王穎、王敞同父裁另標兄弟推導；敦為從兄、獻之為族弟不指定親等或共同祖先。

王洽卒於昇平二年，對照東晉升平357至361，錄中國曆358年；三十六為原報年齡，不倒推生年。正文昇平與年號表升平分存。中書令苦讓遂不受，與王導四項並不行的任命另列未任，不混入實任官職；卒於官也不補出未記明的職名或結束所有任期。本次只提交已錄選段；荀羨婚姻及其餘選段仍待續核，線上版本以部署提交為準。

卷79新錄謝安傳首、謝玄開篇、謝朗完整附傳及謝重、謝絢附傳五段。謝朗父據、叔父安與安父裒相互限定；據接裒獨立標為父系推導，謝安與已錄謝朗支系共用新家族根。原有六個人物ID引用已遷移，正文與提及位置不改，不留舊人物檔作替身。謝朗之子重按連續傳文接合，中間數位節題與空行逐行另存；謝絢父重則本段直接明載，均保留宋書父祖證據。

謝朗母王氏不等於謝重之母，也沒有證據把她認成王胡之女。重為王胡之外孫，母親仍未名；王胡之的完整名保留。謝絢舅袁湛與引語、解說中的謝重未名舅分成不同世代、不同身份，後者不冒作袁湛或王胡之。「朗論」之朗不是另一處謝朗人名。據早卒只有未定年死亡來源；朗終於東陽太守作終官，不補卒年或死地。謝玄、謝尚暫不按數位標題或同姓併入未核父系，王東海仍保留原稱候選。此階段仍未完成整卷或全族，整體收錄目標持續進行。

卷76新錄王廙傳首及末段、子嗣共四段，中興賦等中段尚未錄；另錄宋書卷66敬弘傳首一段。廙父正尚書郎與卷33王覽六子之正接合，胡之、茂之、敬弘沿同一王氏根組裝。胡之父廙以宋書同一後裔的祖、曾祖作獨立推導，晉書頤之弟胡之另存；謝重之外祖王胡之共享此完整身份，不另留截斷副本。元帝姨弟另存母系路徑，不與導從弟混作父系關係。

胡之西中郎將、司州刺史、假節以疾固辭、未行而卒，列未赴任。宋書祖胡之司州刺史只存用稱，不證實任或補任年。原字平南將領護南蠻校尉有疑缺，沒有補成平南將軍；廙先卒後贈侍中、驃騎將軍按完整原段記死後授官，不偽造原文追字。石季龍死只作背景，不把胡之之死定為同年。

敬弘是字。通行南史數位頁缺姓名家世傳首，只留王裕之章題，沒有拿章題補名；另核固定四庫數位正文，王裕之與父茂之、祖胡之、曾祖廙相合，採名裕之、字敬弘，茂之字興元另存來源。四庫字形模板未擅自展開，本名與父祖所用證據不依賴模板。宋書現代校注所報百衲、毛、殿、元龜及補文分層，沒有宣稱親核印本。相關版本觀察見[數位版本與姓名覆核](source-reviews/wangjinghong-digital-name-and-omission.json)。荀羨婚姻及此前待錄傳文仍列未完成；本次提交只驗證已錄選段，公開版本以既有網站部署提交為準。
